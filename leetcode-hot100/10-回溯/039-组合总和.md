# 39. 组合总和【中等】

## 题目描述

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的 **所有** 不同组合，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取**。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

---

## 输入输出示例

### 示例 1
```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7。注意 2 可以使用多次。
7 也是一个候选，7 = 7。
仅有这两种组合。
```

### 示例 2
```
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

### 示例 3
```
输入：candidates = [2], target = 1
输出：[]
```

### 提示
- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素 **互不相同**
- `1 <= target <= 40`

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
1. 元素可以重复使用
2. 组合问题（不关注顺序）
3. 需要找出所有可能的组合

例如：candidates = [2,3,7], target = 7

有效组合：
[2,2,3] → 2+2+3 = 7 ✓
[7]     → 7 = 7 ✓

注意：
[2,2,3] 和 [2,3,2] 和 [3,2,2] 算同一个组合
```

**关键问题：**
```
1. 如何避免重复组合？
   使用start参数，只选择当前位置及之后的元素

2. 如何处理重复使用？
   递归时start不变（可以继续选当前元素）

3. 何时停止？
   - sum = target：找到答案
   - sum > target：剪枝（提前终止）
```

---

### 方法：回溯 + 剪枝

**决策树：**
```
candidates = [2,3,7], target = 7

                        []
           /            |            \
         [2]           [3]           [7]✓
      /   |   \       /   \
    [2,2] [2,3]✓ [2,7]  [3,3] [3,7]
   /  |  \
[2,2,2][2,2,3]✓[2,2,7]

剪枝：
- sum > target：停止递归
- [2,7]：sum=9>7，剪枝
- [2,2,7]：sum=11>7，剪枝
```

**算法流程：**
1. 定义回溯函数backtrack(start, path, sum)
2. 终止条件：
   - sum == target：收集结果
   - sum > target：剪枝
3. 从start开始遍历candidates
4. 选择元素，递归：
   - start保持不变（可以重复选）
   - sum更新
5. 撤销选择

**优化：排序后剪枝**
```
排序后：
如果candidates[i] + sum > target
则candidates[i+1...] + sum 也 > target
可以直接break，不用继续尝试
```

**时间复杂度：** O(n × 2^target/min) - 最坏情况
**空间复杂度：** O(target/min) - 递归深度

## 代码实现（TypeScript）

### 方法一：回溯（基础版本）

```typescript
function combinationSum(candidates: number[], target: number): number[][] {
    const result: number[][] = [];
    const path: number[] = [];

    /**
     * 回溯函数
     * @param start 从哪个位置开始选择（避免重复组合）
     * @param sum 当前路径的和
     */
    function backtrack(start: number, sum: number): void {
        // 剪枝：超过目标值
        if (sum > target) {
            return;
        }

        // 找到一个有效组合
        if (sum === target) {
            result.push([...path]);
            return;
        }

        // 从start开始遍历（避免重复）
        for (let i = start; i < candidates.length; i++) {
            // 做选择
            path.push(candidates[i]);

            // 递归：start=i（可以重复选当前元素）
            backtrack(i, sum + candidates[i]);

            // 撤销选择
            path.pop();
        }
    }

    backtrack(0, 0);
    return result;
}
```

### 方法二：回溯 + 排序剪枝（推荐）

```typescript
function combinationSum(candidates: number[], target: number): number[][] {
    const result: number[][] = [];
    const path: number[] = [];

    // 排序：方便剪枝
    candidates.sort((a, b) => a - b);

    function backtrack(start: number, sum: number): void {
        if (sum === target) {
            result.push([...path]);
            return;
        }

        // 从start开始遍历
        for (let i = start; i < candidates.length; i++) {
            const num = candidates[i];

            // 剪枝：如果加上当前数字已经超过target
            // 由于数组已排序，后面的数字更大，都会超过
            // 可以直接break
            if (sum + num > target) {
                break;  // 注意是break不是continue
            }

            path.push(num);
            backtrack(i, sum + num);  // i不变，可以重复选
            path.pop();
        }
    }

    backtrack(0, 0);
    return result;
}
```

### 方法三：回溯（不传sum）

```typescript
function combinationSum(candidates: number[], target: number): number[][] {
    const result: number[][] = [];
    const path: number[] = [];

    candidates.sort((a, b) => a - b);

    /**
     * @param start 开始位置
     * @param remain 剩余需要凑的数（target - 已选数字之和）
     */
    function backtrack(start: number, remain: number): void {
        if (remain === 0) {
            result.push([...path]);
            return;
        }

        for (let i = start; i < candidates.length; i++) {
            const num = candidates[i];

            // 剪枝
            if (num > remain) {
                break;
            }

            path.push(num);
            backtrack(i, remain - num);
            path.pop();
        }
    }

    backtrack(0, target);
    return result;
}
```

## 代码原理详解

### 关键点1：start参数

```typescript
backtrack(i, sum + candidates[i])
//       ↑
//     注意：是i不是i+1

为什么是i？
- 元素可以重复使用
- 下次递归可以继续选candidates[i]

例如：
candidates = [2,3,7], target = 7

选2后：
backtrack(0, 2)  // start=0，可以再选2
  → 可以生成 [2,2,...]

如果是i+1：
backtrack(1, 2)  // start=1，不能再选2
  → 无法生成 [2,2,...]
```

### 关键点2：避免重复组合

```typescript
for (let i = start; i < candidates.length; i++)
//              ↑
//          从start开始，不是0

为什么从start开始？
- 避免生成重复组合

例如：
candidates = [2,3], target = 5

如果从0开始：
path=[2] → 选3 → [2,3]
path=[3] → 选2 → [3,2]  （重复！）

从start开始：
path=[2] → 只能选2,3 → [2,3]
path=[3] → 只能选3 → 无法生成[3,2]
```

### 关键点3：剪枝优化

```typescript
if (sum + num > target) {
    break;  // 排序后可以直接break
}

没排序：
candidates = [7,3,2]
target = 7
i=0: 7+0=7>7? 否
i=1: 3+0=3>7? 否  ← 还要继续
i=2: 2+0=2>7? 否

排序后：
candidates = [2,3,7]
target = 7
某次递归sum=5:
i=1: 5+3=8>7? 是，break  ← 后面的更大，直接break
```

## 常见问题

**Q1: 为什么可以重复使用元素？**
A: 题目定义：
```
"同一个数字可以无限制重复被选取"

实现：
backtrack(i, ...)  // start=i，不是i+1
下次递归可以继续选candidates[i]
```

**Q2: 如何避免重复组合？**
A: start参数：
```
只选择当前位置及之后的元素

保证：
- 可以选：2 → 2（重复同一个数）
- 不会选：2 → 3 → 2（回头选）

结果：
[2,2,3] ✓
[2,3,2] ✗（不会生成）
```

**Q3: 剪枝是break还是continue？**
A: 排序后用break：
```
candidates已排序

如果candidates[i] + sum > target：
则candidates[i+1] + sum 也 > target
（后面的更大）

所以直接break，不用继续遍历
```

**Q4: 不排序会怎样？**
A: 仍然正确，但效率低：
```
不排序：
- 必须遍历完所有元素
- 每个都要判断sum>target

排序：
- 遇到第一个sum>target就break
- 后面的不用检查
```

**Q5: 与78题（子集）的区别？**
A:
| 特性 | 子集 | 组合总和 |
|------|------|---------|
| 目标 | 所有子集 | 和为target的组合 |
| 元素使用 | 每个最多1次 | 可以重复 |
| 递归 | backtrack(i+1) | backtrack(i) |
| 收集 | 所有节点 | sum==target的节点 |

## 复杂度分析

**时间复杂度：** O(S)
- S是所有可行解的长度之和
- 最坏情况：O(n × 2^(target/min))
  - n个候选数字
  - 每个数字最多选target/min次

**空间复杂度：** O(target/min)
- 递归深度 = 最多选择次数
- 最坏情况：都选最小的数

**例如：**
```
candidates = [2,3,5], target = 8

可行解：
[2,2,2,2] - 长度4
[2,3,3] - 长度3
[3,5] - 长度2

S = 4 + 3 + 2 = 9
```

## 边界情况

### 情况1：无解

```
输入: candidates = [2], target = 1
输出: []
说明：2 > 1，无法组成
```

### 情况2：单个元素即可

```
输入: candidates = [2,3,5], target = 5
输出: [[5]]
说明：5本身就是答案
```

### 情况3：需要重复多次

```
输入: candidates = [2], target = 8
输出: [[2,2,2,2]]

```

```
输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]
```

## 总结

**关键点：**
1. 元素可以重复使用：backtrack(i, ...)
2. 避免重复组合：从start开始遍历
3. 剪枝优化：排序后直接break
4. 终止条件：sum == target

**回溯模板（组合总和）：**
```typescript
function backtrack(start: number, sum: number): void {
    if (sum === target) {
        result.push([...path]);
        return;
    }

    for (let i = start; i < candidates.length; i++) {
        if (sum + candidates[i] > target) {
            break;  // 剪枝
        }

        path.push(candidates[i]);
        backtrack(i, sum + candidates[i]);  // i不变
        path.pop();
    }
}
```

**面试建议：**
- 先画决策树
- 说明start参数的作用
- 强调可以重复使用（i不变）
- 解释剪枝优化
- 对比不同变体（40,216题）

**易错点：**
- start写成i+1（无法重复使用）
- 剪枝写成continue而非break
- 忘记排序导致剪枝失效
- sum > target写成>=（会漏掉正确答案）
- 忘记复制数组
