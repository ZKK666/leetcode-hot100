# 131. 分割回文串【中等】

## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是 **回文串**。返回 `s` 所有可能的分割方案。

**回文串** 是正着读和反着读都一样的字符串。

---

## 输入输出示例

### 示例 1
```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

### 示例 2
```
输入：s = "a"
输出：[["a"]]
```

### 提示
- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
将字符串分割成若干段
每段都必须是回文串

例如："aab"
方案1：["a", "a", "b"]
方案2：["aa", "b"]

不合法：["aab"]（"aab"不是回文）
```

**关键问题：**
```
1. 如何枚举所有分割方案？
   回溯法：每个位置可以选择分割或不分割

2. 如何判断回文？
   双指针或预处理dp数组

3. 如何避免重复？
   从start开始往后分割（顺序固定）
```

---

### 方法一：回溯 + 双指针判断回文（推荐）

**决策树：**
```
s = "aab"

                    []
        /           |           \
     ["a"]       ["aa"]       ["aab"]✗
    /     \         |
["a","a"]["a","ab"]✗["aa","b"]
    |
["a","a","b"]

每个节点：
- 选择一个回文前缀
- 递归处理剩余部分
```

**算法流程：**
1. 定义回溯函数backtrack(start, path)
   - start：从哪个位置开始分割
   - path：当前分割方案
2. 终止条件：start == s.length
3. 从start到end尝试每个分割点：
   - 如果[start, end]是回文，继续递归
4. 撤销选择

**优化：预处理回文判断**
- 使用dp数组预先计算所有子串是否回文
- 避免重复判断

**时间复杂度：** O(n×2^n)
- 2^n个分割方案
- 每个方案O(n)复制

**空间复杂度：** O(n) - 递归深度

---

### 方法二：回溯 + DP预处理

**核心优化：**
- 预处理dp[i][j]：s[i...j]是否回文
- 回溯中O(1)查询

**时间复杂度：** O(n^2 + n×2^n)
- 预处理：O(n^2)
- 回溯：O(n×2^n)

**空间复杂度：** O(n^2) - dp数组

---

## 代码实现（TypeScript）

### 方法一：回溯 + 双指针判断回文

```typescript
function partition(s: string): string[][] {
    const result: string[][] = [];
    const path: string[] = [];

    /**
     * 判断是否回文
     */
    function isPalindrome(left: number, right: number): boolean {
        while (left < right) {
            if (s[left] !== s[right]) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    /**
     * 回溯函数
     * @param start 从哪个位置开始分割
     */
    function backtrack(start: number): void {
        // 终止条件：处理完整个字符串
        if (start === s.length) {
            result.push([...path]);
            return;
        }

        // 尝试每个分割点
        for (let end = start; end < s.length; end++) {
            // 如果[start, end]是回文
            if (isPalindrome(start, end)) {
                // 做选择：分割出s[start...end]
                path.push(s.substring(start, end + 1));

                // 递归：处理剩余部分
                backtrack(end + 1);

                // 撤销选择
                path.pop();
            }
        }
    }

    backtrack(0);
    return result;
}
```

### 方法二：回溯 + DP预处理

```typescript
function partition(s: string): string[][] {
    const n = s.length;
    const result: string[][] = [];
    const path: string[] = [];

    // 预处理：dp[i][j] 表示 s[i...j] 是否回文
    const dp: boolean[][] = Array(n).fill(0).map(() => Array(n).fill(true));

    // 从后往前，从左往右遍历
    for (let i = n - 1; i >= 0; i--) {
        for (let j = i + 1; j < n; j++) {
            // s[i...j] 是回文的条件：
            // s[i] === s[j] && s[i+1...j-1] 是回文
            dp[i][j] = s[i] === s[j] && dp[i + 1][j - 1];
        }
    }

    function backtrack(start: number): void {
        if (start === n) {
            result.push([...path]);
            return;
        }

        for (let end = start; end < n; end++) {
            // O(1) 查询是否回文
            if (dp[start][end]) {
                path.push(s.substring(start, end + 1));
                backtrack(end + 1);
                path.pop();
            }
        }
    }

    backtrack(0);
    return result;
}
```

## 代码原理详解

### 回溯逻辑

**分割点选择：**
```typescript
for (let end = start; end < s.length; end++) {
    if (isPalindrome(start, end)) {
        path.push(s.substring(start, end + 1));
        backtrack(end + 1);  // 下一次从end+1开始
        path.pop();
    }
}

例如："aab"，start=0
end=0: 检查"a"是否回文 → 是
       加入path: ["a"]
       递归backtrack(1)

end=1: 检查"aa"是否回文 → 是
       加入path: ["aa"]
       递归backtrack(2)

end=2: 检查"aab"是否回文 → 否
       跳过
```

### DP预处理

**递推公式：**
```typescript
dp[i][j] = s[i] === s[j] && dp[i+1][j-1]

含义：
s[i...j]是回文 ⟺
  - s[i] === s[j]（首尾相等）
  - s[i+1...j-1]是回文（内部是回文）

初始化：
- dp[i][i] = true（单字符）
- dp[i][i+1] = s[i] === s[i+1]（两字符）

遍历顺序：
从后往前，从左往右
保证dp[i+1][j-1]已经计算
```

**例如："aab"**
```
     0 1 2
   +-------
0  | T T F
1  | · T F
2  | · · T

dp[0][0] = T ("a")
dp[1][1] = T ("a")
dp[2][2] = T ("b")

dp[0][1] = s[0]===s[1] && dp[1][0]
         = 'a'==='a' && true
         = T ("aa")

dp[1][2] = s[1]===s[2] && dp[2][1]
         = 'a'==='b' && ?
         = F ("ab")

dp[0][2] = s[0]===s[2] && dp[1][1]
         = 'a'==='b' && ?
         = F ("aab")
```

## 常见问题

**Q1: 为什么从start开始而不是0？**
A: 避免重复分割：
```
如果从0开始：
可能生成：
["a", "a", "b"]
["a", "a", "b"]（重复）

从start开始：
保证顺序分割
每个分割方案唯一
```

**Q2: 双指针vs DP哪个好？**
A:
| 方法 | 时间 | 空间 | 适用场景 |
|------|------|------|---------|
| 双指针 | O(n×2^n) | O(n) | s.length <= 20 |
| DP | O(n^2+n×2^n) | O(n^2) | 重复判断多 |

面试推荐：双指针（代码简洁）

**Q3: 能否记忆化优化？**
A: 不适用：
```
回溯生成所有方案：
- 必须遍历所有可能
- 无重复子问题
- 记忆化无效

适用记忆化：
- 有重复子问题
- 求最优解
```

**Q4: 最多有多少种分割方案？**
A: 最多2^(n-1)种：
```
n个字符有n-1个分割位置
每个位置：分割 or 不分割
最多：2^(n-1)

例如："aaa"
分割方案：
["aaa"]
["a","aa"]
["aa","a"]
["a","a","a"]

4种 = 2^(3-1) = 2^2
```

**Q5: 如何只求数量？**
A: 不收集结果，只计数：
```typescript
let count = 0;

function backtrack(start: number): void {
    if (start === s.length) {
        count++;
        return;
    }

    for (let end = start; end < s.length; end++) {
        if (isPalindrome(start, end)) {
            backtrack(end + 1);
        }
    }
}
```

## 复杂度分析

### 双指针方法

**时间复杂度：** O(n×2^n)
- 最多2^n个分割方案
- 每个方案：
  - 回文判断：O(n)
  - 字符串复制：O(n)

**空间复杂度：** O(n)
- 递归深度：O(n)
- path数组：O(n)

### DP预处理方法

**时间复杂度：** O(n^2 + n×2^n)
- 预处理：O(n^2)
- 回溯：O(n×2^n)

**空间复杂度：** O(n^2)
- dp数组：O(n^2)
- 递归：O(n)

4. 终止条件：start == s.length
