# 79. 单词搜索【中等】

## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
在二维网格中搜索路径

特点：
1. 从任意位置开始
2. 只能上下左右移动
3. 每个格子最多访问一次
4. 路径必须匹配word

类似问题：
- 迷宫寻路
- DFS + 回溯
```

**为什么用回溯？**
```
需要尝试所有可能的路径：
- 从每个格子开始尝试
- 四个方向递归搜索
- 走不通就回溯（撤销访问标记）
- 直到找到答案或遍历完所有可能
```

---

### 方法：DFS + 回溯

**算法流程：**

1. **主函数**：
   - 遍历board的每个格子
   - 如果第一个字符匹配，开始DFS

2. **DFS函数**：
   - 参数：(x, y, index)
     - x, y：当前位置
     - index：匹配到word的第几个字符
   - 终止条件：
     - index == word.length：找到完整单词
     - 越界或字符不匹配：返回false
     - 已访问：返回false
   - 标记当前格子为已访问
   - 递归四个方向
   - 撤销标记（回溯）

**标记访问的方法：**
```
方法1：visited数组
visited[i][j] = true

方法2：原地修改
board[i][j] = '#'  // 临时修改
回溯时恢复：
board[i][j] = original

推荐：原地修改（节省空间）
```

**时间复杂度：** O(m×n×3^L)
- m×n个起点
- 每个格子最多3个方向（不回头）
- L是单词长度

**空间复杂度：** O(L) - 递归深度

## 代码实现（TypeScript）

### 方法一：回溯 + 原地修改（推荐）

```typescript
function exist(board: string[][], word: string): boolean {
    const m = board.length;
    const n = board[0].length;

    /**
     * DFS搜索
     * @param x 当前行
     * @param y 当前列
     * @param index 匹配到word的第几个字符
     */
    function dfs(x: number, y: number, index: number): boolean {
        // 终止条件：找到完整单词
        if (index === word.length) {
            return true;
        }

        // 边界检查
        if (x < 0 || x >= m || y < 0 || y >= n) {
            return false;
        }

        // 字符不匹配
        if (board[x][y] !== word[index]) {
            return false;
        }

        // 标记为已访问（原地修改）
        const temp = board[x][y];
        board[x][y] = '#';

        // 四个方向搜索
        const found = dfs(x - 1, y, index + 1) ||  // 上
                      dfs(x + 1, y, index + 1) ||  // 下
                      dfs(x, y - 1, index + 1) ||  // 左
                      dfs(x, y + 1, index + 1);    // 右

        // 恢复现场（回溯）
        board[x][y] = temp;

        return found;
    }

    // 从每个位置尝试
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (dfs(i, j, 0)) {
                return true;
            }
        }
    }

    return false;
}
```

### 方法二：回溯 + visited数组

```typescript
function exist(board: string[][], word: string): boolean {
    const m = board.length;
    const n = board[0].length;
    const visited: boolean[][] = Array(m).fill(0).map(() => Array(n).fill(false));

    function dfs(x: number, y: number, index: number): boolean {
        if (index === word.length) {
            return true;
        }

        if (x < 0 || x >= m || y < 0 || y >= n) {
            return false;
        }

        if (visited[x][y] || board[x][y] !== word[index]) {
            return false;
        }

        // 标记已访问
        visited[x][y] = true;

        // 四个方向
        const found = dfs(x - 1, y, index + 1) ||
                      dfs(x + 1, y, index + 1) ||
                      dfs(x, y - 1, index + 1) ||
                      dfs(x, y + 1, index + 1);

        // 回溯
        visited[x][y] = false;

        return found;
    }

    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (dfs(i, j, 0)) {
                return true;
            }
        }
    }

    return false;
}
```

### 方法三：使用方向数组

```typescript
function exist(board: string[][], word: string): boolean {
    const m = board.length;
    const n = board[0].length;
    const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]];

    function dfs(x: number, y: number, index: number): boolean {
        if (index === word.length) {
            return true;
        }

        if (x < 0 || x >= m || y < 0 || y >= n || board[x][y] !== word[index]) {
            return false;
        }

        const temp = board[x][y];
        board[x][y] = '#';

        for (const [dx, dy] of directions) {
            if (dfs(x + dx, y + dy, index + 1)) {
                board[x][y] = temp;
                return true;
            }
        }

        board[x][y] = temp;
        return false;
    }

    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (dfs(i, j, 0)) {
                return true;
            }
        }
    }

    return false;
}
```

## 代码原理详解

### 核心机制

**1. 原地标记：**
```typescript
const temp = board[x][y];
board[x][y] = '#';  // 标记已访问

// DFS搜索...

board[x][y] = temp;  // 恢复（回溯）
```

**为什么要恢复？**
```
同一个格子在不同路径中可能被访问

例如：
A B
C D

搜索路径1：A → B → 失败
  需要恢复B，因为：
搜索路径2：C → B → 可能成功

如果不恢复：
B永远被标记为已访问
路径2无法使用B
```

**2. 短路求值：**
```typescript
const found = dfs(上) || dfs(下) || dfs(左) || dfs(右);

||运算符特点：
- 从左到右求值
- 一旦有true，立即返回
- 后面的不再执行

好处：
- 找到答案立即返回
- 不必遍历所有路径
```

## 常见问题

**Q1: 为什么要回溯（恢复标记）？**
A: 不同路径可能使用同一格子：
```
例如：
A B
C D
搜索"AB"：

路径1：A → B（成功）

如果不恢复B：
路径2：C → B（失败，B被标记）

但如果word="CBD"：
路径2需要使用B
必须恢复B才能找到
```

**Q2: 能否用BFS？**
A: 可以但复杂：
```
BFS问题：
- 需要记录每个状态的visited
- 空间开销大
- 代码复杂

DFS优势：
- 自然的回溯机制
- 空间复杂度低
- 代码简洁
```

**Q3: 为什么是3^L而不是4^L？**
A: 不会回头：
```
第一步：4个方向
后续步：3个方向（不会回头）

例如：
从A往右到B
下一步不会从B往左回到A
（A已被标记）

所以：4 × 3^(L-1) ≈ 3^L
```

**Q4: 能否提前剪枝优化？**
A: 可以：
```typescript
// 优化1：检查字符是否存在
const charCount = new Map();
for (const row of board) {
    for (const char of row) {
        charCount.set(char, (charCount.get(char) || 0) + 1);
    }
}
for (const char of word) {
    if (!charCount.has(char)) {
        return false;  // 字符不存在
    }
}

// 优化2：word反转（如果结尾字符更少）
if (charCount.get(word[0]) > charCount.get(word[word.length-1])) {
    word = word.split('').reverse().join('');
}
```

**Q5: 原地修改和visited数组哪个好？**
A:
| 方法 | 空间 | 优点 | 缺点 |
|------|------|------|------|
| 原地修改 | O(1) | 节省空间 | 修改输入 |
| visited | O(m×n) | 不修改输入 | 额外空间 |

面试推荐：原地修改（更优）

## 复杂度分析

**时间复杂度：** O(m×n×3^L)
- m×n个起点
- 每个格子最多3个方向（除了第一步）
- L是单词长度
- 最坏情况：遍历所有可能路径

**空间复杂度：** O(L)
- 递归栈深度 = 单词长度
- 原地修改不需要额外空间

## 总结

**关键点：**
1. DFS + 回溯遍历所有路径
2. 原地标记避免重复访问
3. 必须恢复标记（回溯）
4. 短路求值提前返回

**DFS模板（网格搜索）：**
```typescript
function dfs(x: number, y: number, index: number): boolean {
    // 终止条件
    if (index === word.length) return true;
    if (越界 || 不匹配) return false;

    // 标记
    const temp = board[x][y];
    board[x][y] = '#';

    // 递归四个方向
    const found = dfs(上) || dfs(下) || dfs(左) || dfs(右);

    // 恢复（回溯）
    board[x][y] = temp;

    return found;
}
```
