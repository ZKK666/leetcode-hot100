# 17. 电话号码的字母组合【中等】

## 题目描述

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![电话按键](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2021/11/09/200px-telephone-keypad2svg.png)

```
2: abc
3: def
4: ghi
5: jkl
6: mno
7: pqrs
8: tuv
9: wxyz
```

---

## 输入输出示例

### 示例 1
```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 示例 2
```
输入：digits = ""
输出：[]
```

### 示例 3
```
输入：digits = "2"
输出：["a","b","c"]
```

### 提示
- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
多个集合的笛卡尔积

例如：digits = "23"
集合2: {a, b, c}
集合3: {d, e, f}

笛卡尔积：
a + d = ad
a + e = ae
a + f = af
b + d = bd
b + e = be
b + f = bf
c + d = cd
c + e = ce
c + f = cf

本质：从每个集合中各选一个元素组合
```

**为什么用回溯？**
```
特点：
1. 多层决策（每个数字一层）
2. 每层有多个选择（2-4个字母）
3. 需要遍历所有可能的组合

回溯适合：
- 组合优化问题
- 需要遍历所有可能
- 有递归结构
```

---

### 方法一：回溯法（推荐）

**决策树：**
```
digits = "23"

                 ""
        /        |        \
       a         b         c
    /  |  \   /  |  \   /  |  \
   ad ae af  bd be bf  cd ce cf

每层：选择当前数字对应的一个字母
深度：digits的长度
```

**算法流程：**
1. 建立数字到字母的映射
2. 回溯函数backtrack(index, path)：
   - index：当前处理第几个数字
   - path：当前组合的字符串
3. 终止条件：index == digits.length
4. 获取当前数字对应的字母
5. 遍历每个字母，递归处理下一个数字

**时间复杂度：** O(3^m × 4^n)
- m个数字对应3个字母（2,3,4,5,6,8）
- n个数字对应4个字母（7,9）

**空间复杂度：** O(m+n) - 递归深度

---

### 方法二：队列迭代

**核心思想：**
- 使用队列，逐个数字处理
- 每次将队列中的组合与新字母组合

**演变过程：**
```
digits = "23"

初始：queue = [""]

处理'2'(abc)：
  取出""，加入a,b,c
  queue = ["a", "b", "c"]

处理'3'(def)：
  取出"a"，加入ad,ae,af
  取出"b"，加入bd,be,bf
  取出"c"，加入cd,ce,cf
  queue = ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**时间复杂度：** O(3^m × 4^n)
**空间复杂度：** O(3^m × 4^n) - 队列大小

## 代码实现（TypeScript）

### 方法一：回溯法（推荐）

```typescript
function letterCombinations(digits: string): string[] {
    if (digits.length === 0) {
        return [];
    }

    // 数字到字母的映射
    const phoneMap: Map<string, string> = new Map([
        ['2', 'abc'],
        ['3', 'def'],
        ['4', 'ghi'],
        ['5', 'jkl'],
        ['6', 'mno'],
        ['7', 'pqrs'],
        ['8', 'tuv'],
        ['9', 'wxyz']
    ]);

    const result: string[] = [];

    /**
     * 回溯函数
     * @param index 当前处理到第几个数字
     * @param path 当前组合的字符串
     */
    function backtrack(index: number, path: string): void {
        // 终止条件：处理完所有数字
        if (index === digits.length) {
            result.push(path);
            return;
        }

        // 获取当前数字对应的字母
        const digit = digits[index];
        const letters = phoneMap.get(digit)!;

        // 遍历每个字母
        for (const letter of letters) {
            // 递归处理下一个数字
            backtrack(index + 1, path + letter);
        }
    }

    backtrack(0, "");
    return result;
}
```

```typescript
        ['9', 'wxyz']

    const path: string[] = [];

    function backtrack(index: number): void {
        if (index === digits.length) {
            result.push(path.join(''));
            return;
        }

        const digit = digits[index];
        const letters = phoneMap.get(digit)!;

        for (const letter of letters) {
            path.push(letter);
            backtrack(index + 1);
            path.pop();
        }
    }

    backtrack(0);
    return result;
}
```

### 方法二：队列迭代

```typescript
function letterCombinations(digits: string): string[] {
    if (digits.length === 0) {
        return [];
    }

    const phoneMap: Map<string, string> = new Map([
        ['2', 'abc'],
        ['3', 'def'],
        ['4', 'ghi'],
        ['5', 'jkl'],
        ['6', 'mno'],
        ['7', 'pqrs'],
        ['8', 'tuv'],
        ['9', 'wxyz']
    ]);

    let queue: string[] = [""];

    // 处理每个数字
    for (const digit of digits) {
        const letters = phoneMap.get(digit)!;
        const newQueue: string[] = [];

        // 对于队列中的每个组合
        for (const combination of queue) {
            // 与当前数字的每个字母组合
            for (const letter of letters) {
                newQueue.push(combination + letter);
            }
        }

        queue = newQueue;
    }

    return queue;
}
```

## 代码原理详解

### 回溯法

**递归过程：**
```typescript
backtrack(index, path)

参数含义：
- index: 当前处理第几个数字（层数）
- path: 当前组合的字符串（决策路径）

递归树：
                backtrack(0, "")
         /              |              \
   backtrack(1,"a") backtrack(1,"b") backtrack(1,"c")
    /    |    \
backtrack(2,"ad") backtrack(2,"ae") backtrack(2,"af")
```

**字符串拼接 vs 数组：**
```typescript
// 方式1：直接拼接字符串
backtrack(index + 1, path + letter);

优点：代码简洁，不需要撤销
缺点：每次创建新字符串，内存开销大

// 方式2：使用数组
path.push(letter);
backtrack(index + 1);
path.pop();  // 撤销

优点：效率更高，原地修改
缺点：需要手动撤销
```

## 常见问题

**Q1: 为什么不需要used标记？**
A: 与全排列不同：
```
全排列：
- 从同一个数组选元素
- 需要标记已选择的

电话号码：
- 每层从不同的字母集合选择
- 不会重复选择同一个字母
- 不需要标记
```

**Q2: 能否用循环代替递归？**
A: 可以，但不推荐：
```
2层循环：
for a in '2':
    for b in '3':
        result.append(a + b)

问题：层数不固定
digits长度未知，无法写固定层数的循环

递归优势：
自动处理任意层数
```

**Q3: 空字符串如何处理？**
A: 题目定义返回空数组：
```typescript
if (digits.length === 0) {
    return [];  // 不是[[""]]
}
```

**Q4: 如何计算结果数量？**
A: 乘法原理：
```
digits = "23"
'2'有3个字母
'3'有3个字母
结果：3 × 3 = 9个

digits = "234"
结果：3 × 3 × 3 = 27个

一般：∏(每个数字的字母数)
```

**Q5: 字符串拼接效率问题？**
A: TypeScript中字符串是不可变的：
```
每次 path + letter：
- 创建新字符串
- 复制旧内容
- 添加新字符

但digits长度≤4：
- 影响可以忽略
- 代码更简洁

如果digits很长：
- 使用数组path
- 最后join()
```

## 复杂度分析

**时间复杂度：** O(3^m × 4^n)
- m：对应3个字母的数字个数（2,3,4,5,6,8）
- n：对应4个字母的数字个数（7,9）
- 每个组合需要O(digits.length)构建

**空间复杂度：**
- **回溯**：O(digits.length) - 递归深度
- **队列**：O(3^m × 4^n) - 队列大小

**结果空间：** O(3^m × 4^n × digits.length)
