# 78. 子集【中等】

## 题目描述

给你一个整数数组 `nums`，数组中的元素 **互不相同**。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

### 示例 2
```
输入：nums = [0]
输出：[[],[0]]
```

### 提示
- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**子集的特点：**
```
子集 = 从数组中选出若干个元素（可以是0个）

例如：[1,2,3]的所有子集：
[]           - 选0个
[1],[2],[3]  - 选1个
[1,2],[1,3],[2,3]  - 选2个
[1,2,3]      - 选3个

总共：2^n = 2^3 = 8个

关键：
- 每个元素有两种状态：选 or 不选
- 元素不重复
- 顺序无关：[1,2]和[2,1]算同一个子集
```

**与全排列的区别：**
```
全排列：
- 固定长度（n个元素）
- 关注顺序
- n!个结果

子集：
- 长度可变（0~n个元素）
- 不关注顺序
- 2^n个结果
```

---

### 方法一：回溯法（推荐）

**核心思想：**
- 每个元素有"选"和"不选"两个决策
- 使用start参数避免重复

**决策树：**
```
输入：[1,2,3]

                    []
         选1 /              \ 不选1
             [1]              []
       选2/    \不选2    选2/    \不选2
        [1,2]   [1]      [2]      []
      /   \    /  \     /  \     /  \
   [1,2,3][1,2][1,3][1][2,3][2] [3] []

收集所有节点（不只是叶子）：
[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]
```

**算法流程：**
1. 每次递归都收集当前path（不同于全排列）
2. 从start开始遍历（避免重复）
3. 做选择：path加入nums[i]
4. 递归：start = i + 1
5. 撤销选择

**时间复杂度：** O(n×2^n) - 2^n个子集，每个O(n)复制
**空间复杂度：** O(n) - 递归深度

---

### 方法二：迭代法

**核心思想：**
- 初始：结果只有空集[[]]
- 每加入一个元素，将已有的所有子集都加上这个元素

**演变过程：**
```
初始：[[]]

加入1：
  已有：[]
  新增：[] + 1 = [1]
  结果：[[], [1]]

加入2：
  已有：[], [1]
  新增：[] + 2 = [2], [1] + 2 = [1,2]
  结果：[[], [1], [2], [1,2]]

加入3：
  已有：[], [1], [2], [1,2]
  新增：[3], [1,3], [2,3], [1,2,3]
  结果：[[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

**时间复杂度：** O(n×2^n)
**空间复杂度：** O(1) - 不计结果空间

---

### 方法三：位运算

**核心思想：**
- 用n位二进制表示选择状态
- 1表示选，0表示不选

**例如：[1,2,3]**
```
000 = 0 → []
001 = 1 → [3]
010 = 2 → [2]
011 = 3 → [2,3]
100 = 4 → [1]
101 = 5 → [1,3]
110 = 6 → [1,2]
111 = 7 → [1,2,3]

从0到2^n-1遍历，检查每一位
```

**时间复杂度：** O(n×2^n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：回溯法（推荐）

```typescript
function subsets(nums: number[]): number[][] {
    const result: number[][] = [];
    const path: number[] = [];

    /**
     * 回溯函数
     * @param start 从哪个位置开始选择（避免重复）
     */
    function backtrack(start: number): void {
        // 每个节点都是一个有效子集
        result.push([...path]);

        // 从start开始遍历，避免重复
        for (let i = start; i < nums.length; i++) {
            // 做选择
            path.push(nums[i]);

            // 递归：下一层从i+1开始
            backtrack(i + 1);

            // 撤销选择
            path.pop();
        }
    }

    backtrack(0);
    return result;
}
```

---

### 方法二：迭代法

```typescript
function subsets(nums: number[]): number[][] {
    const result: number[][] = [[]];  // 初始化为空集

    // 依次加入每个元素
    for (const num of nums) {
        const newSubsets: number[][] = [];

        // 对于每个已有的子集
        for (const subset of result) {
            // 创建新子集：已有子集 + 当前元素
            newSubsets.push([...subset, num]);
        }

        // 将新子集加入结果
        result.push(...newSubsets);
    }

    return result;
}
```

---

### 方法三：位运算

```typescript
function subsets(nums: number[]): number[][] {
    const result: number[][] = [];
    const n = nums.length;

    // 遍历所有可能的状态：0 到 2^n - 1
    for (let mask = 0; mask < (1 << n); mask++) {
        const subset: number[] = [];

        // 检查每一位
        for (let i = 0; i < n; i++) {
            // 如果第i位是1，选择nums[i]
            if ((mask & (1 << i)) !== 0) {
                subset.push(nums[i]);
            }
        }

        result.push(subset);
    }

    return result;
}
```

## 代码原理详解

### 回溯法

**关键点：start参数**
```typescript
backtrack(start: number)

为什么需要start？
避免重复：
- [1,2]和[2,1]是同一个子集
- 只收集按索引递增的组合

例如：
nums = [1,2,3]

从0开始：可以选1,2,3
从1开始：可以选2,3（不能再选1）
从2开始：可以选3（不能再选1,2）

保证：只生成[1,2]，不会生成[2,1]
```

**收集时机：**
```typescript
function backtrack(start: number): void {
    result.push([...path]);  // 每个节点都收集！

    for (let i = start; i < nums.length; i++) {
        // ...
    }
}

区别于全排列：
- 全排列：只在叶子节点收集（path.length === n）
- 子集：在所有节点收集（任意长度都是有效子集）
```

### 迭代法

**演变过程：**
```
nums = [1,2,3]

初始：result = [[]]

处理1：
  遍历已有：[]
  新增：[1]
  result = [[], [1]]

处理2：
  遍历已有：[], [1]
  新增：[2], [1,2]
  result = [[], [1], [2], [1,2]]

处理3：
  遍历已有：[], [1], [2], [1,2]
  新增：[3], [1,3], [2,3], [1,2,3]
  result = [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]
```

### 位运算法

**二进制表示：**
```
nums = [1,2,3]

mask = 5 (二进制101)：

第0位: 1 & 1 = 1 → 选nums[0] = 1
第1位: 1 & 2 = 0 → 不选nums[1]
第2位: 1 & 4 = 1 → 选nums[2] = 3

结果：[1,3]
```

## 常见问题

**Q1: 为什么每个节点都要收集？**
A: 子集的定义：
```
子集：任意长度的元素组合

不只是叶子节点：
- 叶子：[1,2,3]（完整集合）
- 非叶子：[]、[1]、[1,2]等（也是子集）

全排列：只收集叶子（固定长度n）
子集：收集所有节点（长度0~n）
```

**Q2: start参数的作用？**
A: 避免重复：
```
没有start：
i从0开始每次都能选1,2,3
会生成：[1,2]和[2,1]（重复）

有start：
选了1后，i从1开始，只能选2,3
只生成：[1,2]（不会生成[2,1]）

保证：按索引递增顺序选择
```

**Q3: 三种方法如何选择？**
A:
| 方法 | 理解难度 | 代码长度 | 推荐场景 |
|------|---------|---------|---------|
| 回溯 | 中 | 短 | 面试首选（通用） |
| 迭代 | 易 | 中 | 易理解 |
| 位运算 | 难 | 短 | n较小时 |

**Q4: 如何处理重复元素？**
A: 需要去重（见90题）：
```typescript
// 排序后
nums.sort((a, b) => a - b);

// 回溯中
if (i > start && nums[i] === nums[i-1]) {
    continue;  // 跳过重复元素
}
```

**Q5: 能否用DFS而不是回溯？**
A: 回溯就是DFS的一种：
```
DFS：深度优先搜索（更广义）
回溯：DFS + 撤销选择（更具体）

在这道题中：
- DFS遍历决策树
- 回溯保证能遍历所有路径
```

## 复杂度分析

### 所有方法

**时间复杂度：** O(n×2^n)
- 子集数量：2^n
- 复制每个子集：O(n)
- 总计：O(n×2^n)

**空间复杂度：**
- **回溯**：O(n) - 递归深度
- **迭代**：O(1) - 不计结果空间
- **位运算**：O(1) - 不计结果空间

**结果空间：** O(n×2^n)
- 2^n个子集
- 平均长度n/2

## 总结

**关键点：**
1. 子集 = 长度0~n的所有组合
2. 回溯中每个节点都收集（不只是叶子）
3. start参数避免重复
4. 三种方法各有优劣

**回溯模板（子集问题）：**
```typescript
function backtrack(start: number): void {
    result.push([...path]);  // 收集所有节点

    for (let i = start; i < nums.length; i++) {
        path.push(nums[i]);
        backtrack(i + 1);  // i+1避免重复
        path.pop();
    }
}
```

**面试建议：**
- 优先使用回溯法（最通用）
- 解释start参数的作用
- 说明与全排列的区别
- 画出决策树
- 可以补充迭代法（更直观）

**易错点：**
- 忘记收集空集
- start写成0（导致重复）
- 只在叶子节点收集（应该所有节点）
- 忘记复制数组
- 迭代法中直接修改result导致无限循环

**记忆口诀：**
- 排列问题：固定长度，关注顺序，n!
- 组合问题：固定长度，不关注顺序，C(n,k)
- 子集问题：可变长度，不关注顺序，2^n
