# 22. 括号生成【中等】

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

---

## 输入输出示例

### 示例 1
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

### 示例 2
```
输入：n = 1
输出：["()"]
```

### 提示
- `1 <= n <= 8`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**有效括号的规则：**
```
1. 左括号数量 = 右括号数量 = n
2. 任意前缀中，左括号数量 >= 右括号数量

例如：n = 2
有效：
()()  ✓ (每个位置left >= right)
(())  ✓

无效：
))((  ✗ (right > left)
()(   ✗ (数量不对)
```

**回溯策略：**
```
在任意时刻，有两个选择：
1. 添加左括号 '(' - 条件：left < n
2. 添加右括号 ')' - 条件：right < left

保证：
- 左括号不超过n
- 右括号不超过左括号（保证有效性）
```

---

### 方法一：回溯法（推荐）

**决策树：**
```
n = 2

                    ""
                    ↓
                   "("
              /           \
           "(("           "()"
            ↓          /       \
          "(()"     "()("      "())"✗
            ↓         ↓
         "(())"✓   "()()"✓

剪枝：
- left >= n：不能再添加'('
- right >= left：不能再添加')'
```

**算法流程：**
1. 定义回溯函数backtrack(path, left, right)
   - path：当前字符串
   - left：已用的左括号数
   - right：已用的右括号数
2. 终止条件：path.length == 2n
3. 尝试添加'('：如果left < n
4. 尝试添加')'：如果right < left

**时间复杂度：** O(4^n / sqrt(n)) - 卡特兰数
**空间复杂度：** O(n) - 递归深度

---

### 方法二：动态规划（了解）

**核心思想：**
- dp[i]：i对括号的所有有效组合
- dp[i] = "(" + dp[j] + ")" + dp[i-1-j]
  - j从0到i-1

**时间复杂度：** O(4^n / sqrt(n))
**空间复杂度：** O(4^n / sqrt(n))

---

## 代码实现（TypeScript）

### 方法一：回溯法（推荐）

```typescript
function generateParenthesis(n: number): string[] {
    const result: string[] = [];

    /**
     * 回溯函数
     * @param path 当前字符串
     * @param left 已使用的左括号数量
     * @param right 已使用的右括号数量
     */
    function backtrack(path: string, left: number, right: number): void {
        // 终止条件：生成了2n个字符
        if (path.length === 2 * n) {
            result.push(path);
            return;
        }

        // 尝试添加左括号
        if (left < n) {
            backtrack(path + '(', left + 1, right);
        }

        // 尝试添加右括号（必须right < left）
        if (right < left) {
            backtrack(path + ')', left, right + 1);
        }
    }

    backtrack('', 0, 0);
    return result;
}
```

### 方法一变体：使用数组

```typescript
function generateParenthesis(n: number): string[] {
    const result: string[] = [];
    const path: string[] = [];

    function backtrack(left: number, right: number): void {
        if (path.length === 2 * n) {
            result.push(path.join(''));
            return;
        }

        if (left < n) {
            path.push('(');
            backtrack(left + 1, right);
            path.pop();
        }

        if (right < left) {
            path.push(')');
            backtrack(left, right + 1);
            path.pop();
        }
    }

    backtrack(0, 0);
    return result;
}
```

### 方法二：动态规划

```typescript
function generateParenthesis(n: number): string[] {
    if (n === 0) return [''];

    const dp: string[][] = [['']];  // dp[0] = ['']

    for (let i = 1; i <= n; i++) {
        dp[i] = [];

        // dp[i] = '(' + dp[j] + ')' + dp[i-1-j]
        // j从0到i-1
        for (let j = 0; j < i; j++) {
            const left = dp[j];       // 左边j对
            const right = dp[i-1-j];  // 右边i-1-j对

            for (const l of left) {
                for (const r of right) {
                    dp[i].push('(' + l + ')' + r);
                }
            }
        }
    }

    return dp[n];
}
```

## 代码原理详解

### 回溯法

**关键条件：**
```typescript
// 条件1：左括号
if (left < n) {
    backtrack(path + '(', left + 1, right);
}

// 条件2：右括号
if (right < left) {
    backtrack(path + ')', left, right + 1);
}
```

**为什么right < left？**
```
保证有效性：
- 任意前缀中，左括号数 >= 右括号数
- 即：right <= left

添加右括号的条件：
- right < left（还有左括号没配对）

例如：
"(()"：left=2, right=1
- 可以添加')'（right < left）
- 可以添加'('（left < n）

"(())"：left=2, right=2
- 不能添加')'（right = left）
- 可以添加'('（left < n）
```

### 动态规划

**递推公式：**
```
dp[i] = "(" + dp[j] + ")" + dp[i-1-j]

含义：
- 外层一对括号：()
- 内部：j对括号
- 外部右侧：i-1-j对括号

例如：n = 2
dp[2] = "(" + dp[0] + ")" + dp[1]  (j=0)
      = "()" + "()"
      = "()()"

      + "(" + dp[1] + ")" + dp[0]  (j=1)
      = "(" + "()" + ")"
      = "(())"
```

## 常见问题

**Q1: 为什么不需要撤销操作？**
A: 字符串是不可变的：
```typescript
backtrack(path + '(', ...)
//        ↑
//     创建新字符串，不修改原path

所以不需要：
path.push('(');
backtrack(...);
path.pop();  // 不需要

如果用数组就需要撤销：
path.push('(');
backtrack(...);
path.pop();  // 必须撤销
```

**Q2: 能否先生成所有组合再过滤？**
A: 可以但效率低：
```
生成2^(2n)个组合
逐个检查有效性

时间：O(2^(2n) × n)
远大于回溯的O(4^n/√n)

回溯优势：
- 提前剪枝
- 只生成有效组合
```

**Q3: 卡特兰数是什么？**
A: 第n个卡特兰数：
```
C_n = (2n)! / ((n+1)! × n!)
    ≈ 4^n / (n^(3/2) × √π)

应用：
- n对括号的有效组合数
- n个节点的二叉树数
- n×n方格的路径数（不越过对角线）

例如：
n=1: C_1 = 1
n=2: C_2 = 2
n=3: C_3 = 5
n=4: C_4 = 14
```

**Q4: 为什么left < n不是left <= n？**
A: 数量限制：
```
总共n对括号：
- 左括号：n个
- 右括号：n个

left < n：
- 还没用完n个左括号
- 可以继续添加

left <= n：
- 会添加n+1个左括号（错误！）
```

**Q5: 能否用栈验证有效性？**
A: 可以，但回溯中不需要：
```
回溯已保证：
- right < left（自动保证有效）
- left, right都不超过n（保证数量）

额外验证：多余
```

## 复杂度分析

**时间复杂度：** O(4^n / √n)
- 第n个卡特兰数：C_n ≈ 4^n / (n√n)
- 生成每个结果需要O(n)

**空间复杂度：** O(n)
- 递归深度：O(n)
- 每个递归占用：O(1)
- 不计结果空间

**结果数量：** 卡特兰数C_n

## 总结

**关键点：**
1. 回溯生成所有有效组合
2. 两个条件：left < n 和 right < left
3. right < left保证有效性
4. 字符串拼接不需要撤销

**回溯模板（括号生成）：**
```typescript
function backtrack(path: string, left: number, right: number): void {
    if (path.length === 2 * n) {
        result.push(path);
        return;
    }

    if (left < n) {
        backtrack(path + '(', left + 1, right);
    }

    if (right < left) {
        backtrack(path + ')', left, right + 1);
    }
}
```

**面试建议：**
- 先解释有效括号的规则
- 画出决策树
- 说明两个条件的含义
- 强调right < left保证有效性
- 可以提及卡特兰数

**易错点：**
- left和right的含义搞混
- 条件写成right <= left（应该是<）
- 忘记判断left < n
- 终止条件写成left == n && right == n（应该是length == 2n）
- 使用数组时忘记撤销

**记忆技巧：**
- 左括号随意加（只要不超n）
- 右括号要配对（必须有左括号等着）
- right < left：右括号数 < 左括号数
