# 215. 数组中的第K个最大元素【中等】

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

---

## 输入输出示例

### 示例 1
```
输入: nums = [3,2,1,5,6,4], k = 2
输出: 5
```

### 示例 2
```
输入: nums = [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

### 提示
- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题转换：**
```
第k个最大元素
= 排序后第 n-k 个元素（0-indexed）
= 第 n-k+1 小的元素

例如：[3,2,1,5,6,4], k=2
排序后：[1,2,3,4,5,6]
第2大 = 第5小 = 下标4 = 5 ✓
```

**方法对比：**
```
1. 排序：O(nlogn)
   - 简单直接
   - 但超过题目要求的O(n)

2. 堆：O(nlogk)
   - 维护大小为k的小顶堆
   - 适合k较小的情况

3. 快速选择：O(n)平均
   - 基于快排的分区思想
   - 满足题目O(n)要求
   - 推荐！
```

---

### 方法一：快速选择（推荐）

**核心思想：**
- 基于快排的分区（partition）
- 每次分区后，pivot位置确定
- 根据pivot位置决定继续在左边还是右边查找

**算法流程：**

1. **分区（partition）：**
   - 选择pivot（通常选最右元素）
   - 将小于pivot的放左边，大于的放右边
   - 返回pivot的最终位置

2. **递归查找：**
   - 如果 pivot位置 == 目标位置：找到答案
   - 如果 pivot位置 > 目标位置：在左半部分查找
   - 如果 pivot位置 < 目标位置：在右半部分查找

3. **优化：随机化pivot**
   - 避免最坏情况O(n^2)
   - 平均时间O(n)

**为什么是O(n)？**
```
第一次分区：n
第二次分区：n/2
第三次分区：n/4
...

总时间：n + n/2 + n/4 + ... = 2n = O(n)
```

**时间复杂度：** O(n) 平均，O(n^2) 最坏
**空间复杂度：** O(logn) 递归栈

---

### 方法二：小顶堆

**核心思想：**
- 维护大小为k的小顶堆
- 堆顶就是第k大元素

**算法流程：**

1. **前k个元素建堆**
2. **遍历剩余元素：**
   - 如果 > 堆顶：弹出堆顶，加入新元素
3. **返回堆顶**

**时间复杂度：** O(nlogk)
**空间复杂度：** O(k)

---

### 方法三：排序

**核心思想：**
- 直接排序
- 返回倒数第k个

**时间复杂度：** O(nlogn)
**空间复杂度：** O(1) 或 O(n)（取决于排序算法）

## 代码实现（TypeScript）

### 方法一：快速选择（推荐）

```typescript
function findKthLargest(nums: number[], k: number): number {
    // 第k大 = 第 n-k 小（0-indexed）
    const targetIndex = nums.length - k;

    /**
     * 快速选择
     */
    function quickSelect(left: number, right: number): number {
        // 随机选择pivot（避免最坏情况）
        const randomIndex = left + Math.floor(Math.random() * (right - left + 1));
        [nums[randomIndex], nums[right]] = [nums[right], nums[randomIndex]];

        // 分区
        const pivotIndex = partition(left, right);

        if (pivotIndex === targetIndex) {
            // 找到目标
            return nums[pivotIndex];
        } else if (pivotIndex < targetIndex) {
            // 在右半部分
            return quickSelect(pivotIndex + 1, right);
        } else {
            // 在左半部分
            return quickSelect(left, pivotIndex - 1);
        }
    }

    /**
     * 分区：将小于pivot的放左边，大于的放右边
     */
    function partition(left: number, right: number): number {
        const pivot = nums[right];
        let i = left;  // i指向第一个 >= pivot的位置

        for (let j = left; j < right; j++) {
            if (nums[j] < pivot) {
                // 小于pivot，交换到左边
                [nums[i], nums[j]] = [nums[j], nums[i]];
                i++;
            }
        }

        // pivot放到正确位置
        [nums[i], nums[right]] = [nums[right], nums[i]];

        return i;
    }

    return quickSelect(0, nums.length - 1);
}
```

### 方法一优化：三路快排

```typescript
function findKthLargest(nums: number[], k: number): number {
    const targetIndex = nums.length - k;

    function quickSelect(left: number, right: number): number {
        if (left === right) return nums[left];

        // 随机pivot
        const randomIndex = left + Math.floor(Math.random() * (right - left + 1));
        [nums[randomIndex], nums[right]] = [nums[right], nums[randomIndex]];

        // 三路分区：< pivot | = pivot | > pivot
        const [lt, gt] = threeWayPartition(left, right);

        if (targetIndex < lt) {
            return quickSelect(left, lt - 1);
        } else if (targetIndex > gt) {
            return quickSelect(gt + 1, right);
        } else {
            return nums[targetIndex];
        }
    }

    /**
     * 三路分区
     * @returns [lt, gt]，其中 [lt, gt] 区间内的元素都等于pivot
     */
    function threeWayPartition(left: number, right: number): [number, number] {
        const pivot = nums[right];
        let lt = left;      // < pivot 的右边界
        let gt = right;     // > pivot 的左边界
        let i = left;

        while (i <= gt) {
            if (nums[i] < pivot) {
                [nums[i], nums[lt]] = [nums[lt], nums[i]];
                lt++;
                i++;
            } else if (nums[i] > pivot) {
                [nums[i], nums[gt]] = [nums[gt], nums[i]];
                gt--;
                // 注意：不增加i，因为交换过来的元素还没处理
            } else {
                i++;
            }
        }

        return [lt, gt];
    }

    return quickSelect(0, nums.length - 1);
}
```

### 方法二：小顶堆（使用数组模拟）

```typescript
function findKthLargest(nums: number[], k: number): number {
    // TypeScript没有内置堆，使用数组模拟小顶堆
    const minHeap: number[] = [];

    /**
     * 上浮
     */
    function heapifyUp(index: number): void {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (minHeap[index] < minHeap[parentIndex]) {
                [minHeap[index], minHeap[parentIndex]] = [minHeap[parentIndex], minHeap[index]];
                index = parentIndex;
            } else {
                break;
            }
        }
    }

    /**
     * 下沉
     */
    function heapifyDown(index: number): void {
        const size = minHeap.length;
        while (true) {
            let smallest = index;
            const leftChild = 2 * index + 1;
            const rightChild = 2 * index + 2;

            if (leftChild < size && minHeap[leftChild] < minHeap[smallest]) {
                smallest = leftChild;
            }
            if (rightChild < size && minHeap[rightChild] < minHeap[smallest]) {
                smallest = rightChild;
            }

            if (smallest !== index) {
                [minHeap[index], minHeap[smallest]] = [minHeap[smallest], minHeap[index]];
                index = smallest;
            } else {
                break;
            }
        }
    }

    /**
     * 插入元素
     */
    function push(val: number): void {
        minHeap.push(val);
        heapifyUp(minHeap.length - 1);
    }

    /**
     * 弹出堆顶
     */
    function pop(): number {
        const top = minHeap[0];
        const last = minHeap.pop()!;
        if (minHeap.length > 0) {
            minHeap[0] = last;
            heapifyDown(0);
        }
        return top;
    }

    // 维护大小为k的小顶堆
    for (const num of nums) {
        if (minHeap.length < k) {
            push(num);
        } else if (num > minHeap[0]) {
            pop();
            push(num);
        }
    }

    return minHeap[0];
}
```

## 代码原理详解

### 快速选择方法

**1. 分区过程：**
```typescript
function partition(left: number, right: number): number {
    const pivot = nums[right];
    let i = left;

    for (let j = left; j < right; j++) {
        if (nums[j] < pivot) {
            [nums[i], nums[j]] = [nums[j], nums[i]];
            i++;
        }
    }

    [nums[i], nums[right]] = [nums[right], nums[i]];
    return i;
}

维护不变式：
[left...i-1] < pivot
[i...j-1] >= pivot
[j...right-1] 未处理
nums[right] = pivot

例如：[3, 2, 1, 5, 6, 4], pivot=4
j=0: 3<4, swap(i=0, j=0), i=1
j=1: 2<4, swap(i=1, j=1), i=2
j=2: 1<4, swap(i=2, j=2), i=3
j=3: 5>=4, 不交换
j=4: 6>=4, 不交换
最后：swap(i=3, right=5)
结果：[3,2,1,4,6,5], pivot在位置3 ✓
```

**2. 递归查找：**
```typescript
if (pivotIndex === targetIndex) {
    return nums[pivotIndex];
} else if (pivotIndex < targetIndex) {
    return quickSelect(pivotIndex + 1, right);
} else {
    return quickSelect(left, pivotIndex - 1);
}

根据pivot位置决定：
- = 目标：找到答案
- < 目标：在右半部分（更大的元素）
- > 目标：在左半部分（更小的元素）
```

**3. 随机化优化：**
```typescript
const randomIndex = left + Math.floor(Math.random() * (right - left + 1));
[nums[randomIndex], nums[right]] = [nums[right], nums[randomIndex]];

避免最坏情况：
- 如果数组已排序，选最右元素会导致O(n^2)
- 随机选择pivot，期望O(n)
```

## 常见问题

**Q1: 为什么快速选择是O(n)？**
A: 每次只处理一半：
```
第一次：n
第二次：n/2
第三次：n/4
...

总和：n + n/2 + n/4 + ... = n × (1 + 1/2 + 1/4 + ...) = n × 2 = 2n = O(n)

对比快排O(nlogn)：
快排每次都处理两边
快速选择只处理一边
```

**Q2: 为什么要随机化pivot？**
A: 避免最坏情况：
```
最坏情况：数组已排序
如果总选最右元素：
- 每次只减少一个元素
- 递归深度n
- 时间O(n^2)

随机化后：
- 期望每次分成两半
- 期望O(n)
```

**Q3: 堆方法何时更好？**
A:
```
快速选择：
- O(n)平均，O(n^2)最坏
- 原地修改数组

堆：
- O(nlogk)
- k很小时，logk可忽略
- 不修改原数组
- 适合数据流场景

选择：
- k较小：堆
- k较大：快速选择
- 在线算法：堆
```

**Q4: 能否用最大堆？**
A: 可以但效率低：
```
最大堆：
- 存储所有n个元素
- 弹出k次
- 时间：O(n + klogn)

小顶堆：
- 只存储k个元素
- 时间：O(nlogk)

k较小时，小顶堆更优
```

**Q5: 三路快排有什么优势？**
A: 处理重复元素：
```
普通分区：
- 重复元素在两侧
- 每次只确定一个位置

三路分区：
- < pivot | = pivot | > pivot
- 一次确定所有等于pivot的位置
- 重复元素多时更高效
```

## 复杂度分析

### 快速选择

**时间复杂度：**
- 平均：O(n)
- 最坏：O(n^2)（数组已排序且不随机化）

**空间复杂度：** O(logn) - 递归栈

### 堆

**时间复杂度：** O(nlogk)
- 建堆：O(k)
- n-k次插入：O((n-k)logk)
- 总计：O(nlogk)

**空间复杂度：** O(k)

### 排序

**时间复杂度：** O(nlogn)

**空间复杂度：** O(1) 或 O(n)

## 总结

**关键点：**
1. 快速选择基于快排分区思想
2. 每次只处理一半，平均O(n)
3. 随机化pivot避免最坏情况
4. 小顶堆适合k较小的情况

**快速选择模板：**
```typescript
function quickSelect(left: number, right: number, target: number): number {
    if (left === right) return nums[left];

    // 随机pivot
    const randomIndex = left + Math.floor(Math.random() * (right - left + 1));
    [nums[randomIndex], nums[right]] = [nums[right], nums[randomIndex]];

    // 分区
    const pivotIndex = partition(left, right);

    if (pivotIndex === target) {
        return nums[pivotIndex];
    } else if (pivotIndex < target) {
        return quickSelect(pivotIndex + 1, right, target);
    } else {
        return quickSelect(left, pivotIndex - 1, target);
    }
}
```

**面试建议：**
- 优先说明快速选择（满足O(n)要求）
- 解释分区过程
- 提及随机化优化
- 可以补充堆方法（k较小时）
- 分析不同方法的适用场景

**易错点：**
- 第k大和第k小的转换（n-k）
- 分区的边界条件
- 递归的终止条件
- 忘记随机化pivot
- 堆的维护（小顶堆还是大顶堆）

**记忆技巧：**
- 快速选择 = 快排 + 只处理一半
- 第k大 = 第(n-k)小
- 小顶堆存最大的k个，堆顶是第k大
- 随机化 = 期望O(n)
