# 295. 数据流的中位数【困难】

## 题目描述

**中位数**是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如：
- `[2,3,4]` 的中位数是 `3`
- `[2,3]` 的中位数是 `(2 + 3) / 2 = 2.5`

设计一个支持以下两种操作的数据结构：

- `void addNum(int num)` - 从数据流中添加一个整数到数据结构中
- `double findMedian()` - 返回目前所有元素的中位数

---

## 输入输出示例

### 示例
```
输入：
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]

输出：
[null, null, null, 1.5, null, 2.0]

解释：
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr = [1, 2, 3]
medianFinder.findMedian(); // 返回 2.0
```

### 提示
- `-10^5 <= num <= 10^5`
- 在调用 `findMedian` 之前，数据结构中至少有一个元素
- 最多调用 `5 * 10^4` 次 `addNum` 和 `findMedian`

**进阶：**
- 如果数据流中所有整数都在 `0` 到 `100` 范围内，你将如何优化你的算法？
- 如果数据流中 `99%` 的整数都在 `0` 到 `100` 范围内，你将如何优化你的算法？

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
动态数据流：
- 不断加入新数据
- 需要实时获取中位数

中位数的位置：
- 有序数组的中间
- 需要快速访问中间元素
```

**方法对比：**
```
1. 排序：
   - addNum：插入 O(n)
   - findMedian：O(1)
   - 总体：O(n)，效率低

2. 插入排序：
   - addNum：二分查找 + 插入 O(n)
   - findMedian：O(1)
   - 仍然效率低

3. 双堆：
   - addNum：O(logn)
   - findMedian：O(1)
   - 最优解 ✓
```

---

### 方法：对顶堆（双堆）

**核心思想：**
- 使用两个堆维护数据流：
  - 大顶堆（左边）：存储较小的一半
  - 小顶堆（右边）：存储较大的一半
- 中位数就在两个堆顶之间

**堆的性质：**
```
大顶堆（maxHeap）：
- 存储较小的一半
- 堆顶是这一半中最大的

小顶堆（minHeap）：
- 存储较大的一半
- 堆顶是这一半中最小的

结构：
maxHeap    minHeap
[小的一半]  [大的一半]
    ↑          ↑
  堆顶       堆顶

maxHeap.top <= minHeap.top
```

**大小维护：**
```
保持平衡：
- |maxHeap.size - minHeap.size| <= 1

奇数个元素：
- maxHeap.size = minHeap.size + 1
- 中位数 = maxHeap.top

偶数个元素：
- maxHeap.size = minHeap.size
- 中位数 = (maxHeap.top + minHeap.top) / 2
```

**addNum流程：**
```
1. 确定加入哪个堆：
   - 如果 num <= maxHeap.top：加入maxHeap
   - 否则：加入minHeap

2. 调整平衡：
   - 如果 maxHeap.size > minHeap.size + 1：
     移动maxHeap.top到minHeap
   - 如果 minHeap.size > maxHeap.size：
     移动minHeap.top到maxHeap
```

**时间复杂度：**
- addNum：O(logn) - 堆操作
- findMedian：O(1) - 直接访问堆顶

**空间复杂度：** O(n) - 两个堆存储所有元素

## 代码实现（TypeScript）

### 方法：对顶堆（双堆）

```typescript
class MedianFinder {
    private maxHeap: number[];  // 大顶堆：存储较小的一半
    private minHeap: number[];  // 小顶堆：存储较大的一半

    constructor() {
        this.maxHeap = [];
        this.minHeap = [];
    }

    /**
     * 添加数字
     */
    addNum(num: number): void {
        // 1. 先加入大顶堆
        if (this.maxHeap.length === 0 || num <= this.maxHeap[0]) {
            this.pushMaxHeap(num);
        } else {
            this.pushMinHeap(num);
        }

        // 2. 调整平衡
        // 大顶堆最多比小顶堆多1个元素
        if (this.maxHeap.length > this.minHeap.length + 1) {
            const top = this.popMaxHeap();
            this.pushMinHeap(top);
        }
        // 小顶堆不能比大顶堆多
        else if (this.minHeap.length > this.maxHeap.length) {
            const top = this.popMinHeap();
            this.pushMaxHeap(top);
        }
    }

    /**
     * 获取中位数
     */
    findMedian(): number {
        if (this.maxHeap.length === this.minHeap.length) {
            // 偶数个：两个堆顶的平均值
            return (this.maxHeap[0] + this.minHeap[0]) / 2;
        } else {
            // 奇数个：大顶堆的堆顶
            return this.maxHeap[0];
        }
    }

    // ========== 大顶堆操作 ==========

    private pushMaxHeap(val: number): void {
        this.maxHeap.push(val);
        this.maxHeapifyUp(this.maxHeap.length - 1);
    }

    private popMaxHeap(): number {
        const top = this.maxHeap[0];
        const last = this.maxHeap.pop()!;
        if (this.maxHeap.length > 0) {
            this.maxHeap[0] = last;
            this.maxHeapifyDown(0);
        }
        return top;
    }

    private maxHeapifyUp(index: number): void {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (this.maxHeap[index] > this.maxHeap[parentIndex]) {
                [this.maxHeap[index], this.maxHeap[parentIndex]] =
                    [this.maxHeap[parentIndex], this.maxHeap[index]];
                index = parentIndex;
            } else {
                break;
            }
        }
    }

    private maxHeapifyDown(index: number): void {
        const size = this.maxHeap.length;
        while (true) {
            let largest = index;
            const leftChild = 2 * index + 1;
            const rightChild = 2 * index + 2;

            if (leftChild < size && this.maxHeap[leftChild] > this.maxHeap[largest]) {
                largest = leftChild;
            }
            if (rightChild < size && this.maxHeap[rightChild] > this.maxHeap[largest]) {
                largest = rightChild;
            }

            if (largest !== index) {
                [this.maxHeap[index], this.maxHeap[largest]] =
                    [this.maxHeap[largest], this.maxHeap[index]];
                index = largest;
            } else {
                break;
            }
        }
    }

    // ========== 小顶堆操作 ==========

    private pushMinHeap(val: number): void {
        this.minHeap.push(val);
        this.minHeapifyUp(this.minHeap.length - 1);
    }

    private popMinHeap(): number {
        const top = this.minHeap[0];
        const last = this.minHeap.pop()!;
        if (this.minHeap.length > 0) {
            this.minHeap[0] = last;
            this.minHeapifyDown(0);
        }
        return top;
    }

    private minHeapifyUp(index: number): void {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (this.minHeap[index] < this.minHeap[parentIndex]) {
                [this.minHeap[index], this.minHeap[parentIndex]] =
                    [this.minHeap[parentIndex], this.minHeap[index]];
                index = parentIndex;
            } else {
                break;
            }
        }
    }

    private minHeapifyDown(index: number): void {
        const size = this.minHeap.length;
        while (true) {
            let smallest = index;
            const leftChild = 2 * index + 1;
            const rightChild = 2 * index + 2;

            if (leftChild < size && this.minHeap[leftChild] < this.minHeap[smallest]) {
                smallest = leftChild;
            }
            if (rightChild < size && this.minHeap[rightChild] < this.minHeap[smallest]) {
                smallest = rightChild;
            }

            if (smallest !== index) {
                [this.minHeap[index], this.minHeap[smallest]] =
                    [this.minHeap[smallest], this.minHeap[index]];
                index = smallest;
            } else {
                break;
            }
        }
    }
}
```

## 代码原理详解

### 核心思想

**1. 堆的分工：**
```typescript
maxHeap: 存储较小的一半
- 大顶堆：堆顶最大
- 堆顶 = 较小一半中最大的

minHeap: 存储较大的一半
- 小顶堆：堆顶最小
- 堆顶 = 较大一半中最小的

示例：[1, 2, 3, 4, 5]
maxHeap = [3, 2, 1]  // 大顶堆
minHeap = [4, 5]     // 小顶堆

中位数 = 3（maxHeap.top）
```

**2. 平衡维护：**
```typescript
目标：
|maxHeap.size - minHeap.size| <= 1

调整规则：
1. maxHeap.size > minHeap.size + 1：
   移动maxHeap.top到minHeap

2. minHeap.size > maxHeap.size：
   移动minHeap.top到maxHeap

为什么优先放maxHeap？
- 奇数个元素时，中位数在maxHeap
- 保持maxHeap.size >= minHeap.size
```

**3. 中位数计算：**
```typescript
if (maxHeap.size === minHeap.size) {
    // 偶数个：平均值
    return (maxHeap[0] + minHeap[0]) / 2;
} else {
    // 奇数个：大顶堆堆顶
    return maxHeap[0];
}

例如：
[1, 2, 3, 4]
maxHeap = [2, 1]
minHeap = [3, 4]
中位数 = (2 + 3) / 2 = 2.5 ✓

[1, 2, 3]
maxHeap = [2, 1]
minHeap = [3]
中位数 = 2 ✓
```

## 常见问题

**Q1: 为什么要用两个堆？**
A: 快速访问中间元素：
```
有序数组：
[1, 2, 3, 4, 5]
      ↑
   中位数

双堆结构：
maxHeap    minHeap
[3,2,1]    [4,5]
   ↑         ↑
 最大      最小

中位数就在两个堆顶之间
O(1)访问
```

**Q2: 为什么大顶堆存较小的一半？**
A: 中位数的位置：
```
有序：[1, 2, 3, 4, 5]
         ↑
      中位数

需要快速访问中位数左边的最大值
→ 大顶堆

需要快速访问中位数右边的最小值
→ 小顶堆
```

**Q3: 能否让小顶堆比大顶堆多？**
A: 可以但不常见：
```
规则1（本实现）：
maxHeap.size >= minHeap.size
奇数时中位数 = maxHeap.top

规则2（另一种实现）：
minHeap.size >= maxHeap.size
奇数时中位数 = minHeap.top

两种都对，选一种即可
```

**Q4: 进阶问题如何优化？**
A:
```
问题1：所有整数在0-100：
- 使用计数数组counts[101]
- addNum：counts[num]++，O(1)
- findMedian：累计计数找中位数，O(100)=O(1)

问题2：99%在0-100：
- 混合方法：
  - 0-100：计数数组
  - 其他：双堆
- 大部分O(1)，少数O(logn)
```

**Q5: 能否用其他数据结构？**
A: 对比：
```
AVL树/红黑树：
- addNum：O(logn)
- findMedian：O(1)（维护中位数指针）
- 实现复杂

双堆：
- addNum：O(logn)
- findMedian：O(1)
- 实现简单

有序数组：
- addNum：O(n)（插入）
- findMedian：O(1)
- 效率低

双堆最优
```

## 总结

**关键点：**
1. 双堆结构：大顶堆存较小一半，小顶堆存较大一半
2. 保持平衡：|maxHeap.size - minHeap.size| ≤ 1
3. 中位数位置：堆顶或两个堆顶的平均值
4. 所有操作都高效：addNum O(logn)，findMedian O(1)

**对顶堆模板（中位数）：**
```typescript
class MedianFinder {
    private maxHeap: number[];  // 大顶堆
    private minHeap: number[];  // 小顶堆

    addNum(num: number): void {
        // 1. 加入合适的堆
        if (maxHeap为空 || num <= maxHeap[0]) {
            pushMaxHeap(num);
        } else {
            pushMinHeap(num);
        }

        // 2. 调整平衡
        if (maxHeap.size > minHeap.size + 1) {
            pushMinHeap(popMaxHeap());
        } else if (minHeap.size > maxHeap.size) {
            pushMaxHeap(popMinHeap());
        }
    }

    findMedian(): number {
        if (maxHeap.size === minHeap.size) {
            return (maxHeap[0] + minHeap[0]) / 2;
        } else {
            return maxHeap[0];
        }
    }
}
```

- 忘记堆化操作
- 边界情况：空堆、单个元素

**记忆技巧：**
- 对顶堆 = 大顶堆 + 小顶堆
- 大顶堆存小的，小顶堆存大的（反直觉但合理）
- 中位数 = 两个堆顶之间
- maxHeap ≥ minHeap（大小关系）
- O(logn) + O(1) = 最优解
