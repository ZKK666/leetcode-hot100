# 347. 前K个高频元素【中等】

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。你可以按**任意顺序**返回答案。

---

## 输入输出示例

### 示例 1
```
输入: nums = [1,1,1,2,2,3], k = 2
输出: [1,2]
```

### 示例 2
```
输入: nums = [1], k = 1
输出: [1]
```

### 提示
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的

**进阶：** 你所设计算法的时间复杂度**必须**优于 `O(nlogn)`，其中 `n` 是数组大小。

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
1. 统计频率
2. 找出频率最高的k个元素

关键：
如何高效地找到Top K？
```

**方法对比：**
```
1. 排序：O(nlogn)
   - 统计频率：O(n)
   - 排序：O(mlogm)，m是不同元素个数
   - 不满足进阶要求

2. 堆：O(nlogk)
   - 维护大小为k的小顶堆
   - 堆顶是第k高频的元素
   - 满足进阶要求 ✓

3. 桶排序：O(n)
   - 按频率分桶
   - 从高频到低频遍历桶
   - 最优解 ✓

4. 快速选择：O(n)平均
   - 类似第215题
   - 满足进阶要求 ✓
```

---

### 方法一：小顶堆（推荐）

**核心思想：**
- 统计频率（HashMap）
- 维护大小为k的小顶堆（按频率）
- 堆中保存频率最高的k个元素

**算法流程：**

1. **统计频率：** 使用Map
2. **建立小顶堆：**
   - 前k个元素入堆
   - 遍历剩余元素：
     - 如果频率 > 堆顶频率：替换
3. **返回堆中所有元素**

**为什么用小顶堆？**
```
小顶堆：
- 堆顶是第k高频（最小的）
- 新元素只需与堆顶比较
- 如果 > 堆顶，说明它更高频，替换堆顶

大顶堆：
- 堆顶是最高频
- 无法判断新元素是否应该入堆
```

**时间复杂度：** O(nlogk)
**空间复杂度：** O(n) - HashMap

---

### 方法二：桶排序（最优）

**核心思想：**
- 频率最多为n（所有元素相同）
- 创建n+1个桶，bucket[i]存储频率为i的元素
- 从高频到低频遍历桶，收集k个元素

**算法流程：**

1. **统计频率：** Map
2. **按频率分桶：**
   - bucket[freq] = 频率为freq的元素列表
3. **从高到低收集：**
   - 从bucket[n]到bucket[1]遍历
   - 收集k个元素

**时间复杂度：** O(n)
**空间复杂度：** O(n)

---

### 方法三：快速选择

**核心思想：**
- 统计频率
- 对频率数组使用快速选择
- 找到第k高频的分界线

**时间复杂度：** O(n) 平均
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：小顶堆（推荐）

```typescript
function topKFrequent(nums: number[], k: number): number[] {
    // 1. 统计频率
    const freqMap = new Map<number, number>();
    for (const num of nums) {
        freqMap.set(num, (freqMap.get(num) || 0) + 1);
    }

    // 2. 小顶堆（按频率）
    // TypeScript没有内置堆，使用数组模拟
    // 堆中存储 [元素, 频率]
    const minHeap: [number, number][] = [];

    /**
     * 上浮
     */
    function heapifyUp(index: number): void {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (minHeap[index][1] < minHeap[parentIndex][1]) {
                [minHeap[index], minHeap[parentIndex]] = [minHeap[parentIndex], minHeap[index]];
                index = parentIndex;
            } else {
                break;
            }
        }
    }

    /**
     * 下沉
     */
    function heapifyDown(index: number): void {
        const size = minHeap.length;
        while (true) {
            let smallest = index;
            const leftChild = 2 * index + 1;
            const rightChild = 2 * index + 2;

            if (leftChild < size && minHeap[leftChild][1] < minHeap[smallest][1]) {
                smallest = leftChild;
            }
            if (rightChild < size && minHeap[rightChild][1] < minHeap[smallest][1]) {
                smallest = rightChild;
            }

            if (smallest !== index) {
                [minHeap[index], minHeap[smallest]] = [minHeap[smallest], minHeap[index]];
                index = smallest;
            } else {
                break;
            }
        }
    }

    /**
     * 插入元素
     */
    function push(item: [number, number]): void {
        minHeap.push(item);
        heapifyUp(minHeap.length - 1);
    }

    /**
     * 弹出堆顶
     */
    function pop(): [number, number] {
        const top = minHeap[0];
        const last = minHeap.pop()!;
        if (minHeap.length > 0) {
            minHeap[0] = last;
            heapifyDown(0);
        }
        return top;
    }

    // 3. 维护大小为k的小顶堆
    for (const [num, freq] of freqMap) {
        if (minHeap.length < k) {
            push([num, freq]);
        } else if (freq > minHeap[0][1]) {
            pop();
            push([num, freq]);
        }
    }

    // 4. 返回堆中所有元素
    return minHeap.map(item => item[0]);
}
```

### 方法二：桶排序（最优）

```typescript
function topKFrequent(nums: number[], k: number): number[] {
    const n = nums.length;

    // 1. 统计频率
    const freqMap = new Map<number, number>();
    for (const num of nums) {
        freqMap.set(num, (freqMap.get(num) || 0) + 1);
    }

    // 2. 按频率分桶
    // bucket[i] 存储频率为i的元素列表
    const bucket: number[][] = Array(n + 1).fill(0).map(() => []);

    for (const [num, freq] of freqMap) {
        bucket[freq].push(num);
    }

    // 3. 从高频到低频收集k个元素
    const result: number[] = [];

    for (let freq = n; freq >= 1 && result.length < k; freq--) {
        if (bucket[freq].length > 0) {
            result.push(...bucket[freq]);
        }
    }

    // 可能收集了超过k个（同频率的元素）
    return result.slice(0, k);
}
```

### 方法三：排序（不满足进阶要求）

```typescript
function topKFrequent(nums: number[], k: number): number[] {
    // 1. 统计频率
    const freqMap = new Map<number, number>();
    for (const num of nums) {
        freqMap.set(num, (freqMap.get(num) || 0) + 1);
    }

    // 2. 转换为数组并排序
    const freqArray = Array.from(freqMap.entries());
    freqArray.sort((a, b) => b[1] - a[1]);  // 按频率降序

    // 3. 取前k个
    return freqArray.slice(0, k).map(item => item[0]);
}

// 时间复杂度：O(nlogn)
// 不满足进阶要求
```

### 方法四：快速选择

```typescript
function topKFrequent(nums: number[], k: number): number[] {
    // 1. 统计频率
    const freqMap = new Map<number, number>();
    for (const num of nums) {
        freqMap.set(num, (freqMap.get(num) || 0) + 1);
    }

    // 2. 转换为数组
    const unique = Array.from(freqMap.keys());
    const n = unique.length;

    /**
     * 快速选择：找到第k大频率的分界线
     */
    function quickSelect(left: number, right: number, targetIndex: number): void {
        if (left === right) return;

        // 随机pivot
        const randomIndex = left + Math.floor(Math.random() * (right - left + 1));
        [unique[randomIndex], unique[right]] = [unique[right], unique[randomIndex]];

        // 分区（按频率）
        const pivotIndex = partition(left, right);

        if (pivotIndex === targetIndex) {
            return;
        } else if (pivotIndex < targetIndex) {
            quickSelect(pivotIndex + 1, right, targetIndex);
        } else {
            quickSelect(left, pivotIndex - 1, targetIndex);
        }
    }

    /**
     * 分区：按频率降序
     */
    function partition(left: number, right: number): number {
        const pivotFreq = freqMap.get(unique[right])!;
        let i = left;

        for (let j = left; j < right; j++) {
            // 频率 > pivot（降序）
            if (freqMap.get(unique[j])! > pivotFreq) {
                [unique[i], unique[j]] = [unique[j], unique[i]];
                i++;
            }
        }

        [unique[i], unique[right]] = [unique[right], unique[i]];
        return i;
    }

    // 3. 快速选择找到第k-1个位置
    quickSelect(0, n - 1, k - 1);

    // 4. 返回前k个
    return unique.slice(0, k);
}
```

## 代码原理详解

### 小顶堆方法

**1. 为什么维护大小为k的堆？**
```typescript
堆大小 = k：
- 堆中始终保持频率最高的k个元素
- 堆顶是第k高频（最小的）
- 新元素只需与堆顶比较

如果堆大小 = n：
- 需要对所有元素排序
- 时间O(nlogn)
```

**2. 频率比较：**
```typescript
if (freq > minHeap[0][1]) {
    pop();
    push([num, freq]);
}

新元素频率 > 堆顶频率：
- 说明新元素更高频
- 替换堆顶（第k高频）
- 保持堆大小为k
```

### 桶排序方法

**1. 桶的索引 = 频率：**
```typescript
bucket[freq].push(num);

bucket[5] = [元素A, 元素B]
表示：元素A和B的频率都是5

频率范围：1 到 n
因此需要n+1个桶
```

**2. 从高到低遍历：**
```typescript
for (let freq = n; freq >= 1; freq--) {
    result.push(...bucket[freq]);
}

从频率n开始，逐渐降低
收集k个元素后停止
```

## 运行示例

### 示例 1：`nums = [1,1,1,2,2,3], k = 2`

**堆方法执行过程：**

```
1. 统计频率：
   freqMap = {1: 3, 2: 2, 3: 1}

2. 建堆（k=2）：
   (1, 3): heap=[(1,3)]
   (2, 2): heap=[(2,2), (1,3)]  // 小顶堆，堆顶是(2,2)
   (3, 1): 1 < 2，不入堆

3. 返回：[2, 1] 或 [1, 2] ✓
```

**桶排序执行过程：**

```
1. 统计频率：
   freqMap = {1: 3, 2: 2, 3: 1}

2. 分桶：
   bucket[1] = [3]
   bucket[2] = [2]
   bucket[3] = [1]

3. 从高到低收集：
   freq=6: []
   freq=5: []
   freq=4: []
   freq=3: [1] → result=[1]
   freq=2: [2] → result=[1,2]
   收集够k=2个，停止

4. 返回：[1, 2] ✓
```

---

### 示例 2：`nums = [4,1,-1,2,-1,2,3], k = 2`

**执行过程：**

```
1. 统计频率：
   freqMap = {4:1, 1:1, -1:2, 2:2, 3:1}

2. 桶排序：
   bucket[1] = [4, 1, 3]
   bucket[2] = [-1, 2]

3. 从高到低收集：
   freq=2: [-1, 2] → result=[-1, 2]
   收集够k=2个

4. 返回：[-1, 2] ✓
```

## 常见问题

**Q1: 为什么桶排序是O(n)？**
A: 每个操作都是O(n)：
```
统计频率：O(n)
分桶：O(m)，m是不同元素个数，m≤n
收集：O(n)（最坏情况遍历所有桶）

总时间：O(n)
```

**Q2: 堆方法为什么不是O(n)？**
A: 堆操作是O(logk)：
```
遍历m个不同元素：O(m)
每个元素的堆操作：O(logk)
总时间：O(mlogk)

当m接近n时，O(nlogk)
```

**Q3: 何时选择堆，何时选择桶排序？**
A:
```
桶排序：
- 理论最优O(n)
- 但需要额外O(n)空间
- 适合在线面试

堆：
- O(nlogk)
- 代码实现更直观
- 面试更推荐（易理解）

快速选择：
- O(n)平均
- 会修改数据
- 代码复杂
```

**Q4: 如果k很大怎么办？**
A:
```
k接近n：
- 桶排序：O(n)
- 堆：O(nlogk)，k大时logk也大
- 快速选择：O(n)

建议：
- k < n/2：堆
- k >= n/2：可以找频率最低的n-k个（大顶堆）
```

**Q5: 返回顺序有要求吗？**
A: 题目说"任意顺序"：
```
不需要按频率排序
只需要包含频率最高的k个元素

因此桶排序收集时可以直接push
不需要额外排序
```

## 复杂度分析

### 小顶堆

**时间复杂度：** O(nlogk)
- 统计频率：O(n)
- m个不同元素，每个O(logk)：O(mlogk)
- m ≤ n，所以O(nlogk)

**空间复杂度：** O(n)
- Map：O(m)
- 堆：O(k)
- 总计：O(n)

### 桶排序

**时间复杂度：** O(n)
- 统计频率：O(n)
- 分桶：O(m)
- 收集：O(n)
- 总计：O(n)

**空间复杂度：** O(n)
- Map：O(m)
- 桶数组：O(n)

### 快速选择

**时间复杂度：** O(n) 平均，O(n^2) 最坏

**空间复杂度：** O(n)

## 总结

**关键点：**
1. 先统计频率（HashMap）
2. 堆方法：维护大小为k的小顶堆
3. 桶排序：按频率分桶，从高到低收集
4. 桶排序理论最优O(n)，但堆方法更易实现

**堆方法模板（Top K频率）：**
```typescript
// 1. 统计频率
const freqMap = new Map<number, number>();
for (const num of nums) {
    freqMap.set(num, (freqMap.get(num) || 0) + 1);
}

// 2. 小顶堆
const minHeap: [number, number][] = [];

// 3. 维护大小为k
for (const [num, freq] of freqMap) {
    if (minHeap.length < k) {
        push([num, freq]);
    } else if (freq > minHeap[0][1]) {
        pop();
        push([num, freq]);
    }
}

// 4. 返回堆中元素
return minHeap.map(item => item[0]);
```

**面试建议：**
- 优先说明堆方法（最实用）
- 解释为什么用小顶堆
- 可以补充桶排序（理论最优）
- 分析不同方法的适用场景
- 提及快速选择（如果时间充裕）

**易错点：**
- 统计频率时忘记初始化
- 堆的大小维护错误
- 桶排序的桶大小（n+1）
- 收集元素时超过k个（同频率）
- 堆中存储什么（元素还是[元素,频率]）

**记忆技巧：**
- Top K频率 = 先统计 + 再排序（堆/桶）
- 小顶堆 = 保留最大的k个，堆顶是第k大
- 桶排序 = 频率作索引，O(n)
- 堆O(nlogk)，桶O(n)
