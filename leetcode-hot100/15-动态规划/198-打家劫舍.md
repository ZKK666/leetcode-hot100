# 198. 打家劫舍【中等】

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

---

## 输入输出示例

### 示例 1
```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

### 示例 2
```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

### 提示
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题约束：**
```
不能偷相邻的房屋

对于第i个房屋：
- 偷：不能偷第i-1个，可以偷第i-2个
- 不偷：可以偷第i-1个

选择能获得最大金额的方案
```

**状态转移：**
```
dp[i] = 偷到第i个房屋时的最大金额

两种选择：
1. 偷第i个：dp[i] = dp[i-2] + nums[i]
2. 不偷第i个：dp[i] = dp[i-1]

取最大值：
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

**初始状态：**
```
dp[0] = nums[0]（只有1个房屋）
dp[1] = max(nums[0], nums[1])（选较大的）
```

---

### 方法一：动态规划（空间优化）

**核心思想：**
- dp[i] 只依赖 dp[i-1] 和 dp[i-2]
- 使用两个变量滚动更新

**算法流程：**

1. **初始化：**
   - prev2 = 0（没有房屋时）
   - prev1 = nums[0]（第1个房屋）

2. **状态转移：**
   - current = max(prev1, prev2 + nums[i])
   - 滚动更新：prev2 = prev1, prev1 = current

3. **返回 prev1**

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法二：动态规划（数组）

**核心思想：**
- 使用数组保存所有状态

**时间复杂度：** O(n)
**空间复杂度：** O(n)

---

## 代码实现（TypeScript）

### 方法一：动态规划（空间优化，推荐）

```typescript
function rob(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;
    if (n === 1) return nums[0];

    // 滚动变量
    let prev2 = 0;           // dp[i-2]
    let prev1 = nums[0];     // dp[i-1]

    for (let i = 1; i < n; i++) {
        // 当前状态：偷或不偷第i个房屋
        const current = Math.max(prev1, prev2 + nums[i]);

        // 滚动更新
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}
```

---

### 方法一优化：解构赋值

```typescript
function rob(nums: number[]): number {
    let [prev2, prev1] = [0, 0];

    for (const num of nums) {
        [prev2, prev1] = [prev1, Math.max(prev1, prev2 + num)];
    }

    return prev1;
}
```

---

### 方法二：动态规划（数组）

```typescript
function rob(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;
    if (n === 1) return nums[0];

    const dp: number[] = Array(n);
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);

    for (let i = 2; i < n; i++) {
        dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
    }

    return dp[n - 1];
}

// 空间复杂度：O(n)
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
dp[i] = 从前i+1个房屋中能偷到的最大金额

注意：dp[i]不是"必须偷第i个"
而是"考虑到第i个房屋为止"
```

**2. 状态转移方程：**
```typescript
dp[i] = max(dp[i-1], dp[i-2] + nums[i])

解释：
- dp[i-1]：不偷第i个房屋，最大金额 = dp[i-1]
- dp[i-2] + nums[i]：偷第i个房屋，最大金额 = dp[i-2] + nums[i]

为什么偷第i个时是dp[i-2]？
因为不能偷相邻的，所以只能从i-2转移
```

**3. 为什么是max？**
```
贪心选择：
在每个位置，选择金额更大的方案

偷 vs 不偷：
比较两种方案，选最优的
```

**4. 空间优化：**
```typescript
// 未优化
const dp = Array(n);
dp[i] = max(dp[i-1], dp[i-2] + nums[i]);

// 优化
只需要保存前两个状态
let prev2 = dp[i-2];
let prev1 = dp[i-1];
let current = max(prev1, prev2 + nums[i]);

滚动更新：
prev2 = prev1;
prev1 = current;
```

## 运行示例

### 示例 1：`nums = [1,2,3,1]`

**执行过程：**

```
初始：prev2=0, prev1=0

i=0, nums[0]=1：
  current = max(0, 0+1) = 1
  prev2=0, prev1=1

i=1, nums[1]=2：
  current = max(1, 0+2) = 2
  prev2=1, prev1=2

i=2, nums[2]=3：
  current = max(2, 1+3) = 4
  prev2=2, prev1=4

i=3, nums[3]=1：
  current = max(4, 2+1) = 4
  prev2=4, prev1=4

返回：4 ✓

方案：偷第0个(1) + 偷第2个(3) = 4
```

**决策过程：**
```
房屋：[1, 2, 3, 1]
索引： 0  1  2  3

i=0: 偷0，金额=1
i=1: 不偷0，偷1，金额=2
i=2: 偷0+偷2 vs 偷1 → 4 vs 2 → 选4
i=3: 偷0+偷2 vs 偷1+偷3 → 4 vs 3 → 选4
```

---

### 示例 2：`nums = [2,7,9,3,1]`

**执行过程：**

```
i=0: prev1=2
i=1: current=max(2, 0+7)=7, prev1=7
i=2: current=max(7, 2+9)=11, prev1=11
i=3: current=max(11, 7+3)=11, prev1=11
i=4: current=max(11, 11+1)=12, prev1=12

返回：12 ✓

方案：偷0(2) + 偷2(9) + 偷4(1) = 12
```

## 常见问题

**Q1: 为什么dp[1] = max(nums[0], nums[1])？**
A: 只有两个房屋时：
```
不能同时偷两个（相邻）
只能选一个

选金额更大的
```

**Q2: 能否用贪心？**
A: 不能：
```
贪心策略：每次选最大的
反例：[2, 1, 1, 2]

贪心：选2和2 = 4
最优：选1和1 = 2？不对
最优：选2和2 = 4

其实这个例子贪心对了

真正反例：[2, 7, 9, 3, 1]
贪心可能：先选9，然后不能选7和3
但最优是：2 + 9 + 1 = 12

贪心思路不清晰，DP更可靠
```

**Q3: 这题和爬楼梯的区别？**
A: 状态定义不同：
```
爬楼梯：
f(n) = f(n-1) + f(n-2)
累加方案数

打家劫舍：
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
选择最优方案

都是DP，但转移方程不同
```

**Q4: 如果要输出具体方案怎么办？**
A: 记录选择：
```typescript
function rob(nums: number[]): number[] {
    const n = nums.length;
    const dp: number[] = Array(n);
    const choice: boolean[] = Array(n);  // 记录是否偷第i个

    dp[0] = nums[0];
    choice[0] = true;

    dp[1] = Math.max(nums[0], nums[1]);
    choice[1] = nums[1] > nums[0];

    for (let i = 2; i < n; i++) {
        if (dp[i-1] > dp[i-2] + nums[i]) {
            dp[i] = dp[i-1];
            choice[i] = false;  // 不偷
        } else {
            dp[i] = dp[i-2] + nums[i];
            choice[i] = true;   // 偷
        }
    }

    // 回溯找方案
    const result: number[] = [];
    for (let i = n - 1; i >= 0; i--) {
        if (choice[i]) {
            result.push(i);
            i--;  // 跳过相邻的
        }
    }

    return result.reverse();
}
```

**Q5: 房屋围成圈怎么办？**
A: 那是213题：
```
房屋围成圈：
第1个和最后一个相邻

解法：
分两种情况：
1. 偷第1个，不偷最后一个：rob(nums[0...n-2])
2. 不偷第1个，偷最后一个：rob(nums[1...n-1])

取最大值
```

## 总结

**关键点：**
1. 状态定义：dp[i] = 考虑到第i个房屋的最大金额
2. 状态转移：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
3. 空间优化：只保存两个状态
4. 贪心选择：偷或不偷，选最优

**DP模板（打家劫舍）：**
```typescript
let prev2 = 0;
let prev1 = 0;

for (const num of nums) {
    const current = Math.max(prev1, prev2 + num);
    prev2 = prev1;
    prev1 = current;
}

return prev1;
```

**易错点：**
- dp[1]的初始化（要取max）
- 状态转移理解错误

- 边界情况：0个、1个、2个房屋
- 理解为"必须偷第i个"（错误）

**记忆技巧：**
- 打家劫舍 = 不相邻的最大和
- dp[i] = max(不偷, 偷)
- 不偷 = dp[i-1]
- 偷 = dp[i-2] + nums[i]
- 空间优化 = 两个变量滚动
