# 139. 单词拆分【中等】

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` ，则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

---

## 输入输出示例

### 示例 1
```
输入: s = "leetcode", wordDict = ["leet","code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

### 示例 2
```
输入: s = "applepenapple", wordDict = ["apple","pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

### 示例 3
```
输入: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出: false
```

### 提示
- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串**互不相同**

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
判断字符串s能否由字典中的单词拼接而成

关键：
- 单词可以重复使用
- 单词可以任意组合

类似完全背包问题
```

**状态转移：**
```
dp[i] = s[0...i-1]能否由字典中的单词拼接

对于位置i：
枚举所有j（0 <= j < i）
如果dp[j] = true 且 s[j...i-1]在字典中：
  dp[i] = true

换句话说：
如果前j个字符可以拼接（dp[j]=true）
且s[j...i-1]是一个单词
那么前i个字符也可以拼接（dp[i]=true）
```

**初始状态：**
```
dp[0] = true（空字符串可以拼接）
```

---

### 方法一：动态规划（推荐）

**核心思想：**
- dp[i] 表示s的前i个字符能否拼接
- 枚举所有分割点，检查左右两部分

**算法流程：**

1. **初始化：**
   - dp[0] = true
   - 将wordDict转为Set（快速查找）

2. **状态转移：**
   - 对于每个i（1到n）：
     - 枚举所有j（0到i-1）：
       - 如果 dp[j] && s[j...i-1]在字典中：
         - dp[i] = true
         - break

3. **返回 dp[n]**

**时间复杂度：** O(n² × m)，n是s长度，m是单词平均长度
**空间复杂度：** O(n)

---

### 方法二：记忆化递归

**核心思想：**
- 递归检查字符串能否拆分
- 使用memo记录已计算的结果

**时间复杂度：** O(n² × m)
**空间复杂度：** O(n)

---

## 代码实现（TypeScript）

### 方法一：动态规划（推荐）

```typescript
function wordBreak(s: string, wordDict: string[]): boolean {
    const n = s.length;
    const wordSet = new Set(wordDict);  // 转为Set，快速查找

    // dp[i] = s的前i个字符能否由字典拼接
    const dp: boolean[] = Array(n + 1).fill(false);
    dp[0] = true;  // 空字符串可以拼接

    // 遍历字符串的每个位置
    for (let i = 1; i <= n; i++) {
        // 枚举分割点j
        for (let j = 0; j < i; j++) {
            // s[0...j-1]可以拼接 且 s[j...i-1]在字典中
            if (dp[j] && wordSet.has(s.substring(j, i))) {
                dp[i] = true;
                break;  // 找到一种方案即可
            }
        }
    }

    return dp[n];
}
```

### 方法一优化：剪枝

```typescript
function wordBreak(s: string, wordDict: string[]): boolean {
    const n = s.length;
    const wordSet = new Set(wordDict);

    // 找到单词的最大长度（剪枝优化）
    let maxLen = 0;
    for (const word of wordDict) {
        maxLen = Math.max(maxLen, word.length);
    }

    const dp: boolean[] = Array(n + 1).fill(false);
    dp[0] = true;

    for (let i = 1; i <= n; i++) {
        // 只需要检查长度 <= maxLen 的子串
        for (let j = Math.max(0, i - maxLen); j < i; j++) {
            if (dp[j] && wordSet.has(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }

    return dp[n];
}
```

### 方法二：记忆化递归

```typescript
function wordBreak(s: string, wordDict: string[]): boolean {
    const wordSet = new Set(wordDict);
    const memo: Map<number, boolean> = new Map();

    /**
     * 检查s[start...]能否由字典拼接
     */
    function canBreak(start: number): boolean {
        // base case
        if (start === s.length) {
            return true;
        }

        // 记忆化
        if (memo.has(start)) {
            return memo.get(start)!;
        }

        // 枚举结束位置
        for (let end = start + 1; end <= s.length; end++) {
            const word = s.substring(start, end);

            // s[start...end-1]在字典中 且 s[end...]可以拼接
            if (wordSet.has(word) && canBreak(end)) {
                memo.set(start, true);
                return true;
            }
        }

        memo.set(start, false);
        return false;
    }

    return canBreak(0);
}
```

### 方法三：BFS

```typescript
function wordBreak(s: string, wordDict: string[]): boolean {
    const wordSet = new Set(wordDict);
    const queue: number[] = [0];  // 存储起始位置
    const visited: Set<number> = new Set([0]);

    while (queue.length > 0) {
        const start = queue.shift()!;

        // 已经到达字符串末尾
        if (start === s.length) {
            return true;
        }

        // 尝试所有可能的结束位置
        for (let end = start + 1; end <= s.length; end++) {
            const word = s.substring(start, end);

            if (wordSet.has(word) && !visited.has(end)) {
                visited.add(end);
                queue.push(end);
            }
        }
    }

    return false;
}
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
dp[i] = s的前i个字符（s[0...i-1]）能否由字典拼接

注意：
dp[i]对应s[0...i-1]（i个字符）
不是s[0...i]
```

**2. 状态转移方程：**
```typescript
dp[i] = dp[j] && s[j...i-1]在字典中
        for any j in [0, i)

解释：
如果s[0...i-1]可以拼接：
存在某个分割点j，使得：
- s[0...j-1]可以拼接（dp[j]=true）
- s[j...i-1]是字典中的单词

示意图：
s: [0...j-1] [j...i-1]
    ↑         ↑
  dp[j]=true  单词
```

**3. 为什么dp[0] = true？**
```
dp[0]表示前0个字符（空字符串）

空字符串可以由0个单词拼接
因此dp[0] = true

这是递推的起点
```

**4. 为什么用substring(j, i)？**
```typescript
s.substring(j, i) = s[j...i-1]

包含j，不包含i
长度为 i - j

例如：s = "leetcode"
substring(0, 4) = "leet"（下标0到3）
substring(4, 8) = "code"（下标4到7）
```

## 常见问题

**Q1: 为什么不用贪心？**
A: 贪心可能错过最优解：
```
s = "aaaaaaa", wordDict = ["aaaa", "aaa"]

贪心（优先匹配长的）：
"aaaa" + "aaa"？ 7 = 4 + 3 ✓
似乎可行

但如果wordDict = ["aaaa", "aa"]：
贪心："aaaa" + ???
剩下"aaa"无法匹配

最优："aa" + "aa" + "aa" + "a"？
也不行

DP能正确处理所有情况
```

**Q2: 为什么要用Set？**
A: 快速查找：
```
数组查找：O(m)，m是字典大小
Set查找：O(1)

总时间复杂度：
数组：O(n² × m)
Set：O(n²)（忽略substring）

Set更优
```

**Q3: 能否从后往前DP？**
A: 可以：
```typescript
const dp: boolean[] = Array(n + 1).fill(false);
dp[n] = true;  // 空字符串

for (let i = n - 1; i >= 0; i--) {
    for (let j = i + 1; j <= n; j++) {
        if (dp[j] && wordSet.has(s.substring(i, j))) {
            dp[i] = true;
            break;
        }
    }
}

return dp[0];
```

**Q4: substring的时间复杂度？**
A: O(长度)：
```
s.substring(j, i)创建新字符串
时间：O(i - j)

总时间复杂度：
O(n²) × O(平均单词长度) = O(n² × m)

优化：
可以用哈希+前缀匹配
但实现复杂，通常不必要
```

**Q5: 如果要输出所有拆分方案怎么办？**
A: 那是140题：
```
140. 单词拆分 II（困难）

需要回溯记录所有方案
不是简单的DP
```

## 复杂度分析

**时间复杂度：** O(n² × m)
- 外层循环：n
- 内层循环：n
- substring操作：O(m)，m是单词平均长度
- 总计：O(n² × m)

**优化后：** O(n × maxLen)
- maxLen是最长单词长度
- 内层循环最多maxLen次

**空间复杂度：** O(n + k)
- dp数组：O(n)
- wordSet：O(k)，k是字典大小

## 总结

**关键点：**
1. 动态规划（完全背包变体）
2. 状态定义：dp[i] = 前i个字符能否拼接
3. 状态转移：枚举分割点
4. 使用Set优化查找
5. 剪枝：最多检查maxLen长度

**DP模板（单词拆分）：**
```typescript
const wordSet = new Set(wordDict);
const dp: boolean[] = Array(n + 1).fill(false);
dp[0] = true;

for (let i = 1; i <= n; i++) {
    for (let j = 0; j < i; j++) {
        if (dp[j] && wordSet.has(s.substring(j, i))) {
            dp[i] = true;
            break;
        }
    }
}

return dp[n];
```
