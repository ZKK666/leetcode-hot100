# 279. 完全平方数【中等】

## 题目描述

给你一个整数 `n` ，返回 **和为 `n` 的完全平方数的最少数量** 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

---

## 输入输出示例

### 示例 1
```
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4
```

### 示例 2
```
输入：n = 13
输出：2
解释：13 = 4 + 9
```

### 提示
- `1 <= n <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
最少用几个完全平方数相加得到n？

完全平方数：1, 4, 9, 16, 25, ...

类似于：零钱兑换问题
- 完全平方数 = "硬币"
- n = "目标金额"
- 求最少硬币数
```

**状态转移：**
```
dp[i] = 和为i的最少完全平方数数量

对于数字i：
枚举所有小于等于√i的完全平方数j²
dp[i] = min(dp[i - j²] + 1)

例如：dp[12]
- 用1²：dp[12] = dp[12-1] + 1 = dp[11] + 1
- 用2²：dp[12] = dp[12-4] + 1 = dp[8] + 1
- 用3²：dp[12] = dp[12-9] + 1 = dp[3] + 1

取最小值
```

---

### 方法一：动态规划（推荐）

**核心思想：**
- dp[i] 表示和为i的最少完全平方数数量
- 枚举所有可能的完全平方数

**算法流程：**

1. **初始化：**
   - dp[0] = 0
   - dp[i] = ∞（i > 0）

2. **状态转移：**
   - 对于每个i（1到n）：
     - 枚举所有j，满足j² <= i
     - dp[i] = min(dp[i], dp[i - j²] + 1)

3. **返回 dp[n]**

**时间复杂度：** O(n√n)
**空间复杂度：** O(n)

---

### 方法二：BFS

**核心思想：**
- 将问题看作图的最短路径
- 每个数字是一个节点
- 减去完全平方数到达新节点
- 第一次到达n的层数 = 最少数量

**时间复杂度：** O(n√n)
**空间复杂度：** O(n)

---

### 方法三：数学定理（进阶）

**四平方和定理：**
```
任何正整数都可以表示为至多4个完全平方数之和

答案只可能是：1, 2, 3, 4

判断：
- 答案=1：n是完全平方数
- 答案=4：n = 4^k × (8m + 7)
- 答案=2：遍历检查
- 其他：答案=3
```

## 代码实现（TypeScript）

### 方法一：动态规划（推荐）

```typescript
function numSquares(n: number): number {
    // dp[i] = 和为i的最少完全平方数数量
    const dp: number[] = Array(n + 1).fill(Infinity);
    dp[0] = 0;

    // 预计算所有完全平方数
    const squares: number[] = [];
    for (let i = 1; i * i <= n; i++) {
        squares.push(i * i);
    }

    // 动态规划
    for (let i = 1; i <= n; i++) {
        // 枚举所有完全平方数
        for (const square of squares) {
            if (square > i) break;
            dp[i] = Math.min(dp[i], dp[i - square] + 1);
        }
    }

    return dp[n];
}
```

### 方法一优化：在线计算

```typescript
function numSquares(n: number): number {
    const dp: number[] = Array(n + 1).fill(Infinity);
    dp[0] = 0;

    for (let i = 1; i <= n; i++) {
        // 枚举所有j，使得j² <= i
        for (let j = 1; j * j <= i; j++) {
            dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
        }
    }

    return dp[n];
}
```

### 方法二：BFS

```typescript
function numSquares(n: number): number {
    // 预计算完全平方数
    const squares: number[] = [];
    for (let i = 1; i * i <= n; i++) {
        squares.push(i * i);
    }

    // BFS
    const queue: number[] = [n];
    const visited: Set<number> = new Set([n]);
    let level = 0;

    while (queue.length > 0) {
        level++;
        const size = queue.length;

        for (let i = 0; i < size; i++) {
            const current = queue.shift()!;

            // 尝试减去每个完全平方数
            for (const square of squares) {
                const next = current - square;

                if (next === 0) {
                    // 找到答案
                    return level;
                }

                if (next > 0 && !visited.has(next)) {
                    visited.add(next);
                    queue.push(next);
                }
            }
        }
    }

    return level;
}
```

### 方法三：数学定理（四平方和定理）

```typescript
function numSquares(n: number): number {
    /**
     * 判断是否为完全平方数
     */
    function isSquare(n: number): boolean {
        const sqrt = Math.floor(Math.sqrt(n));
        return sqrt * sqrt === n;
    }

    // 答案=1：n本身是完全平方数
    if (isSquare(n)) {
        return 1;
    }

    // 答案=4：n = 4^k × (8m + 7)
    let temp = n;
    while (temp % 4 === 0) {
        temp /= 4;
    }
    if (temp % 8 === 7) {
        return 4;
    }

    // 答案=2：n = a² + b²
    for (let i = 1; i * i <= n; i++) {
        if (isSquare(n - i * i)) {
            return 2;
        }
    }

    // 其他情况：答案=3
    return 3;
}
```

## 代码原理详解

### 动态规划方法

**1. 状态定义：**
```typescript
dp[i] = 和为i的最少完全平方数数量

base case:
dp[0] = 0（和为0，不需要任何数）
```

**2. 状态转移：**
```typescript
dp[i] = min(dp[i - j²] + 1)  for all j where j² <= i

对于数字i：
可以由 i - j² 加上一个完全平方数j²得到

例如：dp[12]
- 12 = 11 + 1²：dp[12] = dp[11] + 1
- 12 = 8 + 2²：dp[12] = dp[8] + 1
- 12 = 3 + 3²：dp[12] = dp[3] + 1

取最小值
```

**3. 为什么是完全背包？**
```
类似于零钱兑换（完全背包）

物品：完全平方数（可重复使用）
背包容量：n
目标：装满背包的最少物品数

状态转移：
dp[i] = min(dp[i - square] + 1)
```

## 运行示例

### 示例 1：`n = 12`

**执行过程：**

```
初始：dp = [0, ∞, ∞, ..., ∞]

完全平方数：1, 4, 9

计算dp[1]到dp[12]：

dp[1] = dp[0] + 1 = 1（1=1²）
dp[2] = dp[1] + 1 = 2（2=1²+1²）
dp[3] = dp[2] + 1 = 3（3=1²+1²+1²）
dp[4] = dp[0] + 1 = 1（4=2²）

dp[5] = min(dp[4]+1, dp[1]+1) = min(2,2) = 2
dp[6] = min(dp[5]+1, dp[2]+1) = min(3,3) = 3
dp[7] = min(dp[6]+1, dp[3]+1) = min(4,4) = 4
dp[8] = min(dp[7]+1, dp[4]+1) = min(5,2) = 2
dp[9] = min(dp[8]+1, dp[5]+1, dp[0]+1) = min(3,3,1) = 1

dp[10] = min(dp[9]+1, dp[6]+1, dp[1]+1) = min(2,4,2) = 2
dp[11] = min(dp[10]+1, dp[7]+1, dp[2]+1) = min(3,5,3) = 3
dp[12] = min(dp[11]+1, dp[8]+1, dp[3]+1) = min(4,3,4) = 3

返回：3 ✓

方案：12 = 4 + 4 + 4
```

## 常见问题

**Q1: 为什么不用贪心？**
A: 贪心不一定最优：
```
n = 12

贪心：
先选最大的9：12 - 9 = 3
再选1: 3 - 1 - 1 - 1 = 0
总共4个：9 + 1 + 1 + 1

最优：
12 = 4 + 4 + 4
只需3个

贪心错误！
```

**Q2: 这题和零钱兑换的区别？**
A: 基本相同：
```
零钱兑换：
- 硬币面额：给定的coins数组
- 求最少硬币数

完全平方数：
- "硬币面额"：所有完全平方数
- 求最少"硬币"数

都是完全背包问题
```

**Q3: BFS为什么也能解决？**
A: 最短路径：
```
将问题看作图：
- 每个数字是节点
- 减去完全平方数 = 边

例如：n=12
12 → 11（-1²）
12 → 8（-2²）
12 → 3（-3²）

BFS找到0的最短路径
= 最少完全平方数数量
```

**Q4: 四平方和定理为什么正确？**
A: 数学定理：
```
拉格朗日四平方和定理：
任何正整数都可表示为至多4个完全平方数之和

证明复杂，这里直接应用

实际应用：
- 答案=1：n是完全平方数
- 答案=4：n = 4^k × (8m+7)（勒让德定理）
- 答案=2：遍历检查n = a² + b²
- 其他：答案=3
```

**Q5: 哪种方法最好？**
A:
```
DP：
- 通用性强
- 容易理解
- 面试推荐 ✓

BFS：
- 空间可能更优（早停）
- 概念清晰

数学定理：
- 时间O(√n)，最快
- 但需要记忆定理
- 面试不一定适用
```

## 复杂度分析

### 动态规划

**时间复杂度：** O(n√n)
- 外层循环：n
- 内层循环：√n（枚举完全平方数）
- 总计：O(n√n)

**空间复杂度：** O(n)
- dp数组

### BFS

**时间复杂度：** O(n√n)
- 最坏情况访问所有节点
- 每个节点枚举√n个完全平方数

**空间复杂度：** O(n)
- 队列和visited集合

### 数学定理

**时间复杂度：** O(√n)
- 检查是否为完全平方数：O(1)
- 检查答案=2：O(√n)

**空间复杂度：** O(1)
