# 416. 分割等和子集【中等】

## 题目描述

给你一个**只包含正整数**的**非空**数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。
```

### 示例 2
```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

### 提示
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题转换：**
```
分割成两个和相等的子集

等价于：
找一个子集，和 = sum / 2

条件：
1. sum必须是偶数
2. 存在子集，和 = target = sum / 2

这是经典的01背包问题！
```

**01背包：**
```
物品：nums中的每个数字
背包容量：target = sum / 2
每个物品只能用一次（01）

问题：能否装满背包？

dp[i] = 能否凑出和为i

状态转移：
dp[i] = dp[i] || dp[i - num]
```

---

### 方法：动态规划（01背包）

**核心思想：**
- dp[i] 表示是否能凑出和为i
- 枚举每个数字，更新状态

**算法流程：**

1. **预处理：**
   - 计算sum
   - 如果sum为奇数，返回false
   - target = sum / 2

2. **初始化：**
   - dp[0] = true（和为0可以凑出：不选任何数）
   - dp[i] = false（i > 0）

3. **状态转移：**
   - 对于每个num：
     - 从target到num，倒序遍历：
       - dp[i] = dp[i] || dp[i - num]

4. **返回 dp[target]**

**时间复杂度：** O(n × target)
**空间复杂度：** O(target)

---

## 代码实现（TypeScript）

### 方法：01背包（推荐）

```typescript
function canPartition(nums: number[]): boolean {
    // 1. 计算总和
    const sum = nums.reduce((a, b) => a + b, 0);

    // 2. 如果总和是奇数，无法分割
    if (sum % 2 !== 0) {
        return false;
    }

    const target = sum / 2;

    // 3. 01背包：dp[i] = 能否凑出和为i
    const dp: boolean[] = Array(target + 1).fill(false);
    dp[0] = true;  // 和为0可以凑出（不选任何数）

    // 4. 遍历每个数字
    for (const num of nums) {
        // 从大到小遍历（01背包，避免重复使用）
        for (let i = target; i >= num; i--) {
            dp[i] = dp[i] || dp[i - num];
        }
    }

    return dp[target];
}
```

### 方法优化：提前剪枝

```typescript
function canPartition(nums: number[]): boolean {
    const sum = nums.reduce((a, b) => a + b, 0);

    if (sum % 2 !== 0) return false;

    const target = sum / 2;

    // 剪枝：如果最大值 > target，无法分割
    const maxNum = Math.max(...nums);
    if (maxNum > target) return false;

    const dp: boolean[] = Array(target + 1).fill(false);
    dp[0] = true;

    for (const num of nums) {
        for (let i = target; i >= num; i--) {
            dp[i] = dp[i] || dp[i - num];

            // 提前返回
            if (dp[target]) {
                return true;
            }
        }
    }

    return dp[target];
}
```

### 方法：使用Set（空间换时间）

```typescript
function canPartition(nums: number[]): boolean {
    const sum = nums.reduce((a, b) => a + b, 0);

    if (sum % 2 !== 0) return false;

    const target = sum / 2;
    let possibleSums = new Set<number>([0]);

    for (const num of nums) {
        const newSums = new Set<number>();

        for (const s of possibleSums) {
            if (s + num === target) {
                return true;
            }
            newSums.add(s + num);
        }

        // 合并
        possibleSums = new Set([...possibleSums, ...newSums]);
    }

    return possibleSums.has(target);
}
```

## 代码原理详解

### 01背包原理

**1. 为什么是01背包？**
```
01背包特点：
- 每个物品只能用一次
- 背包容量有限

本题：
- 每个数字只能选一次
- 目标和 = target = sum / 2

完美匹配01背包模型
```

**2. 状态定义：**
```typescript
dp[i] = 是否能凑出和为i

base case:
dp[0] = true（不选任何数，和为0）
```

**3. 状态转移方程：**
```typescript
dp[i] = dp[i] || dp[i - num]

解释：
凑出和i，有两种方式：
1. 不选num：dp[i]（之前就能凑出）
2. 选num：dp[i - num]（之前能凑出i-num）

只要有一种方式能凑出，dp[i] = true
```

**4. 为什么倒序遍历？**
```typescript
for (let i = target; i >= num; i--) {
    dp[i] = dp[i] || dp[i - num];
}

01背包：每个物品只能用一次

如果正序：
dp[num] = dp[0] = true（选了num）
dp[2*num] = dp[num] = true（又选了num）
错误！num被用了两次

倒序：
dp[2*num] = dp[2*num - num] = dp[num]（旧值）
dp[num] = dp[0]（旧值）
正确！每个num只用一次

完全背包正序，01背包倒序
```

**5. 为什么从target开始？**
```
只关心 dp[0] 到 dp[target]
大于target的状态没有意义

优化：只遍历到target
```

## 常见问题

**Q1: 为什么转换成01背包？**
A: 问题等价：
```
分割成两个和相等的子集

等价于：
找一个子集，和 = sum / 2

这就是背包问题：
- 物品：数字
- 背包容量：target
- 能否装满？
```

**Q2: 01背包和完全背包的区别？**
A:
```
01背包：
- 每个物品只能用一次
- 倒序遍历

完全背包：
- 每个物品可以无限次使用
- 正序遍历

本题：01背包
每个数字只能选一次
```

**Q3: 为什么dp[0] = true？**
A: 初始状态：
```
dp[0] = 和为0能否凑出？

能：不选任何数，和就是0

这是递推的起点
```

**Q4: 时间复杂度为什么是O(n×target)？**
A:
```
外层：遍历n个数字
内层：遍历target个状态

总计：O(n × target)

target最大 = sum / 2 ≈ 100 × 200 / 2 = 10000
时间：200 × 10000 = 2×10^6
可以接受
```

**Q5: 能否用DFS/回溯？**
A: 可以但慢：
```typescript
function canPartition(nums: number[]): boolean {
    const sum = nums.reduce((a, b) => a + b, 0);
    if (sum % 2 !== 0) return false;

    const target = sum / 2;
    const memo = new Map<string, boolean>();

    function dfs(index: number, current: number): boolean {
        if (current === target) return true;
        if (current > target || index === nums.length) return false;

        const key = `${index},${current}`;
        if (memo.has(key)) return memo.get(key)!;

        // 选或不选
        const result = dfs(index + 1, current + nums[index]) ||
                       dfs(index + 1, current);

        memo.set(key, result);
        return result;
    }

    return dfs(0, 0);
}

时间：O(n × target)
但常数更大，DP更优
```

## 总结

**关键点：**
1. 问题转换：分割 → 找子集和=sum/2
2. 01背包模型（每个数只能用一次）
3. 倒序遍历（避免重复使用）
4. dp[0] = true（初始状态）
5. 剪枝优化：sum为奇数、最大值>target

**01背包模板（分割等和子集）：**
```typescript
const sum = nums.reduce((a, b) => a + b, 0);
if (sum % 2 !== 0) return false;

const target = sum / 2;
const dp: boolean[] = Array(target + 1).fill(false);
dp[0] = true;

for (const num of nums) {
    for (let i = target; i >= num; i--) {
        dp[i] = dp[i] || dp[i - num];
    }
}

return dp[target];
```
