# 70. 爬楼梯【简单】

## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

---

## 输入输出示例

### 示例 1
```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

### 示例 2
```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

### 提示
- `1 <= n <= 45`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
到达第n阶的方法数
= 到达第n-1阶的方法数（然后爬1阶）
+ 到达第n-2阶的方法数（然后爬2阶）

状态转移方程：
f(n) = f(n-1) + f(n-2)

这就是斐波那契数列！
```

**方法对比：**
```
1. 递归：
   - 简单但会超时
   - 大量重复计算
   - 时间：O(2^n)

2. 动态规划（数组）：
   - 自底向上计算
   - 时间：O(n)，空间：O(n)

3. 动态规划（空间优化）：
   - 只保存两个状态
   - 时间：O(n)，空间：O(1)
   - 最优解 ✓

4. 矩阵快速幂：
   - 时间：O(logn)
   - 适合n非常大的情况
```

---

### 方法一：动态规划（空间优化）

**核心思想：**
- f(n) 只依赖于 f(n-1) 和 f(n-2)
- 不需要保存所有状态
- 只保存最近两个状态

**算法流程：**

1. **初始化：**
   - f(1) = 1（1种方法：爬1阶）
   - f(2) = 2（2种方法：1+1或2）

2. **状态转移：**
   - 从第3阶开始计算
   - f(i) = f(i-1) + f(i-2)

3. **滚动更新：**
   - 只保存prev1（前一个）和prev2（前前一个）
   - 每次更新后滚动

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法二：动态规划（数组）

**核心思想：**
- 使用数组存储所有状态

**时间复杂度：** O(n)
**空间复杂度：** O(n)

---

### 方法三：递归（不推荐）

**核心思想：**
- 直接递归
- 会超时

**时间复杂度：** O(2^n)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：动态规划（空间优化，推荐）

```typescript
function climbStairs(n: number): number {
    // 边界情况
    if (n <= 2) return n;

    // 滚动变量
    let prev2 = 1;  // f(n-2)
    let prev1 = 2;  // f(n-1)

    // 从第3阶开始计算
    for (let i = 3; i <= n; i++) {
        const current = prev1 + prev2;  // f(n) = f(n-1) + f(n-2)

        // 滚动更新
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}
```

---

### 方法一优化：解构赋值

```typescript
function climbStairs(n: number): number {
    if (n <= 2) return n;

    let [prev2, prev1] = [1, 2];

    for (let i = 3; i <= n; i++) {
        [prev2, prev1] = [prev1, prev2 + prev1];
    }

    return prev1;
}
```

---

### 方法二：动态规划（数组）

```typescript
function climbStairs(n: number): number {
    if (n <= 2) return n;

    const dp: number[] = Array(n + 1);
    dp[1] = 1;
    dp[2] = 2;

    for (let i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }

    return dp[n];
}

// 空间复杂度：O(n)
```

---

### 方法三：递归 + 记忆化

```typescript
function climbStairs(n: number): number {
    const memo: Map<number, number> = new Map();

    function climb(n: number): number {
        if (n <= 2) return n;

        if (memo.has(n)) {
            return memo.get(n)!;
        }

        const result = climb(n - 1) + climb(n - 2);
        memo.set(n, result);

        return result;
    }

    return climb(n);
}

// 带记忆化，时间O(n)，空间O(n)
```

---

### 方法四：纯递归（超时，不推荐）

```typescript
function climbStairs(n: number): number {
    if (n <= 2) return n;

    return climbStairs(n - 1) + climbStairs(n - 2);
}

// 时间复杂度：O(2^n)
// 会超时
```

### 方法五：矩阵快速幂（进阶）

```typescript
function climbStairs(n: number): number {
    if (n <= 2) return n;

    /**
     * 矩阵乘法
     */
    function multiply(a: number[][], b: number[][]): number[][] {
        const result = [[0, 0], [0, 0]];
        for (let i = 0; i < 2; i++) {
            for (let j = 0; j < 2; j++) {
                for (let k = 0; k < 2; k++) {
                    result[i][j] += a[i][k] * b[k][j];
                }
            }
        }
        return result;
    }

    /**
     * 矩阵快速幂
     */
    function matrixPow(matrix: number[][], n: number): number[][] {
        let result = [[1, 0], [0, 1]];  // 单位矩阵
        let base = matrix;

        while (n > 0) {
            if (n % 2 === 1) {
                result = multiply(result, base);
            }
            base = multiply(base, base);
            n = Math.floor(n / 2);
        }

        return result;
    }

    // [[1,1],[1,0]]^(n-1)
    const matrix = [[1, 1], [1, 0]];
    const result = matrixPow(matrix, n - 1);

    return result[0][0];
}

// 时间复杂度：O(logn)
// 适合n非常大的情况
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
f(n) = 到达第n阶的方法数

base case:
f(1) = 1
f(2) = 2
```

**2. 状态转移：**
```typescript
f(n) = f(n-1) + f(n-2)

到达第n阶：
- 从第n-1阶爬1阶：f(n-1)种方法
- 从第n-2阶爬2阶：f(n-2)种方法

总共：f(n-1) + f(n-2)种方法
```

**3. 为什么是斐波那契？**
```
f(1) = 1
f(2) = 2
f(3) = f(2) + f(1) = 2 + 1 = 3
f(4) = f(3) + f(2) = 3 + 2 = 5
f(5) = f(4) + f(3) = 5 + 3 = 8
...

这就是斐波那契数列（从第2项开始）
```

**4. 空间优化：**
```typescript
// 未优化：
const dp = Array(n + 1);
dp[i] = dp[i-1] + dp[i-2];

// 优化：
f(n) 只依赖 f(n-1) 和 f(n-2)
不需要保存所有状态

let prev2 = f(n-2);
let prev1 = f(n-1);
let current = prev1 + prev2;

每次计算后：
prev2 = prev1;
prev1 = current;
```

## 常见问题

**Q1: 为什么f(1)=1，f(2)=2？**
A: 根据题目：
```
n=1：
只有1种方法：爬1阶

n=2：
有2种方法：
- 爬1阶+爬1阶
- 爬2阶

因此：
f(1) = 1
f(2) = 2
```

**Q2: 能否从f(0)开始？**
A: 可以：
```
定义：f(0) = 1（0阶时已经到达）

则：
f(1) = f(0) + f(-1) = 1 + 0 = 1
f(2) = f(1) + f(0) = 1 + 1 = 2

代码：
let prev2 = 1;  // f(0)
let prev1 = 1;  // f(1)

for (let i = 2; i <= n; i++) {
    [prev2, prev1] = [prev1, prev2 + prev1];
}

return prev1;
```

**Q3: 如果每次可以爬1、2或3阶呢？**
A: 状态转移方程改变：
```typescript
f(n) = f(n-1) + f(n-2) + f(n-3)

初始值：
f(1) = 1
f(2) = 2
f(3) = 4

代码：
let prev3 = 1, prev2 = 2, prev1 = 4;

for (let i = 4; i <= n; i++) {
    const current = prev1 + prev2 + prev3;
    [prev3, prev2, prev1] = [prev2, prev1, current];
}
```

**Q4: 递归为什么这么慢？**
A: 重复计算：
```
f(5) = f(4) + f(3)
     = [f(3) + f(2)] + [f(2) + f(1)]
     = ...

f(2)被计算了多次
时间复杂度：O(2^n)

记忆化后：
每个状态只计算一次
时间复杂度：O(n)
```

**Q5: 什么时候用矩阵快速幂？**
A: n非常大时：
```
普通DP：O(n)
矩阵快速幂：O(logn)

本题n <= 45，普通DP足够

如果n = 10^9：
矩阵快速幂更优
```
