# 32. 最长有效括号【困难】

## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

---

## 输入输出示例

### 示例 1
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

### 示例 2
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

### 示例 3
```
输入：s = ""
输出：0
```

### 提示
- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
有效括号：
- 每个'('都有对应的')'
- 正确嵌套

连续子串：
必须是连续的字符

求最长长度
```

**方法对比：**
```
1. 暴力：O(n³) - 枚举所有子串 + 检查有效性
2. 栈：O(n) - 记录匹配位置
3. DP：O(n) - 状态转移
4. 双向遍历：O(n) - 左右各一次

推荐：栈或DP
```

---

### 方法一：动态规划（推荐）

**核心思想：**
- dp[i] = 以s[i]结尾的最长有效括号长度
- 只有')'可能形成有效括号

**状态转移：**
```
如果s[i] = '('：
  dp[i] = 0（左括号不能结尾）

如果s[i] = ')'：
  情况1：s[i-1] = '('
    - 形成"()"
    - dp[i] = dp[i-2] + 2

  情况2：s[i-1] = ')'
    - 需要看更前面
    - 如果s[i - dp[i-1] - 1] = '('
      - 可以匹配
      - dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

---

### 方法二：栈（推荐）

**核心思想：**
- 栈存储下标
- 匹配时计算长度

**算法流程：**

1. **初始化：** 栈中放入-1（作为基准）

2. **遍历字符串：**
   - 如果是'('：下标入栈
   - 如果是')'：
     - 弹出栈顶
     - 如果栈空：当前下标入栈（新的基准）
     - 如果栈不空：长度 = i - 栈顶

3. **返回最大长度**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

---

### 方法三：双向遍历（O(1)空间）

**核心思想：**
- 左到右遍历 + 右到左遍历
- 计数'('和')'

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法一：动态规划（推荐）

```typescript
function longestValidParentheses(s: string): number {
    const n = s.length;
    if (n < 2) return 0;

    // dp[i] = 以s[i]结尾的最长有效括号长度
    const dp: number[] = Array(n).fill(0);
    let maxLen = 0;

    for (let i = 1; i < n; i++) {
        if (s[i] === ')') {
            if (s[i - 1] === '(') {
                // 情况1："()"
                dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
            } else if (i - dp[i - 1] - 1 >= 0 && s[i - dp[i - 1] - 1] === '(') {
                // 情况2："))"
                // s[i - dp[i-1] - 1] 是与当前')'配对的'('
                dp[i] = dp[i - 1] + 2 + (i - dp[i - 1] - 2 >= 0 ? dp[i - dp[i - 1] - 2] : 0);
            }

            maxLen = Math.max(maxLen, dp[i]);
        }
    }

    return maxLen;
}
```

### 方法二：栈（推荐）

```typescript
function longestValidParentheses(s: string): number {
    const stack: number[] = [-1];  // 初始放入-1作为基准
    let maxLen = 0;

    for (let i = 0; i < s.length; i++) {
        if (s[i] === '(') {
            // 左括号：下标入栈
            stack.push(i);
        } else {
            // 右括号：弹出
            stack.pop();

            if (stack.length === 0) {
                // 栈空：当前右括号作为新的基准
                stack.push(i);
            } else {
                // 计算长度
                maxLen = Math.max(maxLen, i - stack[stack.length - 1]);
            }
        }
    }

    return maxLen;
}
```

---

### 方法三：双向遍历（O(1)空间）

```typescript
function longestValidParentheses(s: string): number {
    let left = 0, right = 0;
    let maxLen = 0;

    // 从左到右
    for (let i = 0; i < s.length; i++) {
        if (s[i] === '(') {
            left++;
        } else {
            right++;
        }

        if (left === right) {
            // 匹配
            maxLen = Math.max(maxLen, 2 * right);
        } else if (right > left) {
            // 右括号过多，重置
            left = right = 0;
        }
    }

    // 从右到左
    left = right = 0;
    for (let i = s.length - 1; i >= 0; i--) {
        if (s[i] === '(') {
            left++;
        } else {
            right++;
        }

        if (left === right) {
            maxLen = Math.max(maxLen, 2 * left);
        } else if (left > right) {
            // 左括号过多，重置
            left = right = 0;
        }
    }

    return maxLen;
}
```

## 代码原理详解

### DP方法

**1. 状态定义：**
```typescript
dp[i] = 以s[i]结尾的最长有效括号长度

注意："以s[i]结尾"
只有')'可能结尾

s[i] = '(' → dp[i] = 0
```

**2. 状态转移（s[i] = ')'）：**

**情况1：s[i-1] = '('**
```
形成"()"

例如：s = "...()"
          i-1 i

dp[i] = dp[i-2] + 2

为什么+dp[i-2]？
前面可能还有有效括号

例如：s = "()()"
      dp = [0, 2, 0, 4]
      i=3: dp[3] = dp[1] + 2 = 2 + 2 = 4
```

**情况2：s[i-1] = ')'**
```
形成"))"

需要找与当前')'配对的'('

位置：i - dp[i-1] - 1

例如：s = "(()"
          0 1 2
      dp = [0, 0, 2]

      s = "(())"
          0 1 2 3
      dp = [0, 0, 2, 4]

i=3, s[3]=')'：
  dp[i-1] = dp[2] = 2（内部的"()"）
  配对位置：3 - 2 - 1 = 0
  s[0] = '('，可以配对！

  dp[3] = dp[2] + 2 + dp[0-1]
        = 2 + 2 + 0
        = 4
```

---

### 栈方法

**1. 栈的含义：**
```
栈中存储：
- 未匹配的'('的下标
- 最近的未匹配的')'的下标（作为基准）

初始：stack = [-1]（基准）
```

**2. 匹配过程：**
```
遇到'('：
  入栈

遇到')'：
  弹出栈顶

  如果栈空：
    当前')'无法匹配
    作为新的基准，入栈

  如果栈不空：
    当前')'已匹配
    长度 = i - 栈顶
```

**3. 为什么要基准？**
```
计算长度需要参考点

例如：s = "()()"
      i=0, '(': stack=[-1, 0]
      i=1, ')': pop(0), len=1-(-1)=2, stack=[-1]
      i=2, '(': stack=[-1, 2]
      i=3, ')': pop(2), len=3-(-1)=4, stack=[-1]

基准-1让我们能计算完整长度
```

## 运行示例

### 示例 1：`s = "())"`

**DP方法：**
```
s = "())"
i   0 1 2

i=0, '(': dp[0]=0
i=1, ')': s[0]='(' → dp[1]=dp[-1]+2=0+2=2
i=2, ')': s[1]=')' → 检查配对位置2-2-1=-1<0，无法配对
          dp[2]=0

```

**栈方法：**
```
初始：stack=[-1]

i=0, '(': stack=[-1, 0]
i=1, ')': pop(0), stack=[-1], len=1-(-1)=2, maxLen=2
i=2, ')': pop(-1), stack=[], 栈空，push(2), stack=[2]

maxLen = 2 ✓
```

```
s = ")()())"

i=0, ')': 无配对，dp[0]=0
i=1, '(': dp[1]=0
i=2, ')': s[1]='(' → dp[2]=dp[0]+2=0+2=2
i=3, '(': dp[3]=0
i=4, ')': s[3]='(' → dp[4]=dp[2]+2=2+2=4
i=5, ')': s[4]=')' → 配对位置5-4-1=0, s[0]=')'，无法配对
          dp[5]=0

```

### 示例 3：`s = "(())"`

**DP方法：**
```
s = "(())"

i=1, '(': dp[1]=0

```

## 常见问题

**Q1: 为什么DP中dp[i]是"以i结尾"？**
A: 状态定义：
```
"以i结尾"：
- 必须包含s[i]
- s[i]必须是有效括号的一部分

只有')'可能结尾
'('不能结尾（左括号后面还需要')'）

因此：
s[i]='(' → dp[i]=0
```

**Q2: DP的情况2为什么复杂？**
A: 嵌套结构：
```
s = "(())"
     0123

i=3, s[3]=')':
  s[2]=')'（也是右括号）
  需要跳过内部的有效括号

跳过长度：dp[i-1] = dp[2] = 2
配对位置：i - dp[i-1] - 1 = 3 - 2 - 1 = 0

还要加上前面的：dp[i - dp[i-1] - 2] = dp[0-1] = 0
```

**Q3: 栈方法为什么要放-1？**
A: 计算基准：
```
长度 = 当前位置 - 基准位置

如果不放-1：
s = "()"
i=0, '(': stack=[0]
i=1, ')': pop(0), stack=[]
          无法计算长度

放-1后：
i=1, ')': pop(0), stack=[-1]
          len = 1 - (-1) = 2 ✓
```

**Q4: 双向遍历为什么有效？**
A: 互补：
```
从左到右：
- 检测右括号过多的情况
- 可能漏掉左括号过多的情况

例如：s = "(()"
左到右：left=2, right=1，left>right一直不更新
maxLen=0（错误）

从右到左：
right=1, left=2，当right>left时不更新
但在right==left时更新
可以捕获正确答案

两次遍历互补，确保正确
```

**Q5: 哪种方法最好？**
A:
```
DP：
- 清晰直观
- 空间O(n)
- 面试推荐 ✓

栈：
- 概念简单
- 空间O(n)
- 也推荐 ✓

双向遍历：
- 空间O(1)
- 但不够直观
- 了解即可
```
