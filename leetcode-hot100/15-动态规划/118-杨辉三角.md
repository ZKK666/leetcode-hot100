# 118. 杨辉三角【简单】

## 题目描述

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

![杨辉三角](https://pic.leetcode-cn.com/1626927345-DZmfxB-PascalTriangleAnimated2.gif)

---

## 输入输出示例

### 示例 1
```
输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

### 示例 2
```
输入: numRows = 1
输出: [[1]]
```

### 提示
- `1 <= numRows <= 30`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**杨辉三角的性质：**
```
第1行：[1]
第2行：[1, 1]
第3行：[1, 2, 1]
第4行：[1, 3, 3, 1]
第5行：[1, 4, 6, 4, 1]

规律：
1. 每行首尾都是1
2. 中间的数 = 上一行相邻两数之和

数学表示：
row[i][j] = row[i-1][j-1] + row[i-1][j]
```

**动态规划：**
```
每一行基于上一行生成
自底向上构建
```

---

### 方法：动态规划（逐行生成）

**核心思想：**
- 逐行生成杨辉三角
- 每行的中间元素 = 上一行相邻两元素之和

**算法流程：**

1. **初始化：** result = []

2. **生成每一行：**
   - 第1行：[1]
   - 第i行（i > 1）：
     - 首元素：1
     - 中间元素：prevRow[j-1] + prevRow[j]
     - 尾元素：1

3. **返回 result**

**时间复杂度：** O(numRows^2) - 总共生成约n^2/2个数
**空间复杂度：** O(1) - 不计输出空间

## 代码实现（TypeScript）

### 方法一：逐行生成（推荐）

```typescript
function generate(numRows: number): number[][] {
    const result: number[][] = [];

    for (let i = 0; i < numRows; i++) {
        // 创建当前行，初始化为全1
        const row: number[] = Array(i + 1).fill(1);

        // 计算中间元素（如果有）
        for (let j = 1; j < i; j++) {
            // 当前元素 = 上一行的[j-1] + 上一行的[j]
            row[j] = result[i - 1][j - 1] + result[i - 1][j];
        }

        result.push(row);
    }

    return result;
}
```

---

### 方法二：直接构建（更简洁）

```typescript
function generate(numRows: number): number[][] {
    const result: number[][] = [];

    for (let i = 0; i < numRows; i++) {
        const row: number[] = [];

        for (let j = 0; j <= i; j++) {
            if (j === 0 || j === i) {
                // 首尾元素为1
                row.push(1);
            } else {
                // 中间元素 = 上一行相邻两数之和
                row.push(result[i - 1][j - 1] + result[i - 1][j]);
            }
        }

        result.push(row);
    }

    return result;
}
```

---

### 方法三：优化（原地修改）

```typescript
function generate(numRows: number): number[][] {

        // 创建新行
        const row: number[] = Array(i + 1).fill(1);

        for (let j = 1; j < i; j++) {
            row[j] = result[i - 1][j - 1] + result[i - 1][j];
        }

        result.push(row);
    }

    return result;
}
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
result[i][j] = 第i行第j列的值

规律：
- i = j = 0 或 j = i：值为1
- 其他：result[i][j] = result[i-1][j-1] + result[i-1][j]
```

**2. 为什么首尾是1？**
```
杨辉三角的性质：
每行的首尾都是1

数学解释：
C(n, 0) = 1
C(n, n) = 1

其中C(n, k)是组合数
```

**3. 中间元素的计算：**
```typescript
row[j] = result[i-1][j-1] + result[i-1][j];

图示：
    上一行：  1  3  3  1
                ↘  ↙
    当前行：  1  4  6  4  1

row[1] = 1 + 3 = 4
row[2] = 3 + 3 = 6
row[3] = 3 + 1 = 4
```

**4. 为什么是DP？**
```
每一行依赖于上一行
满足DP的特征：
- 最优子结构
- 重叠子问题（虽然本题没有）

本质是递推关系
```

## 常见问题

**Q1: 杨辉三角和组合数的关系？**
A: 完全对应：
```
第n行第k个数 = C(n, k)

其中C(n, k) = n! / (k! × (n-k)!)

例如：第4行
C(4,0)=1, C(4,1)=4, C(4,2)=6, C(4,3)=4, C(4,4)=1
对应：[1, 4, 6, 4, 1]

递推公式：
C(n, k) = C(n-1, k-1) + C(n-1, k)
就是杨辉三角的规律
```

**Q2: 能否不用二维数组？**
A: 可以但复杂：
```typescript
// 只生成最后一行
function getRow(rowIndex: number): number[] {
    let row = [1];

    for (let i = 1; i <= rowIndex; i++) {
        // 从后往前更新
        for (let j = i - 1; j > 0; j--) {
            row[j] = row[j] + row[j - 1];
        }
        row.push(1);
    }

    return row;
}

注意：必须从后往前，避免覆盖
```

**Q3: 为什么从后往前更新？**
A: 避免数据覆盖：
```
从前往后：
row[1] = row[0] + row[1]  // row[1]被修改
row[2] = row[1] + row[2]  // 但这里需要的是旧的row[1]
错误！

从后往前：
row[2] = row[1] + row[2]  // 先算后面的
row[1] = row[0] + row[1]  // 再算前面的
正确！
```

**Q4: 空间能否优化到O(1)？**
A: 不行：
```
需要存储所有numRows行
每行i有i+1个元素

总元素数：1 + 2 + 3 + ... + numRows
         = numRows × (numRows + 1) / 2
         = O(numRows^2)

必须O(numRows^2)空间
```

**Q5: 有没有数学公式直接计算？**
A: 有：
```typescript
// 计算C(n, k) = n! / (k! × (n-k)!)
function combination(n: number, k: number): number {
    let result = 1;
    for (let i = 0; i < k; i++) {
        result = result * (n - i) / (i + 1);
    }
    return result;
}

// 生成第n行
function getRow(n: number): number[] {
    const row: number[] = [];
    for (let k = 0; k <= n; k++) {
        row.push(combination(n, k));
    }
    return row;
}

但这个方法：
1. 可能有精度问题
2. 不是递推，不符合DP思想
3. 效率不一定更高
```

## 复杂度分析

**时间复杂度：** O(numRows^2)
- 第i行有i+1个元素
- 总元素数：1 + 2 + ... + numRows = O(numRows^2)
- 每个元素O(1)计算

**空间复杂度：** O(1)
- 不计输出空间
- 只用常数额外空间

**如果计算输出空间：** O(numRows^2)
