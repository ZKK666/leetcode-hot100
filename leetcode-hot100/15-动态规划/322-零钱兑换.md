# 322. 零钱兑换【中等】

## 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的**最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

---

## 输入输出示例

### 示例 1
```
输入：coins = [1, 2, 5], amount = 11
输出：3
解释：11 = 5 + 5 + 1
```

### 示例 2
```
输入：coins = [2], amount = 3
输出：-1
```

### 示例 3
```
输入：coins = [1], amount = 0
输出：0
```

### 提示
- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
完全背包问题
- 物品：硬币（可重复使用）
- 背包容量：amount
- 目标：装满背包的最少物品数
```

**状态转移：**
```
dp[i] = 凑成金额i所需的最少硬币数

对于金额i：
枚举每种硬币coin
如果coin <= i：
  dp[i] = min(dp[i], dp[i - coin] + 1)

如果凑不成，dp[i] = ∞
```

**初始状态：**
```
dp[0] = 0（金额0不需要硬币）
dp[i] = ∞（i > 0，初始化为无穷大）
```

---

### 方法一：动态规划（推荐）

**核心思想：**
- dp[i] 表示凑成金额i的最少硬币数
- 枚举每种硬币，更新状态

**算法流程：**

1. **初始化：**
   - dp[0] = 0
   - dp[i] = ∞（i > 0）

2. **状态转移：**
   - 对于每个金额i（1到amount）：
     - 枚举每种硬币coin：
       - 如果 coin <= i：
         - dp[i] = min(dp[i], dp[i - coin] + 1)

3. **返回结果：**
   - 如果 dp[amount] == ∞：返回-1
   - 否则：返回 dp[amount]

**时间复杂度：** O(amount × n)，n是硬币种类数
**空间复杂度：** O(amount)

---

### 方法二：BFS

**核心思想：**
- 将问题看作图的最短路径
- 从0开始，每次加上一种硬币
- 第一次到达amount的层数 = 最少硬币数

**时间复杂度：** O(amount × n)
**空间复杂度：** O(amount)

## 代码实现（TypeScript）

### 方法一：动态规划（推荐）

```typescript
function coinChange(coins: number[], amount: number): number {
    // dp[i] = 凑成金额i的最少硬币数
    const dp: number[] = Array(amount + 1).fill(Infinity);
    dp[0] = 0;

    // 遍历所有金额
    for (let i = 1; i <= amount; i++) {
        // 枚举每种硬币
        for (const coin of coins) {
            if (coin <= i) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }

    // 如果无法凑成，返回-1
    return dp[amount] === Infinity ? -1 : dp[amount];
}
```

        }
    }

    return dp[amount] === Infinity ? -1 : dp[amount];

### 方法二：BFS

```typescript
function coinChange(coins: number[], amount: number): number {
    if (amount === 0) return 0;

    const queue: number[] = [0];
    const visited: Set<number> = new Set([0]);
    let level = 0;

    while (queue.length > 0) {
        level++;
        const size = queue.length;

        for (let i = 0; i < size; i++) {
            const current = queue.shift()!;

            // 尝试加上每种硬币
            for (const coin of coins) {
                const next = current + coin;

                if (next === amount) {
                    return level;
                }

                if (next < amount && !visited.has(next)) {
                    visited.add(next);
                    queue.push(next);
                }
            }
        }
    }

    return -1;
}
```

### 方法三：记忆化递归

```typescript
function coinChange(coins: number[], amount: number): number {
    const memo: Map<number, number> = new Map();

    function dp(amount: number): number {
        if (amount === 0) return 0;
        if (amount < 0) return -1;

        if (memo.has(amount)) {
            return memo.get(amount)!;
        }

        let minCount = Infinity;

        for (const coin of coins) {
            const subResult = dp(amount - coin);
            if (subResult !== -1) {
                minCount = Math.min(minCount, subResult + 1);
            }
        }

        const result = minCount === Infinity ? -1 : minCount;
        memo.set(amount, result);

        return result;
    }

    return dp(amount);
}
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
dp[i] = 凑成金额i所需的最少硬币数

base case:
dp[0] = 0（金额0不需要硬币）
```

**2. 状态转移方程：**
```typescript
dp[i] = min(dp[i - coin] + 1)  for all coin in coins

凑成金额i：
可以由 i - coin 加上一个coin得到

例如：coins = [1, 2, 5], amount = 11
dp[11] = min(
    dp[11 - 1] + 1,  // 使用硬币1
    dp[11 - 2] + 1,  // 使用硬币2
    dp[11 - 5] + 1   // 使用硬币5
)
```

**3. 为什么是完全背包？**
```
完全背包特点：
- 物品可以重复使用
- 求最小/最大值

本题：
- 硬币可以重复使用（无限个）
- 求最少硬币数（最小值）

状态转移：
dp[i] = min(dp[i], dp[i - coin] + 1)

与01背包区别：
01背包：每个物品只能用一次
完全背包：每个物品可以无限次使用
```

**4. 枚举顺序：**
```typescript
// 方式1：先枚举金额，再枚举硬币
for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
        dp[i] = min(dp[i], dp[i - coin] + 1);
    }
}

// 方式2：先枚举硬币，再枚举金额
for (const coin of coins) {
    for (let i = coin; i <= amount; i++) {
        dp[i] = min(dp[i], dp[i - coin] + 1);
    }
}

区别：
求最值：两种都可以
求方案数：顺序不同，结果可能不同

本题求最值，两种都对
```

## 运行示例

### 示例 1：`coins = [1, 2, 5], amount = 11`

**执行过程：**

```
初始：dp = [0, ∞, ∞, ..., ∞]

计算dp[1]到dp[11]：

dp[1]:
  coin=1: dp[1] = min(∞, dp[0]+1) = 1
  coin=2: 2 > 1，跳过
  coin=5: 5 > 1，跳过
  dp[1] = 1

dp[2]:
  coin=1: dp[2] = min(∞, dp[1]+1) = 2
  coin=2: dp[2] = min(2, dp[0]+1) = 1
  coin=5: 5 > 2，跳过
  dp[2] = 1

dp[3]:
  coin=1: dp[3] = min(∞, dp[2]+1) = 2
  coin=2: dp[3] = min(2, dp[1]+1) = 2
  coin=5: 5 > 3，跳过
  dp[3] = 2

dp[5]:
  coin=1: dp[5] = min(∞, dp[4]+1) = 3
  coin=2: dp[5] = min(3, dp[3]+1) = 3
  coin=5: dp[5] = min(3, dp[0]+1) = 1
  dp[5] = 1

...

dp[10]:
  coin=1: dp[10] = min(∞, dp[9]+1) = 4
  coin=2: dp[10] = min(4, dp[8]+1) = 3
  coin=5: dp[10] = min(3, dp[5]+1) = 2
  dp[10] = 2

dp[11]:
  coin=1: dp[11] = min(∞, dp[10]+1) = 3
  coin=2: dp[11] = min(3, dp[9]+1) = 3
  coin=5: dp[11] = min(3, dp[6]+1) = 3
  dp[11] = 3

返回：3 ✓

方案：11 = 5 + 5 + 1
```

## 常见问题

**Q1: 为什么不用贪心？**
A: 贪心不一定最优：
```
coins = [1, 3, 4], amount = 6

贪心（选最大的）：
先选4：6 - 4 = 2
再选1: 2 - 1 - 1 = 0
共3个：4 + 1 + 1

最优：
6 = 3 + 3
只需2个

贪心错误！
```

**Q2: 为什么初始化为Infinity？**
A: 表示无法凑成：
```
dp[i] = ∞ 表示金额i无法凑成

状态转移时：
dp[i] = min(dp[i], dp[i - coin] + 1)

如果dp[i - coin] = ∞：
dp[i] = min(dp[i], ∞ + 1) = min(dp[i], ∞) = dp[i]

不会影响结果
```

**Q3: 枚举顺序为什么不影响？**
A: 求最值 vs 求方案数：
```
求最值（本题）：
dp[i] = min(dp[i], dp[i - coin] + 1)
min操作满足交换律
枚举顺序不影响结果

求方案数（518题）：
枚举顺序不同，结果可能不同
- 先枚举物品：组合数
- 先枚举容量：排列数
```

**Q4: BFS为什么也能解决？**
A: 最短路径：
```
将问题看作图：
- 每个金额是节点
- 加上硬币 = 边
- 从0出发，找到amount的最短路径

BFS保证第一次到达amount时
路径最短（层数最少）
= 硬币数最少
```

**Q5: 如果要求方案数怎么办？**
A: 那是518题：
```
518. 零钱兑换 II（中等）

状态转移：
dp[i] = 凑成金额i的方案数

dp[i] += dp[i - coin]

注意枚举顺序：
先枚举硬币，再枚举金额
避免重复计数
```

## 总结

**关键点：**
1. 完全背包问题（物品可重复）
2. 状态转移：dp[i] = min(dp[i - coin] + 1)
3. 初始化：dp[0] = 0, 其他为∞
4. 无法凑成返回-1
5. 枚举顺序不影响（求最值）

**DP模板（零钱兑换）：**
```typescript
const dp: number[] = Array(amount + 1).fill(Infinity);
dp[0] = 0;

for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
        if (coin <= i) {
            dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
}

return dp[amount] === Infinity ? -1 : dp[amount];
```
