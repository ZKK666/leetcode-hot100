# 152. 乘积最大子数组【中等】

## 题目描述

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

---

## 输入输出示例

### 示例 1
```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

### 示例 2
```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。
```

### 提示
- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何前缀或后缀的乘积都**保证**是一个 **32-位** 整数

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
类似"最大子数组和"（53题）
但乘法有特殊性：
- 负数 × 负数 = 正数
- 最小值可能变成最大值

例如：[-2, 3, -4]
最大值：-2 × 3 × -4 = 24
（负数×负数变正）
```

**状态转移：**
```
dp_max[i] = 以nums[i]结尾的最大乘积
dp_min[i] = 以nums[i]结尾的最小乘积

为什么需要维护最小值？
因为负数 × 最小值（负数）= 最大值

三种情况：
1. nums[i] 自己
2. nums[i] × dp_max[i-1]（正数继续乘）
3. nums[i] × dp_min[i-1]（负数翻转）

dp_max[i] = max(nums[i], nums[i] × dp_max[i-1], nums[i] × dp_min[i-1])
dp_min[i] = min(nums[i], nums[i] × dp_max[i-1], nums[i] × dp_min[i-1])
```

---

### 方法：动态规划（双状态）

**核心思想：**
- 同时维护最大值和最小值
- 最小值可能因为负数变成最大值

**算法流程：**

1. **初始化：**
   - max_prod = nums[0]（最大乘积）
   - min_prod = nums[0]（最小乘积）
   - result = nums[0]（全局最大）

2. **状态转移：**
   - 对于每个i（1到n-1）：
     - 计算三种情况的乘积
     - 更新max_prod和min_prod
     - 更新result

3. **返回 result**

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法：动态规划（空间优化，推荐）

```typescript
function maxProduct(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;

    // max_prod：以当前元素结尾的最大乘积
    // min_prod：以当前元素结尾的最小乘积
    let max_prod = nums[0];
    let min_prod = nums[0];
    let result = nums[0];

    for (let i = 1; i < n; i++) {
        const num = nums[i];

        // 如果num是负数，交换max和min
        // 因为负数会让最大变最小，最小变最大
        if (num < 0) {
            [max_prod, min_prod] = [min_prod, max_prod];
        }

        // 更新最大值和最小值
        max_prod = Math.max(num, max_prod * num);
        min_prod = Math.min(num, min_prod * num);

        // 更新全局最大值
        result = Math.max(result, max_prod);
    }

    return result;
}
```

### 方法优化：不交换

```typescript
function maxProduct(nums: number[]): number {
    let max_prod = nums[0];
    let min_prod = nums[0];
    let result = nums[0];

    for (let i = 1; i < nums.length; i++) {
        const num = nums[i];

        // 暂存旧的max_prod（因为计算min_prod需要用到）
        const temp_max = max_prod;

        // 三种情况：
        // 1. num自己
        // 2. num × 前一个最大值
        // 3. num × 前一个最小值（负数翻转）
        max_prod = Math.max(num, Math.max(num * max_prod, num * min_prod));
        min_prod = Math.min(num, Math.min(num * temp_max, num * min_prod));

        result = Math.max(result, max_prod);
    }

    return result;
}
```

### 方法：DP数组（不推荐，空间O(n)）

```typescript
function maxProduct(nums: number[]): number {
    const n = nums.length;
    const dp_max: number[] = Array(n);  // dp_max[i] = 以i结尾的最大乘积
    const dp_min: number[] = Array(n);  // dp_min[i] = 以i结尾的最小乘积

    dp_max[0] = nums[0];
    dp_min[0] = nums[0];
    let result = nums[0];

    for (let i = 1; i < n; i++) {
        const num = nums[i];

        dp_max[i] = Math.max(num, Math.max(num * dp_max[i-1], num * dp_min[i-1]));
        dp_min[i] = Math.min(num, Math.min(num * dp_max[i-1], num * dp_min[i-1]));

        result = Math.max(result, dp_max[i]);
    }

    return result;
}
```

## 代码原理详解

### 动态规划思想

**1. 状态定义：**
```typescript
max_prod = 以当前元素结尾的最大乘积
min_prod = 以当前元素结尾的最小乘积

为什么需要min_prod？
因为负数可能让最小变最大

例如：[-2, 3, -4]
到3时：max=3, min=-6
到-4时：
  max = (-4) × (-6) = 24（最小变最大！）
  min = (-4) × 3 = -12
```

**2. 状态转移：**
```typescript
max_prod = max(num, max_prod * num, min_prod * num)
min_prod = min(num, max_prod * num, min_prod * num)

三种情况：
1. num自己（重新开始）
   - 前面乘积太小或为0
   - 从当前元素重新开始

2. num × max_prod（继续乘）
   - num为正数，乘以最大值
   - 或num为负数，但max_prod也是负数

3. num × min_prod（负数翻转）
   - num为负数，乘以最小值（负数）
   - 负 × 负 = 正，可能最大
```

**3. 为什么负数时交换？**
```typescript
if (num < 0) {
    [max_prod, min_prod] = [min_prod, max_prod];
}

num为负数时：
- num × max_prod 变小（正变负，或负变更负）
- num × min_prod 变大（负变正，或负变小）

交换后再比较，简化计算

例如：max=3, min=-2, num=-4
不交换：
  new_max = max(-4, -4×3, -4×-2) = max(-4, -12, 8) = 8
  new_min = min(-4, -4×3, -4×-2) = min(-4, -12, 8) = -12

交换：max=-2, min=3
  new_max = max(-4, -4×-2, -4×3) = max(-4, 8, -12) = 8
  new_min = min(-4, -4×-2, -4×3) = min(-4, 8, -12) = -12

结果相同，但代码更简洁
```

## 运行示例

### 示例 1：`nums = [2,3,-2,4]`

**执行过程：**

```
初始：max=2, min=2, result=2

i=1, num=3：
  max = max(3, 2×3, 2×3) = max(3, 6, 6) = 6
  min = min(3, 2×3, 2×3) = min(3, 6, 6) = 3
  result = max(2, 6) = 6

i=2, num=-2：
  交换：max=3, min=6
  max = max(-2, 3×-2, 6×-2) = max(-2, -6, -12) = -2
  min = min(-2, 3×-2, 6×-2) = min(-2, -6, -12) = -12
  result = max(6, -2) = 6

i=3, num=4：
  max = max(4, -2×4, -12×4) = max(4, -8, -48) = 4
  min = min(4, -2×4, -12×4) = min(4, -8, -48) = -48
  result = max(6, 4) = 6

返回：6 ✓

最大乘积子数组：[2, 3]
```

---

### 示例 2：`nums = [-2,0,-1]`

**执行过程：**

```
初始：max=-2, min=-2, result=-2

i=1, num=0：
  交换（num=0，不是负数，不交换）
  max = max(0, -2×0, -2×0) = 0
  min = min(0, -2×0, -2×0) = 0
  result = max(-2, 0) = 0

i=2, num=-1：
  交换：max=0, min=0
  max = max(-1, 0×-1, 0×-1) = -1
  min = min(-1, 0×-1, 0×-1) = -1
  result = max(0, -1) = 0

返回：0 ✓
```

### 示例 3：`nums = [-2,3,-4]`

**执行过程：**

```
初始：max=-2, min=-2, result=-2

i=1, num=3：
  max = max(3, -2×3, -2×3) = 3
  min = min(3, -2×3, -2×3) = -6
  result = max(-2, 3) = 3

i=2, num=-4：
```

## 常见问题

**Q1: 为什么要维护最小值？**
A: 负数翻转：
```
负数 × 最小值（负数）= 最大值（正数）

例如：[-2, -3, -4]
到-3时：max=-2×-3=6, min=-3
到-4时：max=(-4)×(-3)=12（用最小值！）

如果只维护最大值：
无法计算出12
```

**Q2: 为什么有三种情况？**
A: 考虑所有可能：
```
1. num自己：
   前面乘积不好（太小或为0）
   重新开始

2. num × max_prod：
   num为正，继续乘

3. num × min_prod：
   num为负，乘最小（负）变最大

必须考虑全部，才能找到最优
```

**Q3: 和最大子数组和的区别？**
A:
```
最大子数组和（53题）：
- 加法：max(num, sum + num)
- 只需维护一个状态

乘积最大子数组：
- 乘法：负数翻转
- 需要维护最大和最小

相似但不同
```

**Q4: 遇到0怎么办？**
A: 0会重置：
```
num = 0：
max = max(0, max×0, min×0) = 0
min = min(0, max×0, min×0) = 0

相当于重新开始
后续元素从0开始乘

例如：[2, 3, 0, 4, 5]
遇到0后，max=0, min=0
到4时：max=4（重新开始）
```

**Q5: 为什么空间可以优化到O(1)？**
A: 只依赖前一个状态：
```
dp_max[i] 只依赖 dp_max[i-1] 和 dp_min[i-1]

不需要保存所有状态
用两个变量滚动更新即可
```

## 边界情况

### 情况1：单个元素

```
输入: nums = [5]
输出: 5
```

### 情况2：全是正数

```
输入: nums = [2, 3, 4]
输出: 24
说明：全部相乘
```

### 情况3：全是负数

```
输入: nums = [-2, -3, -4]
输出: 24
说明：3个负数相乘 = 负，取两个：-2×-3=6或-3×-4=12
不对，应该是-2×-3×-4=24（负负得正）

实际：如果负数个数是偶数，全乘；奇数，去掉一个
```

### 情况4：包含0

```
输入: nums = [2, 3, 0, 4]
输出: 6
说明：0前后分段
```

### 情况5：混合正负

```
输入: nums = [2, -5, -2, -4, 3]
输出: 960
说明：2×-5×-2×-4×3 = 960
```

## 总结

**关键点：**
1. 同时维护最大值和最小值
2. 负数会让最小变最大
3. 三种情况：自己、乘最大、乘最小
4. 负数时交换max和min（可选优化）
5. 空间优化到O(1)

**DP模板（乘积最大子数组）：**
```typescript
let max_prod = nums[0];
let min_prod = nums[0];
let result = nums[0];

for (let i = 1; i < nums.length; i++) {
    const num = nums[i];

    if (num < 0) {
        [max_prod, min_prod] = [min_prod, max_prod];
    }

    max_prod = Math.max(num, max_prod * num);
    min_prod = Math.min(num, min_prod * num);

    result = Math.max(result, max_prod);
}

return result;
```
