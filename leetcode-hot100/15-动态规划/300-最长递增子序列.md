# 300. 最长递增子序列【中等】

## 题目描述

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

---

## 输入输出示例

### 示例 1
```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

### 示例 2
```
输入：nums = [0,1,0,3,2,3]
输出：4
```

### 示例 3
```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

### 提示
- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

**进阶：**
- 你能将算法的时间复杂度降低到 `O(n log n)` 吗?

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
最长递增子序列（LIS）
- 子序列：不要求连续
- 递增：严格递增（不能相等）

经典DP问题
```

**状态转移：**
```
dp[i] = 以nums[i]结尾的最长递增子序列长度

对于位置i：
枚举所有j < i
如果nums[j] < nums[i]：
  dp[i] = max(dp[i], dp[j] + 1)

答案：max(dp[0...n-1])
```

---

### 方法一：动态规划（O(n²)）

**核心思想：**
- dp[i] 表示以nums[i]结尾的LIS长度
- 枚举所有前面的元素

**算法流程：**

1. **初始化：** dp[i] = 1（每个元素自己是一个子序列）

2. **状态转移：**
   - 对于每个i（1到n-1）：
     - 枚举所有j（0到i-1）：
       - 如果 nums[j] < nums[i]：
         - dp[i] = max(dp[i], dp[j] + 1)

3. **返回 max(dp)**

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

---

### 方法二：贪心 + 二分（O(nlogn)，进阶）

**核心思想：**
- 维护一个递增数组tails
- tails[i]表示长度为i+1的递增子序列的最小尾部元素
- 用二分查找优化

**关键观察：**
```
对于长度相同的递增子序列：
尾部元素越小，越容易扩展

例如：
长度3: [2,3,7] vs [2,5,8]
遇到数字6：
[2,3,7,6]不行（7>6）
[2,5,8,6]也不行（8>6）

但[2,3,6]可以（7→6，更小）
```

**时间复杂度：** O(nlogn)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：动态规划（O(n²)，推荐）

```typescript
function lengthOfLIS(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;

    // dp[i] = 以nums[i]结尾的最长递增子序列长度
    const dp: number[] = Array(n).fill(1);

    for (let i = 1; i < n; i++) {
        // 枚举所有j < i
        for (let j = 0; j < i; j++) {
            // nums[j] < nums[i]：可以接在nums[j]后面
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
    }

    // 返回所有dp[i]的最大值
    return Math.max(...dp);
}
```

---

### 方法二：贪心 + 二分（O(nlogn)，进阶）

```typescript
function lengthOfLIS(nums: number[]): number {
    const tails: number[] = [];  // tails[i] = 长度i+1的LIS的最小尾部

    for (const num of nums) {
        // 二分查找：找到第一个 >= num 的位置
        let left = 0, right = tails.length;

        while (left < right) {
            const mid = Math.floor((left + right) / 2);
            if (tails[mid] < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        // left是第一个 >= num 的位置
        if (left === tails.length) {
            // num大于所有元素，扩展
            tails.push(num);
        } else {
            // 替换：使得尾部更小
            tails[left] = num;
        }
    }

    return tails.length;
}
```

---

### 方法二优化：使用内置二分

```typescript
function lengthOfLIS(nums: number[]): number {
    const tails: number[] = [];

    for (const num of nums) {
        // 找到插入位置（第一个 >= num 的位置）
        const pos = binarySearch(tails, num);

        if (pos === tails.length) {
            tails.push(num);
        } else {
            tails[pos] = num;
        }
    }

    return tails.length;
}

/**
 * 二分查找：找到第一个 >= target 的位置
 */
function binarySearch(arr: number[], target: number): number {
    let left = 0, right = arr.length;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);
        if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

## 代码原理详解

### 动态规划方法

**1. 状态定义：**
```typescript
dp[i] = 以nums[i]结尾的最长递增子序列长度

注意："以nums[i]结尾"
不是"考虑到nums[i]为止"

例如：nums = [10,9,2,5,3,7]
dp[3] = 以5结尾的LIS长度 = 2（[2,5]）
不是前4个元素的LIS长度
```

**2. 状态转移方程：**
```typescript
dp[i] = max(dp[j] + 1)  for all j where j < i && nums[j] < nums[i]

解释：
以nums[i]结尾的LIS：
可以由任何 nums[j] < nums[i] 的LIS扩展而来

例如：nums = [2,5,3,7]
dp[3] (以7结尾)：
- 接在2后面：dp[0] + 1 = 2
- 接在5后面：dp[1] + 1 = 3
- 接在3后面：dp[2] + 1 = 3
取最大值：dp[3] = 3
```

**3. 为什么答案是max(dp)？**
```
dp[i]是以nums[i]结尾的LIS
最长的LIS不一定以最后一个元素结尾

例如：nums = [2,5,3]
dp = [1, 2, 2]
LIS可能是[2,5]（结尾是5）
也可能是[2,3]（结尾是3）

答案 = max(dp) = 2
```

---

### 贪心+二分方法

**1. tails数组的含义：**
```typescript
tails[i] = 长度为i+1的递增子序列的最小尾部元素

例如：nums = [2,5,3,7,11,8]
tails = [2, 3, 7, 8]

tails[0]=2：长度1的LIS，最小尾部是2
tails[1]=3：长度2的LIS，最小尾部是3（[2,3]）
tails[2]=7：长度3的LIS，最小尾部是7（[2,3,7]）
tails[3]=8：长度4的LIS，最小尾部是8（[2,3,7,8]）

LIS长度 = tails.length = 4
```

**2. 为什么要维护最小尾部？**
```
贪心思想：
对于长度相同的LIS，尾部越小越好
因为更容易接上后面的元素

例如：
长度2: [2,5] vs [2,3]
遇到数字4：
[2,5,4]不行（5>4）
[2,3,4]可以 ✓

所以保留[2,3]（尾部3）
```

**3. 二分查找的作用：**
```typescript
找到第一个 >= num 的位置

为什么？
- 如果num > 所有元素：扩展（长度+1）
- 否则：替换，使尾部更小

例如：tails = [2, 5, 7]
num = 3：
  找到tails[1]=5（第一个>=3）
  替换：tails = [2, 3, 7]
  长度不变，但尾部更小了

num = 8：
  找不到（8>所有元素）
  扩展：tails = [2, 3, 7, 8]
  长度+1
```

## 运行示例

### 示例：`nums = [10,9,2,5,3,7,101,18]`

**DP方法（O(n²)）：**

```
初始：dp = [1, 1, 1, 1, 1, 1, 1, 1]

i=1 (nums[1]=9):
  j=0: 10 > 9，不能接
  dp[1] = 1

i=2 (nums[2]=2):
  j=0: 10 > 2，不能接
  j=1: 9 > 2，不能接
  dp[2] = 1

i=3 (nums[3]=5):
  j=0: 10 > 5，不能接
  j=1: 9 > 5，不能接
  j=2: 2 < 5，可以接：dp[3] = dp[2]+1 = 2
  dp[3] = 2

i=4 (nums[4]=3):
  j=2: 2 < 3，可以接：dp[4] = dp[2]+1 = 2
  dp[4] = 2

i=5 (nums[5]=7):
  j=2: 2 < 7，dp[5] = dp[2]+1 = 2
  j=3: 5 < 7，dp[5] = max(2, dp[3]+1) = 3
  j=4: 3 < 7，dp[5] = max(3, dp[4]+1) = 3
  dp[5] = 3

i=6 (nums[6]=101):
  最大dp[6] = 4（接在7后面）

i=7 (nums[7]=18):
  最大dp[7] = 4（接在7后面）

结果：max(dp) = 4 ✓
LIS: [2,5,7,101]或[2,3,7,101]等
```

**贪心+二分方法（O(nlogn)）：**

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]

tails = []

num=10: tails=[10]
num=9: 替换10 → tails=[9]
num=2: 替换9 → tails=[2]
num=5: 扩展 → tails=[2,5]
num=3: 替换5 → tails=[2,3]
num=7: 扩展 → tails=[2,3,7]
num=101: 扩展 → tails=[2,3,7,101]
num=18: 替换101 → tails=[2,3,7,18]

返回：tails.length = 4 ✓
```

## 常见问题

**Q1: DP方法的答案为什么是max(dp)？**
A: 理解状态定义：
```
dp[i] = 以nums[i]结尾的LIS

LIS不一定以最后一个元素结尾
需要检查所有位置

例如：[5,1,2,3]
dp = [1,1,2,3]
LIS是[1,2,3]（以3结尾）
不是[5]（以5结尾）

答案 = max(dp) = 3
```

**Q2: 贪心+二分为什么正确？**
A: 贪心性质：
```
核心思想：
对于长度相同的LIS，保留尾部最小的

证明：
假设tails[i]不是最小的
存在长度i+1的LIS，尾部 < tails[i]
那么用它替换tails[i]，不会影响答案
且更容易扩展

因此贪心策略是最优的
```

**Q3: tails数组是LIS吗？**
A: 不一定：
```
tails只保证单调递增
但不一定是实际的LIS

例如：[2,5,3,7]
tails = [2,3,7]

实际LIS可能是[2,5,7]
tails只是用来记录"长度为k的LIS的最小尾部"

tails.length = LIS长度
但tails本身不一定是LIS
```

**Q4: 如何输出具体的LIS？**
A: DP方法记录前驱：
```typescript
const dp: number[] = Array(n).fill(1);
const prev: number[] = Array(n).fill(-1);  // 记录前驱

for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
        if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
            dp[i] = dp[j] + 1;
            prev[i] = j;  // i的前驱是j
        }
    }
}

// 找到最大dp的位置
let maxLen = 0, lastIndex = -1;
for (let i = 0; i < n; i++) {
    if (dp[i] > maxLen) {
        maxLen = dp[i];
        lastIndex = i;
    }
}

// 回溯构造LIS
const lis: number[] = [];
let i = lastIndex;
while (i !== -1) {
    lis.push(nums[i]);
    i = prev[i];
}
lis.reverse();
```

**Q5: 如果要求非严格递增（可以相等）呢？**
A: 修改条件：
```typescript
// 原来：nums[j] < nums[i]
// 改为：nums[j] <= nums[i]
if (nums[j] <= nums[i]) {
    dp[i] = Math.max(dp[i], dp[j] + 1);
}
```

## 复杂度分析

### DP方法

**时间复杂度：** O(n²)
- 外层循环：n
- 内层循环：n
- 总计：O(n²)

**空间复杂度：** O(n)
- dp数组

### 贪心+二分

**时间复杂度：** O(nlogn)
- 外层循环：n
- 每次二分查找：O(logn)
- 总计：O(nlogn)

**空间复杂度：** O(n)
- tails数组

## 总结

**关键点：**
1. DP：dp[i] = 以nums[i]结尾的LIS长度
2. 状态转移：dp[i] = max(dp[j] + 1) where nums[j] < nums[i]
3. 答案：max(dp)
4. 进阶：贪心+二分，O(nlogn)
5. tails数组维护最小尾部

**DP模板（LIS）：**
```typescript
const dp: number[] = Array(n).fill(1);

for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
}

return Math.max(...dp);
```
