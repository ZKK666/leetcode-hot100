# 153. 寻找旋转排序数组中的最小值【中等】

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：
- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`。

给你一个元素值 **互不相同** 的数组 `nums`，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素**。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

---

## 输入输出示例

### 示例 1
```
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组为 [1,2,3,4,5]，旋转 3 次得到输入数组。
```

### 示例 2
```
输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组为 [0,1,2,4,5,6,7]，旋转 4 次得到输入数组。
```

### 示例 3
```
输入：nums = [11,13,15,17]
输出：11
解释：原数组为 [11,13,15,17]，旋转 4 次得到输入数组（相当于没旋转）。
```

### 提示
- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数 **互不相同**
- `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转

## 解题思路（面试推荐 - 最优解）

### 核心思想

**旋转数组的特点：**
```
原数组：[0,1,2,4,5,6,7]（升序）
旋转后：[4,5,6,7,0,1,2]

观察：
1. 分成两段，每段都升序
2. 第一段的所有元素 > 第二段的所有元素
3. 最小值 = 旋转点 = 第二段的第一个元素

例如：[4,5,6,7|0,1,2]
              ↑
           最小值
```

**如何找最小值？**
```
O(log n) → 二分查找

关键：
比较nums[mid]和nums[right]

如果nums[mid] > nums[right]：
  最小值在右半部分（包括mid右边）
  left = mid + 1

如果nums[mid] < nums[right]：
  最小值在左半部分（包括mid）
  right = mid

终止：left == right时，找到最小值
```

**为什么比较right而不是left？**
```
比较right更简单：

nums[mid] > nums[right]：
明确表示mid在左半段（大值段）
最小值必在右边

比较left会复杂：
nums[mid] > nums[left]：
可能mid在右半段，也可能整体有序
需要额外判断
```

---

### 方法：二分查找

**算法流程：**
1. 初始化left = 0, right = n - 1
2. 循环条件：left < right
3. 计算mid
4. 比较nums[mid]和nums[right]：
   - nums[mid] > nums[right]：left = mid + 1
   - nums[mid] < nums[right]：right = mid
5. 返回nums[left]

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：二分查找（推荐）

```typescript
function findMin(nums: number[]): number {
    let left = 0;
    let right = nums.length - 1;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] > nums[right]) {
            // 最小值在右半部分
            // mid肯定不是最小值（因为比right大）
            left = mid + 1;
        } else {
            // nums[mid] < nums[right]
            // 最小值在左半部分（包括mid）
            // mid可能是最小值
            right = mid;
        }
    }

    // left == right时，找到最小值
    return nums[left];
}
```

---

### 方法二：二分（比较left）

```typescript
function findMin(nums: number[]): number {
    let left = 0;
    let right = nums.length - 1;

    // 特殊情况：数组未旋转（已经有序）
    if (nums[left] < nums[right]) {
        return nums[left];
    }

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        // 比较mid和left
        if (nums[mid] > nums[left]) {
            // mid在左半段
            if (nums[mid] > nums[right]) {
                // 有旋转，最小值在右边
                left = mid + 1;
            } else {
                // 无旋转，最小值是left
                right = mid;
            }
        } else {
            // mid在右半段
            right = mid;
        }
    }

    return nums[left];
}
```

## 代码原理详解

### 核心判断逻辑

**nums[mid] vs nums[right]：**
```typescript
if (nums[mid] > nums[right])

例子1：[4,5,6,7,0,1,2]
       L     M     R
nums[mid]=7, nums[right]=2
7 > 2 ✓ → mid在左半段（大值段）
       → 最小值在右边
       → left = mid + 1

例子2：[5,6,7,0,1,2,4]
       L     M     R
nums[mid]=0, nums[right]=4
0 < 4 ✓ → mid在右半段（小值段）或整体有序
       → 最小值在左边（包括mid）
       → right = mid
```

### 为什么right = mid而不是mid - 1？

```
因为mid可能就是最小值：

例如：[3,4,5,1,2]
      L   M   R

nums[mid]=5 > nums[right]=2
left = mid + 1 = 3
nums = [1,2]
       L R
mid = 3, nums[mid]=1

nums[mid]=1 < nums[right]=2
如果right = mid - 1：
  right = 2
  错过了最小值！

正确：right = mid
  包含mid，不会错过
```

### 循环不变量

```
循环不变量：
[left, right]区间内必包含最小值

初始：
[0, n-1]包含最小值 ✓

每次迭代：
- 如果nums[mid] > nums[right]：
  最小值在(mid, right]
  更新left = mid + 1
  新区间[mid+1, right]包含最小值 ✓

- 如果nums[mid] < nums[right]：
  最小值在[left, mid]
  更新right = mid
  新区间[left, mid]包含最小值 ✓

终止：
left == right
[left, left]只有一个元素
就是最小值 ✓
```

### 示例：`nums = [4,5,6,7,0,1,2]`

```
初始：left=0, right=6

迭代1：
  mid = 3, nums[3] = 7
  nums[mid]=7 > nums[right]=2 ✓
  最小值在右半
  left = mid + 1 = 4

  区间：[4, 6]

迭代2：
  left=4, right=6
  mid = 5, nums[5] = 1
  nums[mid]=1 < nums[right]=2 ✓
  最小值在左半（包括mid）
  right = mid = 5

迭代3：
  left=4, right=5
  mid = 4, nums[4] = 0
  nums[mid]=0 < nums[right]=1 ✓
  最小值在左半（包括mid）
  right = mid = 4

  区间：[4, 4]

终止：left=4 == right=4
返回：nums[4] = 0 ✓
```

## 常见问题

**Q1: 为什么循环条件是left < right而不是left <= right？**
A: 避免死循环：
```
如果left <= right：
当left == right时：
  mid = left = right
  如果nums[mid] < nums[right]：
    right = mid（不变）
  死循环！

left < right：
必然会收敛到left == right
```

**Q2: 能否比较nums[mid]和nums[left]？**
A: 可以但更复杂：
```typescript
if (nums[mid] > nums[left]) {
    // mid可能在左半段，也可能整体有序
    // 需要进一步判断nums[mid]和nums[right]
    if (nums[mid] > nums[right]) {
        left = mid + 1;
    } else {
        right = mid;
    }
} else {
    // mid在右半段
    right = mid;
}

比较right更简洁：
只需一次判断
```

**Q3: 如果数组未旋转怎么办？**
A: 算法仍然正确：
```
nums = [1,2,3,4,5]（未旋转）

所有迭代：
nums[mid] < nums[right]
right不断缩小
最终left == right = 0
返回nums[0] = 1 ✓

或者提前判断：
if (nums[0] < nums[n-1]) {
    return nums[0];
}
```

**Q5: 有重复元素怎么办？**
A: 见154题（困难）：
```
nums[mid] == nums[right]时：
无法判断哪一半有最小值

解决：

最坏：O(n)
```

## 总结

**关键点：**
1. O(log n) → 二分查找
2. 比较nums[mid]和nums[right]
3. nums[mid] > nums[right] → 最小值在右
4. nums[mid] < nums[right] → 最小值在左（含mid）
5. 循环条件：left < right

**二分模板（找最小值）：**
```typescript
let left = 0, right = nums.length - 1;

while (left < right) {
    const mid = Math.floor((left + right) / 2);

    if (nums[mid] > nums[right]) {
        left = mid + 1;
    } else {
        right = mid;
    }
}

return nums[left];
```

- 对比33题的异同

**易错点：**
- 循环条件写成left <= right
- right = mid - 1（会错过最小值）
- 比较nums[mid]和nums[left]（更复杂）
- 返回left而非nums[left]
- 忘记处理未旋转的情况

**记忆技巧：**
- 比较right不比较left
- 大于right搜右边（left = mid + 1）
- 小于right搜左边（right = mid，保留mid）
- 循环条件：left < right（不带等号）
