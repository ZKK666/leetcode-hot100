# 4. 寻找两个正序数组的中位数【困难】

## 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数**。

算法的时间复杂度应该为 `O(log(m+n))`。

---

## 输入输出示例

### 示例 1
```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3]，中位数 2
```

### 示例 2
```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4]，中位数 (2 + 3) / 2 = 2.5
```

### 提示
- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**中位数的定义：**
```
总长度为奇数：
[1,2,3,4,5] → 中位数 = 3（中间元素）

总长度为偶数：
[1,2,3,4] → 中位数 = (2+3)/2 = 2.5（中间两个元素的平均）

转化：
找第k小的数（k = (m+n+1)/2）
```

**为什么O(log(m+n))？**
```
提示：对数时间 → 二分查找

不能：
- 合并两个数组：O(m+n)
- 暴力搜索：O(m+n)

必须：
- 在某个数组上二分
- 每次排除一半
```

---

### 方法一：二分查找（分割线法）- 推荐

**核心思想：**
```
在两个数组中找分割线，使得：
1. 左半部分元素数量 = 右半部分元素数量（或相差1）
2. 左半部分的最大值 <= 右半部分的最小值

nums1: [1, 3, 5, 7]
       分割 ↓
nums2: [2, 4, 6]
       分割 ↓

左半部分：[1, 2, 3]
右半部分：[4, 5, 6, 7]

条件：
max(left) <= min(right)
max(1,2,3) <= min(4,5,6,7)
3 <= 4 ✓

中位数 = (max(left) + min(right)) / 2
       = (3 + 4) / 2 = 3.5
```

**如何二分？**
```
在较短的数组上二分（nums1）
假设nums1在i位置分割，nums2在j位置分割

条件：
i + j = (m + n + 1) / 2（左右元素数量相等）

需要满足：
nums1[i-1] <= nums2[j]（左1 <= 右2）
nums2[j-1] <= nums1[i]（左2 <= 右1）

如果不满足，调整i：
- 如果nums1[i-1] > nums2[j]：i太大，向左
- 如果nums2[j-1] > nums1[i]：i太小，向右
```

**算法流程：**
1. 确保nums1是较短的数组（减少二分次数）
2. 在nums1上二分，范围[0, m]
3. 计算j = (m + n + 1) / 2 - i
4. 检查分割是否正确
5. 根据条件调整i
6. 找到正确分割后，计算中位数

**时间复杂度：** O(log(min(m,n)))
**空间复杂度：** O(1)

---

### 方法二：第K小问题

**核心思想：**
```
中位数 = 第k小的元素
k = (m + n + 1) / 2

问题转化：
在两个有序数组中找第k小的元素

递归思路：
每次排除k/2个元素
```

**时间复杂度：** O(log(m+n))
**空间复杂度：** O(log(m+n)) - 递归栈

## 代码实现（TypeScript）

### 方法一：二分查找（分割线法）- 推荐

```typescript
function findMedianSortedArrays(nums1: number[], nums2: number[]): number {
    // 确保nums1是较短的数组
    if (nums1.length > nums2.length) {
        [nums1, nums2] = [nums2, nums1];
    }

    const m = nums1.length;
    const n = nums2.length;

    let left = 0;
    let right = m;

    while (left <= right) {
        // nums1的分割点
        const i = Math.floor((left + right) / 2);
        // nums2的分割点
        const j = Math.floor((m + n + 1) / 2) - i;

        // 边界值
        const maxLeft1 = i === 0 ? -Infinity : nums1[i - 1];
        const minRight1 = i === m ? Infinity : nums1[i];

        const maxLeft2 = j === 0 ? -Infinity : nums2[j - 1];
        const minRight2 = j === n ? Infinity : nums2[j];

        // 检查分割是否正确
        if (maxLeft1 <= minRight2 && maxLeft2 <= minRight1) {
            // 找到正确的分割
            if ((m + n) % 2 === 1) {
                // 奇数：返回左半部分最大值
                return Math.max(maxLeft1, maxLeft2);
            } else {
                // 偶数：返回左半最大和右半最小的平均
                return (Math.max(maxLeft1, maxLeft2) + Math.min(minRight1, minRight2)) / 2;
            }
        } else if (maxLeft1 > minRight2) {
            // i太大，nums1分太多了，向左移
            right = i - 1;
        } else {
            // i太小，nums1分太少了，向右移
            left = i + 1;
        }
    }

    // 理论上不会到这里
    return 0;
}
```

### 方法二：第K小问题

```typescript
function findMedianSortedArrays(nums1: number[], nums2: number[]): number {
    const m = nums1.length;
    const n = nums2.length;
    const total = m + n;

    /**
     * 找第k小的元素（k从1开始）
     */
    function findKth(start1: number, start2: number, k: number): number {
        // nums1用完了
        if (start1 >= m) {
            return nums2[start2 + k - 1];
        }

        // nums2用完了
        if (start2 >= n) {
            return nums1[start1 + k - 1];
        }

        // k=1，返回两个数组当前最小值
        if (k === 1) {
            return Math.min(nums1[start1], nums2[start2]);
        }

        // 每次排除k/2个元素
        const half = Math.floor(k / 2);

        const index1 = Math.min(start1 + half - 1, m - 1);
        const index2 = Math.min(start2 + half - 1, n - 1);

        if (nums1[index1] <= nums2[index2]) {
            // 排除nums1的前half个
            return findKth(index1 + 1, start2, k - (index1 - start1 + 1));
        } else {
            // 排除nums2的前half个
            return findKth(start1, index2 + 1, k - (index2 - start2 + 1));
        }
    }

    if (total % 2 === 1) {
        // 奇数
        return findKth(0, 0, Math.floor(total / 2) + 1);
    } else {
        // 偶数
        const left = findKth(0, 0, total / 2);
        const right = findKth(0, 0, total / 2 + 1);
        return (left + right) / 2;
    }
}
```

## 代码原理详解

### 分割线法

**分割点的选择：**
```typescript
i + j = (m + n + 1) / 2

为什么+1？
奇数：左边多一个
偶数：左右相等
使用(m+n+1)/2的整数除法统一处理

例如：
m=4, n=6, total=10（偶数）
(10+1)/2 = 5
左边5个，右边5个

m=3, n=4, total=7（奇数）
(7+1)/2 = 4
左边4个，右边3个
```

**边界处理：**
```typescript
const maxLeft1 = i === 0 ? -Infinity : nums1[i-1];
const minRight1 = i === m ? Infinity : nums1[i];

为什么用Infinity？
- i=0：nums1左边没有元素，用-Infinity
- i=m：nums1右边没有元素，用Infinity

保证比较时不会影响结果：
-Infinity <= 任何数
Infinity >= 任何数
```

**调整策略：**
```typescript
if (maxLeft1 > minRight2) {
    // nums1[i-1] > nums2[j]
    // i太大了，nums1分太多
    right = i - 1;
} else {
    // nums2[j-1] > nums1[i]
    // i太小了，nums1分太少
    left = i + 1;
}
```

### 第K小问题

**递归思路：**
```
找第k小：
1. 比较nums1[k/2-1]和nums2[k/2-1]
2. 较小的那个数组的前k/2个必不是第k小
3. 排除，递归剩余

例如：
nums1 = [1,3,5,7]
nums2 = [2,4,6,8,10]
找第5小：

比较nums1[2]=5和nums2[2]=6
5 < 6，排除nums1的[1,3,5]
剩余：nums1=[7], nums2=[2,4,6,8,10]
找第2小（5-3=2）

比较nums1[0]=7和nums2[0]=2
2 < 7，排除nums2的[2]
剩余：nums1=[7], nums2=[4,6,8,10]
找第1小（2-1=1）

返回min(7,4) = 4
```

## 运行示例

### 示例：`nums1 = [1,3], nums2 = [2]`

**分割线法：**
```
m=2, n=1, total=3（奇数）

初始：left=0, right=2

迭代1：
  i = 1（nums1在位置1分割）
  j = (3+1)/2 - 1 = 1（nums2在位置1分割）

  nums1: [1 | 3]
  nums2: [2 |]

  maxLeft1 = nums1[0] = 1
  minRight1 = nums1[1] = 3
  maxLeft2 = nums2[0] = 2
  minRight2 = Infinity

  检查：
  maxLeft1 <= minRight2? 1 <= Infinity ✓
  maxLeft2 <= minRight1? 2 <= 3 ✓

  分割正确！
  total是奇数：
  返回max(1, 2) = 2
```

## 常见问题

**Q1: 为什么要在较短的数组上二分？**
A: 减少时间复杂度：
```
在nums1上二分：O(log m)
在nums2上二分：O(log n)

如果m < n：
在nums1上二分更快
O(log m) < O(log n)
```

**Q2: (m+n+1)/2的作用？**
A: 统一处理奇偶：
```
奇数总长度：
(7+1)/2 = 4
左边4个，右边3个
中位数 = 左边最大值

偶数总长度：
(6+1)/2 = 3
左边3个，右边3个
中位数 = (左边最大 + 右边最小)/2

使用+1：
保证奇数时左边多一个
偶数时左右相等
```

**Q3: 为什么需要Infinity？**
A: 处理边界：
```
当i=0或i=m时：
nums1的某一边没有元素

如果没有Infinity：
需要大量if判断

使用Infinity：
-Infinity自动小于任何数
Infinity自动大于任何数
简化边界处理
```

**Q4: 两种方法如何选择？**
A:
| 方法 | 时间 | 空间 | 理解难度 | 推荐度 |
|------|------|------|---------|--------|
| 分割线法 | O(log(min(m,n))) | O(1) | 难 | ⭐⭐⭐⭐ |
| 第K小 | O(log(m+n)) | O(log(m+n)) | 中 | ⭐⭐⭐⭐⭐ |

面试推荐：第K小（更好理解）

**Q5: 能否合并后取中位数？**
A: 可以但不满足要求：
```typescript
const merged = [];
let i = 0, j = 0;

while (i < m && j < n) {
    if (nums1[i] < nums2[j]) {
        merged.push(nums1[i++]);
    } else {
        merged.push(nums2[j++]);
    }
}

// 取中位数

时间：O(m+n)
不满足O(log(m+n))的要求
```

## 复杂度分析

### 分割线法

**时间复杂度：** O(log(min(m,n)))
- 在较短数组上二分
- 每次缩小一半

**空间复杂度：** O(1)
- 只用常数空间

### 第K小问题

**时间复杂度：** O(log(m+n))
- 每次排除k/2个元素
- 递归深度log(m+n)

**空间复杂度：** O(log(m+n))
- 递归栈深度

## 总结

**关键点：**
1. O(log(m+n)) → 二分查找
2. 分割线法：找正确的分割位置
3. 第K小：递归排除k/2个元素
4. 边界处理：Infinity简化判断

**面试建议：**
- 优先使用第K小方法（更好理解）
- 画图说明分割线位置
- 解释边界处理的必要性
- 说明时间复杂度的推导
- 可以先说合并法，再优化

**易错点：**
- 没有确保nums1是较短数组
- 边界处理遗漏（i=0, i=m）
- j的计算公式错误
- 奇偶情况混淆
- Infinity的使用

**记忆技巧：**
- 分割线：左右元素数量平衡
- 第K小：每次排除k/2
- 奇数：取左边最大
- 偶数：取左右中间值的平均
