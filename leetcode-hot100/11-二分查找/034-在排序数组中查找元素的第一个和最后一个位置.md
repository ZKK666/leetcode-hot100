# 34. 在排序数组中查找元素的第一个和最后一个位置【中等】

## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

---

## 输入输出示例

### 示例 1
```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

### 示例 2
```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

### 示例 3
```
输入：nums = [], target = 0
输出：[-1,-1]
```

### 提示
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
在有序数组中找：
1. target的第一次出现位置（左边界）
2. target的最后一次出现位置（右边界）

例如：[5,7,7,8,8,10], target=8
      0 1 2 3 4 5
左边界：3
右边界：4
```

**O(log n) 要求：**
```
必须用二分查找
但标准二分只能找到一个位置

解决方案：
- 二分查找左边界
- 二分查找右边界
- 两次独立的二分查找
```

---

### 方法一：两次二分查找（推荐）

**寻找左边界：**
```
目标：找到第一个 >= target 的位置

nums = [5,7,7,8,8,10]
target = 8

找到第一个 >= 8 的位置
即：第一个8的位置 = 3
```

**寻找右边界：**
```
目标：找到最后一个 <= target 的位置

或者：找到第一个 > target 的位置，然后-1

nums = [5,7,7,8,8,10]
target = 8

找到第一个 > 8 的位置 = 5
右边界 = 5 - 1 = 4
```

**算法流程：**
1. findLeft(nums, target)：
   - 找第一个 >= target 的位置
2. findRight(nums, target)：
   - 找最后一个 <= target 的位置
3. 验证：
   - 如果left > right 或 nums[left] != target
   - 返回[-1, -1]

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：两次二分（推荐）

```typescript
function searchRange(nums: number[], target: number): number[] {
    /**
     * 找左边界：第一个 >= target 的位置
     */
    function findLeft(target: number): number {
        let left = 0;
        let right = nums.length - 1;
        let result = nums.length;  // 如果不存在，返回length

        while (left <= right) {
            const mid = Math.floor((left + right) / 2);

            if (nums[mid] >= target) {
                // mid可能是左边界，继续向左找
                result = mid;
                right = mid - 1;
            } else {
                // mid小于target，向右找
                left = mid + 1;
            }
        }

        return result;
    }

    /**
     * 找右边界：最后一个 <= target 的位置
     */
    function findRight(target: number): number {
        let left = 0;
        let right = nums.length - 1;
        let result = -1;  // 如果不存在，返回-1

        while (left <= right) {
            const mid = Math.floor((left + right) / 2);

            if (nums[mid] <= target) {
                // mid可能是右边界，继续向右找
                result = mid;
                left = mid + 1;
            } else {
                // mid大于target，向左找
                right = mid - 1;
            }
        }

        return result;
    }

    const leftBound = findLeft(target);
    const rightBound = findRight(target);

    // 验证是否找到
    if (leftBound <= rightBound && leftBound < nums.length && nums[leftBound] === target) {
        return [leftBound, rightBound];
    }

    return [-1, -1];
}
```

### 方法二：统一模板

```typescript
function searchRange(nums: number[], target: number): number[] {
    /**
     * 通用二分查找
     * @param target 目标值
     * @param lower true找左边界，false找右边界
     */
    function binarySearch(target: number, lower: boolean): number {
        let left = 0;
        let right = nums.length - 1;
        let result = -1;

        while (left <= right) {
            const mid = Math.floor((left + right) / 2);

            if (nums[mid] === target) {
                result = mid;

                if (lower) {
                    // 找左边界，继续向左
                    right = mid - 1;
                } else {
                    // 找右边界，继续向右
                    left = mid + 1;
                }
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return result;
    }

    const leftBound = binarySearch(target, true);

    if (leftBound === -1) {
        return [-1, -1];
    }

    const rightBound = binarySearch(target, false);

    return [leftBound, rightBound];
}
```

### 方法三：找左边界 + 长度

```typescript
function searchRange(nums: number[], target: number): number[] {
    // 找第一个 >= target 的位置
    const leftBound = lowerBound(nums, target);

    // target不存在
    if (leftBound === nums.length || nums[leftBound] !== target) {
        return [-1, -1];
    }

    // 找第一个 > target 的位置
    const rightBound = lowerBound(nums, target + 1) - 1;

    return [leftBound, rightBound];
}

/**
 * 找第一个 >= target 的位置（lower_bound）
 */
function lowerBound(nums: number[], target: number): number {
    let left = 0;
    let right = nums.length;  // 注意是length而不是length-1

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] >= target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    return left;
}
```

## 代码原理详解

### 寻找左边界

**关键逻辑：**
```typescript
if (nums[mid] >= target) {
    result = mid;
    right = mid - 1;  // 继续向左找更小的
}

例如：[5,7,7,8,8,10], target=8
     0 1 2 3 4 5

mid=2, nums[2]=7 < 8
  left = 3

mid=4, nums[4]=8 >= 8
  result = 4
  right = 3

mid=3, nums[3]=8 >= 8
  result = 3  （更新为更小的）
  right = 2

终止：left > right
返回：result = 3（左边界）
```

### 寻找右边界

**关键逻辑：**
```typescript
if (nums[mid] <= target) {
    result = mid;
    left = mid + 1;  // 继续向右找更大的
}

例如：[5,7,7,8,8,10], target=8

mid=2, nums[2]=7 <= 8
  result = 2
  left = 3

mid=4, nums[4]=8 <= 8
  result = 4  （更新为更大的）
  left = 5

mid=5, nums[5]=10 > 8
  right = 4

终止：left > right
返回：result = 4（右边界）
```

### 边界细节

**为什么result初始化不同？**
```
findLeft：
result = nums.length
如果target比所有元素都大
返回length表示不存在

findRight：
result = -1
如果target比所有元素都小
返回-1表示不存在
```

## 常见问题

**Q1: 为什么不能直接用标准二分？**
A: 标准二分只能找到一个位置：
```
标准二分：
找到任意一个target
但不知道是第一个还是最后一个

本题需要：
明确的第一个和最后一个
必须修改二分逻辑
```

**Q2: 能否先找任意位置再扩展？**
A: 可以但不是O(log n)：
```typescript
// 先二分找到任意位置
const pos = binarySearch(nums, target);
if (pos === -1) return [-1, -1];

// 向左扩展找左边界
let left = pos;
while (left > 0 && nums[left-1] === target) {
    left--;
}

// 向右扩展找右边界
let right = pos;
while (right < nums.length-1 && nums[right+1] === target) {
    right++;
}

return [left, right];

问题：
扩展过程是O(n)
总时间：O(log n + n) = O(n)
不满足题目要求
```

**Q3: lower_bound和upper_bound是什么？**
A: C++ STL的概念：
```
lower_bound(target)：
- 第一个 >= target 的位置

upper_bound(target)：
- 第一个 > target 的位置

关系：
[lower_bound(target), upper_bound(target))
= target的所有出现位置

本题：
leftBound = lower_bound(target)
rightBound = upper_bound(target) - 1
```

**Q4: 如果target不存在如何判断？**
A: 多种方法：
```
方法1：
if (leftBound > rightBound)
  return [-1, -1]

方法2：
if (leftBound == nums.length || nums[leftBound] != target)
  return [-1, -1]

方法3：
if (rightBound == -1)
  return [-1, -1]
```

**Q5: 能否只用一次二分？**
A: 不能在O(log n)内完成：
```
一次二分只能确定一个边界
必须两次独立的二分查找
```

## 总结

**关键点：**
1. O(log n) → 两次二分查找
2. 左边界：第一个 >= target
3. 右边界：最后一个 <= target
4. 找到后继续搜索（缩小区间）

**二分模板（找边界）：**
```typescript
// 找左边界
function findLeft(target: number): number {
    let left = 0, right = n - 1, result = n;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] >= target) {
            result = mid;
            right = mid - 1;  // 继续向左
        } else {
            left = mid + 1;
        }
    }

    return result;
}

// 找右边界
function findRight(target: number): number {
    let left = 0, right = n - 1, result = -1;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] <= target) {
            result = mid;
            left = mid + 1;  // 继续向右
        } else {
            right = mid - 1;
        }
    }

    return result;
}
```

- 左边界：>= target，继续向左（right = mid - 1）
- 右边界：<= target，继续向右（left = mid + 1）
- 两次独立二分，互不影响
