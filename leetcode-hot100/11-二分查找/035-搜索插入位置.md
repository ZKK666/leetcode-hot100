# 35. 搜索插入位置【简单】

## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,3,5,6], target = 5
输出：2
```

### 示例 2
```
输入：nums = [1,3,5,6], target = 2
输出：1
```

### 示例 3
```
输入：nums = [1,3,5,6], target = 7
输出：4
```

### 提示
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 为**无重复元素**的**升序**排列数组
- `-10^4 <= target <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
有序数组 + O(logn) → 二分查找

目标：
1. 找到target → 返回索引
2. 找不到 → 返回插入位置
```

**插入位置的理解：**
```
插入位置 = 第一个 >= target 的位置

例如：[1, 3, 5, 6], target = 2
插入位置是1（在3之前）

[1, 3, 5, 6], target = 7
插入位置是4（在末尾）
```

---

### 方法：二分查找

**核心思想：**
- 二分查找找到第一个 >= target 的位置
- 如果找到相等的，返回该位置
- 如果找不到，left指针指向的就是插入位置

**算法流程：**

1. **初始化：**
   - left = 0, right = n

2. **二分查找：**
   - mid = (left + right) / 2
   - nums[mid] >= target → right = mid
   - nums[mid] < target → left = mid + 1

3. **返回 left**

**为什么返回left？**
```
循环结束时，left == right
left 指向第一个 >= target 的位置

如果 target 存在：left 指向 target
如果 target 不存在：left 指向插入位置
```

**时间复杂度：** O(logn)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法：二分查找（推荐）

```typescript
function searchInsert(nums: number[], target: number): number {
    let left = 0;
    let right = nums.length;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] < target) {
            // 目标在右半部分
            left = mid + 1;
        } else {
            // 目标在左半部分（包括mid）
            right = mid;
        }
    }

    return left;
}
```

**详细注释版本：**

```typescript
function searchInsert(nums: number[], target: number): number {
    // 左闭右开区间 [left, right)
    let left = 0;
    let right = nums.length; // 注意：right = n，不是 n-1

    while (left < right) {
        // 防止溢出
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] < target) {
            // nums[mid] 太小，目标在右半部分
            // 下一轮搜索区间：[mid+1, right)
            left = mid + 1;
        } else {
            // nums[mid] >= target
            // mid 可能是答案，保留
            // 下一轮搜索区间：[left, mid)
            right = mid;
        }
    }

    // 循环结束：left == right
    // left 指向第一个 >= target 的位置
    return left;
}
```

### 方法二：左闭右闭区间

```typescript
function searchInsert(nums: number[], target: number): number {
    let left = 0;
    let right = nums.length - 1; // 右闭区间

    while (left <= right) { // 注意：<=
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] === target) {
            return mid; // 找到目标
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    // 找不到，返回插入位置
    return left;
}
```

## 代码原理详解

### 左闭右开区间 [left, right)

**1. 为什么 right = n？**
```
左闭右开：[left, right)
right 不包含在搜索范围内
所以初始化为 n（数组长度）

搜索范围：[0, n)，即整个数组
```

**2. 为什么 left < right？**
```
left < right：区间非空
left == right：区间为空，结束

例如：[3, 5)
left=3, right=5：包含3, 4
left=5, right=5：空区间
```

**3. 为什么 right = mid 而不是 mid-1？**
```
nums[mid] >= target：
mid 可能是答案（第一个 >= target 的位置）
需要保留 mid

下一轮搜索：[left, mid)
mid 不在搜索范围内（右开）
但 mid 已经被检查过
```

**4. 为什么最后返回 left？**
```
循环结束：left == right

left 指向第一个 >= target 的位置

情况1：target 存在
nums[left] == target
返回 left（找到）

情况2：target 不存在
nums[left] > target
返回 left（插入位置）

情况3：target > 所有元素
left = n（插入末尾）
```

---

### 左闭右闭区间 [left, right]

**1. 为什么 right = n-1？**
```
左闭右闭：[left, right]
right 包含在搜索范围内
所以初始化为 n-1（最后一个索引）
```

**2. 为什么 left <= right？**
```
left <= right：区间非空
left > right：区间为空，结束

例如：[3, 3]
left=3, right=3：包含3
left=4, right=3：空区间
```

**3. 为什么需要 nums[mid] === target？**
```
左闭右闭模板：
需要显式判断找到的情况

找到：返回 mid
找不到：返回 left（插入位置）
```

## 常见问题

**Q1: 左闭右开和左闭右闭哪个更好？**
A: 各有优劣：
```
左闭右开 [left, right)：
优点：更统一（STL风格），边界清晰
缺点：right 初始化容易错

左闭右闭 [left, right]：
优点：更直观，right 是最后一个索引
缺点：需要多一个判断

推荐：左闭右开（更简洁）
```

**Q2: 为什么不用 nums[mid] == target 判断？**
A: 左闭右开模板更简洁：
```
只需判断 < 和 >=
找到和找不到都返回 left

左闭右闭需要三个分支：
==, <, >
```

**Q3: 如果数组为空怎么办？**
A: 返回0：
```
nums = [], target = 5
left = 0, right = 0
left == right，立即结束
返回 left = 0（插入第一个位置）
```

**Q4: mid 计算会溢出吗？**
A: 会，但TypeScript不会：
```
C++/Java：
mid = left + (right - left) / 2（防溢出）

TypeScript：
数字是浮点数，不会溢出
可以直接用 (left + right) / 2
```

**Q5: 可以用其他方法吗？**
A: 可以，但不推荐：
```
线性查找：O(n)
不满足题目要求 O(logn)
```

## 总结

**关键点：**
1. 二分查找：O(logn)
2. 左闭右开区间 [left, right)：
   - right = n
   - left < right
   - right = mid
3. 返回 left：第一个 >= target 的位置
4. 找到 or 找不到都返回 left

**二分查找模板（左闭右开）：**
```typescript
function searchInsert(nums: number[], target: number): number {
    let left = 0;
    let right = nums.length; // 右开

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid; // 保留mid
        }
    }

    return left;
}
```

**面试建议：**
- 说明左闭右开区间的优势
- 解释为什么返回 left
- 画图演示二分过程
- 讨论边界情况
- 提及左闭右闭区间作为对比

**易错点：**
- right 初始化（n vs n-1）
- 循环条件（< vs <=）
- right 更新（mid vs mid-1）
- 返回值（left vs right）
- 边界情况（空数组、插入开头/末尾）

**记忆技巧：**
- 左闭右开 = 右开不包含 = right = n
- left < right = 区间非空
- nums[mid] >= target = right = mid（保留）
- 返回 left = 第一个 >= target
- 时间 O(logn)，空间 O(1)
