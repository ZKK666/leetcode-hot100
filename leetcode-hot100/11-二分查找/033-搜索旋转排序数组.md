# 33. 搜索旋转排序数组【中等】

## 题目描述

整数数组 `nums` 按升序排列，数组中的值 **互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如，`[0,1,2,4,5,6,7]` 在下标 `3` 处经旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你 **旋转后** 的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

---

## 输入输出示例

### 示例 1
```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

### 示例 2
```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

### 示例 3
```
输入：nums = [1], target = 0
输出：-1
```

### 提示
- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中的每个值都 **独一无二**
- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
- `-10^4 <= target <= 10^4`

## 解题思路（面试推荐 - 最优解）

### 核心思想

**旋转数组的特点：**
```
原数组：[0,1,2,4,5,6,7]（升序）
旋转后：[4,5,6,7,0,1,2]（k=3）

特点：
1. 分成两段，每段都是升序
2. 第一段的所有元素 > 第二段的所有元素
3. 至少有一段是完全有序的

例如：[4,5,6,7|0,1,2]
     左半部分  右半部分
```

**二分查找的核心：**
```
O(log n) → 必须用二分

普通二分：
- 数组有序
- mid与target比较，确定搜索方向

旋转数组二分：
- 数组部分有序
- 先判断哪一半有序
- 再判断target在哪一段
```

---

### 方法：二分查找

**算法流程：**

1. 计算mid = (left + right) / 2

2. **判断哪一半有序**：
   - 如果nums[left] <= nums[mid]：左半部分有序
   - 否则：右半部分有序

3. **判断target在哪一段**：
   - 如果左半部分有序：
     - target在[nums[left], nums[mid]]范围内 → 搜索左半
     - 否则 → 搜索右半
   - 如果右半部分有序：
     - target在[nums[mid], nums[right]]范围内 → 搜索右半
     - 否则 → 搜索左半

4. 更新left或right，重复直到找到或left > right

**关键判断：**
```
为什么nums[left] <= nums[mid]表示左半有序？

例如：[4,5,6,7,0,1,2]
       L     M     R

如果nums[L] <= nums[M]：
[4,5,6,7] 是升序的 → 左半有序

如果nums[L] > nums[M]：
必然经过了旋转点 → 右半有序
```

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：标准二分（推荐）

```typescript
function search(nums: number[], target: number): number {
    let left = 0;
    let right = nums.length - 1;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        // 找到目标值
        if (nums[mid] === target) {
            return mid;
        }

        // 判断哪一半是有序的
        if (nums[left] <= nums[mid]) {
            // 左半部分有序 [left, mid]
            if (nums[left] <= target && target < nums[mid]) {
                // target 在左半部分
                right = mid - 1;
            } else {
                // target 在右半部分
                left = mid + 1;
            }
        } else {
            // 右半部分有序 [mid, right]
            if (nums[mid] < target && target <= nums[right]) {
                // target 在右半部分
                left = mid + 1;
            } else {
                // target 在左半部分
                right = mid - 1;
            }
        }
    }

    return -1;  // 未找到
}
```

### 方法二：先找旋转点（两次二分）

```typescript
function search(nums: number[], target: number): number {
    const n = nums.length;

    // 第一步：找旋转点（最小值的位置）
    let left = 0;
    let right = n - 1;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] > nums[right]) {
            // 最小值在右半部分
            left = mid + 1;
        } else {
            // 最小值在左半部分（包括mid）
            right = mid;
        }
    }

    const pivot = left;  // 旋转点

    // 第二步：确定搜索范围
    left = 0;
    right = n - 1;

    if (target >= nums[pivot] && target <= nums[right]) {
        // target 在右半部分
        left = pivot;
    } else {
        // target 在左半部分
        right = pivot - 1;
    }

    // 第三步：标准二分查找
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[mid] === target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

## 代码原理详解

### 判断有序区间

**左半有序的条件：**
```typescript
if (nums[left] <= nums[mid])

例子1：[4,5,6,7,0,1,2]
       L     M     R
nums[0]=4, nums[3]=7
4 <= 7 ✓ → 左半[4,5,6,7]有序

例子2：[6,7,0,1,2,4,5]
       L     M     R
nums[0]=6, nums[3]=1
6 > 1 ✗ → 左半不完全有序
     → 右半[1,2,4,5]有序
```

### Target范围判断

**左半有序时：**
```typescript
if (nums[left] <= target && target < nums[mid])

必须同时满足：
1. target >= nums[left]（不小于左端点）
2. target < nums[mid]（小于中点）

才能确定target在左半

例如：[4,5,6,7,0,1,2], target=5
nums[left]=4, nums[mid]=7
4 <= 5 < 7 ✓ → target在左半
```

**右半有序时：**
```typescript
if (nums[mid] < target && target <= nums[right])

必须同时满足：
1. target > nums[mid]（大于中点）
2. target <= nums[right]（不大于右端点）

才能确定target在右半
```

## 运行示例

### 示例：`nums = [4,5,6,7,0,1,2], target = 0`

```
初始：left=0, right=6

迭代1：
  mid = 3, nums[3] = 7
  7 ≠ 0

  判断有序部分：
  nums[left]=4 <= nums[mid]=7 → 左半有序

  判断target位置：
  target=0 不在 [4, 7) 范围内
  → target在右半
  left = mid + 1 = 4

迭代2：
  left=4, right=6
  mid = 5, nums[5] = 1
  1 ≠ 0

  判断有序部分：
  nums[left]=0 <= nums[mid]=1 → 左半有序

  判断target位置：
  target=0 在 [0, 1) 范围内
  → target在左半
  right = mid - 1 = 4

迭代3：
  left=4, right=4
  mid = 4, nums[4] = 0
  0 = 0 ✓

返回：4
```

## 常见问题

**Q1: 为什么nums[left] <= nums[mid]有等号？**
A: 处理left == mid的情况：
```
当left和mid相同时：
nums[left] == nums[mid]

此时左半部分只有一个元素
也算有序

如果没有等号：
会进入右半判断
但实际上左半也可以
```

**Q2: target范围判断为什么是开区间/闭区间？**
A: 避免边界问题：
```
左半有序：
nums[left] <= target < nums[mid]
          ↑闭区间    ↑开区间

为什么target < nums[mid]而不是<=？
- 因为已经判断了nums[mid] != target
- 如果target == nums[mid]，已经返回了

右半有序：
nums[mid] < target <= nums[right]
        ↑开区间     ↑闭区间

同理
```

**Q3: 能否用递归？**
A: 可以但不推荐：
```typescript
function search(nums: number[], target: number, left = 0, right = nums.length - 1): number {
    if (left > right) return -1;

    const mid = Math.floor((left + right) / 2);
    if (nums[mid] === target) return mid;

    if (nums[left] <= nums[mid]) {
        if (nums[left] <= target && target < nums[mid]) {
            return search(nums, target, left, mid - 1);
        } else {
            return search(nums, target, mid + 1, right);
        }
    } else {
        if (nums[mid] < target && target <= nums[right]) {
            return search(nums, target, mid + 1, right);
        } else {
            return search(nums, target, left, mid - 1);
        }
    }
}

缺点：递归栈开销
```

**Q4: 如果有重复元素怎么办？**
A: 见81题（困难）：
```
有重复元素时：
nums[left] == nums[mid] == nums[right]
无法判断哪一半有序

解决：
left++或right--，缩小范围
最坏情况：O(n)
```

**Q5: 与153题的区别？**
A:
- 153题：找最小值（旋转点）
- 33题：找target

思路相似，都需要判断有序区间

## 总结

**关键点：**
1. O(log n) → 二分查找
2. 判断哪一半有序
3. 判断target在哪一段
4. 注意边界条件（等号）

**二分模板（旋转数组）：**
```typescript
while (left <= right) {
    const mid = Math.floor((left + right) / 2);

    if (nums[mid] === target) return mid;

    if (nums[left] <= nums[mid]) {
        // 左半有序
        if (nums[left] <= target < nums[mid]) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    } else {
        // 右半有序
        if (nums[mid] < target <= nums[right]) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
}
```

**面试建议：**
- 先画图说明旋转数组特点
- 解释如何判断有序区间
- 说明target范围判断逻辑
- 强调边界条件的处理
- 可以对比普通二分

**易错点：**
- 判断有序时忘记等号
- target范围判断开闭区间搞混
- left/right更新错误
- 忘记nums[mid] == target的情况
- 边界left > right处理

**记忆技巧：**
- 左半有序：nums[left] <= nums[mid]
- 右半有序：否则
- 范围判断：闭开、开闭组合
