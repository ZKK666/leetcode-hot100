# 74. 搜索二维矩阵【中等】

## 题目描述

给你一个满足下述两条属性的 `m x n` 整数矩阵 `matrix`：

- 每行中的整数从左到右按**非严格递增**顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target`，如果 `target` 在矩阵中，返回 `true`；否则，返回 `false`。

---

## 输入输出示例

### 示例 1
```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

### 示例 2
```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

### 提示
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
特殊的二维矩阵：
1. 每行递增
2. 每行第一个元素 > 上一行最后一个元素

等价于：
将二维矩阵展开成一维有序数组

[1,  3,  5,  7]
[10, 11, 16, 20]
[23, 30, 34, 60]

展开 →
[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]

一维有序数组 → 二分查找
```

**索引转换：**
```
一维索引 → 二维索引
假设一维数组长度为 m*n

一维索引 idx：
row = idx / n（行号）
col = idx % n（列号）

二维索引 (i, j) → 一维索引：
idx = i * n + j
```

---

### 方法一：一次二分查找（推荐）

**核心思想：**
- 将二维矩阵看作一维有序数组
- 对一维索引进行二分查找
- 通过索引转换访问二维元素

**算法流程：**

1. **初始化：**
   - left = 0
   - right = m * n - 1

2. **二分查找：**
   - mid = (left + right) / 2
   - 转换为二维索引：row = mid / n, col = mid % n
   - 比较 matrix[row][col] 与 target

3. **返回结果**

**时间复杂度：** O(log(m*n))
**空间复杂度：** O(1)

---

### 方法二：两次二分查找

**核心思想：**
- 第一次二分：找到目标可能所在的行
- 第二次二分：在该行中查找目标

**算法流程：**

1. **二分查找行：**
   - 找到最后一个 first_element <= target 的行

2. **二分查找列：**
   - 在该行中查找 target

**时间复杂度：** O(logm + logn)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法一：一次二分查找（推荐）

```typescript
function searchMatrix(matrix: number[][], target: number): boolean {
    const m = matrix.length;
    const n = matrix[0].length;

    let left = 0;
    let right = m * n - 1;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        // 一维索引转二维索引
        const row = Math.floor(mid / n);
        const col = mid % n;
        const midValue = matrix[row][col];

        if (midValue === target) {
            return true;
        } else if (midValue < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return false;
}
```

**详细注释版本：**

function searchMatrix(matrix: number[][], target: number): boolean {
    const m = matrix.length;    // 行数
    const n = matrix[0].length; // 列数

            return true; // 找到

            // 目标在右半部分
            left = mid + 1;
        } else {
            // 目标在左半部分
            right = mid - 1;
        }
    }

    return false; // 未找到
}

### 方法二：两次二分查找

```typescript
function searchMatrix(matrix: number[][], target: number): boolean {
    const m = matrix.length;
    const n = matrix[0].length;

    // 第一次二分：找到目标可能所在的行
    let top = 0;
    let bottom = m - 1;

    while (top <= bottom) {
        const mid = Math.floor((top + bottom) / 2);

        if (matrix[mid][0] <= target && target <= matrix[mid][n - 1]) {
            // 目标在这一行
            break;
        } else if (matrix[mid][0] > target) {
            // 目标在上方
            bottom = mid - 1;
        } else {
            // 目标在下方
            top = mid + 1;
        }
    }

    // 未找到合适的行
    if (top > bottom) {
        return false;
    }

    // 第二次二分：在找到的行中查找
    const row = Math.floor((top + bottom) / 2);
    let left = 0;
    let right = n - 1;

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (matrix[row][mid] === target) {
            return true;
        } else if (matrix[row][mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return false;
}
```

## 代码原理详解

### 一次二分查找

**1. 索引转换公式：**

```typescript
一维 → 二维：
row = Math.floor(mid / n)
col = mid % n

例如：m=3, n=4
mid=5：
row = 5 / 4 = 1
col = 5 % 4 = 1
→ matrix[1][1]

验证：
一维索引5 = 1*4 + 1 = 5 ✓
```

**2. 为什么可以这样转换？**

```
二维矩阵按行展开：
[0, 1, 2, 3]     → [0, 1, 2, 3,
[4, 5, 6, 7]     →  4, 5, 6, 7,
[8, 9, 10, 11]   →  8, 9, 10, 11]

位置5（值5）：
第几行？5 / 4 = 1（第1行，从0开始）
第几列？5 % 4 = 1（第1列，从0开始）

公式推导：
mid = row * n + col
row = mid / n（整除）
col = mid % n（取余）
```

**3. 为什么用 left <= right？**

```
左闭右闭区间 [left, right]
需要 <=

找到：返回 true
找不到：left > right，返回 false
```

---

### 两次二分查找

**1. 第一次二分：找行**

```typescript
if (matrix[mid][0] <= target && target <= matrix[mid][n-1]) {
    // 目标在这一行
    break;
}

判断：
target >= 该行第一个元素
target <= 该行最后一个元素
→ 目标可能在这一行
```

**2. 第二次二分：找列**

```
在确定的行中进行标准二分查找
```

**3. 为什么两次二分更慢？**

```
时间复杂度：
一次二分：O(log(m*n))
两次二分：O(logm + logn)

数学关系：
log(m*n) = logm + logn

实际上时间复杂度相同
但两次二分需要更多比较操作
```

## 常见问题

**Q1: 为什么可以看作一维数组？**
A: 矩阵的特殊性质：
```
1. 每行递增
2. 每行第一个 > 上一行最后一个

等价于：
一维有序数组

例如：
[1, 3, 5]
[7, 9, 11]
等价于 [1, 3, 5, 7, 9, 11]
```

**Q2: 索引转换会溢出吗？**
A: 不会：
```
题目限制：m, n <= 100
m * n <= 10000

TypeScript 数字是浮点数
不会溢出
```

**Q3: 如果矩阵不满足第二个条件呢？**
A: 变成240题：
```
240. 搜索二维矩阵 II
只满足：每行递增，每列递增
不满足：每行第一个 > 上一行最后一个

不能看作一维数组
需要其他方法（从右上角或左下角开始）
```

**Q4: 可以用线性查找吗？**
A: 可以但不推荐：
```
遍历每个元素：O(m*n)
二分查找：O(log(m*n))

二分更快
```

**Q5: 一次二分和两次二分哪个更好？**
A: 一次二分更好：
```
时间复杂度相同
但代码更简洁
比较次数更少
```
