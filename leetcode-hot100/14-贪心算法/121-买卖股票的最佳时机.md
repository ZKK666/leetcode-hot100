# 121. 买卖股票的最佳时机【简单】

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择**某一天**买入这只股票，并选择在**未来的某一个不同的日子**卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

---

## 输入输出示例

### 示例 1
```
输入：prices = [7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

### 示例 2
```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```

### 提示
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
找到最大差值：
maxProfit = prices[j] - prices[i]
其中 j > i

等价于：
在每个位置，计算"当前价格 - 历史最低价"
```

**暴力解法的问题：**
```
枚举所有买卖组合：
for i in range(n):
    for j in range(i+1, n):
        profit = prices[j] - prices[i]

时间：O(n^2)
会超时
```

**贪心优化：**
```
关键观察：
要获取最大利润：
- 买入价越低越好
- 卖出价越高越好

策略：
遍历价格数组：
- 维护历史最低价
- 计算当前利润（当前价 - 历史最低价）
- 更新最大利润

时间：O(n)
空间：O(1)
```

---

### 方法：一次遍历 + 贪心

**核心思想：**
- 维护遍历过的最低价格
- 计算每天卖出的利润
- 取最大值

**算法流程：**

1. **初始化：**
   - minPrice = ∞（历史最低价）
   - maxProfit = 0（最大利润）

2. **遍历价格数组：**
   - 更新历史最低价：minPrice = min(minPrice, price)
   - 计算今天卖出的利润：profit = price - minPrice
   - 更新最大利润：maxProfit = max(maxProfit, profit)

3. **返回 maxProfit**

**贪心性质：**
```
局部最优 → 全局最优

局部：
在每个位置，用历史最低价买入
计算当前的最大利润

全局：
所有位置的最大利润中的最大值
就是全局最优解
```

**时间复杂度：** O(n) - 遍历一次
**空间复杂度：** O(1) - 只用常数空间

## 代码实现（TypeScript）

### 方法：一次遍历（推荐）

```typescript
function maxProfit(prices: number[]): number {
    let minPrice = Infinity;   // 历史最低价
    let maxProfit = 0;         // 最大利润

    for (const price of prices) {
        // 更新历史最低价
        minPrice = Math.min(minPrice, price);

        // 计算今天卖出的利润
        const profit = price - minPrice;

        // 更新最大利润
        maxProfit = Math.max(maxProfit, profit);
    }

    return maxProfit;
}
```

---

### 方法优化：代码简化

```typescript
function maxProfit(prices: number[]): number {
    let minPrice = prices[0];  // 第一天的价格
    let maxProfit = 0;

    for (let i = 1; i < prices.length; i++) {
        if (prices[i] < minPrice) {
            // 找到更低价格
            minPrice = prices[i];
        } else {
            // 计算利润
            maxProfit = Math.max(maxProfit, prices[i] - minPrice);
        }
    }

    return maxProfit;
}
```

### 方法二：动态规划思路

```typescript
function maxProfit(prices: number[]): number {
    const n = prices.length;
    if (n === 0) return 0;

    // dp[i] 表示第i天卖出的最大利润
    // 等价于：prices[i] - min(prices[0...i-1])

    let minPrice = prices[0];
    let maxProfit = 0;

    for (let i = 1; i < n; i++) {
        // 状态转移
        maxProfit = Math.max(maxProfit, prices[i] - minPrice);
        minPrice = Math.min(minPrice, prices[i]);
    }

    return maxProfit;
}

// 本质上和方法一相同
// 只是从DP角度理解
```

## 代码原理详解

### 贪心策略

**1. 为什么维护历史最低价？**
```typescript
minPrice = Math.min(minPrice, price);

要获取最大利润：
- 买入价要尽可能低
- 在每个位置，用历史最低价买入

例如：[7, 1, 5, 3, 6, 4]
i=0: minPrice=7
i=1: minPrice=1（更新）
i=2: minPrice=1（不变）
i=3: minPrice=1（不变）
i=4: minPrice=1（不变）
i=5: minPrice=1（不变）

在后面的每个位置，都用1作为买入价
```

**2. 为什么计算当前利润？**
```typescript
profit = price - minPrice;

当前价格 - 历史最低价：
= 如果在历史最低点买入，今天卖出的利润

遍历所有可能的卖出点
取最大值
```

**3. 为什么是O(n)？**
```
只遍历一次：
- 每个元素访问一次
- 每次O(1)操作

总时间：O(n)
```

### 示例 1：`prices = [7,1,5,3,6,4]`

**执行过程：**

```
初始：minPrice=∞, maxProfit=0

i=0, price=7：
  minPrice = min(∞, 7) = 7
  profit = 7 - 7 = 0
  maxProfit = max(0, 0) = 0

i=1, price=1：
  minPrice = min(7, 1) = 1
  profit = 1 - 1 = 0
  maxProfit = max(0, 0) = 0

i=2, price=5：
  minPrice = min(1, 5) = 1
  profit = 5 - 1 = 4
  maxProfit = max(0, 4) = 4

i=3, price=3：
  minPrice = min(1, 3) = 1
  profit = 3 - 1 = 2
  maxProfit = max(4, 2) = 4

i=4, price=6：
  minPrice = min(1, 6) = 1
  profit = 6 - 1 = 5
  maxProfit = max(4, 5) = 5 ✓

i=5, price=4：
  minPrice = min(1, 4) = 1
  profit = 4 - 1 = 3
  maxProfit = max(5, 3) = 5

返回：5 ✓

最优方案：
在第1天（价格1）买入
在第4天（价格6）卖出
利润 = 6 - 1 = 5
```

## 常见问题

**Q1: 为什么不需要记录买卖日期？**
A: 题目只要求最大利润：
```
只需要知道最大差值
不需要知道具体哪一天买卖

如果需要记录：
可以额外维护buyDay和sellDay
```

**Q2: 能在同一天买卖吗？**
A: 不能：
```
题目说明："未来的某一个不同的日子"
买卖必须在不同的天

代码中：
profit = price - minPrice
如果同一天，profit = 0
不影响结果
```

**Q3: 为什么不用动态规划？**
A: 贪心更简单：
```
DP思路：
dp[i] = 第i天卖出的最大利润
dp[i] = max(dp[i-1], prices[i] - min(prices[0...i-1]))

空间优化后：
就是贪心解法

因此直接用贪心
```

**Q4: 如果可以多次买卖呢？**
A: 那是另一道题（122题）：
```
本题：只能买卖一次
122题：可以多次买卖

122题解法：
累加所有上涨的差值
profit += max(0, prices[i] - prices[i-1])
```

**Q5: 负数价格怎么办？**
A: 题目约束 >= 0：
```
实际题目：0 <= prices[i] <= 10^4

如果有负数：
算法仍然正确
minPrice会正确更新
```

## 边界情况

### 情况1：单个元素

```
输入: prices = [5]
输出: 0
说明：无法完成交易
```

### 情况2：两个元素

```

输出: 1

输出: 0
```

### 情况3：全部相同

```
输入: prices = [3, 3, 3, 3]
输出: 0
说明：价格不变，无法获利
```

### 情况4：最大值在第一天

```
输入: prices = [10, 9, 8, 7, 6]
输出: 0
说明：价格一直下跌
```

```
输入: prices = [6, 7, 8, 9, 1]
输出: 3
说明：最大利润 = 9 - 6 = 3
     （不能在第4天买第0天卖）
```

## 总结

**关键点：**
1. 维护历史最低价格
2. 计算每天卖出的最大利润
3. 取所有利润的最大值
4. 贪心策略：局部最优 → 全局最优

**贪心模板（买卖股票I）：**
```typescript
let minPrice = Infinity;
let maxProfit = 0;

for (const price of prices) {
    minPrice = Math.min(minPrice, price);
    maxProfit = Math.max(maxProfit, price - minPrice);
}

return maxProfit;
```

**面试建议：**
- 先说明贪心策略（历史最低价买入）
- 解释为什么一次遍历就够
- 分析时间空间复杂度都是最优
- 可以画图演示minPrice和profit的变化
- 提及DP思路（本质相同）

**易错点：**
- 初始化minPrice为0（应该是Infinity或prices[0]）
- 忘记更新minPrice
- 先更新maxProfit再更新minPrice（顺序错误）
- 理解为可以多次买卖（那是122题）
- 边界情况：单个元素、递减序列

**记忆技巧：**
- 历史最低价 + 当前价格 = 最大利润
- 一次遍历，两个变量
- min在前，max在后（先更新价格，再更新利润）
- 贪心 = 每步局部最优
