# 55. 跳跃游戏【中等】

## 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true`；否则，返回 `false`。

---

## 输入输出示例

### 示例 1
```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
```

### 示例 2
```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0，所以永远不可能到达最后一个下标。
```

### 提示
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题转换：**
```
能否到达最后一个位置？

等价于：
最后一个位置是否在可达范围内？

关键：
维护"当前能到达的最远位置"
```

**暴力解法的问题：**
```
DFS/BFS遍历所有可能路径：
- 从每个位置尝试所有跳跃步数
- 时间：O(n^n)
- 会超时
```

**贪心优化：**
```
关键观察：
不需要知道具体路径
只需要知道能否到达

策略：
维护 maxReach（最远可达位置）
遍历每个可达位置：
- 更新 maxReach = max(maxReach, i + nums[i])
- 如果 maxReach >= n-1，返回true

时间：O(n)
```

---

### 方法一：贪心（推荐）

**核心思想：**
- 维护当前能到达的最远位置
- 如果最远位置 >= 终点，返回true

**算法流程：**

1. **初始化：** maxReach = 0

2. **遍历数组：**
   - 如果 i > maxReach：无法到达位置i，返回false
   - 更新：maxReach = max(maxReach, i + nums[i])
   - 如果 maxReach >= n-1：可以到达终点，返回true

3. **遍历结束：** 返回 maxReach >= n-1

**贪心性质：**
```
局部最优：
在每个位置，尽可能跳得远

全局最优：
如果按照这个策略能到达终点
那么就一定能到达
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法二：反向遍历

**核心思想：**
- 从后往前找"能跳到终点的位置"
- 不断更新目标位置

**算法流程：**

1. **初始化：** target = n - 1（最后位置）
2. **从后往前遍历：**
   - 如果 i + nums[i] >= target：
     - 位置i可以跳到target
     - 更新 target = i
3. **返回：** target == 0

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法三：动态规划

**核心思想：**
- dp[i] 表示是否能到达位置i

**缺点：**
- 时间O(n^2)
- 空间O(n)
- 不如贪心

---

## 代码实现（TypeScript）

### 方法一：贪心（正向遍历）

```typescript
function canJump(nums: number[]): boolean {
    const n = nums.length;
    let maxReach = 0;  // 当前能到达的最远位置

    for (let i = 0; i < n; i++) {
        // 如果当前位置超出可达范围
        if (i > maxReach) {
            return false;
        }

        // 更新最远可达位置
        maxReach = Math.max(maxReach, i + nums[i]);

        // 如果已经可以到达终点
        if (maxReach >= n - 1) {
            return true;
        }
    }

    return maxReach >= n - 1;
}
```

---

### 方法一优化：提前剪枝

```typescript
function canJump(nums: number[]): boolean {
    const n = nums.length;
    let maxReach = 0;

    // 只遍历到maxReach（优化）
    for (let i = 0; i <= maxReach && i < n; i++) {
        maxReach = Math.max(maxReach, i + nums[i]);

        // 提前返回
        if (maxReach >= n - 1) {
            return true;
        }
    }

    return maxReach >= n - 1;
}
```

---

### 方法二：反向遍历

```typescript
function canJump(nums: number[]): boolean {
    const n = nums.length;
    let target = n - 1;  // 当前目标位置

    // 从后往前找能跳到目标的位置
    for (let i = n - 2; i >= 0; i--) {
        if (i + nums[i] >= target) {
            // 位置i可以跳到target
            target = i;
        }
    }

    // 如果目标变成了起点，说明可以到达
    return target === 0;
}
```

---

### 方法三：动态规划（不推荐）

```typescript
function canJump(nums: number[]): boolean {
    const n = nums.length;
    const dp: boolean[] = Array(n).fill(false);
    dp[0] = true;  // 起点可达

    for (let i = 0; i < n; i++) {
        if (!dp[i]) continue;  // 位置i不可达

        // 从位置i可以跳到的所有位置
        for (let j = 1; j <= nums[i] && i + j < n; j++) {
            dp[i + j] = true;
        }
    }

    return dp[n - 1];
}

// 时间复杂度：O(n^2)
// 空间复杂度：O(n)
// 不如贪心
```

## 代码原理详解

### 贪心方法

**1. maxReach的含义：**
```typescript
maxReach = max(maxReach, i + nums[i]);

i + nums[i]：
从位置i最远能跳到哪里

maxReach：
从起点出发，能到达的最远位置

例如：nums = [2,3,1,1,4]
i=0: maxReach = max(0, 0+2) = 2
i=1: maxReach = max(2, 1+3) = 4
i=2: maxReach = max(4, 2+1) = 4
...
```

**2. 为什么 i > maxReach 就返回false？**
```typescript
if (i > maxReach) return false;

maxReach：当前能到达的最远位置
i > maxReach：位置i超出可达范围

说明：
有一个"坑"（值为0）挡住了路
无法跨越

例如：nums = [3,2,1,0,4]
i=0: maxReach=3
i=1: maxReach=3
i=2: maxReach=3
i=3: maxReach=3（nums[3]=0）
i=4: i(4) > maxReach(3) → false ✗
```

**3. 为什么提前返回？**
```typescript
if (maxReach >= n - 1) return true;

一旦可以到达终点：
不需要继续遍历
提前返回
```

### 反向遍历方法

**1. target的含义：**
```typescript
target：当前需要跳到的目标位置

初始：target = n-1（终点）

如果位置i能跳到target：
将target更新为i

最终：
如果target == 0，说明起点能跳到终点
```

**2. 为什么从后往前？**
```
从后往前：
不断找"能跳到当前目标的位置"

例如：nums = [2,3,1,1,4]
target = 4
i=3: 3+1=4 >= 4 → target=3
i=2: 2+1=3 >= 3 → target=2
i=1: 1+3=4 >= 2 → target=1
i=0: 0+2=2 >= 1 → target=0
target == 0 → true ✓
```

## 运行示例

### 示例 1：`nums = [2,3,1,1,4]`

**正向遍历执行过程：**

```
初始：maxReach=0

i=0, nums[0]=2：
  i(0) <= maxReach(0) ✓
  maxReach = max(0, 0+2) = 2

i=1, nums[1]=3：
  i(1) <= maxReach(2) ✓
  maxReach = max(2, 1+3) = 4
  maxReach(4) >= n-1(4) → true ✓

提前返回：true
```

**反向遍历执行过程：**

```
初始：target=4

i=3, nums[3]=1：
  3+1=4 >= 4 → target=3

i=2, nums[2]=1：
  2+1=3 >= 3 → target=2

i=1, nums[1]=3：
  1+3=4 >= 2 → target=1

i=0, nums[0]=2：
  0+2=2 >= 1 → target=0

target == 0 → true ✓
```

---

### 示例 2：`nums = [3,2,1,0,4]`

**正向遍历执行过程：**

```
初始：maxReach=0

i=0: maxReach = max(0, 0+3) = 3
i=1: maxReach = max(3, 1+2) = 3
i=2: maxReach = max(3, 2+1) = 3
i=3: maxReach = max(3, 3+0) = 3
i=4: i(4) > maxReach(3) → false ✗

返回：false
```

**反向遍历执行过程：**

```
初始：target=4

i=3: 3+0=3 < 4，target不变
i=2: 2+1=3 < 4，target不变
i=1: 1+2=3 < 4，target不变
i=0: 0+3=3 < 4，target不变

target = 4 ≠ 0 → false ✗
```

## 常见问题

**Q1: 为什么贪心是正确的？**
A: 只关心能否到达：
```
不需要知道具体跳几步
只需要知道能否到达

贪心策略：
尽可能跳得远
如果这样都到不了，那就真的到不了

证明：
如果存在一条路径能到达终点
那么贪心策略也能到达
因为贪心覆盖了所有可达位置
```

**Q2: 为什么不需要DFS/BFS？**
A: 不需要具体路径：
```
DFS/BFS：
- 找所有路径
- 时间复杂度高

本题：
- 只需要判断能否到达
- 贪心O(n)足够
```

**Q3: 如果要求最少步数呢？**
A: 那是另一道题（45题）：
```
本题（55）：能否到达
45题：最少步数到达

45题需要BFS或贪心+分层
```

**Q4: 正向和反向哪个更好？**
A:
```
正向（推荐）：
- 更直观
- 可以提前返回
- 更容易理解

反向：
- 代码更简洁
- 但不太直观
- 无法提前返回

面试推荐正向
```

**Q5: maxReach初始化为什么是0？**
A: 起点位置：
```
初始在位置0
因此maxReach = 0

如果初始化为-1：
第一步 i(0) > maxReach(-1)
会错误返回false
```

## 边界情况

### 情况1：单个元素

```
输入: nums = [0]
输出: true
说明：已经在终点
```

### 情况2：第一个就是0

```
输入: nums = [0, 1, 2]
输出: false
说明：无法离开起点
```

### 情况3：中间有0但可以跳过

```
输入: nums = [2, 0, 0]
输出: true
说明：从0直接跳到2
```

### 情况4：中间有0且无法跳过

```
输入: nums = [1, 0, 1, 0]
输出: false
说明：被第一个0困住
```

### 情况5：可以跳很远

```
输入: nums = [10, 1, 1, 1, 1]
输出: true
说明：第一步就能跳到终点
```

## 总结

**关键点：**
1. 维护最远可达位置（贪心）
2. 如果当前位置超出可达范围，返回false
3. 如果最远位置 >= 终点，返回true
4. 只需一次遍历，O(n)时间，O(1)空间

**贪心模板（跳跃游戏I）：**
```typescript
let maxReach = 0;

for (let i = 0; i < n; i++) {
    if (i > maxReach) return false;
    maxReach = Math.max(maxReach, i + nums[i]);
    if (maxReach >= n - 1) return true;
}

return maxReach >= n - 1;
```

- 解释为什么不需要DFS/BFS
- 画图演示maxReach的变化
- 分析时间空间复杂度
- 可以提及反向遍历方法

**易错点：**
- maxReach初始化错误
- 忘记检查 i > maxReach
- 边界条件：单个元素、第一个为0
- 提前返回的条件
- 理解为"最少步数"（那是45题）

**记忆技巧：**
- 跳跃游戏 = 贪心 + 最远位置
- maxReach >= n-1 = 可以到达
- i > maxReach = 被困住
- 一次遍历，O(n)
