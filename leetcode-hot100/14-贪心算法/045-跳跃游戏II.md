# 45. 跳跃游戏 II【中等】

## 题目描述

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。换句话说，如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处：
- `0 <= j <= nums[i]`
- `i + j < n`

返回到达 `nums[n - 1]` 的**最小跳跃次数**。生成的测试用例可以到达 `nums[n - 1]`。

---

## 输入输出示例

### 示例 1
```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是 2。
     从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。
```

### 示例 2
```
输入: nums = [2,3,0,1,4]
输出: 2
```

### 提示
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `nums[n-1]`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
55题：能否到达？（判断题）
45题：最少几步？（计数题）

关键：
在保证能到达的前提下
求最少跳跃次数
```

**方法对比：**
```
1. BFS（层序遍历）：
   - 将每一跳看作一层
   - 第一次到达终点的层数 = 最少步数
   - 时间：O(n)，空间：O(n)

2. 贪心（推荐）：
   - 记录当前跳跃能到达的最远位置
   - 在这个范围内，找下一跳能到达的最远位置
   - 时间：O(n)，空间：O(1)
```

---

### 方法一：贪心（推荐）

**核心思想：**
- 将每一跳看作一个"区间"
- 在当前区间内，找下一跳能到达的最远位置
- 跳到当前区间末尾时，步数+1

**关键变量：**
```
end：当前跳跃能到达的最远位置（当前区间右边界）
maxReach：下一跳能到达的最远位置（下一区间右边界）
steps：跳跃次数
```

**算法流程：**

1. **初始化：**
   - end = 0（第0跳的边界）
   - maxReach = 0
   - steps = 0

2. **遍历数组（0 到 n-2）：**
   - 更新 maxReach = max(maxReach, i + nums[i])
   - 如果 i == end：
     - 到达当前跳跃的边界
     - steps++
     - end = maxReach（开始新的一跳）

3. **返回 steps**

**为什么遍历到 n-2？**
```
因为题目保证能到达
当遍历到n-2时：
- 如果还没到达终点，最后一跳必然能到达
- 不需要遍历最后一个元素
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法二：BFS（层序遍历）

**核心思想：**
- 将每一跳看作BFS的一层
- 第一次到达终点的层数 = 最少步数

**算法流程：**

1. **第0层：** 位置0
2. **第1层：** 从位置0能跳到的所有位置
3. **第2层：** 从第1层的所有位置能跳到的所有位置
4. ...

**时间复杂度：** O(n)
**空间复杂度：** O(n) - 队列

---

## 代码实现（TypeScript）

### 方法一：贪心（推荐）

```typescript
function jump(nums: number[]): number {
    const n = nums.length;
    let steps = 0;         // 跳跃次数
    let end = 0;           // 当前跳跃能到达的最远位置（右边界）
    let maxReach = 0;      // 下一跳能到达的最远位置

    // 遍历到 n-2（最后一个元素不需要遍历）
    for (let i = 0; i < n - 1; i++) {
        // 更新下一跳的最远位置
        maxReach = Math.max(maxReach, i + nums[i]);

        // 到达当前跳跃的边界
        if (i === end) {
            steps++;           // 进行下一跳
            end = maxReach;    // 更新边界

            // 如果已经可以到达终点，提前返回
            if (end >= n - 1) {
                break;
            }
        }
    }

    return steps;
}
```

### 方法二：BFS（层序遍历）

```typescript
function jump(nums: number[]): number {
    const n = nums.length;
    if (n === 1) return 0;

    let steps = 0;         // 当前层数（跳跃次数）
    let currentEnd = 0;    // 当前层的右边界
    let nextEnd = 0;       // 下一层的右边界

    for (let i = 0; i <= currentEnd; i++) {
        // 更新下一层的右边界
        nextEnd = Math.max(nextEnd, i + nums[i]);

        // 到达当前层的边界
        if (i === currentEnd) {
            steps++;
            currentEnd = nextEnd;

            // 如果下一层能到达终点
            if (currentEnd >= n - 1) {
                return steps;
            }
        }
    }

    return steps;
}

// 本质上和贪心方法相同
```

### 方法三：动态规划（不推荐）

```typescript
function jump(nums: number[]): number {
    const n = nums.length;
    const dp: number[] = Array(n).fill(Infinity);
    dp[0] = 0;

    for (let i = 0; i < n; i++) {
        // 从位置i能跳到的所有位置
        for (let j = 1; j <= nums[i] && i + j < n; j++) {
            dp[i + j] = Math.min(dp[i + j], dp[i] + 1);
        }
    }

    return dp[n - 1];
}

// 时间复杂度：O(n*m)，m是nums[i]的最大值
// 空间复杂度：O(n)
// 不如贪心
```

## 代码原理详解

### 贪心方法

**1. 区间的概念：**
```
每一跳对应一个区间 [start, end]

第0跳：[0, 0]（起点）
第1跳：[1, end1]（从0能跳到的范围）
第2跳：[end1+1, end2]（从第1跳的范围能跳到的范围）
...

例如：nums = [2,3,1,1,4]
第0跳：[0, 0]
第1跳：[1, 2]（从0能跳到1和2）
第2跳：[3, 4]（从1和2能跳到3和4）
```

**2. maxReach的更新：**
```typescript
maxReach = Math.max(maxReach, i + nums[i]);

在当前区间内：
不断更新下一跳能到达的最远位置

例如：第1跳区间 [1, 2]
i=1: maxReach = max(0, 1+3) = 4
i=2: maxReach = max(4, 2+1) = 4

第2跳能到达位置4
```

**3. 为什么 i == end 时步数+1？**
```typescript
if (i === end) {
    steps++;
    end = maxReach;
}

到达当前区间右边界：
- 必须进行下一跳
- 步数+1
- 更新边界为下一跳的最远位置

这是贪心的关键：
在当前区间内，已经找到了下一跳的最优位置
```

**4. 为什么遍历到 n-2？**
```
题目保证能到达终点

遍历到 n-2：
- 如果此时 end >= n-1，已经能到达
- 如果此时 end < n-1，最后一跳必然能到达

不需要遍历最后一个元素
```

## 运行示例

### 示例 1：`nums = [2,3,1,1,4]`

**执行过程：**

```
初始：steps=0, end=0, maxReach=0

i=0, nums[0]=2：
  maxReach = max(0, 0+2) = 2
  i == end(0)：
    steps = 1
    end = 2

状态：steps=1, end=2, maxReach=2
（第1跳：能到达位置1和2）

i=1, nums[1]=3：
  maxReach = max(2, 1+3) = 4
  i != end(2)

i=2, nums[2]=1：
  maxReach = max(4, 2+1) = 4
  i == end(2)：
    steps = 2
    end = 4

状态：steps=2, end=4, maxReach=4
（第2跳：能到达位置3和4）

i=3（到达n-1=4，循环结束）

返回：steps = 2 ✓

路径：
0 → 1 → 4
或 0 → 2 → 4
（任意一条都是2步）
```

**区间示意：**
```
nums = [2, 3, 1, 1, 4]
        0  1  2  3  4

第0跳：[0]
第1跳：[1, 2]（从0能跳到）
第2跳：[3, 4]（从1或2能跳到）

总共2跳 ✓
```

---

### 示例 2：`nums = [2,3,0,1,4]`

**执行过程：**

```
i=0: maxReach=2, i==end → steps=1, end=2
i=1: maxReach=max(2,1+3)=4, i!=end
i=2: maxReach=max(4,2+0)=4, i==end → steps=2, end=4

返回：2 ✓

路径：0 → 1 → 4
```

## 常见问题

**Q1: 为什么这个贪心策略是最优的？**
A: 证明：
```
贪心策略：
在每一跳的区间内，找下一跳能到达的最远位置

假设最优解需要k步：
第1步：到达区间[a1, b1]
第2步：到达区间[a2, b2]
...

贪心解：
第1步：到达[a1, b1']，其中b1' >= b1（更远）
第2步：到达[a2, b2']，其中b2' >= b2（更远）

因此：
贪心解的步数 <= 最优解的步数
贪心解就是最优解
```

**Q2: 能否从后往前贪心？**
A: 可以但不够优：
```
从后往前：
找能跳到当前位置的"最远"位置
倒推回起点

时间：O(n^2)（最坏）
因为每次可能要遍历前面所有位置

从前往后：
O(n)，更优
```

**Q3: 如果不保证能到达怎么办？**
A: 需要额外判断：
```typescript
function jump(nums: number[]): number {
    if (nums.length === 1) return 0;

    let steps = 0, end = 0, maxReach = 0;

    for (let i = 0; i < nums.length - 1; i++) {
        maxReach = Math.max(maxReach, i + nums[i]);

        if (i === end) {
            // 无法前进
            if (maxReach <= end) {
                return -1;  // 无法到达
            }
            steps++;
            end = maxReach;
        }
    }

    return end >= nums.length - 1 ? steps : -1;
}
```

**Q4: BFS和贪心本质相同吗？**
A: 是的：
```
BFS的每一层 = 贪心的每一跳

BFS：
第1层：从0能到达的位置
第2层：从第1层能到达的位置

贪心：
第1跳：end = 从0能到达的最远位置
第2跳：end = 从[1, end1]能到达的最远位置

本质相同，贪心更简洁
```

**Q5: 为什么不用DP？**
A: 复杂度高：
```
DP：
dp[i] = min(dp[j] + 1) for all j that can reach i
时间：O(n*m)

贪心：
时间：O(n)

贪心更优
```

## 总结

**关键点：**
1. 将每一跳看作一个区间
2. 在当前区间内，找下一跳的最远位置
3. 到达区间边界时，步数+1
4. 遍历到 n-2 即可

**贪心模板（跳跃游戏II）：**
```typescript
let steps = 0;
let end = 0;
let maxReach = 0;

for (let i = 0; i < n - 1; i++) {
    maxReach = Math.max(maxReach, i + nums[i]);

    if (i === end) {
        steps++;
        end = maxReach;
    }
}

return steps;
```
