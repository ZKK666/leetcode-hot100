# 763. 划分字母区间【中等】

## 题目描述

给你一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s`。

返回一个表示每个字符串片段的长度的列表。

---

## 输入输出示例

### 示例 1
```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。
```

### 示例 2
```
输入：s = "eccbbbbdec"
输出：[10]
```

### 提示
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
划分片段的条件：
同一字母只能出现在一个片段中

等价于：
片段内的所有字母，最后一次出现都在片段内

关键：
如何确定片段的边界？
```

**贪心策略：**
```
1. 记录每个字母最后一次出现的位置
2. 遍历字符串：
   - 维护当前片段的右边界（所有字母最后出现位置的最大值）
   - 当遍历到右边界时，划分一个片段
```

---

### 方法：贪心 + 区间合并

**核心思想：**
- 预处理：记录每个字母最后一次出现的位置
- 遍历字符串，维护当前片段的右边界
- 当遍历到右边界时，完成一个片段

**算法流程：**

1. **预处理：**
   - lastIndex[char] = 字母char最后一次出现的位置

2. **遍历字符串：**
   - start：当前片段起始位置
   - end：当前片段结束位置（右边界）
   - 对于每个字符 s[i]：
     - 更新 end = max(end, lastIndex[s[i]])
     - 如果 i == end：
       - 到达片段边界
       - 记录片段长度：end - start + 1
       - 更新 start = end + 1

3. **返回片段长度列表**

**贪心性质：**
```
局部最优：
尽可能早地划分片段

全局最优：
片段数量最多

如果某个位置可以划分：
立即划分，不会影响后续
```

**时间复杂度：** O(n) - 遍历两次
**空间复杂度：** O(1) - 固定26个字母

---

## 代码实现（TypeScript）

### 方法：贪心（推荐）

```typescript
function partitionLabels(s: string): number[] {
    const n = s.length;

    // 1. 记录每个字母最后一次出现的位置
    const lastIndex: Map<string, number> = new Map();
    for (let i = 0; i < n; i++) {
        lastIndex.set(s[i], i);
    }

    // 2. 贪心划分
    const result: number[] = [];
    let start = 0;  // 当前片段起始位置
    let end = 0;    // 当前片段结束位置（右边界）

    for (let i = 0; i < n; i++) {
        // 更新右边界：当前字母最后出现的位置
        end = Math.max(end, lastIndex.get(s[i])!);

        // 到达片段边界
        if (i === end) {
            // 记录片段长度
            result.push(end - start + 1);
            // 更新起始位置
            start = end + 1;
        }
    }

    return result;
}
```

---

### 方法优化：使用数组代替Map

```typescript
function partitionLabels(s: string): number[] {
    const n = s.length;

    // 使用数组存储（a-z对应0-25）
    const lastIndex: number[] = Array(26).fill(-1);
    for (let i = 0; i < n; i++) {
        const charCode = s.charCodeAt(i) - 'a'.charCodeAt(0);
        lastIndex[charCode] = i;
    }

    const result: number[] = [];
    let start = 0;
    let end = 0;

    for (let i = 0; i < n; i++) {
        const charCode = s.charCodeAt(i) - 'a'.charCodeAt(0);
        end = Math.max(end, lastIndex[charCode]);

        if (i === end) {
            result.push(end - start + 1);
            start = end + 1;
        }
    }

    return result;
}
```

## 代码原理详解

### 核心思想

**1. 为什么记录最后出现位置？**
```typescript
lastIndex[char] = 字母最后一次出现的位置

某个字母在片段中：
它的所有出现位置都必须在片段内

因此：
片段的右边界至少要到lastIndex[char]

例如：s = "ababcbaca"
'a'最后在位置8
片段必须延伸到位置8
```

**2. 为什么是max(end, lastIndex[s[i]])?**
```typescript
end = Math.max(end, lastIndex.get(s[i])!);

当前片段包含多个字母：
- 'a'最后在位置8
- 'b'最后在位置5
- 'c'最后在位置7

片段右边界 = max(8, 5, 7) = 8

确保所有字母都在片段内
```

**3. 为什么 i == end 时划分？**
```typescript
if (i === end) {
    // 划分片段
}

i == end：
- 遍历到了当前片段的右边界
- 片段内所有字母的最后出现位置都已包含
- 可以安全划分

继续遍历：
- 后面的字母不会出现在当前片段
- 开始新的片段
```

**4. 为什么是贪心？**
```
能划分就立即划分：
不会影响后续片段
片段数量最多

例如：
如果位置5可以划分，立即划分
不需要等到位置10

贪心 = 局部最优（尽早划分）→ 全局最优（片段最多）
```

## 常见问题

**Q1: 为什么要记录最后出现位置，而不是第一次？**
A: 最后位置决定边界：
```
某个字母最后一次出现的位置：
= 包含这个字母的片段的最小右边界

例如：'a'在位置0, 5, 8出现
片段至少要到位置8
否则位置8的'a'会在另一个片段
```

**Q2: 能否不预处理，直接遍历？**
A: 不行：
```
需要提前知道每个字母的最后位置
才能确定片段边界

如果不预处理：
遍历时无法知道当前片段应该延伸到哪里
```

**Q3: 为什么是O(n)而不是O(26n)？**
A: 常数不计：
```
预处理：O(n)
遍历：O(n)
总时间：O(2n) = O(n)

Map操作：O(1)（最多26个字母）
```

**Q4: 如果要求最少片段数怎么办？**
A: 本题就是最少：
```
题目要求：
尽可能多的片段

贪心策略：
尽早划分

结果：
片段数最多 = 片段最多

如果要求最少：
就是1个片段（整个字符串）
```

**Q5: 能否用其他方法？**
A: 其他方法复杂：
```
区间合并：
- 将每个字母看作一个区间[first, last]
- 合并重叠区间
- 时间：O(n + 26log26) ≈ O(n)

并查集：
- 将重叠字母合并
- 时间：O(n × α(n)) ≈ O(n)

贪心最简单直接
```

## 总结

**关键点：**
1. 预处理：记录每个字母最后出现的位置
2. 维护片段右边界（所有字母最后位置的最大值）
3. 到达右边界时划分片段
4. 贪心策略：尽早划分，片段最多

**贪心模板（划分字母区间）：**
```typescript
// 1. 记录最后位置
const lastIndex = new Map<string, number>();
for (let i = 0; i < s.length; i++) {
    lastIndex.set(s[i], i);
}

// 2. 贪心划分
const result: number[] = [];
let start = 0, end = 0;

for (let i = 0; i < s.length; i++) {
    end = Math.max(end, lastIndex.get(s[i])!);

    if (i === end) {
        result.push(end - start + 1);
        start = end + 1;
    }
}

return result;
```

**面试建议：**
- 先说明预处理的必要性
- 解释右边界的含义（所有字母最后位置的max）
- 说明为什么 i == end 时划分
- 画图演示片段的划分过程
- 分析时间空间复杂度

**易错点：**
- 忘记预处理最后位置
- end更新错误（应该用max）
- 片段长度计算错误（end - start + 1）
- 忘记更新start（start = end + 1）
- 边界情况：单个字符、全部相同

**记忆技巧：**
- 最后位置 → 片段右边界
- 贪心 = 尽早划分 = 片段最多
- i == end：到边界，立即划分
- 预处理 + 一次遍历 = O(n)
