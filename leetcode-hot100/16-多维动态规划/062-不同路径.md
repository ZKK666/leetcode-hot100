# 62. 不同路径【中等】

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 "Start" ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish" ）。

问总共有多少条不同的路径？

---

## 输入输出示例

### 示例 1
```
输入：m = 3, n = 7
输出：28
```

### 示例 2
```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

### 示例 3
```
输入：m = 7, n = 3
输出：28
```

### 示例 4
```
输入：m = 3, n = 3
输出：6
```

### 提示
- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
只能向右或向下移动
求路径数量

经典二维DP问题
```

**状态转移：**
```
dp[i][j] = 到达(i,j)的路径数

到达(i,j)的方式：
1. 从(i-1,j)向下
2. 从(i,j-1)向右

dp[i][j] = dp[i-1][j] + dp[i,j-1]
```

**边界条件：**
```
第一行：dp[0][j] = 1（只能一直向右）
第一列：dp[i][0] = 1（只能一直向下）
```

---

### 方法一：动态规划（二维数组）

**核心思想：**
- dp[i][j] 表示到达(i,j)的路径数
- 状态转移：dp[i][j] = dp[i-1][j] + dp[i,j-1]

**时间复杂度：** O(m×n)
**空间复杂度：** O(m×n)

---

### 方法二：动态规划（空间优化）

**核心思想：**
- 只需要一维数组
- 滚动更新

**时间复杂度：** O(m×n)
**空间复杂度：** O(n)

---

### 方法三：组合数学

**核心思想：**
- 从(0,0)到(m-1,n-1)
- 需要向下m-1步，向右n-1步
- 总共m+n-2步，选择m-1步向下
- 答案 = C(m+n-2, m-1)

**时间复杂度：** O(m)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法一：二维DP（推荐）

```typescript
function uniquePaths(m: number, n: number): number {
    // dp[i][j] = 到达(i,j)的路径数
    const dp: number[][] = Array(m).fill(0).map(() => Array(n).fill(0));

    // 初始化第一行和第一列
    for (let i = 0; i < m; i++) {
        dp[i][0] = 1;
    }
    for (let j = 0; j < n; j++) {
        dp[0][j] = 1;
    }

    // 状态转移
    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }

    return dp[m - 1][n - 1];
}
```

---

### 方法二：一维DP（空间优化）

```typescript
function uniquePaths(m: number, n: number): number {
    // 只用一维数组
    const dp: number[] = Array(n).fill(1);

    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {
            // dp[j]表示当前行第j列的路径数
            // dp[j]（旧值）= 上一行第j列
            // dp[j-1]（新值）= 当前行第j-1列
            dp[j] = dp[j] + dp[j - 1];
        }
    }

    return dp[n - 1];
}
```

---

### 方法三：组合数学

```typescript
function uniquePaths(m: number, n: number): number {
    // C(m+n-2, m-1) = (m+n-2)! / ((m-1)! × (n-1)!)
    // = (m+n-2) × (m+n-3) × ... × n / (m-1)!

    let numerator = 1;
    let denominator = 1;

    // 计算 C(m+n-2, m-1)
    for (let i = 0; i < m - 1; i++) {
        numerator *= (m + n - 2 - i);
        denominator *= (i + 1);
    }

    return numerator / denominator;
}
```

---

## 复杂度分析

**二维DP：**
- 时间：O(m×n)
- 空间：O(m×n)

**一维DP：**
- 时间：O(m×n)
- 空间：O(n)

**组合数学：**
- 时间：O(min(m,n))
- 空间：O(1)

## 运行示例

### 示例：`m = 3, n = 3`

**二维DP：**
```
初始化：
dp = [[1, 1, 1],
      [1, 0, 0],
      [1, 0, 0]]

状态转移：
dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2
dp[1][2] = dp[0][2] + dp[1][1] = 1 + 2 = 3
dp[2][1] = dp[1][1] + dp[2][0] = 2 + 1 = 3
dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6

dp = [[1, 1, 1],
      [1, 2, 3],
      [1, 3, 6]]

返回：dp[2][2] = 6 ✓
```

## 总结

**关键点：**
1. 二维DP：dp[i][j] = dp[i-1][j] + dp[i][j-1]
2. 空间优化：一维数组滚动
3. 组合数学：C(m+n-2, m-1)

**DP模板（不同路径）：**
```typescript
const dp: number[][] = Array(m).fill(0).map(() => Array(n).fill(1));

for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
        dp[i][j] = dp[i-1][j] + dp[i][j-1];
    }
}

return dp[m-1][n-1];
```

**面试建议：**
- 优先说明二维DP方法
- 解释状态转移方程
- 提及空间优化
- 进阶：组合数学解法

**易错点：**
- 边界初始化（第一行、第一列）
- 空间优化时的滚动更新
- 组合数溢出

**记忆技巧：**
- 网格路径 = 二维DP
- dp[i][j] = 上 + 左
- 空间优化 = 一维滚动
- 组合数 = C(m+n-2, m-1)
