# 1143. 最长公共子序列【中等】

## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长**公共子序列**的长度。如果不存在**公共子序列**，返回 `0`。

一个字符串的**子序列**是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的**公共子序列**是这两个字符串所共同拥有的子序列。

---

## 输入输出示例

### 示例 1
```
输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace"，它的长度为 3。
```

### 示例 2
```
输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc"，它的长度为 3。
```

### 示例 3
```
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0。
```

### 提示
- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字符组成

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
子序列 vs 子串：
- 子串：连续字符
- 子序列：不要求连续，但保持相对顺序

例如："ace" 是 "abcde" 的子序列
a - - - e
    c

不连续，但顺序不变
```

**经典二维DP问题：**
```
两个字符串 → 二维DP
求最值 → 动态规划
```

---

### 方法：二维动态规划

**状态定义：**
```
dp[i][j] = text1[0...i-1] 和 text2[0...j-1] 的最长公共子序列长度

注意：
i 和 j 表示前 i 个、前 j 个字符
dp数组大小是 (m+1) × (n+1)
dp[0][j] 和 dp[i][0] 表示空字符串
```

**状态转移：**
```
情况1：text1[i-1] == text2[j-1]
  当前字符相同
  dp[i][j] = dp[i-1][j-1] + 1

  解释：
  前面的LCS长度 + 当前这个相同的字符

情况2：text1[i-1] != text2[j-1]
  当前字符不同
  dp[i][j] = max(dp[i-1][j], dp[i][j-1])

  解释：
  不能同时选两个字符
  要么跳过text1[i-1]：dp[i-1][j]
  要么跳过text2[j-1]：dp[i][j-1]
  取较大值
```

**边界条件：**
```
dp[0][j] = 0  // text1为空
dp[i][0] = 0  // text2为空

空字符串的LCS长度为0
```

**算法流程：**

1. **初始化：**
   - 创建 (m+1) × (n+1) 的dp数组
   - dp[0][...] = 0, dp[...][0] = 0

2. **状态转移：**
   - 遍历 i 从 1 到 m
   - 遍历 j 从 1 到 n
   - 根据字符是否相同更新 dp[i][j]

3. **返回 dp[m][n]**

**时间复杂度：** O(m × n)
**空间复杂度：** O(m × n)

---

## 代码实现（TypeScript）

### 方法一：二维DP（推荐）

```typescript
function longestCommonSubsequence(text1: string, text2: string): number {
    const m = text1.length;
    const n = text2.length;

    // dp[i][j] = text1[0...i-1] 和 text2[0...j-1] 的LCS长度
    const dp: number[][] = Array(m + 1).fill(0).map(() => Array(n + 1).fill(0));

    // 边界条件：dp[0][j] = 0, dp[i][0] = 0（已初始化）

    // 状态转移
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (text1[i - 1] === text2[j - 1]) {
                // 字符相同：LCS长度+1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 字符不同：取跳过text1[i-1]或text2[j-1]的较大值
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}
```

---

### 方法二：空间优化（一维DP）

```typescript
function longestCommonSubsequence(text1: string, text2: string): number {
    const m = text1.length;
    const n = text2.length;

    // 优化：只用一维数组
    // dp[j] = 当前行的 LCS[j]
    const dp: number[] = Array(n + 1).fill(0);

    for (let i = 1; i <= m; i++) {
        let prev = 0; // 保存 dp[i-1][j-1]

        for (let j = 1; j <= n; j++) {
            const temp = dp[j]; // 保存旧值（下一轮的prev）

            if (text1[i - 1] === text2[j - 1]) {
                dp[j] = prev + 1;
            } else {
                dp[j] = Math.max(dp[j], dp[j - 1]);
            }

            prev = temp; // 更新prev
        }
    }

    return dp[n];
}
```

## 代码原理详解

### 二维DP详解

**1. 为什么是 dp[i-1][j-1] + 1？**
```typescript
if (text1[i-1] === text2[j-1]) {
    dp[i][j] = dp[i-1][j-1] + 1;
}

举例：
text1 = "abc"
text2 = "ac"

当 i=3, j=2 时（字符'c'）：
text1[2] == text2[1] == 'c'

dp[3][2] = dp[2][1] + 1
         = "ab"和"a"的LCS长度 + 1
         = 1 + 1 = 2

LCS = "ac"
```

**2. 为什么是 max(dp[i-1][j], dp[i][j-1])？**
```typescript
if (text1[i-1] !== text2[j-1]) {
    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
}

举例：
text1 = "abc"
text2 = "aec"

当 i=2, j=2 时（'b' vs 'e'）：
text1[1] != text2[1]

dp[2][2] = max(dp[1][2], dp[2][1])
         = max("a"和"ae"的LCS, "ab"和"a"的LCS)
         = max(1, 1) = 1

选择：
- 跳过text1[1]='b'：匹配"a"和"ae" → LCS=1
- 跳过text2[1]='e'：匹配"ab"和"a" → LCS=1

取较大值
```

**3. 为什么索引是 i-1 和 j-1？**
```
dp数组大小：(m+1) × (n+1)
dp[i][j] 表示前 i 个和前 j 个字符

但字符串索引从0开始：
text1[i-1] 是第 i 个字符
text2[j-1] 是第 j 个字符

例如：
dp[1][1] 对应 text1[0] 和 text2[0]
```

---

### 空间优化详解

**1. 为什么可以优化到一维？**
```
观察状态转移：
dp[i][j] 只依赖：
- dp[i-1][j-1]（左上）
- dp[i-1][j]  （上）
- dp[i][j-1]  （左）

一维滚动数组：
用 dp[j] 表示当前行的值
用 prev 保存左上角的值
dp[j] 更新前是上方的值
dp[j-1] 是左方的值
```

**2. 变量含义：**
```typescript
for (let i = 1; i <= m; i++) {
    let prev = 0; // dp[i-1][j-1]（左上）

    for (let j = 1; j <= n; j++) {
        const temp = dp[j]; // 保存更新前的值（下一轮的左上）

        if (text1[i-1] === text2[j-1]) {
            dp[j] = prev + 1; // 用左上角 + 1
        } else {
            dp[j] = Math.max(dp[j], dp[j-1]);
            //               ↑上     ↑左
        }

        prev = temp; // 更新左上角
    }
}
```

**3. 执行过程示意：**
```
初始：dp = [0, 0, 0, 0]

i=1：
  j=1: prev=0, temp=dp[1]=0, dp[1]=?, prev=0
  j=2: prev=0, temp=dp[2]=0, dp[2]=?, prev=0
  ...

每次迭代：
- temp 保存旧的 dp[j]（下一轮的prev）
- dp[j] 更新为新值
- prev 更新为 temp
```

## 运行示例

### 示例 1：`text1 = "abcde", text2 = "ace"`

**DP表构建：**

```
    ""  a  c  e
""   0  0  0  0
a    0  1  1  1
b    0  1  1  1
c    0  1  2  2
d    0  1  2  2
e    0  1  2  3
```

**详细过程：**

```
初始化：
dp[0][...] = 0
dp[...][0] = 0

i=1, text1[0]='a'：
  j=1, text2[0]='a'：
    'a' == 'a' ✓
    dp[1][1] = dp[0][0] + 1 = 1

  j=2, text2[1]='c'：
    'a' != 'c' ✗
    dp[1][2] = max(dp[0][2], dp[1][1]) = max(0, 1) = 1

  j=3, text2[2]='e'：
    'a' != 'e' ✗
    dp[1][3] = max(dp[0][3], dp[1][2]) = max(0, 1) = 1

i=2, text1[1]='b'：
  j=1: 'b' != 'a', dp[2][1] = max(dp[1][1], dp[2][0]) = 1
  j=2: 'b' != 'c', dp[2][2] = max(dp[1][2], dp[2][1]) = 1
  j=3: 'b' != 'e', dp[2][3] = max(dp[1][3], dp[2][2]) = 1

i=3, text1[2]='c'：
  j=1: 'c' != 'a', dp[3][1] = 1
  j=2: 'c' == 'c' ✓, dp[3][2] = dp[2][1] + 1 = 2
  j=3: 'c' != 'e', dp[3][3] = max(dp[2][3], dp[3][2]) = 2

i=4, text1[3]='d'：
  j=1: 'd' != 'a', dp[4][1] = 1
  j=2: 'd' != 'c', dp[4][2] = max(dp[3][2], dp[4][1]) = 2
  j=3: 'd' != 'e', dp[4][3] = max(dp[3][3], dp[4][2]) = 2

i=5, text1[4]='e'：
  j=1: 'e' != 'a', dp[5][1] = 1
  j=2: 'e' != 'c', dp[5][2] = 2
  j=3: 'e' == 'e' ✓, dp[5][3] = dp[4][2] + 1 = 3

返回：dp[5][3] = 3 ✓
LCS = "ace"
```

## 常见问题

**Q1: 子序列和子串有什么区别？**
A: 连续性不同：
```
子串（substring）：
- 必须连续
- "abc" 的子串："a", "ab", "abc", "b", "bc", "c"

子序列（subsequence）：
- 不要求连续
- "abc" 的子序列："a", "b", "c", "ab", "ac", "bc", "abc", ""

LCS 是子序列问题，不要求连续
```

**Q2: 为什么不能用贪心？**
A: 局部最优 ≠ 全局最优：
```
text1 = "abcde"
text2 = "ace"

贪心：
第一个匹配'a' ✓
第二个匹配？'b'不在text2中，跳过
第三个匹配'c' ✓
第四个匹配？'d'不在text2中，跳过
第五个匹配'e' ✓

结果：LCS = "ace" ✓

但考虑：
text1 = "abcdef"
text2 = "aecdf"

贪心可能错过更优解
需要DP考虑所有可能
```

**Q3: 如何输出LCS字符串（而非长度）？**
A: 回溯DP表：
```typescript
function getLCS(text1: string, text2: string, dp: number[][]): string {
    let i = text1.length;
    let j = text2.length;
    const result: string[] = [];

    while (i > 0 && j > 0) {
        if (text1[i-1] === text2[j-1]) {
            result.push(text1[i-1]);
            i--;
            j--;
        } else if (dp[i-1][j] > dp[i][j-1]) {
            i--;
        } else {
            j--;
        }
    }

    return result.reverse().join('');
}
```

**Q4: 空间优化后如何输出LCS？**
A: 不能直接输出：
```
一维DP只能求长度
要输出字符串需要二维DP表
或者用递归+记忆化
```

**Q5: 如果有多个LCS怎么办？**
A: 题目只要求长度：
```
可能有多个相同长度的LCS：
text1 = "abc"
text2 = "bac"

LCS可能是 "ac" 或 "bc"
长度都是2

题目只要求返回长度，不关心具体是哪个
```

## 复杂度分析

**时间复杂度：** O(m × n)
- 双层循环遍历所有状态
- m = text1.length, n = text2.length

**空间复杂度：**
- 二维DP：O(m × n)
- 一维优化：O(min(m, n))

## 总结

**关键点：**
1. 状态定义：dp[i][j] = 前i个和前j个字符的LCS长度
2. 状态转移：
   - 字符相同：dp[i-1][j-1] + 1
   - 字符不同：max(dp[i-1][j], dp[i][j-1])
3. 边界条件：dp[0][j] = dp[i][0] = 0
4. 空间优化：一维滚动数组

**二维DP模板（LCS）：**
```typescript
function longestCommonSubsequence(text1: string, text2: string): number {
    const m = text1.length;
    const n = text2.length;
    const dp: number[][] = Array(m + 1).fill(0).map(() => Array(n + 1).fill(0));

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (text1[i - 1] === text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}
```

- 边界条件忘记初始化
- 状态转移条件写反
- 空间优化时prev变量处理错误
- 子序列和子串概念混淆

**记忆技巧：**
- LCS = 二维DP经典问题
- 字符相同 = 左上角+1
- 字符不同 = max(上，左)
- 空间优化 = 一维数组 + prev变量
- 时间O(mn)，空间O(mn)或O(n)
