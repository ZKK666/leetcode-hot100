# 64. 最小路径和【中等】

## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：**每次只能向下或者向右移动一步。

---

## 输入输出示例

### 示例 1
```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

### 示例 2
```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

### 提示
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**状态转移：**
```
dp[i][j] = 到达(i,j)的最小路径和

到达(i,j)的方式：
1. 从(i-1,j)向下：dp[i-1][j] + grid[i][j]
2. 从(i,j-1)向右：dp[i][j-1] + grid[i][j]

取最小值：
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

**边界条件：**
```
第一行：dp[0][j] = dp[0][j-1] + grid[0][j]
第一列：dp[i][0] = dp[i-1][0] + grid[i][0]
起点：dp[0][0] = grid[0][0]
```

---

## 代码实现（TypeScript）

### 方法：二维DP

```typescript
function minPathSum(grid: number[][]): number {
    const m = grid.length;
    const n = grid[0].length;

    const dp: number[][] = Array(m).fill(0).map(() => Array(n).fill(0));

    // 起点
    dp[0][0] = grid[0][0];

    // 第一列
    for (let i = 1; i < m; i++) {
        dp[i][0] = dp[i - 1][0] + grid[i][0];
    }

    // 第一行
    for (let j = 1; j < n; j++) {
        dp[0][j] = dp[0][j - 1] + grid[0][j];
    }

    // 状态转移
    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {
            dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
        }
    }

    return dp[m - 1][n - 1];
}
```

---

## 总结

**DP模板（最小路径和）：**
```typescript
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

**关键点：**
1. 状态转移：取上方和左方的最小值
2. 边界处理：第一行、第一列
3. 可以原地修改或空间优化到O(n)
