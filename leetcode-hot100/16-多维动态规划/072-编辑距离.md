# 72. 编辑距离【困难】

## 题目描述

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

- **插入**一个字符
- **删除**一个字符
- **替换**一个字符

---

## 输入输出示例

### 示例 1
```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

### 示例 2
```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```

### 提示
- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**编辑距离（Levenshtein Distance）：**
```
衡量两个字符串之间的相似度
最少需要多少次编辑操作

经典的二维动态规划问题
```

**三种操作：**
```
1. 插入：word1 中插入一个字符
2. 删除：word1 中删除一个字符
3. 替换：word1 中替换一个字符

目标：使 word1 变成 word2
```

---

### 方法：二维动态规划

**状态定义：**
```
dp[i][j] = word1[0...i-1] 转换成 word2[0...j-1] 的最少操作数

注意：
i 和 j 表示前 i 个、前 j 个字符
dp数组大小是 (m+1) × (n+1)
dp[0][j] 和 dp[i][0] 表示空字符串
```

**状态转移：**
```
情况1：word1[i-1] == word2[j-1]
  当前字符相同，不需要操作
  dp[i][j] = dp[i-1][j-1]

情况2：word1[i-1] != word2[j-1]
  需要操作，选择代价最小的：

  a) 替换：dp[i-1][j-1] + 1
     将 word1[i-1] 替换成 word2[j-1]

  b) 删除：dp[i-1][j] + 1
     删除 word1[i-1]，继续匹配 word1[0...i-2] 和 word2[0...j-1]

  c) 插入：dp[i][j-1] + 1
     在 word1[i] 位置插入 word2[j-1]
     等价于 word1[0...i-1] 匹配 word2[0...j-2]

  dp[i][j] = min(替换, 删除, 插入)
```

**边界条件：**
```
dp[0][j] = j  // word1为空，需要插入j个字符
dp[i][0] = i  // word2为空，需要删除i个字符

例如：
"" -> "abc" 需要3次插入
"abc" -> "" 需要3次删除
```

**算法流程：**

1. **初始化：**
   - 创建 (m+1) × (n+1) 的dp数组
   - dp[0][j] = j, dp[i][0] = i

2. **状态转移：**
   - 遍历 i 从 1 到 m
   - 遍历 j 从 1 到 n
   - 根据字符是否相同更新 dp[i][j]

3. **返回 dp[m][n]**

**时间复杂度：** O(m × n)
**空间复杂度：** O(m × n)

---

## 代码实现（TypeScript）

### 方法一：二维DP（推荐）

```typescript
function minDistance(word1: string, word2: string): number {
    const m = word1.length;
    const n = word2.length;

    // dp[i][j] = word1[0...i-1] 转换成 word2[0...j-1] 的最少操作数
    const dp: number[][] = Array(m + 1).fill(0).map(() => Array(n + 1).fill(0));

    // 边界条件
    for (let i = 0; i <= m; i++) {
        dp[i][0] = i; // word2为空，删除i个字符
    }
    for (let j = 0; j <= n; j++) {
        dp[0][j] = j; // word1为空，插入j个字符
    }

    // 状态转移
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (word1[i - 1] === word2[j - 1]) {
                // 字符相同，不需要操作
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                // 字符不同，选择代价最小的操作
                dp[i][j] = Math.min(
                    dp[i - 1][j - 1] + 1,  // 替换
                    dp[i - 1][j] + 1,      // 删除
                    dp[i][j - 1] + 1       // 插入
                );
            }
        }
    }

    return dp[m][n];
}
```

### 方法二：空间优化（一维DP）

```typescript
function minDistance(word1: string, word2: string): number {
    const m = word1.length;
    const n = word2.length;

    // 优化：只用一维数组
    const dp: number[] = Array(n + 1).fill(0);

    // 初始化
    for (let j = 0; j <= n; j++) {
        dp[j] = j;
    }

    for (let i = 1; i <= m; i++) {
        let prev = dp[0]; // 保存 dp[i-1][j-1]
        dp[0] = i;        // 更新 dp[i][0]

        for (let j = 1; j <= n; j++) {
            const temp = dp[j]; // 保存旧值（下一轮的prev）

            if (word1[i - 1] === word2[j - 1]) {
                dp[j] = prev;
            } else {
                dp[j] = Math.min(
                    prev + 1,      // 替换
                    dp[j] + 1,     // 删除
                    dp[j - 1] + 1  // 插入
                );
            }

            prev = temp;
        }
    }

    return dp[n];
}
```

## 代码原理详解

### 二维DP详解

**1. 三种操作的理解：**

```typescript
dp[i][j] = min(
    dp[i-1][j-1] + 1,  // 替换
    dp[i-1][j] + 1,    // 删除
    dp[i][j-1] + 1     // 插入
)

举例：word1 = "horse", word2 = "ros"

当 i=3, j=2 时：
word1[0...2] = "hor"
word2[0...1] = "ro"
word1[2] = 'r', word2[1] = 'o'

不相同，需要操作：

1) 替换：dp[2][1] + 1
   "ho" -> "r" 的编辑距离 + 替换'r'为'o'
   = dp[2][1] + 1

2) 删除：dp[2][2] + 1
   删除word1[2]='r'
   "ho" -> "ro" 的编辑距离 + 删除操作
   = dp[2][2] + 1

3) 插入：dp[3][1] + 1
   在word1[3]位置插入'o'
   "hor" -> "r" 的编辑距离 + 插入'o'
   = dp[3][1] + 1

取最小值
```

**2. 为什么插入是 dp[i][j-1]？**

```
插入操作的理解：

在 word1[i] 位置插入 word2[j-1]

等价于：
word1[0...i-1] 已经匹配 word2[0...j-1]
（因为插入了word2[j-1]）

所以状态来自 dp[i][j-1]

例如：
word1 = "hor"
word2 = "ros"

在 "hor" 后插入 's'
等价于 "hor" 匹配 "ro"（dp[3][2]）+ 插入操作
```

**3. 为什么删除是 dp[i-1][j]？**

```
删除操作的理解：

删除 word1[i-1]

等价于：
word1[0...i-2] 匹配 word2[0...j-1]
（删除了word1[i-1]）

所以状态来自 dp[i-1][j]

例如：
word1 = "horse"
word2 = "ros"

删除 'e'
等价于 "hors" 匹配 "ros"（dp[4][3]）+ 删除操作
```

**4. 边界条件：**

```typescript
dp[0][j] = j  // "" -> "abc" 需要3次插入
dp[i][0] = i  // "abc" -> "" 需要3次删除

空字符串转换：
只能通过插入或删除
操作数等于字符串长度
```

---

### 空间优化详解

**状态依赖关系：**

```
dp[i][j] 依赖：
- dp[i-1][j-1]（左上）
- dp[i-1][j]  （上）
- dp[i][j-1]  （左）

一维滚动数组：
dp[j] 更新前是上方的值
dp[j-1] 是左方的值
prev 保存左上角的值
```

**变量含义：**

```typescript
for (let i = 1; i <= m; i++) {
    let prev = dp[0]; // dp[i-1][j-1]（左上）
    dp[0] = i;        // 更新 dp[i][0]

    for (let j = 1; j <= n; j++) {
        const temp = dp[j]; // 保存更新前的值（下一轮的左上）

        if (word1[i-1] === word2[j-1]) {
            dp[j] = prev; // 用左上角
        } else {
            dp[j] = Math.min(
                prev + 1,      // 左上（替换）
                dp[j] + 1,     // 上（删除）
                dp[j-1] + 1    // 左（插入）
            );
        }

        prev = temp; // 更新左上角
    }
}
```

## 运行示例

### 示例 1：`word1 = "horse", word2 = "ros"`

**DP表构建：**

```
      ""  r  o  s
""     0  1  2  3
h      1  1  2  3
o      2  2  1  2
r      3  2  2  2
s      4  3  3  2
e      5  4  4  3
```

**详细过程：**

```
初始化：
dp[0][0]=0, dp[0][1]=1, dp[0][2]=2, dp[0][3]=3
dp[1][0]=1, dp[2][0]=2, ..., dp[5][0]=5

i=1, word1[0]='h'：
  j=1, word2[0]='r'：
    'h' != 'r'
    dp[1][1] = min(dp[0][0]+1, dp[0][1]+1, dp[1][0]+1)
             = min(1, 2, 2) = 1（替换）

  j=2, word2[1]='o'：
    'h' != 'o'
    dp[1][2] = min(dp[0][1]+1, dp[0][2]+1, dp[1][1]+1)
             = min(2, 3, 2) = 2

  j=3, word2[2]='s'：
    'h' != 's'
    dp[1][3] = min(dp[0][2]+1, dp[0][3]+1, dp[1][2]+1)
             = min(3, 4, 3) = 3

i=2, word1[1]='o'：
  j=1, word2[0]='r'：
    'o' != 'r'
    dp[2][1] = min(1+1, 1+1, 2+1) = 2

  j=2, word2[1]='o'：
    'o' == 'o' ✓
    dp[2][2] = dp[1][1] = 1（不需要操作）

  j=3, word2[2]='s'：
    'o' != 's'
    dp[2][3] = min(2+1, 1+1, 3+1) = 2

i=3, word1[2]='r'：
  j=1, word2[0]='r'：
    'r' == 'r' ✓
    dp[3][1] = dp[2][0] = 2

  j=2, word2[1]='o'：
    'r' != 'o'
    dp[3][2] = min(1+1, 2+1, 2+1) = 2

  j=3, word2[2]='s'：
    'r' != 's'
    dp[3][3] = min(1+1, 2+1, 2+1) = 2

i=4, word1[3]='s'：
  j=1: dp[4][1] = 3
  j=2: dp[4][2] = 3
  j=3: 's' == 's', dp[4][3] = dp[3][2] = 2

i=5, word1[4]='e'：
  j=1: dp[5][1] = 4
  j=2: dp[5][2] = 4
  j=3: 'e' != 's', dp[5][3] = min(2+1, 2+1, 4+1) = 3

返回：dp[5][3] = 3 ✓
```

**操作路径（回溯）：**
```
horse -> rorse (替换 h -> r)
rorse -> rose  (删除 r)
rose  -> ros   (删除 e)
```

## 常见问题

**Q1: 编辑距离和LCS有什么关系？**
A: 可以互相转换：
```
编辑距离 = m + n - 2 × LCS长度

但直接用DP求编辑距离更直观
LCS只能插入/删除，编辑距离还能替换
```

**Q2: 为什么替换是 dp[i-1][j-1] + 1？**
A: 替换操作的理解：
```
将 word1[i-1] 替换成 word2[j-1]

替换后：
word1[0...i-1] 匹配 word2[0...j-1]
（最后一个字符已经相同）

所以状态来自 dp[i-1][j-1]
```

**Q3: 如何输出具体操作步骤？**
A: 回溯DP表：
```typescript
function getEditPath(word1: string, word2: string, dp: number[][]) {
    let i = word1.length;
    let j = word2.length;
    const operations: string[] = [];

    while (i > 0 || j > 0) {
        if (i === 0) {
            operations.push(`插入 ${word2[j-1]}`);
            j--;
        } else if (j === 0) {
            operations.push(`删除 ${word1[i-1]}`);
            i--;
        } else if (word1[i-1] === word2[j-1]) {
            i--;
            j--;
        } else {
            const replace = dp[i-1][j-1];
            const del = dp[i-1][j];
            const insert = dp[i][j-1];

            if (replace <= del && replace <= insert) {
                operations.push(`替换 ${word1[i-1]} -> ${word2[j-1]}`);
                i--;
                j--;
            } else if (del <= insert) {
                operations.push(`删除 ${word1[i-1]}`);
                i--;
            } else {
                operations.push(`插入 ${word2[j-1]}`);
                j--;
            }
        }
    }

    return operations.reverse();
}
```

**Q4: 如果只允许插入和删除呢？**
A: 简化为：
```typescript
dp[i][j] = Math.min(
    dp[i-1][j] + 1,   // 删除
    dp[i][j-1] + 1    // 插入
)

等价于用LCS求解
```

**Q5: 可以用递归吗？**
A: 可以，但会超时：
```typescript
function minDistance(word1: string, word2: string): number {
    function helper(i: number, j: number): number {
        if (i === 0) return j;
        if (j === 0) return i;

        if (word1[i-1] === word2[j-1]) {
            return helper(i-1, j-1);
        }

        return Math.min(
            helper(i-1, j-1) + 1, // 替换
            helper(i-1, j) + 1,   // 删除
            helper(i, j-1) + 1    // 插入
        );
    }

    return helper(word1.length, word2.length);
}

需要加记忆化优化
```

## 复杂度分析

**时间复杂度：** O(m × n)
- 双层循环遍历所有状态
- m = word1.length, n = word2.length

**空间复杂度：**
- 二维DP：O(m × n)
- 一维优化：O(min(m, n))

## 边界情况

### 情况1：一个字符串为空
```
输入: word1 = "", word2 = "abc"
输出: 3（插入3次）

输入: word1 = "abc", word2 = ""
输出: 3（删除3次）
```

### 情况2：两个字符串相同
```
输入: word1 = "abc", word2 = "abc"
输出: 0
```

### 情况3：完全不同
```
输入: word1 = "abc", word2 = "def"
输出: 3（替换3次）
```

### 情况4：一个是另一个的子序列
```
输入: word1 = "ace", word2 = "abcde"
输出: 2（插入'b'和'd'）
```

### 情况5：长度差异大
```
输入: word1 = "a", word2 = "abcdefgh"
输出: 7（插入7次）
```

## 总结

**关键点：**
1. 状态定义：dp[i][j] = word1前i个 -> word2前j个的最少操作数
2. 状态转移：
   - 字符相同：dp[i-1][j-1]
   - 字符不同：min(替换, 删除, 插入)
3. 三种操作：
   - 替换：dp[i-1][j-1] + 1
   - 删除：dp[i-1][j] + 1
   - 插入：dp[i][j-1] + 1
4. 边界条件：dp[0][j] = j, dp[i][0] = i

**二维DP模板（编辑距离）：**
```typescript
function minDistance(word1: string, word2: string): number {
    const m = word1.length, n = word2.length;
    const dp: number[][] = Array(m + 1).fill(0).map(() => Array(n + 1).fill(0));

    for (let i = 0; i <= m; i++) dp[i][0] = i;
    for (let j = 0; j <= n; j++) dp[0][j] = j;

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (word1[i - 1] === word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.min(
                    dp[i - 1][j - 1] + 1,  // 替换
                    dp[i - 1][j] + 1,      // 删除
                    dp[i][j - 1] + 1       // 插入
                );
            }
        }
    }

    return dp[m][n];
}
```

**记忆技巧：**
- 编辑距离 = 三种操作（替换/删除/插入）
- 字符相同 = 左上角（不操作）
- 字符不同 = min(左上+1, 上+1, 左+1)
- 边界 = 空串操作数 = 字符串长度
- 时间O(mn)，空间O(mn)或O(n)
