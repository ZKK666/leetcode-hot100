# 5. 最长回文子串【中等】

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**回文串**是正着读和反着读都一样的字符串。

---

## 输入输出示例

### 示例 1
```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

### 示例 2
```
输入：s = "cbbd"
输出："bb"
```

### 提示
- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
回文串特性：
- 正着读 = 反着读
- s[i] == s[j] 且 s[i+1...j-1] 也是回文

关键问题：
如何高效判断所有子串？
```

**多种解法：**
```
1. 动态规划：O(n²) 时间，O(n²) 空间
2. 中心扩展：O(n²) 时间，O(1) 空间 ⭐
3. Manacher算法：O(n) 时间，O(n) 空间
```

---

### 方法一：中心扩展法（推荐）

**核心思想：**
- 回文串有中心对称性
- 遍历每个可能的中心
- 从中心向两边扩展

**中心的类型：**
```
1. 单字符中心：奇数长度回文
   "aba" 中心是 'b'

2. 双字符中心：偶数长度回文
   "abba" 中心是 'bb'

共有 2n-1 个中心：
- n 个单字符中心
- n-1 个双字符中心
```

**算法流程：**

1. **遍历所有中心：**
   - 对于每个位置 i（0 到 n-1）
   - 以 i 为中心扩展（奇数）
   - 以 i 和 i+1 为中心扩展（偶数）

2. **中心扩展：**
   - left 和 right 指针从中心开始
   - 向两边扩展，直到不满足回文条件
   - 记录最长回文

3. **返回最长回文子串**

**时间复杂度：** O(n²) - 每个中心最多扩展 O(n)
**空间复杂度：** O(1) - 只用常数空间

---

### 方法二：动态规划

**状态定义：**
```
dp[i][j] = s[i...j] 是否是回文串

状态转移：
1. 单字符：dp[i][i] = true
2. 双字符：dp[i][i+1] = (s[i] == s[i+1])
3. 长度≥3：dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]

边界条件：
i <= j
j - i < 3 时，只需检查 s[i] == s[j]
```

**遍历顺序：**
```
按长度从小到大遍历
或按对角线方向遍历

确保 dp[i+1][j-1] 在 dp[i][j] 之前计算
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n²)

---

## 代码实现（TypeScript）

### 方法一：中心扩展（推荐，空间最优）

```typescript
function longestPalindrome(s: string): string {
    const n = s.length;
    if (n === 0) return "";

    let start = 0;  // 最长回文的起始位置
    let maxLen = 1; // 最长回文的长度

    // 辅助函数：从中心扩展
    function expandAroundCenter(left: number, right: number): number {
        while (left >= 0 && right < n && s[left] === s[right]) {
            left--;
            right++;
        }
        // 返回回文长度
        return right - left - 1;
    }

    // 遍历每个可能的中心
    for (let i = 0; i < n; i++) {
        // 奇数长度：单字符中心
        const len1 = expandAroundCenter(i, i);
        // 偶数长度：双字符中心
        const len2 = expandAroundCenter(i, i + 1);

        // 取较长的
        const len = Math.max(len1, len2);

        // 更新最长回文
        if (len > maxLen) {
            maxLen = len;
            // 计算起始位置
            start = i - Math.floor((len - 1) / 2);
        }
    }

    return s.substring(start, start + maxLen);
}
```

### 方法二：动态规划

```typescript
function longestPalindrome(s: string): string {
    const n = s.length;
    if (n < 2) return s;

    // dp[i][j] 表示 s[i...j] 是否是回文
    const dp: boolean[][] = Array(n).fill(false).map(() => Array(n).fill(false));

    let start = 0;
    let maxLen = 1;

    // 单字符都是回文
    for (let i = 0; i < n; i++) {
        dp[i][i] = true;
    }

    // 按长度遍历
    for (let len = 2; len <= n; len++) {
        for (let i = 0; i < n - len + 1; i++) {
            const j = i + len - 1;

            if (s[i] === s[j]) {
                // 长度为2或3时，直接判断
                if (len <= 3) {
                    dp[i][j] = true;
                } else {
                    // 长度>3，依赖子问题
                    dp[i][j] = dp[i + 1][j - 1];
                }

                // 更新最长回文
                if (dp[i][j] && len > maxLen) {
                    start = i;
                    maxLen = len;
                }
            }
        }
    }

    return s.substring(start, start + maxLen);
}
```

### 方法三：Manacher算法（最优时间复杂度）

```typescript
function longestPalindrome(s: string): string {
    // 预处理：插入特殊字符，统一奇偶
    let t = "#";
    for (const c of s) {
        t += c + "#";
    }

    const n = t.length;
    const p: number[] = Array(n).fill(0); // p[i] = 以i为中心的回文半径

    let center = 0; // 当前回文中心
    let right = 0;  // 当前回文右边界

    let maxCenter = 0;
    let maxLen = 0;

    for (let i = 0; i < n; i++) {
        // 利用对称性初始化 p[i]
        if (i < right) {
            const mirror = 2 * center - i;
            p[i] = Math.min(right - i, p[mirror]);
        }

        // 中心扩展
        let left = i - (p[i] + 1);
        let r = i + (p[i] + 1);

        while (left >= 0 && r < n && t[left] === t[r]) {
            p[i]++;
            left--;
            r++;
        }

        // 更新右边界
        if (i + p[i] > right) {
            center = i;
            right = i + p[i];
        }

        // 更新最长回文
        if (p[i] > maxLen) {
            maxLen = p[i];
            maxCenter = i;
        }
    }

    // 还原原字符串位置
    const start = (maxCenter - maxLen) / 2;
    return s.substring(start, start + maxLen);
}
```

## 代码原理详解

### 中心扩展法

**1. 为什么有两种中心？**
```typescript
// 奇数长度："aba"
expandAroundCenter(i, i)
中心是单个字符

// 偶数长度："abba"
expandAroundCenter(i, i+1)
中心是两个字符之间
```

**2. 如何计算起始位置？**
```typescript
start = i - Math.floor((len - 1) / 2)

推导：
设回文中心在 i，长度为 len

奇数长度 len=5：
"abcba"，中心 i=2
start = 2 - (5-1)/2 = 2 - 2 = 0 ✓

偶数长度 len=4：
"abba"，中心 i=1 (第一个b)
start = 1 - (4-1)/2 = 1 - 1 = 0 ✓

统一公式：start = i - ⌊(len-1)/2⌋
```

**3. 扩展函数的返回值：**
```typescript
function expandAroundCenter(left: number, right: number): number {
    while (left >= 0 && right < n && s[left] === s[right]) {
        left--;
        right++;
    }
    return right - left - 1;
}

退出循环时：
left 和 right 不满足回文条件
回文长度 = (right - 1) - (left + 1) + 1 = right - left - 1
```

---

### 动态规划

**1. 状态转移：**
```typescript
dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]

条件：
1. s[i] == s[j]：首尾字符相同
2. dp[i+1][j-1]：去掉首尾后也是回文

特殊情况：
len <= 3 时，s[i] == s[j] 就足够了
因为中间最多1个字符，必然回文
```

**2. 遍历顺序：**
```typescript
// 按长度遍历
for (let len = 2; len <= n; len++) {
    for (let i = 0; i < n - len + 1; i++) {
        const j = i + len - 1;
        // ...
    }
}

确保 dp[i+1][j-1] 在 dp[i][j] 之前计算
```

---

### Manacher算法

**1. 预处理：**
```typescript
原串："babad"
处理后："#b#a#b#a#d#"

作用：
统一奇偶长度
所有回文都变成奇数长度
```

**2. 核心优化：**
```typescript
利用对称性：
如果已知 [left, right] 是回文
且 i 在 right 内
则 p[i] 至少等于 p[mirror]（对称位置）

减少重复扩展
```

**3. 时间复杂度：**
```
每个位置最多被访问2次
总时间：O(n)
```

## 运行示例

### 示例 1：`s = "babad"`

**中心扩展法：**

```
初始：start=0, maxLen=1

i=0, 'b'：
  奇数中心：expandAroundCenter(0, 0) = 1
  偶数中心：expandAroundCenter(0, 1) = 0
  len = max(1, 0) = 1
  不更新（len <= maxLen）

i=1, 'a'：
  奇数中心：expandAroundCenter(1, 1)
    left=1, right=1: s[1]='a' == s[1]='a' ✓
    left=0, right=2: s[0]='b' == s[2]='b' ✓
    left=-1, right=3: 越界
    返回：3 - 0 - 1 = 3
  偶数中心：expandAroundCenter(1, 2) = 0
  len = max(3, 0) = 3
  更新：maxLen=3, start = 1 - (3-1)/2 = 0

i=2, 'b'：
  奇数中心：expandAroundCenter(2, 2)
    left=2, right=2: s[2]='b' == s[2]='b' ✓
    left=1, right=3: s[1]='a' == s[3]='a' ✓
    left=0, right=4: s[0]='b' != s[4]='d' ✗
    返回：4 - 0 - 1 = 3
  偶数中心：expandAroundCenter(2, 3) = 0
  len = max(3, 0) = 3
  不更新（len <= maxLen）

i=3, 'a'：
  奇数中心：expandAroundCenter(3, 3)
    left=3, right=3: 'a' == 'a' ✓
    left=2, right=4: 'b' != 'd' ✗
    返回：4 - 2 - 1 = 1
  偶数中心：expandAroundCenter(3, 4) = 0
  len = 1
  不更新

i=4, 'd'：
  len = 1
  不更新

最终：start=0, maxLen=3
返回：s.substring(0, 3) = "bab" ✓
```

---

### 示例 2：`s = "cbbd"`

**执行过程：**

```
i=0, 'c': len=1
i=1, 'b':
  奇数：1
  偶数：expandAroundCenter(1, 2)
    left=1, right=2: 'b' == 'b' ✓
    left=0, right=3: 'c' != 'd' ✗
    返回：3 - 0 - 1 = 2
  len=2, start = 1 - (2-1)/2 = 1

i=2, 'b': len最大2
i=3, 'd': len=1

返回：s.substring(1, 3) = "bb" ✓
```

## 常见问题

**Q1: 为什么中心扩展法空间复杂度是O(1)？**
A: 不需要额外数组：
```
只用常数个变量：
- start, maxLen（记录结果）
- i（遍历索引）
- len1, len2（临时长度）

不像DP需要O(n²)的二维数组
```

**Q2: 如何选择方法？**
A: 根据场景：
```
面试推荐：中心扩展
- 代码简洁
- 空间O(1)
- 容易理解

追求极致性能：Manacher
- O(n)时间
- 但代码复杂

练习DP：动态规划
- 理解状态转移
- 空间换时间思想
```

**Q3: 动态规划为什么按长度遍历？**
A: 依赖关系：
```
dp[i][j] 依赖 dp[i+1][j-1]

按长度遍历：
先计算长度2的子串
再计算长度3的子串
...

确保依赖的子问题已解决
```

**Q4: 如何处理单字符？**
A: 直接返回：
```typescript
if (n === 0) return "";
if (n === 1) return s;

单字符本身就是回文
```

**Q5: Manacher为什么插入'#'？**
A: 统一奇偶：
```
"aba" → "#a#b#a#"
"abba" → "#a#b#b#a#"

所有回文变成奇数长度
简化处理逻辑
```

## 复杂度分析

### 中心扩展法
**时间复杂度：** O(n²)
- 遍历n个中心：O(n)
- 每个中心最多扩展n次：O(n)
- 总计：O(n²)

**空间复杂度：** O(1)
- 只用常数个变量

### 动态规划
**时间复杂度：** O(n²)
- 填充dp表：O(n²)

**空间复杂度：** O(n²)
- dp二维数组

### Manacher算法
**时间复杂度：** O(n)
- 每个位置最多访问2次

**空间复杂度：** O(n)
- p数组和预处理字符串

## 总结

**关键点：**
1. 中心扩展：遍历所有中心，向两边扩展
2. 两种中心：单字符（奇数）、双字符（偶数）
3. DP状态：dp[i][j] = s[i]==s[j] && dp[i+1][j-1]
4. Manacher：利用对称性优化到O(n)

**中心扩展模板：**
```typescript
function longestPalindrome(s: string): string {
    let start = 0, maxLen = 1;

    function expand(left: number, right: number): number {
        while (left >= 0 && right < s.length && s[left] === s[right]) {
            left--;
            right++;
        }
        return right - left - 1;
    }

    for (let i = 0; i < s.length; i++) {
        const len1 = expand(i, i);     // 奇数
        const len2 = expand(i, i + 1); // 偶数
        const len = Math.max(len1, len2);

        if (len > maxLen) {
            maxLen = len;
            start = i - Math.floor((len - 1) / 2);
        }
    }

    return s.substring(start, start + maxLen);
}
```

**面试建议：**
- 首选中心扩展法（代码简洁、空间最优）
- 说明两种中心的必要性
- 解释起始位置的计算
- 提及DP和Manacher作为优化方向
- 分析时间空间复杂度

**易错点：**
- 忘记偶数长度回文（双字符中心）
- 起始位置计算错误
- 边界判断（left >= 0 && right < n）
- DP遍历顺序错误
- 返回值是子串而非长度

**记忆技巧：**
- 中心扩展 = 两种中心（奇偶）
- DP = s[i]==s[j] && dp[i+1][j-1]
- Manacher = 插入'#' + 对称性
- 时间都是O(n²)，Manacher是O(n)
