# 146. LRU 缓存【中等】

## 题目描述

请你设计并实现一个满足 **LRU (最近最少使用)** 缓存约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1`
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value`；如果不存在，则向缓存中插入该组 `key-value`。如果插入操作导致关键字数量超过 `capacity`，则应该 **逐出** 最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

---

## 输入输出示例

### 示例 1
```
输入
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]

输出
[null, null, null, 1, null, -1, null, -1, 3, 4]

解释
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1
lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4
```

### 提示
- `1 <= capacity <= 3000`
- `0 <= key <= 10^4`
- `0 <= value <= 10^5`
- 最多调用 `2 * 10^5` 次 `get` 和 `put`

## 解题思路（面试推荐 - 最优解）

### 方法：哈希表 + 双向链表

**核心思想：**
- **哈希表**：实现O(1)的查找
- **双向链表**：维护访问顺序，实现O(1)的插入和删除

**为什么需要双向链表？**
```
LRU缓存的特点：
1. 最近使用的放在前面（头部）
2. 最久未使用的在后面（尾部）
3. 容量满时，删除尾部

双向链表可以：
- O(1)在头部添加节点（最近使用）
- O(1)删除尾部节点（最久未使用）
- O(1)移动中间节点到头部（访问后更新）
```

**为什么需要哈希表？**
```
如果只用链表：
- 查找key：需要遍历，O(n)

哈希表 + 链表：
- 查找key：哈希表，O(1)
- 更新位置：通过哈希表找到节点，移动到头部，O(1)
```

**数据结构设计：**
```
双向链表节点：
  key: number      // 键
  value: number    // 值
  prev: Node       // 前驱
  next: Node       // 后继

哈希表：
  key → Node      // 键到链表节点的映射

链表结构：
  dummy_head ⇄ node1 ⇄ node2 ⇄ ... ⇄ dummy_tail
  ↑                                        ↑
  最近使用                             最久未使用

哑节点简化边界处理
```

**操作流程：**

1. **get(key)**：
   - 如果key不存在，返回-1
   - 如果存在，移动到头部（标记为最近使用），返回value

2. **put(key, value)**：
   - 如果key存在：更新value，移动到头部
   - 如果key不存在：
     - 创建新节点，添加到头部
     - 如果超过容量，删除尾部节点

**时间复杂度：** O(1) - get和put都是O(1)
**空间复杂度：** O(capacity) - 存储最多capacity个节点

## 代码实现（TypeScript）

```typescript
/**
 * 双向链表节点
 */
class DListNode {
    key: number;
    value: number;
    prev: DListNode | null;
    next: DListNode | null;

    constructor(key: number = 0, value: number = 0) {
        this.key = key;
        this.value = value;
        this.prev = null;
        this.next = null;
    }
}

class LRUCache {
    private capacity: number;
    private cache: Map<number, DListNode>;  // key → 链表节点
    private head: DListNode;                // 哑头节点
    private tail: DListNode;                // 哑尾节点

    constructor(capacity: number) {
        this.capacity = capacity;
        this.cache = new Map();

        // 创建哑节点
        this.head = new DListNode();
        this.tail = new DListNode();

        // 连接哑节点
        this.head.next = this.tail;
        this.tail.prev = this.head;
    }

    get(key: number): number {
        if (!this.cache.has(key)) {
            return -1;
        }

        // 获取节点
        const node = this.cache.get(key)!;

        // 移动到头部（标记为最近使用）
        this.moveToHead(node);

        return node.value;
    }

    put(key: number, value: number): void {
        if (this.cache.has(key)) {
            // key存在：更新value，移动到头部
            const node = this.cache.get(key)!;
            node.value = value;
            this.moveToHead(node);
        } else {
            // key不存在：创建新节点
            const node = new DListNode(key, value);

            // 添加到哈希表
            this.cache.set(key, node);

            // 添加到链表头部
            this.addToHead(node);

            // 检查容量
            if (this.cache.size > this.capacity) {
                // 删除尾部节点（最久未使用）
                const removed = this.removeTail();
                this.cache.delete(removed.key);
            }
        }
    }

    /**
     * 将节点添加到链表头部
     */
    private addToHead(node: DListNode): void {
        node.prev = this.head;
        node.next = this.head.next;
        this.head.next!.prev = node;
        this.head.next = node;
    }

    /**
     * 从链表中移除节点
     */
    private removeNode(node: DListNode): void {
        node.prev!.next = node.next;
        node.next!.prev = node.prev;
    }

    /**
     * 将节点移动到头部
     */
    private moveToHead(node: DListNode): void {
        this.removeNode(node);
        this.addToHead(node);
    }

    /**
     * 删除尾部节点并返回
     */
    private removeTail(): DListNode {
        const node = this.tail.prev!;
        this.removeNode(node);
        return node;
    }
}

/**
 * Your LRUCache object will be instantiated and called as such:
 * var obj = new LRUCache(capacity)
 * var param_1 = obj.get(key)
 * obj.put(key,value)
 */
```

## 代码原理详解

### 核心逻辑

1. **哑节点**：
   ```
   head (哑) ⇄ node1 ⇄ node2 ⇄ tail (哑)

   好处：
   - 不需要处理空链表
   - 统一的插入删除逻辑
   - head.next是最近使用
   - tail.prev是最久未使用
   ```

2. **添加到头部**：
   ```typescript
   addToHead(node):
     node.prev = head
     node.next = head.next
     head.next.prev = node  // 原来的第一个节点
     head.next = node

   结果：head ⇄ node ⇄ (原第一个)
   ```

3. **移除节点**：
   ```typescript
   removeNode(node):
     node.prev.next = node.next
     node.next.prev = node.prev

   绕过node，前后节点直接连接
   ```

4. **移动到头部**：
   ```typescript
   moveToHead(node):
     removeNode(node)  // 从当前位置移除
     addToHead(node)   // 添加到头部
   ```

### 操作流程图

**get(key)：**
```
1. 检查缓存：key in cache?
   - 否：返回 -1
   - 是：继续

2. 获取节点：node = cache[key]

3. 移动到头部：
   head ⇄ ... ⇄ node ⇄ ... ⇄ tail
   变成
   head ⇄ node ⇄ ... ⇄ tail

4. 返回 node.value
```

**put(key, value)：**
```
1. 检查缓存：key in cache?

   情况A：key存在
     - 更新 node.value = value
     - 移动到头部
     - 结束

   情况B：key不存在
     - 创建新节点 node
     - 添加到 cache
     - 添加到链表头部
     - 检查容量：
       * 如果 size > capacity:
         删除尾部节点（最久未使用）
         从cache中删除对应的key
```

## 常见问题

**Q1: 为什么需要双向链表而不是单向链表？**
A: 删除节点需要知道前驱：
```
单向链表删除节点：
  需要找到前驱，O(n)

双向链表删除节点：
  直接通过prev找到前驱，O(1)
```

**Q2: 为什么节点要存储key？**
A: 删除节点时需要从哈希表中删除：
```
removeTail():
  node = tail.prev
  removeNode(node)
  cache.delete(node.key)  // 需要知道key！
```

**Q3: 能否用数组实现？**
A: 不行，数组插入删除是O(n)：
```
数组：
- 查找：O(1)（如果用索引）
- 删除：O(n)（需要移动元素）
- 插入头部：O(n)（需要移动所有元素）

双向链表：
- 查找：O(1)（通过哈希表）
- 删除：O(1)
- 插入头部：O(1)
```

**Q4: JavaScript/TypeScript有没有现成的数据结构？**
A: ES6的Map保持插入顺序，可以简化实现：
```typescript
class LRUCache {
    private capacity: number;
    private cache: Map<number, number>;

    constructor(capacity: number) {
        this.capacity = capacity;
        this.cache = new Map();
    }

    get(key: number): number {
        if (!this.cache.has(key)) {
            return -1;
        }

        // 重新插入以更新顺序
        const value = this.cache.get(key)!;
        this.cache.delete(key);
        this.cache.set(key, value);

        return value;
    }

    put(key: number, value: number): void {
        if (this.cache.has(key)) {
            this.cache.delete(key);
        }

        this.cache.set(key, value);

        if (this.cache.size > this.capacity) {
            // Map迭代器的第一个元素是最旧的
            const firstKey = this.cache.keys().next().value;
            this.cache.delete(firstKey);
        }
    }
}
```

但面试建议手写双向链表+哈希表的实现。

## 复杂度分析

### 时间复杂度：O(1)
- **get(key)**：
  - 哈希表查找：O(1)
  - 移动节点：O(1)
  - 总计：O(1)

- **put(key, value)**：
  - 哈希表查找/插入：O(1)
  - 添加/删除节点：O(1)
  - 总计：O(1)

### 空间复杂度：O(capacity)
- 哈希表：最多capacity个键值对
- 双向链表：最多capacity个节点
- 总计：O(capacity)

## 总结

**关键点：**
1. 哈希表实现O(1)查找
2. 双向链表维护访问顺序
3. 哑节点简化边界处理
4. 头部是最近使用，尾部是最久未使用
5. get和put都要更新顺序

**面试建议：**

- 强调O(1)时间复杂度

**易错点：**
- 节点忘记存储key
- 忘记在删除节点后从哈希表中删除
- get操作忘记更新顺序
- 哑节点的prev/next连接错误
