# 105. 从前序与中序遍历序列构造二叉树【中等】

## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的**先序遍历**，`inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

---

## 输入输出示例

### 示例 1
```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

![示例1](https://assets.leetcode.com/uploads/2021/02/19/tree.jpg)

### 示例 2
```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

### 提示
- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均 **无重复** 元素
- `inorder` 均出现在 `preorder`
- `preorder` **保证** 为二叉树的前序遍历序列
- `inorder` **保证** 为二叉树的中序遍历序列

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**前序和中序遍历的特点：**
```
前序遍历：根 → 左 → 右
中序遍历：左 → 根 → 右

例如：
      3
     / \
    9  20
      / \
     15  7

前序：[3, 9, 20, 15, 7]
      ↑  ↑   ↑
     根 左子  右子

中序：[9, 3, 15, 20, 7]
      ↑  ↑   ↑
     左  根  右子
```

**关键观察：**
1. **前序遍历的第一个元素一定是根**
2. **在中序遍历中找到根，可以划分左右子树**

```
前序：[3, 9, 20, 15, 7]
       ↑
      根节点

中序：[9, 3, 15, 20, 7]
       ↑  ↑  ↑
      左  根  右

左子树：inorder中根的左边 [9]
右子树：inorder中根的右边 [15, 20, 7]

递归构建：
- 左子树：preorder[9]，inorder[9]
- 右子树：preorder[20,15,7]，inorder[15,20,7]
```

---

### 方法：递归 + 哈希表优化

**算法流程：**
1. 用哈希表存储中序遍历中每个值的索引（快速查找根位置）
2. 递归构建：
   - 从前序遍历取根节点
   - 在中序遍历中找到根的位置
   - 划分左右子树的范围
   - 递归构建左右子树

**为什么需要哈希表？**
```
不用哈希表：每次在中序数组中查找根，O(n)
用哈希表：O(1)查找

总时间：O(n²) → O(n)
```

**时间复杂度：** O(n)
**空间复杂度：** O(n) - 哈希表 + 递归栈

## 代码实现（TypeScript）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function buildTree(preorder: number[], inorder: number[]): TreeNode | null {
    // 构建哈希表：值 → 中序遍历中的索引
    const inorderMap = new Map<number, number>();
    for (let i = 0; i < inorder.length; i++) {
        inorderMap.set(inorder[i], i);
    }

    /**
     * 递归构建二叉树
     * @param preStart 前序遍历的起始索引
     * @param preEnd 前序遍历的结束索引
     * @param inStart 中序遍历的起始索引
     * @param inEnd 中序遍历的结束索引
     */
    function build(
        preStart: number,
        preEnd: number,
        inStart: number,
        inEnd: number
    ): TreeNode | null {
        // 递归终止条件
        if (preStart > preEnd || inStart > inEnd) {
            return null;
        }

        // 前序遍历的第一个元素是根节点
        const rootVal = preorder[preStart];
        const root = new TreeNode(rootVal);

        // 在中序遍历中找到根节点的位置
        const rootIndexInInorder = inorderMap.get(rootVal)!;

        // 左子树的节点数量
        const leftSize = rootIndexInInorder - inStart;

        // 递归构建左子树
        // 前序：[preStart+1, preStart+leftSize]
        // 中序：[inStart, rootIndexInInorder-1]
        root.left = build(
            preStart + 1,
            preStart + leftSize,
            inStart,
            rootIndexInInorder - 1
        );

        // 递归构建右子树
        // 前序：[preStart+leftSize+1, preEnd]
        // 中序：[rootIndexInInorder+1, inEnd]
        root.right = build(
            preStart + leftSize + 1,
            preEnd,
            rootIndexInInorder + 1,
            inEnd
        );

        return root;
    }

    return build(0, preorder.length - 1, 0, inorder.length - 1);
}
```

## 代码原理详解

### 核心逻辑

**1. 确定根节点：**
```typescript
const rootVal = preorder[preStart];  // 前序第一个是根
```

**2. 划分左右子树：**
```typescript
const rootIndexInInorder = inorderMap.get(rootVal);

中序：[inStart ... rootIndexInInorder-1] | rootIndexInInorder | [rootIndexInInorder+1 ... inEnd]
            左子树                          根                      右子树

leftSize = rootIndexInInorder - inStart
```

**3. 递归构建：**
```typescript
左子树：
  前序：[preStart+1, preStart+leftSize]
  中序：[inStart, rootIndexInInorder-1]

右子树：
  前序：[preStart+leftSize+1, preEnd]
  中序：[rootIndexInInorder+1, inEnd]
```

### 递归过程

```
前序：[3, 9, 20, 15, 7]
中序：[9, 3, 15, 20, 7]

build(0, 4, 0, 4):
  root = 3
  rootIndex in inorder = 1
  leftSize = 1 - 0 = 1

  left = build(1, 1, 0, 0):
    root = 9
    rootIndex = 0
    leftSize = 0
    left = build(2, 1, ...) → null
    right = build(2, 1, ...) → null
    return 9

  right = build(2, 4, 2, 4):
    root = 20
    rootIndex = 3
    leftSize = 3 - 2 = 1

    left = build(3, 3, 2, 2):
      root = 15
      return 15

    right = build(4, 4, 4, 4):
      root = 7
      return 7

    return 20(15, 7)

  return 3(9, 20(15,7))

结果：
      3
     / \
    9  20
      / \
     15  7
```

## 常见问题

**Q1: 为什么前序+中序能唯一确定一棵树？**
A:
- **前序**：确定根节点
- **中序**：划分左右子树
- 递归下去，每个子树都能确定

**不能确定的情况：**
```
只有前序：
  [1,2,3] 可能是：
    1          1        1
     \        /          \
      2      2            2
       \      \          /
        3      3        3

只有中序：
  [1,2,3] 可能是：
    2        3      1
   / \      /        \
  1   3    2          2
          /            \
         1              3
```

**Q2: 为什么需要四个参数（preStart, preEnd, inStart, inEnd）？**
A: 避免创建子数组：
```typescript
// 不推荐：创建新数组
build(preorder.slice(...), inorder.slice(...))

// 推荐：使用索引
build(preStart, preEnd, inStart, inEnd)

避免额外空间和拷贝时间
```

**Q3: 如果有重复元素怎么办？**
A: 无法唯一确定：
```
前序：[1,1,2]
中序：[1,1,2]

可能是：
    1          1
   /            \
  1              1
   \            /
    2          2
```
题目保证无重复元素。

**Q4: 能否用后序+中序构建？**
A: 可以！类似的思路：
```typescript
function buildTree(inorder, postorder) {
    // 后序的最后一个元素是根
    const rootVal = postorder[postEnd];
    // 其余逻辑类似
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 构建哈希表：O(n)
- 递归：每个节点访问一次，O(n)
- 总计：O(n)

**空间复杂度：** O(n)
- 哈希表：O(n)
- 递归栈：O(h)，最坏O(n)
- 总计：O(n)

## 总结

**关键点：**
1. 前序第一个元素是根
2. 在中序中找到根，划分左右子树
3. 递归构建左右子树
4. 哈希表优化查找（O(1)）

**面试建议：**
- 先解释前序和中序的特点
- 画图演示如何划分左右子树
- 强调哈希表的优化作用
- 注意索引计算（leftSize的使用）

**易错点：**
- leftSize计算错误
- 前序和中序的索引范围搞混
- 忘记处理空树/单节点
- 递归终止条件不对
