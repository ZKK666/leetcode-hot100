# 98. 验证二叉搜索树【中等】

## 题目描述

给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **小于** 当前节点的数。
- 节点的右子树只包含 **大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

## 解题思路（面试推荐 - 最优解）

### 常见错误思路

**❌ 错误做法：只比较节点和其左右子节点**
```typescript
// 错误！
function isValidBST(root) {
    if (root === null) return true;
    if (root.left && root.left.val >= root.val) return false;
    if (root.right && root.right.val <= root.val) return false;
    return isValidBST(root.left) && isValidBST(root.right);
}
```

**为什么错误？**
```
反例：
      5
     / \
    1   4
       / \
      3   6

按错误方法：
- 5 > 1 ✓, 5 < 4 ✗ → 应该返回false
- 但实际上是错的！因为：节点3在5的右子树中，但3 < 5，违反BST性质

正确判断：
右子树的所有节点都必须 > 5
但节点3 < 5，所以不是BST
```

---

### 方法一：递归 + 范围检查（推荐）

**核心思想：**
- 每个节点都有一个取值范围 [min, max]
- 根节点：范围 (-∞, +∞)
- 左子节点：范围 (min, root.val)
- 右子节点：范围 (root.val, max)

**为什么需要范围？**
```
      10
     /  \
    5   15
       /  \
      6   20

节点6的判断：
- 6 < 15 ✓（小于父节点）
- 但6必须 > 10（因为在10的右子树中）

使用范围：
- 节点10：范围 (-∞, +∞)
- 节点5：范围 (-∞, 10)
- 节点15：范围 (10, +∞)
- 节点6：范围 (10, 15) ✗ 6不在这个范围！
```

**算法流程：**
1. 定义辅助函数 isValid(node, min, max)
2. 检查 node.val 是否在 (min, max) 范围内
3. 递归检查左子树：范围 (min, node.val)
4. 递归检查右子树：范围 (node.val, max)

**时间复杂度：** O(n)
**空间复杂度：** O(h) - 递归栈深度

---

### 方法二：中序遍历（利用BST性质）

**核心思想：**
- BST的中序遍历结果是严格递增序列
- 遍历过程中检查是否递增

**为什么中序遍历有效？**
```
BST性质：左 < 根 < 右
中序遍历：左 → 根 → 右

自然得到递增序列

例如：
      5
     / \
    3   7
   / \
  2   4

中序遍历：2, 3, 4, 5, 7（递增✓）

如果不是BST：
      5
     / \
    3   7
   / \
  2   6

中序遍历：2, 3, 6, 5, 7（不递增✗）
```

**算法流程：**
1. 中序遍历二叉树
2. 记录前一个节点的值
3. 检查当前值是否 > 前一个值

**时间复杂度：** O(n)
**空间复杂度：** O(h)

## 代码实现（TypeScript）

### 方法一：递归 + 范围检查

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function isValidBST(root: TreeNode | null): boolean {
    /**
     * 检查节点值是否在 (min, max) 范围内
     * @param node 当前节点
     * @param min 最小值（不包含）
     * @param max 最大值（不包含）
     */
    function isValid(node: TreeNode | null, min: number, max: number): boolean {
        // 空节点是有效的BST
        if (node === null) {
            return true;
        }

        // 检查当前节点值是否在范围内
        if (node.val <= min || node.val >= max) {
            return false;
        }

        // 递归检查左右子树
        // 左子树：所有值必须在 (min, node.val) 范围内
        // 右子树：所有值必须在 (node.val, max) 范围内
        return isValid(node.left, min, node.val) &&
               isValid(node.right, node.val, max);
    }

    // 根节点的范围是 (-∞, +∞)
    return isValid(root, -Infinity, Infinity);
}
```

### 方法二：中序遍历（递归）

```typescript
function isValidBST(root: TreeNode | null): boolean {
    let prev: number | null = null;  // 记录前一个节点的值

    function inorder(node: TreeNode | null): boolean {
        if (node === null) {
            return true;
        }

        // 遍历左子树
        if (!inorder(node.left)) {
            return false;
        }

        // 访问当前节点：检查是否递增
        if (prev !== null && node.val <= prev) {
            return false;
        }
        prev = node.val;

        // 遍历右子树
        return inorder(node.right);
    }

    return inorder(root);
}
```

---

### 方法三：中序遍历（迭代）

```typescript
function isValidBST(root: TreeNode | null): boolean {
    const stack: TreeNode[] = [];
    let curr: TreeNode | null = root;
    let prev: number | null = null;

    while (curr !== null || stack.length > 0) {
        // 一直往左走到底
        while (curr !== null) {
            stack.push(curr);
            curr = curr.left;
        }

        // 弹出栈顶节点
        curr = stack.pop()!;

        // 检查是否递增
        if (prev !== null && curr.val <= prev) {
            return false;
        }
        prev = curr.val;

        // 转向右子树
        curr = curr.right;
    }

    return true;
}
```

## 代码原理详解

### 方法一：范围检查

```
树结构：
      10
     /  \
    5   15
       /  \
      6   20

递归过程：
isValid(10, -∞, +∞):
  10 ∈ (-∞, +∞) ✓

  isValid(5, -∞, 10):
    5 ∈ (-∞, 10) ✓
    left = null ✓
    right = null ✓
    return true

  isValid(15, 10, +∞):
    15 ∈ (10, +∞) ✓

    isValid(6, 10, 15):
      6 ∈ (10, 15)?
      6 <= 10 ✗
      return false

    return false

返回：false
```

### 方法二：中序遍历

```
树结构：
      5
     / \
    3   7
   / \
  2   4

中序遍历过程：
prev = null

访问2：
  prev = null, curr = 2
  prev = 2

访问3：
  prev = 2, curr = 3
  3 > 2 ✓
  prev = 3

访问4：
  prev = 3, curr = 4
  4 > 3 ✓
  prev = 4

访问5：
  prev = 4, curr = 5
  5 > 4 ✓
  prev = 5

访问7：
  prev = 5, curr = 7
  7 > 5 ✓
  prev = 7

返回：true（所有值都递增）
```

## 常见问题

**Q1: 为什么不能只比较节点和其子节点？**
A: 因为需要满足全局约束：
```
错误示例：
      5
     / \
    1   6
       / \
      3   7

只比较相邻节点：
- 5 > 1 ✓
- 5 < 6 ✓
- 6 > 3 ✓
- 6 < 7 ✓

但实际上无效！因为：
节点3在5的右子树中，应该 > 5
但3 < 5 ✗
```

**Q2: 为什么用 <= 而不是 < ？**
A: BST要求值**严格递增**，不能有重复：
```
定义：左子树 < 根 < 右子树（严格不等）

如果用 <：
    5
   /
  5  ← 允许相等，错误！

正确用 <=：
node.val <= min || node.val >= max
```

**Q3: 中序遍历时为什么用 prev <= curr 而不是 prev >= curr？**
A: 中序遍历应该递增：
```
BST中序遍历：递增序列
2 → 3 → 5 → 7

检查：每个值 > 前一个值
如果 curr <= prev，说明不递增，不是BST
```

**Q4: 两种方法哪个更好？**
A:
- **范围检查**：更直观，明确表达BST定义，推荐面试使用
- **中序遍历**：利用BST性质，代码更简洁，但需要额外空间存储prev

## 复杂度分析

### 方法一：范围检查

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- 递归栈深度 = 树高
- 平衡树：O(log n)
- 链式树：O(n)

### 方法二：中序遍历

**时间复杂度：** O(n)
- 遍历所有节点

**空间复杂度：** O(h)
- 递归版本：递归栈
- 迭代版本：显式栈

## 总结

**关键点：**
1. 不能只比较相邻节点，需要全局约束
2. 范围检查：每个节点有取值范围 (min, max)
3. 中序遍历：利用BST中序递增的性质
4. 严格不等：不允许重复值

**面试建议：**
- 先说明错误做法（只比较相邻节点）

- 画图演示反例

**易错点：**
- 只比较节点和其左右子节点
- 忘记严格不等（允许重复值）
- 边界值处理（Integer.MAX_VALUE）
- 中序遍历时初始prev值的设置
