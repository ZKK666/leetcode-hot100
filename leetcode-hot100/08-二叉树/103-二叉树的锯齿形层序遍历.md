# 103. 二叉树的锯齿形层序遍历【中等】

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的 **锯齿形层序遍历**。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

---

## 输入输出示例

### 示例 1
```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[20,9],[15,7]]
```

![示例1](https://assets.leetcode.com/uploads/2021/02/19/tree1.jpg)

### 示例 2
```
输入：root = [1]
输出：[[1]]
```

### 示例 3
```
输入：root = []
输出：[]
```

### 提示
- 树中节点数目在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**锯齿形遍历的特点：**
```
      3
     / \
    9  20
      / \
     15  7

层0：从左到右 → [3]
层1：从右到左 → [20, 9]
层2：从左到右 → [15, 7]

规律：
- 偶数层（0,2,4...）：从左到右
- 奇数层（1,3,5...）：从右到左
```

---

### 方法一：BFS + 反转（推荐）

**核心思想：**
- 正常进行层序遍历
- 奇数层结果反转

**算法流程：**
1. 使用队列进行BFS
2. 处理每一层时记录层号
3. 如果是奇数层，反转当前层数组
4. 加入结果

**时间复杂度：** O(n)
**空间复杂度：** O(w) - w是树的最大宽度

---

### 方法二：BFS + 双端队列

**核心思想：**
- 使用双端队列（deque）
- 偶数层：从左往右加入队列（正常）
- 奇数层：从右往左加入队列（反向）

**算法流程：**
1. 根据层号决定遍历方向
2. 偶数层：左→右入队，左→右出队
3. 奇数层：右→左入队，右→左出队

**时间复杂度：** O(n)
**空间复杂度：** O(w)

---

### 方法三：BFS + 条件插入

**核心思想：**
- 正常BFS遍历
- 根据层号决定插入位置：
  - 偶数层：push到数组末尾
  - 奇数层：unshift到数组开头

**算法流程：**
1. 正常层序遍历
2. 偶数层：currentLevel.push(node.val)
3. 奇数层：currentLevel.unshift(node.val)

**时间复杂度：** O(n)
**空间复杂度：** O(w)

## 代码实现（TypeScript）

### 方法一：BFS + 反转（推荐）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function zigzagLevelOrder(root: TreeNode | null): number[][] {
    if (root === null) {
        return [];
    }

    const result: number[][] = [];
    const queue: TreeNode[] = [root];
    let level = 0;  // 当前层号（从0开始）

    while (queue.length > 0) {
        const levelSize = queue.length;
        const currentLevel: number[] = [];

        // 处理当前层的所有节点
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift()!;
            currentLevel.push(node.val);

            // 加入下一层节点
            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }

        // 奇数层需要反转
        if (level % 2 === 1) {
            currentLevel.reverse();
        }

        result.push(currentLevel);
        level++;
    }

    return result;
}
```

### 方法二：BFS + 条件插入

```typescript
function zigzagLevelOrder(root: TreeNode | null): number[][] {
    if (root === null) {
        return [];
    }

    const result: number[][] = [];
    const queue: TreeNode[] = [root];
    let level = 0;

    while (queue.length > 0) {
        const levelSize = queue.length;
        const currentLevel: number[] = [];

        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift()!;

            // 根据层号决定插入位置
            if (level % 2 === 0) {
                // 偶数层：从左到右（push到末尾）
                currentLevel.push(node.val);
            } else {
                // 奇数层：从右到左（unshift到开头）
                currentLevel.unshift(node.val);
            }

            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }

        result.push(currentLevel);
        level++;
    }

    return result;
}
```

### 方法三：DFS + 层号

```typescript
function zigzagLevelOrder(root: TreeNode | null): number[][] {
    const result: number[][] = [];

    function dfs(node: TreeNode | null, level: number): void {
        if (node === null) {
            return;
        }

        // 初始化当前层数组
        if (result.length === level) {
            result.push([]);
        }

        // 根据层号决定插入位置
        if (level % 2 === 0) {
            // 偶数层：从左到右
            result[level].push(node.val);
        } else {
            // 奇数层：从右到左（插入开头）
            result[level].unshift(node.val);
        }

        // 递归处理子树
        dfs(node.left, level + 1);
        dfs(node.right, level + 1);
    }

    dfs(root, 0);
    return result;
}
```

## 代码原理详解

### 方法一：BFS + 反转

```
树结构：
      3
     / \
    9  20
      / \
     15  7

执行过程：

层0（level=0，偶数）：
  queue = [3]
  currentLevel = [3]
  不反转
  result = [[3]]
  queue = [9, 20]

层1（level=1，奇数）：
  queue = [9, 20]
  currentLevel = [9, 20]
  反转：[20, 9]
  result = [[3], [20, 9]]
  queue = [15, 7]

层2（level=2，偶数）：
  queue = [15, 7]
  currentLevel = [15, 7]
  不反转
  result = [[3], [20, 9], [15, 7]]
  queue = []

返回：[[3], [20, 9], [15, 7]] ✓
```

### 方法二：条件插入

```
层1（level=1，奇数）：
  queue = [9, 20]
  currentLevel = []

  处理节点9：
    level % 2 === 1，unshift
    currentLevel = [9]

  处理节点20：
    level % 2 === 1，unshift
    currentLevel = [20, 9]

  结果：[20, 9] ✓

unshift的效果：
  [9]
  unshift(20) → [20, 9]（20插入到开头）
```

## 常见问题

**Q1: 反转和条件插入哪个更好？**
A:
- **反转**：代码更清晰，易理解，推荐面试使用
- **条件插入**：避免反转操作，但unshift的时间复杂度是O(n)

实际效率：
```
反转：O(levelSize) 一次性反转
unshift：O(levelSize²) 每个元素插入都是O(n)

所以反转方法更高效！
```

**Q2: 为什么奇数层要反转？**
A: 题目要求锯齿形：
```
层0：0 % 2 = 0（偶数）→ 从左到右
层1：1 % 2 = 1（奇数）→ 从右到左
层2：2 % 2 = 0（偶数）→ 从左到右
...
```

**Q3: 能否改变入队顺序实现？**
A: 不能简单改变入队顺序：
```
错误想法：奇数层先入右子节点
      3
     / \
    9  20

层1要从右到左：[20, 9]
如果先入右子节点：queue = [20, 9]
但层2的顺序会错误！

正确做法：正常入队，调整输出顺序
```

**Q4: DFS方法为什么要用unshift？**
A: DFS先访问左子树：
```
层1（奇数层）：
dfs(9, 1) → result[1] = [9]
dfs(20, 1) → result[1] = [9, 20]

但我们要[20, 9]，所以：
dfs(9, 1) → result[1].unshift(9) → [9]
dfs(20, 1) → result[1].unshift(20) → [20, 9] ✓
```

## 复杂度分析

### 方法一、二：BFS

**时间复杂度：** O(n)
- 每个节点访问一次
- 反转操作：O(levelSize)，所有层加起来是O(n)

**空间复杂度：** O(w)
- w是树的最大宽度

### 方法三：DFS

**时间复杂度：** O(n²)
- 最坏情况：每个节点unshift，时间O(n²)

**空间复杂度：** O(h)
- 递归栈深度

## 总结

**关键点：**
1. 锯齿形 = 偶数层从左到右，奇数层从右到左
2. BFS正常遍历，奇数层反转结果（推荐）
3. 条件插入用unshift，但效率较低
4. 层号从0开始，0是偶数层

**面试建议：**
- 优先使用BFS + 反转（最清晰）
- 解释锯齿形的含义
- 画图演示每层的遍历方向
- 提及reverse()的时间复杂度
- 可以对比unshift方法

**易错点：**
- 层号从0还是1开始（影响奇偶判断）
- 忘记判断奇偶层
- unshift效率问题
- 空树的处理
