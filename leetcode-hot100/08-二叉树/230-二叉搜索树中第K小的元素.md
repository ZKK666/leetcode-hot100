# 230. 二叉搜索树中第K小的元素【中等】

## 题目描述

给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

---

## 输入输出示例

### 示例 1
```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

### 示例 2
```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

![示例2](https://assets.leetcode.com/uploads/2021/01/28/kthtree2.jpg)

### 提示
- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶**：如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**BST的关键性质：**
```
BST的中序遍历结果是升序序列

例如：
      5
     / \
    3   6
   / \
  2   4
 /
1

中序遍历：1, 2, 3, 4, 5, 6（升序）

第k小的元素 = 中序遍历的第k个元素
```

---

### 方法一：中序遍历（递归）

**核心思想：**
- 进行中序遍历
- 遍历到第k个元素时返回

**算法流程：**
1. 中序遍历：左 → 根 → 右
2. 计数器count，每访问一个节点+1
3. 当count == k时，找到答案

**时间复杂度：** O(k) - 最多访问k个节点
**空间复杂度：** O(h) - 递归栈深度

---

### 方法二：中序遍历（迭代）

**核心思想：**
- 使用栈进行迭代中序遍历
- 弹出第k个元素即为答案

**算法流程：**
1. 使用栈模拟中序遍历
2. 每弹出一个节点，计数+1
3. 当计数达到k时返回

**时间复杂度：** O(k)
**空间复杂度：** O(h)

---

## 代码实现（TypeScript）

### 方法一：中序遍历（递归）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function kthSmallest(root: TreeNode | null, k: number): number {
    let count = 0;      // 计数器
    let result = 0;     // 结果

    function inorder(node: TreeNode | null): void {
        if (node === null || count >= k) {
            return;  // 提前终止：已找到答案
        }

        // 遍历左子树
        inorder(node.left);

        // 访问当前节点
        count++;
        if (count === k) {
            result = node.val;
            return;
        }

        // 遍历右子树
        inorder(node.right);
    }

    inorder(root);
    return result;
}
```

### 方法二：中序遍历（迭代）

```typescript
function kthSmallest(root: TreeNode | null, k: number): number {
    const stack: TreeNode[] = [];
    let curr: TreeNode | null = root;
    let count = 0;

    while (curr !== null || stack.length > 0) {
        // 一直往左走到底
        while (curr !== null) {
            stack.push(curr);
            curr = curr.left;
        }

        // 弹出栈顶节点（当前最小的）
        curr = stack.pop()!;

        // 计数
        count++;
        if (count === k) {
            return curr.val;
        }

        // 转向右子树
        curr = curr.right;
    }

    return -1;  // 不会到达这里（题目保证k有效）
}
```

### 方法三：存储所有值（不推荐）

```typescript
function kthSmallest(root: TreeNode | null, k: number): number {
    const values: number[] = [];

    function inorder(node: TreeNode | null): void {
        if (node === null) return;
        inorder(node.left);
        values.push(node.val);
        inorder(node.right);
    }

    inorder(root);
    return values[k - 1];
}
```

**缺点**：
- 空间O(n)，存储所有值
- 时间O(n)，遍历整棵树

## 代码原理详解

### 方法一：递归中序遍历

```
树结构：
      5
     / \
    3   6
   / \
  2   4
 /
1

寻找第3小的元素（k=3）：

count=0, result=0

inorder(5):
  inorder(3):
    inorder(2):
      inorder(1):
        inorder(null) ← 左子树为空
        count=1, result=1 ← 访问节点1
        inorder(null) ← 右子树为空

      count=2, result=2 ← 访问节点2
      inorder(null) ← 右子树为空

    count=3, result=3 ← 访问节点3，找到！
    return

返回：3
```

### 方法二：迭代中序遍历

```
树结构：
      5
     / \
    3   6
   / \
  2   4
 /
1

寻找第3小的元素（k=3）：

初始：curr=5, stack=[], count=0

往左走到底：
  push(5), curr=3
  push(3), curr=2
  push(2), curr=1
  push(1), curr=null
  stack=[5,3,2,1]

弹出1：
  curr=1, count=1
  count != 3，继续
  curr=1.right=null

弹出2：
  curr=2, count=2
  count != 3，继续
  curr=2.right=null

弹出3：
  curr=3, count=3
  count == 3，返回3 ✓
```

## 常见问题

**Q1: 为什么是中序遍历而不是前序或后序？**
A: BST的中序遍历是升序：
```
前序遍历：根左右 → 5,3,2,1,4,6（不是升序）
中序遍历：左根右 → 1,2,3,4,5,6（升序✓）
后序遍历：左右根 → 1,2,4,3,6,5（不是升序）
```

**Q2: 如何优化到只访问k个节点？**
A: 提前终止：
```typescript
// 当count达到k时，立即返回，不继续遍历
if (count === k) {
    result = node.val;
    return;  // 终止递归
}
```

**Q3: 如果要找第k大的元素怎么办？**
A: 反向中序遍历（右 → 根 → 左）：
```typescript
function kthLargest(root: TreeNode | null, k: number): number {
    let count = 0;
    let result = 0;

    function reverseInorder(node: TreeNode | null): void {
        if (node === null || count >= k) return;

        reverseInorder(node.right);  // 先右
        count++;
        if (count === k) {
            result = node.val;
            return;
        }
        reverseInorder(node.left);   // 后左
    }

    reverseInorder(root);
    return result;
}
```

**Q4: 进阶问题：频繁修改时如何优化？**
A: 在每个节点存储子树大小：
```typescript
class TreeNodeWithSize {
    val: number;
    left: TreeNodeWithSize | null;
    right: TreeNodeWithSize | null;
    size: number;  // 以该节点为根的子树节点数

    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
        this.size = 1;
    }
}

function kthSmallest(root: TreeNodeWithSize | null, k: number): number {
    if (root === null) return -1;

    const leftSize = root.left ? root.left.size : 0;

    if (k <= leftSize) {
        // 在左子树
        return kthSmallest(root.left, k);
    } else if (k === leftSize + 1) {
        // 就是当前节点
        return root.val;
    } else {
        // 在右子树
        return kthSmallest(root.right, k - leftSize - 1);
    }
}
```

优化效果：
- 不修改：O(k) → O(log n)（跳过不需要的子树）
- 修改：需要维护size，插入/删除 O(log n)

## 复杂度分析

### 方法一、二：中序遍历

**时间复杂度：** O(k)
- 最多访问k个节点
- 找到第k个后提前终止

**空间复杂度：** O(h)
- 递归：递归栈深度
- 迭代：显式栈
- h是树的高度
- 平衡树：O(log n)
- 链式树：O(n)

### 方法三：存储所有值

**时间复杂度：** O(n)
- 遍历整棵树

**空间复杂度：** O(n)
- 存储所有值

## 总结

**关键点：**
1. BST中序遍历 = 升序序列
2. 第k小 = 中序遍历第k个元素
3. 提前终止：找到后立即返回
4. 时间O(k)，优于O(n)

**面试建议：**
- 先说明BST的中序遍历性质
- 解释为什么中序遍历是升序
- 强调可以提前终止（O(k)而非O(n)）
- 可以提进阶优化（存储子树大小）

**易错点：**
- 忘记BST中序遍历是升序
- 遍历整棵树而不提前终止
- count从0还是1开始（建议从0开始）
- 递归终止条件的设置
