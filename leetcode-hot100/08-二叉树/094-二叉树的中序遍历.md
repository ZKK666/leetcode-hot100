# 94. 二叉树的中序遍历【简单】

## 题目描述

给定一个二叉树的根节点 `root`，返回它的 **中序** 遍历结果。

---

## 解题思路（面试推荐 - 最优解）

### 二叉树遍历基础

**三种遍历方式：**
```
前序遍历（Pre-order）：  根 → 左 → 右
中序遍历（In-order）：   左 → 根 → 右
后序遍历（Post-order）： 左 → 右 → 根
```

**中序遍历特点：**
- 对于二叉搜索树，中序遍历得到升序序列
- 访问顺序：左子树 → 根节点 → 右子树

**示例：**
```
      1
       \
        2
       /
      3

中序遍历：
1. 访问左子树（空）
2. 访问根（1）
3. 访问右子树（2）
   3.1 访问左子树（3）
   3.2 访问根（2）
   3.3 访问右子树（空）

结果：[1, 3, 2]
```

---

### 方法一：递归（最简单）

**核心思想：**
- 递归定义：中序(root) = 中序(left) + root.val + 中序(right)

**算法流程：**
1. 如果节点为空，返回
2. 递归遍历左子树
3. 访问当前节点
4. 递归遍历右子树

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(n) - 递归栈，最坏情况（链式）为n

---

### 方法二：迭代（栈模拟递归）

**核心思想：**
- 用栈模拟递归的过程
- 先一直往左走到底，再处理节点，然后转向右子树

**为什么用栈？**
```
递归本质就是函数调用栈
手动用栈可以消除递归

递归：系统自动管理栈
迭代：手动管理栈
```

**算法流程：**
1. 从根节点开始，一直往左走，将路径上的节点入栈
2. 弹出栈顶节点，访问它
3. 转向右子树，重复步骤1

**时间复杂度：** O(n)
**空间复杂度：** O(n) - 显式栈

---

### 方法三：Morris遍历（O(1)空间）

**核心思想：**
- 利用树的空闲指针（叶子节点的右指针）
- 建立临时线索，遍历后恢复

**算法流程：**
1. 如果当前节点的左子树为空，访问当前节点，转向右子树
2. 如果左子树不空，找到左子树的最右节点（前驱）：
   - 如果前驱的右指针为空，建立线索，转向左子树
   - 如果前驱的右指针指向当前节点，断开线索，访问当前节点，转向右子树

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：递归

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function inorderTraversal(root: TreeNode | null): number[] {
    const result: number[] = [];

    function inorder(node: TreeNode | null): void {
        if (node === null) {
            return;
        }

        // 1. 遍历左子树
        inorder(node.left);

        // 2. 访问根节点
        result.push(node.val);

        // 3. 遍历右子树
        inorder(node.right);
    }

    inorder(root);
    return result;
}
```

---

### 方法二：迭代（栈）

```typescript
function inorderTraversal(root: TreeNode | null): number[] {
    const result: number[] = [];
    const stack: TreeNode[] = [];
    let curr: TreeNode | null = root;

    while (curr !== null || stack.length > 0) {
        // 一直往左走到底，将路径上的节点入栈
        while (curr !== null) {
            stack.push(curr);
            curr = curr.left;
        }

        // 弹出栈顶节点（最左的节点）
        curr = stack.pop()!;

        // 访问节点
        result.push(curr.val);

        // 转向右子树
        curr = curr.right;
    }

    return result;
}
```

---

### 方法三：Morris遍历

```typescript
function inorderTraversal(root: TreeNode | null): number[] {
    const result: number[] = [];
    let curr: TreeNode | null = root;

    while (curr !== null) {
        if (curr.left === null) {
            // 左子树为空，访问当前节点，转向右子树
            result.push(curr.val);
            curr = curr.right;
        } else {
            // 找到左子树的最右节点（前驱）
            let predecessor = curr.left;
            while (predecessor.right !== null && predecessor.right !== curr) {
                predecessor = predecessor.right;
            }

            if (predecessor.right === null) {
                // 建立线索
                predecessor.right = curr;
                curr = curr.left;
            } else {
                // 断开线索，访问当前节点
                predecessor.right = null;
                result.push(curr.val);
                curr = curr.right;
            }
        }
    }

    return result;
}
```

## 代码原理详解

### 递归方法

```
递归调用栈：

inorder(1):
  inorder(null)       // 左子树为空
  result.push(1)      // 访问1
  inorder(2):
    inorder(3):
      inorder(null)
      result.push(3)  // 访问3
      inorder(null)
    result.push(2)    // 访问2
    inorder(null)

结果：[1, 3, 2]
```

### 迭代方法（栈）

```
树结构：
      1
       \
        2
       /
      3

执行过程：
curr=1, stack=[]

步骤1：往左走到底
  curr=1: push(1), curr=null
  curr=null: 退出内层while
  stack=[1]

步骤2：弹出并访问
  curr=pop()=1
  result.push(1)
  curr=1.right=2
  result=[1]

步骤3：往左走到底
  curr=2: push(2), curr=2.left=3
  curr=3: push(3), curr=null
  stack=[2,3]

步骤4：弹出并访问
  curr=pop()=3
  result.push(3)
  curr=3.right=null
  result=[1,3]

步骤5：弹出并访问
  curr=null, stack=[2]
  curr=pop()=2
  result.push(2)
  curr=2.right=null
  result=[1,3,2]

结束
```

### Morris遍历

```
树结构：
      1
       \
        2
       /
      3

执行过程：
curr=1

步骤1：curr.left为空
  result.push(1)
  curr=1.right=2
  result=[1]

步骤2：curr=2, curr.left=3
  找前驱：predecessor=3
  predecessor.right为空，建立线索
  3.right=2
  curr=curr.left=3

步骤3：curr=3, curr.left为空
  result.push(3)
  curr=3.right=2（线索）
  result=[1,3]

步骤4：curr=2, curr.left=3
  找前驱：predecessor=3
  predecessor.right=2（已有线索）
  断开线索：3.right=null
  result.push(2)
  curr=2.right=null
  result=[1,3,2]

结束
```

      1

inorder(1):

## 常见问题

**Q1: 三种遍历方式的区别？**
A:
```
前序（Pre-order）：  根左右  →  [1,2,3]
中序（In-order）：   左根右  →  [1,3,2]
后序（Post-order）： 左右根  →  [3,2,1]

对于同一棵树：
      1
       \
        2
       /
      3
```

**Q2: 为什么BST的中序遍历是升序？**
A: BST的定义：左 < 根 < 右
```
中序遍历：先访问左（较小），再访问根，再访问右（较大）
自然得到升序序列
```

**Q3: 迭代方法的栈最大深度是多少？**
A: 取决于树的高度：
```
平衡树：O(log n)
链式树：O(n)
```

**Q4: Morris遍历为什么能做到O(1)空间？**
A: 利用叶子节点的空闲右指针建立临时线索，不需要额外空间。
