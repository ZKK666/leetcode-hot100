# 226. 翻转二叉树【简单】

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

## 解题思路（面试推荐 - 最优解）

### 方法一：递归（DFS）

**核心思想：**
- 翻转一棵树 = 交换左右子树 + 递归翻转左右子树
- 自顶向下或自底向上都可以

**为什么能递归？**
```
翻转整棵树的步骤：
1. 翻转左子树
2. 翻转右子树
3. 交换左右子树

子问题和原问题结构相同，适合递归
```

**算法流程：**
1. 如果节点为空，返回null
2. 递归翻转左子树
3. 递归翻转右子树
4. 交换左右子树
5. 返回根节点

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(h) - 递归栈深度，h是树高

---

### 方法二：迭代（BFS）

**核心思想：**
- 使用队列进行层序遍历
- 对每个节点交换其左右子树

**算法流程：**
1. 将根节点加入队列
2. 从队列取出节点
3. 交换该节点的左右子树
4. 将左右子节点加入队列
5. 重复直到队列为空

**时间复杂度：** O(n)
**空间复杂度：** O(w) - w是树的最大宽度

## 代码实现（TypeScript）

### 方法一：递归（DFS）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function invertTree(root: TreeNode | null): TreeNode | null {
    // 递归终止条件：空节点
    if (root === null) {
        return null;
    }

    // 递归翻转左右子树
    const left = invertTree(root.left);
    const right = invertTree(root.right);

    // 交换左右子树
    root.left = right;
    root.right = left;

    return root;
}
```

**更简洁的写法：**
```typescript
function invertTree(root: TreeNode | null): TreeNode | null {
    if (root === null) return null;

    // 交换左右子树（使用解构赋值）
    [root.left, root.right] = [invertTree(root.right), invertTree(root.left)];

    return root;
}
```

### 方法二：迭代（BFS）

```typescript
function invertTree(root: TreeNode | null): TreeNode | null {
    if (root === null) {
        return null;
    }

    // 使用队列进行层序遍历
    const queue: TreeNode[] = [root];

    while (queue.length > 0) {
        // 取出队首节点
        const node = queue.shift()!;

        // 交换左右子树
        [node.left, node.right] = [node.right, node.left];

        // 将非空子节点加入队列
        if (node.left !== null) {
            queue.push(node.left);
        }
        if (node.right !== null) {
            queue.push(node.right);
        }
    }

    return root;
}
```

---

### 方法三：迭代（DFS用栈）

```typescript
function invertTree(root: TreeNode | null): TreeNode | null {
    if (root === null) {
        return null;
    }

    // 使用栈进行深度优先遍历
    const stack: TreeNode[] = [root];

    while (stack.length > 0) {
        const node = stack.pop()!;

        // 交换左右子树
        [node.left, node.right] = [node.right, node.left];

        // 将非空子节点加入栈
        if (node.left !== null) {
            stack.push(node.left);
        }
        if (node.right !== null) {
            stack.push(node.right);
        }
    }

    return root;
}
```

## 代码原理详解

### 递归方法

```
树结构：
      4
     / \
    2   7
   / \ / \
  1  3 6  9

递归过程：
invertTree(4):
  left = invertTree(2):
    left = invertTree(1):
      return 1
    right = invertTree(3):
      return 3
    swap: 2.left=3, 2.right=1
    return 2

  right = invertTree(7):
    left = invertTree(6):
      return 6
    right = invertTree(9):
      return 9
    swap: 7.left=9, 7.right=6
    return 7

  swap: 4.left=7, 4.right=2
  return 4

结果：
      4
     / \
    7   2
   / \ / \
  9  6 3  1
```

### 迭代方法（BFS）

```
初始：queue=[4]

处理4：
  交换：4的左右子树
  4: 2和7 → 7和2
  加入队列：[2,7]

处理2：
  交换：2的左右子树
  2: 1和3 → 3和1
  加入队列：[7,1,3]

处理7：
  交换：7的左右子树
  7: 6和9 → 9和6
  加入队列：[1,3,6,9]

处理叶子节点1,3,6,9：
  无子节点，不加入队列

完成
```

## 运行示例

### 示例：`root = [4,2,7,1,3,6,9]`

**原始树：**
```
      4
     / \
    2   7
   / \ / \
  1  3 6  9
```

**翻转后：**
```
      4
     / \
    7   2
   / \ / \
  9  6 3  1
```

**递归执行步骤：**

```
1. 处理节点4：
   - 递归翻转左子树（2）
   - 递归翻转右子树（7）
   - 交换：4的左右子树

2. 处理节点2（在步骤1的递归中）：
   - 递归翻转左子树（1）
   - 递归翻转右子树（3）
   - 交换：2的左右子树
   结果：2的左子树变成3，右子树变成1

3. 处理节点7（在步骤1的递归中）：
   - 递归翻转左子树（6）
   - 递归翻转右子树（9）
   - 交换：7的左右子树
   结果：7的左子树变成9，右子树变成6

4. 回到步骤1：
   - 交换：4的左子树（翻转后的2）和右子树（翻转后的7）
   结果：4的左子树变成翻转后的7，右子树变成翻转后的2
```

**层序遍历对比：**
```
原始：[4,2,7,1,3,6,9]
翻转：[4,7,2,9,6,3,1]
```

## 常见问题

**Q1: 交换的时机重要吗？**
A: 不重要。可以先交换再递归，也可以先递归再交换：
```typescript
// 先交换
function invertTree(root: TreeNode | null): TreeNode | null {
    if (root === null) return null;

    [root.left, root.right] = [root.right, root.left];
    invertTree(root.left);
    invertTree(root.right);

    return root;
}

// 先递归（推荐，更清晰）
function invertTree(root: TreeNode | null): TreeNode | null {
    if (root === null) return null;

    const left = invertTree(root.left);
    const right = invertTree(root.right);

    root.left = right;
    root.right = left;

    return root;
}
```

**Q2: BFS和DFS的区别？**
A:
- **BFS（队列）**：按层翻转，先翻转上层再翻转下层
- **DFS（栈/递归）**：按深度翻转，先翻转到叶子再回溯

两种方法结果相同，只是遍历顺序不同。

**Q3: 能否原地翻转不返回新树？**
A: 本题就是原地翻转，只是交换指针，没有创建新节点。

**Q4: 这题为什么这么有名？**
A: 据说有个Google面试官因为一个优秀候选人不会做这题而拒绝了他，引发了讨论。这题很简单但很经典。

## 复杂度分析

### 递归方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- 递归栈深度 = 树高
- 平衡树：O(log n)
- 链式树：O(n)

### 迭代方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：**
- **BFS（队列）**：O(w) - 树的最大宽度
- **DFS（栈）**：O(h) - 树的高度

## 总结

**关键点：**
1. 翻转 = 递归翻转左右 + 交换左右
2. 递归最简洁（推荐）
3. 迭代用队列（BFS）或栈（DFS）
4. 交换时机不影响结果

**面试建议：**
- 优先写递归（最简洁）
- 解释翻转的含义（镜像）
- 可以画图演示
- 说明迭代方法作为补充

**易错点：**
- 忘记返回root
- 交换时丢失引用（需要临时变量）
- 空节点的处理
