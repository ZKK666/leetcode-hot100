# 108. 将有序数组转换为二叉搜索树【简单】

## 题目描述

给你一个整数数组 `nums`，其中元素已经按 **升序** 排列，请你将其转换为一棵 **平衡** 二叉搜索树。

**平衡二叉树** 是指该树所有节点的左右子树的深度相差不超过 1。

---

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]

```

### 提示
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按 **严格递增** 顺序排列

## 解题思路（面试推荐 - 最优解）

### 方法：递归（分治）

**核心思想：**
- BST的中序遍历是升序序列
- 选择中间元素作为根，可以保证平衡
- 递归构建左右子树

**为什么选中间元素作为根？**
```
有序数组：[-10, -3, 0, 5, 9]
                     ↑
                    中间

选0作为根：
- 左边：[-10, -3] → 左子树
- 右边：[5, 9] → 右子树
- 左右元素数量相近，保证平衡

      0
     / \
  [-10,-3] [5,9]
```

**BST的性质：**
```
二叉搜索树（BST）：
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点
- 中序遍历得到升序序列

有序数组 + 选中间元素 → 自然满足BST性质
```

**算法流程：**
1. 如果数组为空，返回null
2. 选择中间元素作为根节点
3. 递归构建左子树（左半部分数组）
4. 递归构建右子树（右半部分数组）
5. 返回根节点

**时间复杂度：** O(n) - 每个元素访问一次
**空间复杂度：** O(log n) - 递归栈深度（平衡树）

## 代码实现（TypeScript）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function sortedArrayToBST(nums: number[]): TreeNode | null {
    // 辅助函数：将nums[left...right]转换为BST
    function buildBST(left: number, right: number): TreeNode | null {
        // 递归终止条件：区间为空
        if (left > right) {
            return null;
        }

        // 选择中间元素作为根节点
        // 如果有两个中间元素，选择左边的（或右边的，都可以）
        const mid = Math.floor((left + right) / 2);

        // 创建根节点
        const root = new TreeNode(nums[mid]);

        // 递归构建左右子树
        root.left = buildBST(left, mid - 1);
        root.right = buildBST(mid + 1, right);

        return root;
    }

    return buildBST(0, nums.length - 1);
}
```

**选择右中间元素的版本：**
```typescript
function sortedArrayToBST(nums: number[]): TreeNode | null {
    function buildBST(left: number, right: number): TreeNode | null {
        if (left > right) {
            return null;
        }

        // 选择右中间元素
        const mid = Math.floor((left + right) / 2) + 1;

        // 当left和right相邻时，选择right
        // 例如：[1,3]，mid=1（选3作为根）

        const root = new TreeNode(nums[mid]);
        root.left = buildBST(left, mid - 1);
        root.right = buildBST(mid + 1, right);

        return root;
    }

    return buildBST(0, nums.length - 1);
}
```

## 代码原理详解

### 核心逻辑

1. **中点选择**：
   ```typescript
   mid = Math.floor((left + right) / 2)

   例如：
   left=0, right=4: mid=2 ✓
   left=0, right=3: mid=1（左中）或 mid=2（右中）
   ```

2. **区间划分**：
   ```
   原区间：[left, right]
   选中点：mid

   左子树：[left, mid-1]
   右子树：[mid+1, right]
   ```

3. **递归构建**：
   ```
   每次递归处理一个区间
   创建根节点 = nums[mid]
   递归构建左右子树
   ```

### 递归过程

```
数组：[-10, -3, 0, 5, 9]
索引：  0    1   2  3  4

buildBST(0, 4):
  mid = 2, root = 0

  left = buildBST(0, 1):
    mid = 0, root = -10
    left = buildBST(0, -1) = null
    right = buildBST(1, 1):
      mid = 1, root = -3
      left = buildBST(1, 0) = null
      right = buildBST(2, 1) = null
      return -3
    return -10

  right = buildBST(3, 4):
    mid = 3, root = 5
    left = buildBST(3, 2) = null
    right = buildBST(4, 4):
      mid = 4, root = 9
      left = buildBST(4, 3) = null
      right = buildBST(5, 4) = null
      return 9
    return 5

  return 0

结果树：
      0
     / \
  -10   5
    \    \
    -3    9
```

## 运行示例

### 示例 1：`nums = [-10,-3,0,5,9]`

**构建过程：**

```
步骤1：处理整个数组 [0, 4]
  mid = 2，选择 0 作为根

步骤2：处理左半部分 [0, 1]
  mid = 0，选择 -10 作为根
  左子树：[0, -1]（空）
  右子树：[1, 1]
    mid = 1，选择 -3

步骤3：处理右半部分 [3, 4]
  mid = 3，选择 5 作为根
  左子树：[3, 2]（空）
  右子树：[4, 4]
    mid = 4，选择 9

结果树：
      0
     / \
   -10  5
     \   \
     -3   9
```

**验证BST性质：**
```
中序遍历：-10 → -3 → 0 → 5 → 9 ✓（升序）

平衡性：
- 节点0：左深度2，右深度2 ✓
- 节点-10：左深度0，右深度1 ✓
- 节点5：左深度0，右深度1 ✓
```

---

### 示例 2：`nums = [1,3]`

**两种可能的构建方式：**

```
方式1：选择左中间元素
  mid = Math.floor((0 + 1) / 2) = 0
  root = 1
  左子树：[0, -1]（空）
  右子树：[1, 1] → 3

结果：
    1
     \
      3

方式2：选择右中间元素
  mid = Math.floor((0 + 1) / 2) + 1 = 1
  root = 3
  左子树：[0, 0] → 1
  右子树：[2, 1]（空）

结果：
    3
   /
  1
```

两种都是正确答案！

## 常见问题

**Q1: 为什么选中间元素能保证平衡？**
A: 中间元素将数组平分：
```
数组长度 n：
- 左半：约 n/2 个元素
- 右半：约 n/2 个元素

递归下去，每层都是平分
最终树的高度约为 log n，保证平衡
```

**Q2: 选左中还是右中有什么区别？**
A: 只影响树的形状，不影响平衡性：
```
[1,2,3,4]

左中（mid=1）：
    2
   / \
  1   3
       \
        4

右中（mid=2）：
    3
   / \
  2   4
 /
1

都是平衡的！
```

**Q3: 为什么不需要比较大小？**
A: 数组已经有序，选择中点自然满足BST性质：
```
中点左边 < 中点 < 中点右边
递归构建，自然满足左<根<右
```

**Q4: 空间复杂度是O(log n)还是O(n)？**
A:
- 递归栈：O(log n)（平衡树的高度）
- 树本身：O(n)（n个节点）
- 通常说的空间复杂度不计树本身，所以是O(log n)

---

## 复杂度分析

### 时间复杂度：O(n)
- 每个数组元素被访问一次
- 创建一个节点：O(1)
- 总共n个节点：O(n)

### 空间复杂度：O(log n)
- 递归栈深度 = 树的高度
- 平衡树高度：log n
- 不计树本身的空间

## 总结

**关键点：**
1. 有序数组 → 选中间元素 → 平衡BST
2. BST性质：左 < 根 < 右
3. 平衡性：递归平分保证
4. 递归分治：mid作根，递归构建左右

**面试建议：**
- 解释BST的性质

- 说明如何保证平衡

**易错点：**
- 区间边界（mid-1和mid+1）
- 递归终止条件（left > right）
- 忘记处理空数组
