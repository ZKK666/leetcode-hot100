# 101. 对称二叉树【简单】

## 题目描述

给你一个二叉树的根节点 `root`，检查它是否轴对称。

---

## 解题思路（面试推荐 - 最优解）

### 方法一：递归

**核心思想：**
- 对称的定义：左子树和右子树互为镜像
- 镜像的定义：
  1. 两个树的根节点值相同
  2. 第一棵树的左子树 = 第二棵树的右子树（镜像）
  3. 第一棵树的右子树 = 第二棵树的左子树（镜像）

**为什么这样判断？**
```
对称树：
      1
     / \
    2   2
   / \ / \
  3  4 4  3

左子树：  右子树：
   2        2
  / \      / \
 3   4    4   3

镜像关系：
- 2 == 2 ✓
- 左子树的左(3) == 右子树的右(3) ✓
- 左子树的右(4) == 右子树的左(4) ✓
```

**算法流程：**
1. 定义辅助函数isMirror(left, right)
2. 如果left和right都为空，返回true
3. 如果只有一个为空，返回false
4. 如果值不相等，返回false
5. 递归检查：
   - left.left 和 right.right
   - left.right 和 right.left

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(h) - 递归栈深度

---

### 方法二：迭代（队列）

**核心思想：**
- 使用队列模拟递归过程
- 每次取出两个节点进行比较

**算法流程：**
1. 初始化队列，放入root.left和root.right
2. 循环：
   - 取出两个节点left和right
   - 如果都为空，继续
   - 如果只有一个为空或值不等，返回false
   - 将left.left和right.right入队
   - 将left.right和right.left入队
3. 返回true

**时间复杂度：** O(n)
**空间复杂度：** O(w) - w是树的最大宽度

## 代码实现（TypeScript）

### 方法一：递归

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function isSymmetric(root: TreeNode | null): boolean {
    if (root === null) {
        return true;
    }

    // 检查左右子树是否镜像
    return isMirror(root.left, root.right);
}

/**
 * 判断两棵树是否互为镜像
 */
function isMirror(left: TreeNode | null, right: TreeNode | null): boolean {
    // 两个都为空，镜像
    if (left === null && right === null) {
        return true;
    }

    // 只有一个为空，不镜像
    if (left === null || right === null) {
        return false;
    }

    // 值不相等，不镜像
    if (left.val !== right.val) {
        return false;
    }

    // 递归检查：
    // 1. left的左子树 和 right的右子树 是否镜像
    // 2. left的右子树 和 right的左子树 是否镜像
    return isMirror(left.left, right.right) && isMirror(left.right, right.left);
}
```

### 方法二：迭代（队列）

```typescript
function isSymmetric(root: TreeNode | null): boolean {
    if (root === null) {
        return true;
    }

    // 使用队列进行层序遍历
    const queue: (TreeNode | null)[] = [root.left, root.right];

    while (queue.length > 0) {
        // 每次取出两个节点进行比较
        const left = queue.shift()!;
        const right = queue.shift()!;

        // 两个都为空，继续
        if (left === null && right === null) {
            continue;
        }

        // 只有一个为空，或值不相等，不对称
        if (left === null || right === null || left.val !== right.val) {
            return false;
        }

        // 按镜像顺序加入队列
        queue.push(left.left);
        queue.push(right.right);
        queue.push(left.right);
        queue.push(right.left);
    }

    return true;
}
```

## 代码原理详解

### 递归方法

```
树结构：
      1
     / \
    2   2
   / \ / \
  3  4 4  3

检查过程：
isMirror(2左, 2右):
  2 == 2 ✓
  isMirror(3, 3):
    3 == 3 ✓
    isMirror(null, null) = true
    isMirror(null, null) = true
    return true
  isMirror(4, 4):
    4 == 4 ✓
    isMirror(null, null) = true
    isMirror(null, null) = true
    return true
  return true && true = true
```

### 迭代方法

```
树结构：
      1
     / \
    2   2
   / \ / \
  3  4 4  3

队列变化：
初始：[2左, 2右]

迭代1：
  取出：2左, 2右
  比较：2 == 2 ✓
  加入：[3, 3, 4, 4]

迭代2：
  取出：3, 3
  比较：3 == 3 ✓
  加入：[4, 4, null, null, null, null]

迭代3：
  取出：4, 4
  比较：4 == 4 ✓
  加入：[null, null, null, null, null, null, null, null]

迭代4-7：
  取出：null, null
  都为空，继续

返回：true
```


## 常见问题

**Q1: 对称和相等有什么区别？**
A:
```
相等：两棵树结构和值完全相同
对称：两棵树互为镜像

例如：
     1           1
    / \         / \
   2   3       3   2

相等？否
对称？是
```

**Q2: 为什么要比较left.left和right.right？**
A: 这是镜像的定义：
```
      根
     /  \
   left right

镜像关系：
left的左 ←→ right的右
left的右 ←→ right的左
```

**Q3: 能否用中序遍历判断对称？**
A: 不能，反例：
```
      1
     / \
    2   2

中序遍历：[2,1,2]
回文序列，但不对称（右边的2没有子节点）
```

**Q4: 递归和迭代哪个更好？**
A:
- **递归**：代码简洁，易理解，推荐面试使用
- **迭代**：避免递归栈溢出，空间可能更大

## 复杂度分析

### 递归方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- 递归栈深度 = 树高
- 平衡树：O(log n)
- 链式树：O(n)

### 迭代方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(w)
- 队列最大元素数 = 树的最大宽度
- 完全二叉树：O(n/2) = O(n)

## 总结

**关键点：**
1. 对称 = 左右子树互为镜像
2. 镜像 = 值相等 + 左的左=右的右 + 左的右=右的左
3. 递归最清晰（推荐）
4. 迭代用队列，每次取两个节点

**面试建议：**
- 优先写递归（最清晰）
- 解释对称和镜像的定义
- 画图演示镜像关系
- 强调边界情况（null的处理）
- 可以补充迭代方法

**易错点：**
- 混淆对称和相等
- 递归时比较的节点顺序错误
- 忘记处理null节点
- 队列中节点的入队顺序
