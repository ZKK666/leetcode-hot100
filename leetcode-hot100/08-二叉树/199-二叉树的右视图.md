# 199. 二叉树的右视图【中等】

## 题目描述

给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

---

## 输入输出示例

### 示例 1
```
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]
```

![示例1](https://assets.leetcode.com/uploads/2021/02/14/tree.jpg)

### 示例 2
```
输入：root = [1,null,3]
输出：[1,3]
```

### 示例 3
```
输入：root = []
输出：[]
```

### 提示
- 二叉树的节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**右视图的定义：**
```
从右侧看二叉树，每一层只能看到最右边的节点

      1
     / \
    2   3
     \   \
      5   4

从右侧看：
层0：1（最右）
层1：3（最右）
层2：4（最右）

结果：[1, 3, 4]
```

**关键观察：**
- 右视图 = 每一层的最右边节点
- 可以用层序遍历（BFS）或深度优先（DFS）

---

### 方法一：BFS（层序遍历）

**核心思想：**
- 层序遍历每一层
- 取每层的最后一个节点

**算法流程：**
1. 使用队列进行BFS
2. 处理每一层时，记录最后一个节点
3. 将最后节点加入结果

**时间复杂度：** O(n)
**空间复杂度：** O(w) - w是树的最大宽度

---

### 方法二：DFS（深度优先）

**核心思想：**
- 优先遍历右子树
- 每层第一次访问的节点就是最右边的

**为什么先遍历右子树？**
```
      1
     / \
    2   3
     \
      5

DFS顺序（根→右→左）：
1 → 3 → 2 → 5

每层第一次访问：
层0：1（第一次访问层0）
层1：3（第一次访问层1）
层2：5（第一次访问层2）

结果：[1, 3, 5]

如果先遍历左子树（根→左→右）：
1 → 2 → 5 → 3
每层第一次访问：
层0：1
层1：2（错误！应该是3）
```

**算法流程：**
1. 递归：根 → 右 → 左
2. 记录每层第一次访问的节点
3. 使用result.length判断是否是第一次访问该层

**时间复杂度：** O(n)
**空间复杂度：** O(h) - 递归栈深度

## 代码实现（TypeScript）

### 方法一：BFS（层序遍历）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function rightSideView(root: TreeNode | null): number[] {
    if (root === null) {
        return [];
    }

    const result: number[] = [];
    const queue: TreeNode[] = [root];

    while (queue.length > 0) {
        const levelSize = queue.length;

        // 遍历当前层
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift()!;

            // 最后一个节点就是最右边的
            if (i === levelSize - 1) {
                result.push(node.val);
            }

            // 加入下一层节点
            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }
    }

    return result;
}
```

### 方法二：DFS（深度优先）

```typescript
function rightSideView(root: TreeNode | null): number[] {
    const result: number[] = [];

    function dfs(node: TreeNode | null, level: number): void {
        if (node === null) {
            return;
        }

        // 如果是第一次访问这一层，记录节点值
        if (result.length === level) {
            result.push(node.val);
        }

        // 优先遍历右子树（保证右边节点先被访问）
        dfs(node.right, level + 1);
        dfs(node.left, level + 1);
    }

    dfs(root, 0);
    return result;
}
```

## 代码原理详解

### BFS方法

```
树结构：
      1
     / \
    2   3
     \   \
      5   4

层序遍历：

层0：queue = [1]
  levelSize = 1
  i=0（最后一个）: 记录1
  result = [1]
  queue = [2, 3]

层1：queue = [2, 3]
  levelSize = 2
  i=0: 处理2，不记录
  i=1（最后一个）: 记录3
  result = [1, 3]
  queue = [5, 4]

层2：queue = [5, 4]
  levelSize = 2
  i=0: 处理5，不记录
  i=1（最后一个）: 记录4
  result = [1, 3, 4]

返回：[1, 3, 4] ✓
```

### DFS方法

```
树结构：
      1
     / \
    2   3
     \   \
      5   4

DFS遍历（根→右→左）：

dfs(1, 0):
  result.length=0, level=0
  第一次访问层0，记录1
  result = [1]

  dfs(3, 1):  // 先右
    result.length=1, level=1
    第一次访问层1，记录3
    result = [1, 3]

    dfs(null, 2)  // 3的右子树
    dfs(4, 2):     // 3的左子树
      result.length=2, level=2
      第一次访问层2，记录4
      result = [1, 3, 4]

  dfs(2, 1):  // 后左
    result.length=3, level=1
    NOT第一次访问层1（result[1]已存在）
    不记录

    dfs(null, 2)  // 2的右子树
    dfs(5, 2):     // 2的左子树
      result.length=3, level=2
      NOT第一次访问层2
      不记录

返回：[1, 3, 4] ✓
```

## 运行示例

### 示例：`root = [1,2,3,null,5,null,4]`

**树结构：**
```
      1
     / \
    2   3
     \   \
      5   4
```

**从右侧看：**
```
视角：

      1  ← 层0，看到1
     / \
    2   3  ← 层1，看到3（最右）
     \   \
      5   4  ← 层2，看到4（最右）

结果：[1, 3, 4]
```

**BFS执行：**
```
层0：[1] → 取最后一个 → 1
层1：[2, 3] → 取最后一个 → 3
层2：[5, 4] → 取最后一个 → 4

结果：[1, 3, 4] ✓
```

**DFS执行（先右后左）：**
```
访问顺序：1 → 3 → 4 → 2 → 5

层0第一次：1 ✓
层1第一次：3 ✓（先访问右子树）
层2第一次：4 ✓（先访问右子树）
层1第二次：2 ✗（跳过）
层2第二次：5 ✗（跳过）

结果：[1, 3, 4] ✓
```

## 常见问题

**Q1: 为什么DFS要先遍历右子树？**
A: 保证每层最右边的节点先被访问：
```
先右后左：
  层1：先访问3（最右），记录3 ✓
  层1：后访问2（不记录）

先左后右：
  层1：先访问2，记录2 ✗
  层1：后访问3（不记录）
  错误！
```

**Q2: BFS和DFS哪个更好？**
A:
- **BFS**：更直观，容易理解，推荐面试使用
- **DFS**：代码简洁，但需要理解先右后左的技巧

**Q3: 如果要左视图怎么办？**
A: 两种改法：
```typescript
// BFS：取每层第一个节点
if (i === 0) {
    result.push(node.val);
}

// DFS：先遍历左子树
dfs(node.left, level + 1);
dfs(node.right, level + 1);
```

**Q4: 时间复杂度是否都是O(n)？**
A: 是的，两种方法都要访问所有节点一次。

## 复杂度分析

### BFS方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(w)
- w是树的最大宽度
- 完全二叉树：O(n/2) = O(n)
- 链式树：O(1)

### DFS方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- h是树的高度（递归栈）
- 平衡树：O(log n)
- 链式树：O(n)

## 总结

**关键点：**
1. 右视图 = 每层最右边的节点
2. BFS：取每层最后一个节点（推荐）
3. DFS：先右后左，记录每层第一次访问的节点
4. 判断是否第一次访问：result.length === level

**面试建议：**
- 优先使用BFS（更直观）
- 解释右视图的含义
- 画图演示从右侧看的效果
- 可以补充DFS方法
- 提及左视图的变体

**易错点：**
- BFS忘记判断是否是最后一个节点
- DFS先左后右（应该先右后左）
- 混淆层序遍历和右视图
- 空树的处理
