# 102. 二叉树的层序遍历【中等】

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的 **层序遍历**。（即逐层地，从左到右访问所有节点）。

---

## 输入输出示例

### 示例 1
```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
```

![示例1](https://assets.leetcode.com/uploads/2021/02/19/tree1.jpg)

### 示例 2
```
输入：root = [1]
输出：[[1]]
```

### 示例 3
```
输入：root = []
输出：[]
```

### 提示
- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`

---

## 解题思路（面试推荐 - 最优解）

### 方法一：BFS（队列）

**核心思想：**
- 使用队列进行广度优先搜索（BFS）
- 逐层处理节点，每层的节点放在一个数组中

**为什么用队列？**
```
层序遍历的特点：
- 先访问的节点，其子节点也先访问
- 符合"先进先出"特性 → 使用队列

例如：
      3
     / \
    9  20
      / \
     15  7

访问顺序：
层1：3
层2：9, 20（3的子节点先入队）
层3：15, 7（9和20的子节点）
```

**如何区分层？**
```
关键技巧：记录每层的节点数量

在处理每一层之前，记录当前队列的大小
这个大小就是当前层的节点数

例如：
初始：queue = [3], size = 1（第1层）
处理完第1层后：queue = [9, 20], size = 2（第2层）
处理完第2层后：queue = [15, 7], size = 2（第3层）
```

**算法流程：**
1. 将根节点加入队列
2. 当队列非空时：
   - 记录当前层的节点数levelSize
   - 创建当前层的数组currentLevel
   - 处理levelSize个节点：
     - 弹出节点，加入currentLevel
     - 将子节点加入队列
   - 将currentLevel加入结果
3. 返回结果

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(w) - w是树的最大宽度

---

### 方法二：DFS（递归）

**核心思想：**
- 使用递归，传递当前层数
- 根据层数将节点值放入对应的数组

**为什么DFS也能层序遍历？**
```
关键：传递层数参数

例如：
      3
     / \
    9  20
      / \
     15  7

DFS过程：
dfs(3, level=0) → result[0] = [3]
  dfs(9, level=1) → result[1] = [9]
  dfs(20, level=1) → result[1] = [9, 20]
    dfs(15, level=2) → result[2] = [15]
    dfs(7, level=2) → result[2] = [15, 7]

虽然访问顺序是 3→9→20→15→7（前序）
但按层数分组，结果正确！
```

**算法流程：**
1. 定义辅助函数dfs(node, level)
2. 如果result[level]不存在，创建空数组
3. 将node.val加入result[level]
4. 递归处理左右子树，层数+1

**时间复杂度：** O(n)
**空间复杂度：** O(h) - 递归栈深度

## 代码实现（TypeScript）

### 方法一：BFS（队列）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function levelOrder(root: TreeNode | null): number[][] {
    if (root === null) {
        return [];
    }

    const result: number[][] = [];
    const queue: TreeNode[] = [root];

    while (queue.length > 0) {
        // 当前层的节点数量
        const levelSize = queue.length;
        const currentLevel: number[] = [];

        // 处理当前层的所有节点
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift()!;
            currentLevel.push(node.val);

            // 将下一层的节点加入队列
            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }

        result.push(currentLevel);
    }

    return result;
}
```

### 方法二：DFS（递归）

```typescript
function levelOrder(root: TreeNode | null): number[][] {
    const result: number[][] = [];

    function dfs(node: TreeNode | null, level: number): void {
        if (node === null) {
            return;
        }

        // 如果当前层还没有数组，创建一个
        if (result.length === level) {
            result.push([]);
        }

        // 将当前节点的值加入对应层
        result[level].push(node.val);

        // 递归处理左右子树（层数+1）
        dfs(node.left, level + 1);
        dfs(node.right, level + 1);
    }

    dfs(root, 0);
    return result;
}
```

## 代码原理详解

### BFS方法

```
树结构：
      3
     / \
    9  20
      / \
     15  7

执行过程：

初始：queue = [3], result = []

层1：
  levelSize = 1
  currentLevel = []

  处理节点3：
    currentLevel = [3]
    加入子节点：queue = [9, 20]

  result = [[3]]

层2：
  levelSize = 2
  currentLevel = []

  处理节点9：
    currentLevel = [9]
    无子节点

  处理节点20：
    currentLevel = [9, 20]
    加入子节点：queue = [15, 7]

  result = [[3], [9, 20]]

层3：
  levelSize = 2
  currentLevel = []

  处理节点15：
    currentLevel = [15]
    无子节点

  处理节点7：
    currentLevel = [15, 7]
    无子节点

  result = [[3], [9, 20], [15, 7]]

返回：[[3], [9, 20], [15, 7]]
```

### DFS方法

```
树结构：
      3
     / \
    9  20
      / \
     15  7

执行过程：

dfs(3, 0):
  result[0] = []
  result[0].push(3) → result = [[3]]

  dfs(9, 1):
    result[1] = []
    result[1].push(9) → result = [[3], [9]]
    dfs(null, 2)
    dfs(null, 2)

  dfs(20, 1):
    result[1].push(20) → result = [[3], [9, 20]]

    dfs(15, 2):
      result[2] = []
      result[2].push(15) → result = [[3], [9, 20], [15]]
      dfs(null, 3)
      dfs(null, 3)

    dfs(7, 2):
      result[2].push(7) → result = [[3], [9, 20], [15, 7]]
      dfs(null, 3)
      dfs(null, 3)

返回：[[3], [9, 20], [15, 7]]
```

## 常见问题

**Q1: 如何区分每一层？**
A: 关键是记录当前层的节点数：
```typescript
const levelSize = queue.length;  // 当前层有多少个节点
for (let i = 0; i < levelSize; i++) {
    // 只处理levelSize个节点
}
```

**Q2: BFS和DFS哪个更好？**
A:
- **BFS**：更直观，符合层序遍历的定义，推荐面试使用
- **DFS**：代码简洁，但不够直观

**Q3: 能否从右到左遍历每层？**
A: 可以，调整子节点入队顺序：
```typescript
// 先右后左
if (node.right !== null) queue.push(node.right);
if (node.left !== null) queue.push(node.left);
```

**Q4: 队列的最大长度是多少？**
A: 取决于树的最大宽度：
- 完全二叉树：O(n/2) = O(n)
- 链式树：O(1)

## 复杂度分析

### BFS方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(w)
- w是树的最大宽度
- 完全二叉树：O(n/2) = O(n)
- 链式树：O(1)

### DFS方法

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- h是树的高度（递归栈）
- 平衡树：O(log n)
- 链式树：O(n)

## 总结

**关键点：**
1. BFS用队列，逐层处理
2. 记录每层节点数levelSize区分层
3. DFS传递层数参数也能实现
4. 队列大小 = 树的最大宽度

**面试建议：**
- 优先使用BFS（更直观）
- 解释如何区分每一层
- 画图演示队列变化
- 可以补充DFS方法
- 提及空间复杂度取决于树的形状

**易错点：**
- 忘记记录levelSize导致层混乱
- for循环用queue.length作为终止条件（会变化）
- 空树的处理
- DFS时忘记传递level参数
