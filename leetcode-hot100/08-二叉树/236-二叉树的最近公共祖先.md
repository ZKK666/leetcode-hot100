# 236. 二叉树的最近公共祖先【中等】

## 题目描述

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。"

---

## 输入输出示例

### 示例 1
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。
```

![示例1](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

### 示例 2
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5 。因为根据定义最近公共祖先节点可以为节点本身。
```

### 示例 3
```
输入：root = [1,2], p = 1, q = 2
输出：1
```

### 提示
- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中

## 解题思路（面试推荐 - 最优解）

### 方法：递归

**核心思想：**
- 从底向上查找，利用后序遍历
- 如果左右子树都找到p或q，当前节点就是最近公共祖先

**最近公共祖先的情况：**
```
情况1：p和q分别在当前节点的左右子树
      3
     / \
    5   1
   p在左，q在右 → 3是LCA

情况2：当前节点是p或q，另一个在其子树中
      5
     / \
    6   2
       / \
      7   4
   当前节点5，q在其子树 → 5是LCA

情况3：p和q都在左子树或都在右子树
递归到子树中处理
```

**递归定义：**
```
lowestCommonAncestor(root, p, q)返回：
- 如果root是p或q，返回root
- 如果p和q分别在左右子树，返回root
- 如果p和q都在左子树，返回左子树的结果
- 如果p和q都在右子树，返回右子树的结果
- 如果都没找到，返回null
```

**算法流程：**
1. 如果root为null，返回null
2. 如果root是p或q，返回root
3. 递归查找左右子树
4. 根据左右子树的返回值判断：
   - 都不为null：当前节点是LCA
   - 只有left不为null：LCA在左子树
   - 只有right不为null：LCA在右子树

**时间复杂度：** O(n) - 最坏情况访问所有节点
**空间复杂度：** O(h) - 递归栈深度

## 代码实现（TypeScript）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function lowestCommonAncestor(
    root: TreeNode | null,
    p: TreeNode | null,
    q: TreeNode | null
): TreeNode | null {
    // 递归终止条件
    if (root === null) {
        return null;
    }

    // 如果当前节点是p或q，直接返回
    // （找到目标节点之一）
    if (root === p || root === q) {
        return root;
    }

    // 递归查找左右子树
    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);

    // 后序位置：根据左右子树的返回值判断
    if (left !== null && right !== null) {
        // p和q分别在左右子树，当前节点是LCA
        return root;
    }

    // 返回不为null的那个（或者都为null）
    // 如果left不为null，说明p和q都在左子树
    // 如果right不为null，说明p和q都在右子树
    return left !== null ? left : right;
}
```

## 代码原理详解

### 核心逻辑

**1. 递归终止条件：**
```typescript
if (root === null) return null;
if (root === p || root === q) return root;
```

**2. 递归左右子树：**
```typescript
const left = lowestCommonAncestor(root.left, p, q);
const right = lowestCommonAncestor(root.right, p, q);
```

**3. 后序位置判断：**
```typescript
if (left !== null && right !== null) {
    // p和q分别在左右子树
    return root;
}
return left !== null ? left : right;
```

### 递归过程

```
树结构：
        3
       / \
      5   1
     / \
    6   2

p = 5, q = 2

lowestCommonAncestor(3, 5, 2):
  3 != 5 && 3 != 2

  left = lowestCommonAncestor(5, 5, 2):
    5 == 5，返回5

  right = lowestCommonAncestor(1, 5, 2):
    1 != 5 && 1 != 2

    left = lowestCommonAncestor(null, ...) → null
    right = lowestCommonAncestor(null, ...) → null

    left = null, right = null
    返回 null

  left = 5, right = null
  返回 5

结果：5（节点5本身是LCA）✓
```

```
树结构：
        3
       / \
      5   1

p = 5, q = 1

lowestCommonAncestor(3, 5, 1):
  3 != 5 && 3 != 1

  left = lowestCommonAncestor(5, 5, 1):
    5 == 5，返回5

  right = lowestCommonAncestor(1, 5, 1):
    1 == 1，返回1

  left = 5, right = 1
  left !== null && right !== null
  返回 3 ✓

结果：3（节点3是LCA）✓
```

## 运行示例

### 示例 1：`p = 5, q = 1`

**树结构：**
```
        3
       / \
      5   1
     / \
    6   2
   / \
  7   4
```

**执行过程：**

```
lowestCommonAncestor(3, 5, 1):
  递归左子树(5):
    5 == p，返回5

  递归右子树(1):
    1 == q，返回1

  left = 5, right = 1
  都不为null → 3是LCA

返回：3 ✓
```

---

### 示例 2：`p = 5, q = 4`

**树结构：**
```
        3
       / \
      5   1
     / \
    6   2
       / \
      7   4
```

**执行过程：**

```
lowestCommonAncestor(3, 5, 4):
  递归左子树(5):
    5 == p，返回5
    （不继续递归子树，直接返回）

  递归右子树(1):
    1 != p && 1 != q
    递归左右子树都返回null
    返回null

  left = 5, right = null
  返回5

返回：5 ✓（5是4的祖先，同时也是自己的祖先）
```

**关键点：** 当找到p时直接返回，不继续往下找q，因为q一定在p的子树中。

## 常见问题

**Q1: 为什么找到p或q就直接返回？**
A: 基于题目保证：
- p和q一定存在于树中
- p != q

如果当前节点是p，有两种情况：
1. q在p的子树中 → p是LCA
2. q不在p的子树中 → LCA在p的祖先

无论哪种情况，都应该返回p向上传递。

**Q2: 后序位置的判断逻辑？**
A:
```typescript
if (left && right) return root;  // 情况1
return left || right;             // 情况2和3

情况1：p和q分别在左右子树 → root是LCA
情况2：都在左子树 → 返回left（左子树的LCA）
情况3：都在右子树 → 返回right（右子树的LCA）
```

**Q3: 如果p或q不存在怎么办？**
A: 题目保证存在。如果不保证，需要先遍历确认存在性。

**Q4: 能否用其他方法？**
A: 可以，但不如递归简洁：
```typescript
// 方法2：存储路径后比较
1. 找到root到p的路径
2. 找到root到q的路径
3. 比较路径，找到最后的公共节点

时间：O(n)，空间：O(n)
不如递归方法优雅
```

## 复杂度分析

**时间复杂度：** O(n)
- 最坏情况访问所有节点
- 例如：p和q分别是最左和最右的叶子节点

**空间复杂度：** O(h)
- 递归栈深度 = 树的高度
- 平衡树：O(log n)
- 链式树：O(n)

## 与BST版本的对比

**235. 二叉搜索树的最近公共祖先：**
```typescript
function lowestCommonAncestor(root, p, q) {
    // 利用BST性质：左<根<右
    if (root.val > p.val && root.val > q.val) {
        return lowestCommonAncestor(root.left, p, q);
    }
    if (root.val < p.val && root.val < q.val) {
        return lowestCommonAncestor(root.right, p, q);
    }
    return root;
}

// BST可以根据值判断，不需要遍历整棵树
```

**普通二叉树（本题）：**
- 无法根据值判断方向
- 需要后序遍历判断

## 总结

**关键点：**
1. 后序遍历（左右根）
2. 找到p或q立即返回
3. 根据左右子树返回值判断LCA
4. 一个节点可以是自己的祖先

**面试建议：**
- 先画图说明3种情况
- 强调后序位置的判断逻辑
- 解释为什么找到就返回
- 可以对比BST版本

**易错点：**
- 在前序位置判断（应该后序）
- 找到p后继续递归
- 忘记"节点可以是自己的祖先"
- 递归返回值的理解
