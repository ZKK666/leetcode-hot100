# 124. 二叉树中的最大路径和【困难】

## 题目描述

**路径** 被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。同一个节点在一条路径序列中 **至多出现一次**。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root`，返回其 **最大路径和**。

---

## 输入输出示例

### 示例 1
```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

```
输入：root = [-10,9,20,null,null,15,7]

```

## 解题思路（面试推荐 - 最优解）

### 核心思想

**路径的特点：**
```
路径可以：
1. 从任意节点开始
2. 到任意节点结束
3. 不一定经过根节点
4. 不能重复经过节点（不能走回头路）

关键观察：
对于任意节点，经过它的最大路径 = 左子树贡献 + 节点值 + 右子树贡献
```

**为什么类似"直径"问题？**
```
543. 二叉树的直径：
  经过节点的最长路径 = 左深度 + 右深度

本题：
  经过节点的最大路径和 = 左贡献 + 节点值 + 右贡献

区别：
- 直径：计数边数
- 本题：计算路径和
- 本题可以有负数，需要特殊处理
```

**负数的处理：**
```
如果子树的贡献是负数，可以选择不要

例如：
      10
     /  \
   -5   -5

左右子树都是负数
最大路径和 = 10（只要根节点，不要子树）

所以：贡献 = max(子树路径和, 0)
```

---

### 方法：递归（后序遍历）

**算法流程：**
1. 定义全局变量maxSum存储最大路径和
2. 递归计算每个节点作为路径"拐点"时的最大路径和
3. 每个节点返回：向父节点提供的最大贡献（单侧路径和）

**关键点：**
- **更新全局最大值**：左贡献 + 节点值 + 右贡献
- **返回给父节点**：节点值 + max(左贡献, 右贡献)（只能选一边）

**为什么返回值和更新值不同？**
```
更新maxSum：可以同时使用左右子树（路径的"拐点"）
      10
     /  \
    2    10
   / \
  20  1

maxSum = 20 + 2 + 10 = 32（拐点是2）

返回给父节点：只能选一边（路径不能分叉）
  如果父节点选择节点2，路径必须是一条链
  只能选：max(20+2, 1+2) = 22
```

**时间复杂度：** O(n)
**空间复杂度：** O(h)

## 代码实现（TypeScript）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function maxPathSum(root: TreeNode | null): number {
    let maxSum = -Infinity;  // 全局最大路径和

    /**
     * 计算以node为根的子树能提供的最大路径和贡献
     * 返回：node → 某个叶子节点的最大路径和（单侧）
     */
    function maxGain(node: TreeNode | null): number {
        if (node === null) {
            return 0;
        }

        // 递归计算左右子树的最大贡献
        // 如果贡献为负，选择0（不要该子树）
        const leftGain = Math.max(maxGain(node.left), 0);
        const rightGain = Math.max(maxGain(node.right), 0);

        // 后序位置：更新全局最大路径和
        // 经过当前节点的最大路径 = 左贡献 + 节点值 + 右贡献
        const currentPathSum = node.val + leftGain + rightGain;
        maxSum = Math.max(maxSum, currentPathSum);

        // 返回给父节点的最大贡献（只能选一边）
        return node.val + Math.max(leftGain, rightGain);
    }

    maxGain(root);
    return maxSum;
}
```

## 代码原理详解

### 核心逻辑

**1. 计算子树贡献：**
```typescript
const leftGain = Math.max(maxGain(node.left), 0);
const rightGain = Math.max(maxGain(node.right), 0);

// 与0比较：负数贡献选择放弃
```

**2. 更新全局最大值：**
```typescript
const currentPathSum = node.val + leftGain + rightGain;
maxSum = Math.max(maxSum, currentPathSum);

// 当前节点作为"拐点"的最大路径和
```

**3. 返回单侧贡献：**
```typescript
return node.val + Math.max(leftGain, rightGain);

// 父节点只能选择一边继续延伸路径
```

### 递归过程

```
树结构：
      -10
      /  \
     9   20
        /  \
       15   7

maxGain(-10):
  leftGain = maxGain(9):
    leftGain = 0
    rightGain = 0
    currentPathSum = 9
    maxSum = max(-∞, 9) = 9
    返回 9

  rightGain = maxGain(20):
    leftGain = maxGain(15):
      currentPathSum = 15
      maxSum = max(9, 15) = 15
      返回 15

    rightGain = maxGain(7):
      currentPathSum = 7
      maxSum = max(15, 7) = 15
      返回 7

    currentPathSum = 20 + 15 + 7 = 42
    maxSum = max(15, 42) = 42 ✓

    返回 20 + max(15, 7) = 35

  currentPathSum = -10 + 9 + 35 = 34
  maxSum = max(42, 34) = 42

  返回 -10 + max(9, 35) = 25

最终：maxSum = 42
路径：15 → 20 → 7
```

## 常见问题

**Q1: 为什么要与0比较？**
A: 处理负数贡献：
```
如果子树贡献为负，不如不要

例如：
      10
     /
   -5

左贡献 = -5
max(-5, 0) = 0
路径和 = 10 + 0 = 10（不选左子树）

如果不与0比较：
路径和 = 10 + (-5) = 5（更小）
```

**Q2: 为什么返回值和更新值不同？**
A: 路径的形状限制：
```
更新maxSum：可以是 ∧ 形（拐点）
  left ← node → right

返回给父节点：只能是 | 形（一条链）
  parent
    ↓
  node
    ↓
  child（只能选一边）
```

**Q3: 为什么初始化为-Infinity？**
A: 所有节点值可能都是负数：
```
如果初始化为0：
树：[-3]
正确答案：-3
如果maxSum=0，错误！

所以用-Infinity，保证会被更新
```

**Q4: 与543题（直径）的区别？**
A:
| 特性 | 543.直径 | 124.最大路径和 |
|------|---------|---------------|
| 计算 | 边数 | 节点值之和 |
| 负数 | 无 | 需处理（与0比较） |
| 更新 | left + right | left + val + right |
| 返回 | max(left,right) + 1 | val + max(left,right) |

## 总结

**关键点：**
1. 每个节点可能是路径的"拐点"
2. 负数贡献选择放弃（与0比较）
3. 更新全局最大值：左+根+右
4. 返回单侧贡献：根+max(左,右)

**面试建议：**
- 先说明路径的定义和特点
- 画图演示"拐点"的概念
- 解释为什么要与0比较
- 强调返回值和更新值的区别
- 可以对比543题（直径）

**易错点：**
- 忘记与0比较（负数处理）
- 混淆更新值和返回值
- 初始化maxSum为0（应该-Infinity）
- 在前序位置更新（应该后序）
