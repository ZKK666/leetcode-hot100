# 114. 二叉树展开为链表【中等】

## 题目描述

给你二叉树的根结点 `root`，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`。
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

---

## 输入输出示例

### 示例 1
```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

![示例1](https://assets.leetcode.com/uploads/2021/01/14/flaten.jpg)

### 示例 2
```
输入：root = []
输出：[]
```

### 示例 3
```
输入：root = [0]
输出：[0]
```

### 提示
- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

**进阶**：你可以使用原地算法（O(1) 额外空间）展开这棵树吗？

## 解题思路（面试推荐 - 最优解）

### 核心思想

**展开的规律：**
```
原树：
      1
     / \
    2   5
   / \   \
  3   4   6

先序遍历：1, 2, 3, 4, 5, 6

展开后：
1
 \
  2
   \
    3
     \
      4
       \
        5
         \
          6

规律：
- 所有节点通过right指针连接
- left指针都为null
- 顺序 = 先序遍历顺序
```

---

### 方法一：前序遍历 + 重建（简单但需额外空间）

**核心思想：**
- 前序遍历得到所有节点
- 按顺序重新连接

**算法流程：**
1. 前序遍历存储所有节点
2. 遍历节点数组，依次连接

**时间复杂度：** O(n)
**空间复杂度：** O(n) - 存储所有节点

---

### 方法二：递归（后序位置处理）

**核心思想：**
- 递归展开左右子树
- 将展开后的左子树插入到root和右子树之间

**为什么是后序位置？**
```
后序：先处理子树，再处理当前节点

例如：
      1
     / \
    2   5
   / \   \
  3   4   6

后序处理：
1. 展开左子树：2 → 3 → 4
2. 展开右子树：5 → 6
3. 连接：1 → (2 → 3 → 4) → (5 → 6)
```

**操作步骤：**
```
1. 递归展开左右子树
2. 保存右子树
3. 将左子树移到右边
4. 将原右子树接到左子树末尾
```

**时间复杂度：** O(n)
**空间复杂度：** O(h) - 递归栈

---

### 方法三：前序遍历的迭代展开（原地 O(1)）

**核心思想（Morris遍历思想）：**
- 对于当前节点，找到左子树的最右节点
- 将右子树接到左子树最右节点的右边
- 将左子树移到右边

**为什么这样做？**
```
      1
     / \
    2   5
   / \   \
  3   4   6

处理节点1：
1. 找到左子树（2）的最右节点（4）
2. 将右子树（5）接到4的右边
3. 将左子树（2）移到右边
4. left置为null

结果：
1
 \
  2
 / \
3   4
     \
      5
       \
        6

继续处理节点2、3、4...
```

**算法流程：**
1. 当前节点有左子树时：
   - 找到左子树的最右节点
   - 将右子树接到最右节点
   - 将左子树移到右边
   - left置为null
2. 移动到右子树继续处理

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：前序遍历 + 重建

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

/**
 Do not return anything, modify root in-place instead.
 */
function flatten(root: TreeNode | null): void {
    if (root === null) {
        return;
    }

    // 前序遍历得到所有节点
    const nodes: TreeNode[] = [];

    function preorder(node: TreeNode | null): void {
        if (node === null) return;
        nodes.push(node);
        preorder(node.left);
        preorder(node.right);
    }

    preorder(root);

    // 按顺序连接节点
    for (let i = 0; i < nodes.length - 1; i++) {
        nodes[i].left = null;
        nodes[i].right = nodes[i + 1];
    }

    // 最后一个节点
    nodes[nodes.length - 1].left = null;
    nodes[nodes.length - 1].right = null;
}
```

---

### 方法二：递归

```typescript
function flatten(root: TreeNode | null): void {
    if (root === null) {
        return;
    }

    // 递归展开左右子树
    flatten(root.left);
    flatten(root.right);

    // 后序位置：处理当前节点
    // 1. 保存右子树
    const rightSubtree = root.right;

    // 2. 将左子树移到右边
    root.right = root.left;
    root.left = null;

    // 3. 找到当前右边（原左子树）的最后一个节点
    let curr = root;
    while (curr.right !== null) {
        curr = curr.right;
    }

    // 4. 将原右子树接到末尾
    curr.right = rightSubtree;
}
```

---

### 方法三：迭代（原地 O(1)空间）

```typescript
function flatten(root: TreeNode | null): void {
    let curr = root;

    while (curr !== null) {
        if (curr.left !== null) {
            // 找到左子树的最右节点
            let rightmost = curr.left;
            while (rightmost.right !== null) {
                rightmost = rightmost.right;
            }

            // 将当前节点的右子树接到左子树的最右节点
            rightmost.right = curr.right;

            // 将左子树移到右边
            curr.right = curr.left;
            curr.left = null;
        }

        // 移动到下一个节点（右子树）
        curr = curr.right;
    }
}
```

      左子树 = 3

      2.left = null

      结果：2 → 3 → 4

## 常见问题

**Q1: 为什么递归要在后序位置处理？**
A: 需要先展开子树：
```
如果在前序位置处理：
- 当前节点还没展开子树
- 无法正确连接

后序位置：
- 左右子树已经展开完成
- 可以直接连接
```

**Q2: 迭代方法为什么是O(1)空间？**
A: 只用了几个指针变量，没有递归栈或额外数组。

**Q3: 如何理解迭代方法的正确性？**
A: 关键在于"找左子树最右节点"：
```
      1
     / \
    2   5

前序：1, 2, 5
展开：1 → 2 → 5

操作：
1. 找2的最右（2本身）
2. 将5接到2后面
3. 将2移到1的右边

结果正确：1 → 2 → 5 ✓
```

**Q4: 三种方法哪个最好？**
A:
- **方法一**：简单易懂，但O(n)空间
- **方法二**：代码清晰，O(h)空间
- **方法三**：O(1)空间，最优！推荐面试使用

## 复杂度分析

### 方法一：前序遍历

**时间复杂度：** O(n)
- 遍历一次 + 连接一次

**空间复杂度：** O(n)
- 存储所有节点

### 方法二：递归

**时间复杂度：** O(n)
- 每个节点访问常数次
- 找最右节点：每个节点最多被访问2次

**空间复杂度：** O(h)
- 递归栈深度

### 方法三：迭代

**时间复杂度：** O(n)
- 每个节点作为curr访问一次
- 每个节点作为rightmost访问一次
- 总共：O(2n) = O(n)

**空间复杂度：** O(1)
- 只用指针变量

## 总结

**关键点：**
1. 展开后顺序 = 前序遍历顺序
2. 所有节点left=null，通过right连接
3. 迭代方法：找左子树最右节点，插入右子树
4. O(1)空间的迭代方法最优

**面试建议：**
- 优先讲迭代方法（O(1)空间）
- 画图演示"找最右节点-插入"过程
- 强调原地修改（in-place）
- 可以补充递归方法

**易错点：**
- 忘记设置left=null
- 递归在前序位置处理（应该后序）
- 迭代时丢失右子树引用
- 没有找到真正的最右节点
