# 543. 二叉树的直径【简单】

## 题目描述

给你一棵二叉树的根节点，返回该树的 **直径**。

二叉树的 **直径** 是指树中任意两个节点之间最长路径的 **长度**。这条路径可能经过也可能不经过根节点 `root`。

两节点之间路径的 **长度** 由它们之间边的数目表示。

---

## 输入输出示例

### 示例 1
```
输入：root = [1,2,3,4,5]
输出：3
解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。
```

### 示例 2

- `-100 <= Node.val <= 100`

## 解题思路（面试推荐 - 最优解）

### 方法：递归（DFS）

**核心思想：**
- 直径 = 任意节点的左子树深度 + 右子树深度
- 对每个节点计算经过它的最长路径，取最大值

**为什么不一定经过根节点？**
```
例如：
      1
     /
    2
   / \
  3   4
 /
5

直径是 [5,3,2,4]，长度为3
不经过根节点1
```

**关键观察：**
```
对于任意节点node：
- 经过node的最长路径 = 左子树深度 + 右子树深度
- 整棵树的直径 = 所有节点中，最长路径的最大值

例如：
      1
     / \
    2   3
   / \
  4   5

节点1：左深度2 + 右深度1 = 3 ✓（最大）
节点2：左深度1 + 右深度1 = 2
节点3：左深度0 + 右深度0 = 0
节点4：左深度0 + 右深度0 = 0
节点5：左深度0 + 右深度0 = 0

直径 = 3
```

**算法流程：**
1. 定义全局变量diameter存储最大直径
2. 递归计算每个节点的深度
3. 在计算深度的过程中更新diameter
4. 返回diameter

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(h) - 递归栈深度

## 代码实现（TypeScript）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function diameterOfBinaryTree(root: TreeNode | null): number {
    // 全局变量存储最大直径
    let diameter = 0;

    /**
     * 计算树的深度，同时更新直径
     * 返回：以node为根的树的深度
     */
    function depth(node: TreeNode | null): number {
        if (node === null) {
            return 0;
        }

        // 递归计算左右子树深度
        const leftDepth = depth(node.left);
        const rightDepth = depth(node.right);

        // 更新直径：经过当前节点的最长路径
        diameter = Math.max(diameter, leftDepth + rightDepth);

        // 返回当前节点的深度
        return Math.max(leftDepth, rightDepth) + 1;
    }

    depth(root);
    return diameter;
}
```

## 代码原理详解

### 核心逻辑

1. **深度计算**：
   ```typescript
   depth(node) = max(depth(left), depth(right)) + 1
   ```

2. **直径更新**：
   ```typescript
   // 经过node的路径长度 = 左子树深度 + 右子树深度
   diameter = max(diameter, leftDepth + rightDepth)
   ```

3. **为什么在递归中更新直径？**
   ```
   需要对每个节点都计算经过它的最长路径
   在计算深度的过程中顺便更新，一次遍历完成
   ```

### 递归过程

```
树结构：
      1
     / \
    2   3
   / \
  4   5

递归调用：

depth(1):
  leftDepth = depth(2):
    leftDepth = depth(4):
      leftDepth = depth(null) = 0
      rightDepth = depth(null) = 0
      diameter = max(0, 0+0) = 0
      return 1

    rightDepth = depth(5):
      leftDepth = depth(null) = 0
      rightDepth = depth(null) = 0
      diameter = max(0, 0+0) = 0
      return 1

    diameter = max(0, 1+1) = 2
    return 2

  rightDepth = depth(3):
    leftDepth = depth(null) = 0
    rightDepth = depth(null) = 0
    diameter = max(2, 0+0) = 2
    return 1

  diameter = max(2, 2+1) = 3 ✓
  return 3

返回：diameter = 3
```

## 常见问题

**Q1: 直径和深度有什么区别？**
A:
```
深度（Depth）：从根到某节点的边数
直径（Diameter）：树中任意两节点间的最长路径长度

例如：
      1
     / \
    2   3

深度（节点2）：1
直径：2（路径[2,1,3]）
```

**Q2: 为什么直径 = 左深度 + 右深度？**
A: 经过某节点的最长路径：
```
      node
      /  \
   left  right

最长路径：从左子树最深处 → node → 右子树最深处
路径长度 = 左子树深度 + 右子树深度
```

**Q3: 为什么不能直接返回 depth(root.left) + depth(root.right)？**
A: 因为最长路径可能不经过根节点：
```
      1
     /
    2
   / \
  3   4
 /
5

直接计算根节点：depth(left) + depth(right) = 3 + 0 = 3 ✓

但如果是：
      1
       \
        2
       / \
      3   4
     /
    5

直接计算根节点：0 + 3 = 3
但实际最大直径在节点2：2 + 1 = 3

需要检查所有节点！
```

**Q4: 全局变量diameter是否会有问题？**
A: 在TypeScript/JavaScript中，闭包变量是安全的。每次调用diameterOfBinaryTree都会创建新的diameter变量。

## 复杂度分析

### 时间复杂度：O(n)
- 每个节点访问一次
- 每次访问做常数时间操作

### 空间复杂度：O(h)
- 递归栈深度 = 树的高度
- 平衡树：O(log n)
- 链式树：O(n)

## 总结

**关键点：**
1. 直径 = 经过某节点的左深度 + 右深度
2. 需要检查所有节点，找最大值
3. 在计算深度的过程中同时更新直径
4. 一次遍历完成，O(n)时间

**面试建议：**
- 解释直径的定义（任意两节点间最长路径）
- 强调可能不经过根节点
- 说明为什么是左深度+右深度
- 画图演示递归过程

**易错点：**
- 忘记更新全局变量diameter
- 混淆深度和直径
- 认为一定经过根节点
- 边界情况（单节点、空树）
