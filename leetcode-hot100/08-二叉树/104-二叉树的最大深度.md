# 104. 二叉树的最大深度【简单】

## 题目描述

给定一个二叉树 `root`，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

---

## 输入输出示例

### 示例 1
```
输入：root = [3,9,20,null,null,15,7]
输出：3
```

### 示例 2

- `-100 <= Node.val <= 100`

## 解题思路（面试推荐 - 最优解）

### 方法一：递归（DFS）

**核心思想：**
- 树的深度 = max(左子树深度, 右子树深度) + 1
- 递归定义：depth(root) = max(depth(left), depth(right)) + 1

**为什么加1？**
```
深度包括当前节点本身

例如：
      3
     / \
    9  20

左子树深度：1（只有节点9）
右子树深度：1（只有节点20）
整棵树深度：max(1,1) + 1 = 2
```

**算法流程：**
1. 如果节点为空，深度为0
2. 递归计算左子树深度
3. 递归计算右子树深度
4. 返回max(左深度, 右深度) + 1

**时间复杂度：** O(n) - 每个节点访问一次
**空间复杂度：** O(h) - h是树的高度，递归栈深度

---

### 方法二：迭代（BFS层序遍历）

**核心思想：**
- 使用层序遍历（BFS）
- 每遍历一层，深度+1

**为什么用队列？**
```
层序遍历需要先进先出
队列正好满足这个特性

例如：
      3
     / \
    9  20
      / \
     15  7

层1：[3] → depth=1
层2：[9,20] → depth=2
层3：[15,7] → depth=3
```

**算法流程：**
1. 使用队列存储每一层的节点
2. 逐层处理，每处理完一层，深度+1
3. 返回深度

**时间复杂度：** O(n)
**空间复杂度：** O(w) - w是树的最大宽度

## 代码实现（TypeScript）

### 方法一：递归（DFS）

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function maxDepth(root: TreeNode | null): number {
    // 递归终止条件：空节点深度为0
    if (root === null) {
        return 0;
    }

    // 递归计算左右子树的深度
    const leftDepth = maxDepth(root.left);
    const rightDepth = maxDepth(root.right);

    // 返回较大的深度 + 1（当前节点）
    return Math.max(leftDepth, rightDepth) + 1;
}
```

**简洁写法：**
```typescript
function maxDepth(root: TreeNode | null): number {
    return root === null ? 0 : Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
}
```

### 方法二：迭代（BFS）

```typescript
function maxDepth(root: TreeNode | null): number {
    if (root === null) {
        return 0;
    }

    // 使用队列进行层序遍历
    const queue: TreeNode[] = [root];
    let depth = 0;

    while (queue.length > 0) {
        // 当前层的节点数量
        const levelSize = queue.length;

        // 处理当前层的所有节点
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift()!;

            // 将下一层的节点加入队列
            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }

        // 处理完一层，深度+1
        depth++;
    }

    return depth;
}
```

---

### 方法三：迭代（DFS用栈）

```typescript
function maxDepth(root: TreeNode | null): number {
    if (root === null) {
        return 0;
    }

    // 栈存储（节点，深度）对
    const stack: [TreeNode, number][] = [[root, 1]];
    let maxDepth = 0;

    while (stack.length > 0) {
        const [node, depth] = stack.pop()!;

        // 更新最大深度
        maxDepth = Math.max(maxDepth, depth);

        // 将子节点加入栈（深度+1）
        if (node.left !== null) {
            stack.push([node.left, depth + 1]);
        }
        if (node.right !== null) {
            stack.push([node.right, depth + 1]);
        }
    }

    return maxDepth;
}
```

## 代码原理详解

### 递归方法（DFS）

```
树结构：
      3
     / \
    9  20
      / \
     15  7

递归调用：
maxDepth(3):
  leftDepth = maxDepth(9):
    leftDepth = maxDepth(null) = 0
    rightDepth = maxDepth(null) = 0
    return max(0, 0) + 1 = 1

  rightDepth = maxDepth(20):
    leftDepth = maxDepth(15):
      leftDepth = 0
      rightDepth = 0
      return 1
    rightDepth = maxDepth(7):
      leftDepth = 0
      rightDepth = 0
      return 1
    return max(1, 1) + 1 = 2

  return max(1, 2) + 1 = 3
```

### 迭代方法（BFS）

```
树结构：
      3
     / \
    9  20
      / \
     15  7

执行过程：
初始：queue=[3], depth=0

层1：
  levelSize=1
  处理3：加入9和20
  queue=[9,20]
  depth=1

层2：
  levelSize=2
  处理9：无子节点
  处理20：加入15和7
  queue=[15,7]
  depth=2

层3：
  levelSize=2
  处理15：无子节点
  处理7：无子节点
  queue=[]
  depth=3

返回：3
```

## 常见问题

**Q1: 深度和高度有什么区别？**
A:
```
深度（Depth）：从根到节点的路径长度
高度（Height）：从节点到最深叶子的路径长度

对于根节点：
- 深度 = 0（到自己的距离）
- 高度 = 树的最大深度 - 1

本题求的"最大深度"实际上是：
- 节点数 = 高度 + 1
```

**Q2: 递归和迭代哪个更好？**
A:
- **递归**：代码简洁，易理解，推荐面试使用
- **BFS迭代**：适合需要按层处理的场景
- **DFS迭代**：可以避免递归栈溢出

**Q3: 空间复杂度的区别？**
A:
```
递归（DFS）：O(h) - 递归栈深度 = 树高
BFS：O(w) - 队列最大宽度 = 树的最大宽度
DFS栈：O(h) - 显式栈深度 = 树高

完全二叉树：h = log n, w = n/2
链式树：h = n, w = 1

所以BFS在平衡树时空间更大
```

**Q4: 如何求最小深度？**
A: 改为求min，但需要注意：
```typescript
function minDepth(root: TreeNode | null): number {
    if (root === null) return 0;

    // 如果只有一个子树，不能算叶子
    if (root.left === null) return minDepth(root.right) + 1;
    if (root.right === null) return minDepth(root.left) + 1;

    return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
}
```

## 复杂度分析

### 递归方法（DFS）

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(h)
- 递归栈深度 = 树的高度
- 平衡树：O(log n)
- 链式树：O(n)

### 迭代方法（BFS）

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(w)
- 队列最大元素数 = 树的最大宽度
- 完全二叉树：O(n/2) = O(n)
- 链式树：O(1)

## 总结

**关键点：**
1. 递归定义：depth = max(left_depth, right_depth) + 1
2. DFS（递归/栈）：深度优先搜索
3. BFS（队列）：广度优先搜索，按层遍历
4. 空间复杂度取决于树的形状

**面试建议：**
- 优先写递归（最简洁）
- 说明DFS和BFS的区别
- 分析空间复杂度（平衡树vs链式树）
- 可以对比最小深度问题

**易错点：**
- 忘记+1（当前节点）
- 空节点的处理
- 最小深度时单子树的处理
