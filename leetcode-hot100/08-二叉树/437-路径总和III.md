# 437. 路径总和 III【中等】

## 题目描述

给定一个二叉树的根节点 `root`，和一个整数 `targetSum`，求该二叉树里节点值之和等于 `targetSum` 的 **路径** 的数目。

**路径** 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

---

### 示例 1
```
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条，如图所示。
```

```

输出：3
```

- 二叉树的节点个数的范围是 `[0, 1000]`
- `-10^9 <= Node.val <= 10^9`
- `-1000 <= targetSum <= 1000`

## 解题思路（面试推荐 - 最优解）

### 方法一：双重递归（暴力但清晰）

**核心思想：**
- 对每个节点，计算从该节点开始的路径数
- 递归遍历所有节点

**算法流程：**
1. 主递归：遍历每个节点
2. 辅助递归：从当前节点开始，计算有多少条路径和为targetSum

**为什么是双重递归？**
```
外层递归：遍历所有节点作为路径起点
内层递归：从起点开始向下搜索路径

      10
     /  \
    5   -3
   / \    \
  3   2   11
 / \   \
3  -2   1

路径可以从任意节点开始：
- 从10开始的路径
- 从5开始的路径
- 从-3开始的路径
- ...
```

**时间复杂度：** O(n²) - 最坏情况（链式树）
**空间复杂度：** O(h) - 递归栈深度

---

### 方法二：前缀和 + 哈希表（最优）

**核心思想：**
- 使用前缀和思想：路径和 = 当前前缀和 - 之前某个前缀和
- 用哈希表记录前缀和出现的次数

**前缀和的定义：**
```
从根到当前节点的路径和

例如：
      10
     /
    5
   /
  3

路径和：
节点10：10
节点5：10 + 5 = 15
节点3：10 + 5 + 3 = 18
```

**如何找到和为targetSum的路径？**
```
当前前缀和 = currSum
目标和 = targetSum

如果存在前缀和 = currSum - targetSum
说明两个前缀和之间的路径和 = targetSum

例如：targetSum = 8
      10
     /
    5
   /
  3

节点3的前缀和：18
需要找：18 - 8 = 10
存在前缀和10（节点10）
所以路径 5→3 的和是8 ✓
```

**算法流程：**
1. 维护哈希表：前缀和 → 出现次数
2. DFS遍历：
   - 更新当前前缀和
   - 查找是否存在 currSum - targetSum
   - 将当前前缀和加入哈希表
   - 递归左右子树
   - 回溯：移除当前前缀和

**时间复杂度：** O(n)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：双重递归

```typescript
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

function pathSum(root: TreeNode | null, targetSum: number): number {
    if (root === null) {
        return 0;
    }

    // 从当前节点开始的路径数 + 左子树的路径数 + 右子树的路径数
    return (
        countPaths(root, targetSum) +
        pathSum(root.left, targetSum) +
        pathSum(root.right, targetSum)
    );
}

/**
 * 从node节点开始，向下搜索和为targetSum的路径数
 */
function countPaths(node: TreeNode | null, targetSum: number): number {
    if (node === null) {
        return 0;
    }

    let count = 0;

    // 当前节点值等于目标和
    if (node.val === targetSum) {
        count++;
    }

    // 继续向左右子树搜索（目标和减去当前节点值）
    count += countPaths(node.left, targetSum - node.val);
    count += countPaths(node.right, targetSum - node.val);

    return count;
}
```

### 方法二：前缀和 + 哈希表（推荐）

```typescript
function pathSum(root: TreeNode | null, targetSum: number): number {
    // 哈希表：前缀和 → 出现次数
    const prefixSumCount = new Map<number, number>();

    // 初始化：前缀和0出现1次（表示从根开始的路径）
    prefixSumCount.set(0, 1);

    function dfs(node: TreeNode | null, currSum: number): number {
        if (node === null) {
            return 0;
        }

        // 更新当前前缀和
        currSum += node.val;

        // 查找是否存在前缀和 = currSum - targetSum
        // 如果存在，说明有路径和为targetSum
        let count = prefixSumCount.get(currSum - targetSum) || 0;

        // 将当前前缀和加入哈希表
        prefixSumCount.set(currSum, (prefixSumCount.get(currSum) || 0) + 1);

        // 递归左右子树
        count += dfs(node.left, currSum);
        count += dfs(node.right, currSum);

        // 回溯：移除当前前缀和（返回父节点时，当前路径不再有效）
        prefixSumCount.set(currSum, prefixSumCount.get(currSum)! - 1);

        return count;
    }

    return dfs(root, 0);
}
```

## 代码原理详解

### 方法一：双重递归

```
树结构：
      10
     /  \
    5   -3
   / \    \
  3   2   11

targetSum = 8

pathSum(10, 8):
  countPaths(10, 8) = 1 (10→5→-2→-5)
  + pathSum(5, 8) = 2 (5→3, 5→2→1)
  + pathSum(-3, 8) = 0

总计：3条路径
```

### 方法二：前缀和

```
树结构：
      10
     /
    5
   /
  3

targetSum = 8
prefixSumCount = {0: 1}

dfs(10, 0):
  currSum = 0 + 10 = 10

  查找：10 - 8 = 2
  不存在，count = 0

  加入：{0:1, 10:1}

  dfs(5, 10):
    currSum = 10 + 5 = 15

    查找：15 - 8 = 7
    不存在，count = 0

    加入：{0:1, 10:1, 15:1}

    dfs(3, 15):
      currSum = 15 + 3 = 18

      查找：18 - 8 = 10
      存在！count = 1 ✓（路径 5→3）

      加入：{0:1, 10:1, 15:1, 18:1}

      dfs(null, 18): 返回0
      dfs(null, 18): 返回0

      回溯：{0:1, 10:1, 15:1}
      返回：1

    回溯：{0:1, 10:1}
    返回：1

  回溯：{0:1}
  返回：1
```

### 示例：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8`

**树结构：**
```
        10
       /  \
      5   -3
     / \    \
    3   2   11
   / \   \
  3  -2   1
```

**三条和为8的路径：**
```
路径1：5 → 3
路径2：5 → 2 → 1

```

**前缀和方法执行：**
```
遍历到节点3（5的左子节点）：

  路径：5→3 ✓

遍历到节点1（2的右子节点）：
  currSum = 10 + 5 + 2 + 1 = 18
  查找：18 - 8 = 10
  找到前缀和10
  路径：5→2→1 ✓

遍历到节点11：
  currSum = 10 + (-3) + 11 = 18
  查找：18 - 8 = 10
  找到前缀和10
  路径：-3→11 ✓

总计：3条路径 ✓
```

## 常见问题

**Q1: 为什么初始化 prefixSumCount.set(0, 1)？**
A: 表示从根节点开始的路径：
```
如果从根到某节点的路径和 = targetSum
则 currSum - targetSum = 0

需要提前将0加入哈希表
```

**Q2: 为什么需要回溯？**
A: 避免不同路径的前缀和相互干扰：
```
      1
     / \
    2   3

处理完左子树后，回溯移除左子树的前缀和
否则会影响右子树的计算
```

**Q3: 双重递归为什么是O(n²)？**
A: 最坏情况（链式树）：
```
1
 \
  2
   \
    3
     \
      ...

每个节点都要向下搜索到底
1搜索n次，2搜索n-1次...
总计：n + (n-1) + ... + 1 = O(n²)
```

**Q4: 两种方法哪个更好？**
A:
- **双重递归**：清晰易懂，适合面试讲解
- **前缀和**：O(n)最优，但需要理解前缀和思想

面试建议：先说双重递归，再优化到前缀和。

## 复杂度分析

### 方法一：双重递归

**时间复杂度：** O(n²)
- 外层递归：O(n)
- 内层递归：每个节点最坏O(n)
- 总计：O(n²)

**空间复杂度：** O(h)
- 递归栈深度

### 方法二：前缀和

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：** O(n)
- 哈希表：O(n)
- 递归栈：O(h)
- 总计：O(n)

## 总结

**关键点：**
1. 路径可以从任意节点开始
2. 双重递归：遍历所有起点+向下搜索
3. 前缀和优化：用哈希表记录前缀和
4. 回溯：处理完子树后移除前缀和

**面试建议：**

- 忘记初始化prefixSumCount.set(0, 1)
- 忘记回溯（移除前缀和）
- 混淆从根开始和从任意节点开始
- 负数节点的处理
