# 240. 搜索二维矩阵 II【中等】

## 题目描述

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

---

## 输入输出示例

### 示例 1
```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true
```

### 示例 2
```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
输出：false
```

### 提示
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- `-10^9 <= target <= 10^9`

## 解题思路（面试推荐 - 最优解）

### 方法：从右上角或左下角开始搜索

**核心思想：**
- 从右上角（或左下角）开始
- 利用矩阵的有序性，每次可以排除一行或一列
- 如果当前值 > target，向左移动（排除当前列）
- 如果当前值 < target，向下移动（排除当前行）
- 如果相等，找到目标

**为什么从右上角？**
```
右上角元素的特点:
- 是当前行的最大值
- 是当前列的最小值

如果 matrix[row][col] > target:
  target一定不在当前列（当前列最小值都大于target）
  col--，向左移动

如果 matrix[row][col] < target:
  target一定不在当前行（当前行最大值都小于target）
  row++，向下移动
```

**为什么不从左上角或右下角？**
```
左上角：是行列的最小值，无法确定方向
右下角：是行列的最大值，无法确定方向

只有右上角和左下角可以确定唯一方向
```

**时间复杂度：** O(m + n) - 最多走m+n步
**空间复杂度：** O(1) - 只用常数个变量

---

## 代码实现（TypeScript）

```typescript
function searchMatrix(matrix: number[][], target: number): boolean {
    // 边界情况
    if (matrix.length === 0 || matrix[0].length === 0) {
        return false;
    }

    const m = matrix.length;
    const n = matrix[0].length;

    // 从右上角开始
    let row = 0;
    let col = n - 1;

    while (row < m && col >= 0) {
        const current = matrix[row][col];

        if (current === target) {
            // 找到目标
            return true;
        } else if (current > target) {
            // 当前值太大，向左移动（排除当前列）
            col--;
        } else {
            // 当前值太小，向下移动（排除当前行）
            row++;
        }
    }

    // 遍历完没找到
    return false;
}
```

**从左下角开始的版本：**

```typescript

            return true;

            row--;
        } else {
            // 当前值太小，向右移动（排除当前列）
            col++;
        }
    }

    return false;
}
```

## 代码原理详解

### 核心逻辑

1. **起点选择**：
   - 右上角：`(0, n-1)`
   - 左下角：`(m-1, 0)`

2. **移动规则（右上角）**：
   - `current > target`：`col--`（左移）
   - `current < target`：`row++`（下移）
   - `current == target`：返回true

3. **终止条件**：
   - `row >= m` 或 `col < 0`：越界，未找到

4. **为什么能保证不遗漏？**
   - 每次移动都排除了一整行或一整列
   - 被排除的部分一定不包含target
   - 最终要么找到，要么遍历完所有可能

### 设计思路

- **利用有序性**：每次排除一行或一列
- **贪心选择**：从特殊位置开始，确定唯一方向
- **线性时间**：最多m+n步

## 常见问题

**Q1: 为什么时间复杂度是 O(m+n)？**
A: 每一步要么row增加，要么col减少。row最多增加m次，col最多减少n次，总共最多m+n步。

**Q2: 能否用二分查找？**
A: 可以对每一行二分查找，但时间复杂度是O(m log n)，不如O(m+n)优。

**Q3: 从右上角和左下角哪个更好？**
A: 效果一样，都是O(m+n)。习惯上用右上角。

**Q4: 如果矩阵不满足列有序，只有行有序呢？**
A: 只能对每一行二分查找，O(m log n)。

## 其他解法（了解）

### 方法二：每行二分查找

```typescript
function searchMatrix(matrix: number[][], target: number): boolean {
    for (const row of matrix) {
        if (binarySearch(row, target)) {
            return true;
        }
    }
    return false;
}

function binarySearch(arr: number[], target: number): boolean {
    let left = 0, right = arr.length - 1;
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        if (arr[mid] === target) return true;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return false;
}
```

**时间复杂度**：O(m log n)
**适用场景**：矩阵只有行有序，列无序

### 方法三：分治法

```typescript
function searchMatrix(matrix: number[][], target: number): boolean {
    return search(matrix, target, 0, 0, matrix.length - 1, matrix[0].length - 1);
}

function search(
    matrix: number[][],
    target: number,
    top: number,
    left: number,
    bottom: number,
    right: number
): boolean {
    if (top > bottom || left > right) return false;

    const midRow = Math.floor((top + bottom) / 2);
    const midCol = Math.floor((left + right) / 2);

    if (matrix[midRow][midCol] === target) {
        return true;
    } else if (matrix[midRow][midCol] > target) {
        // 搜索左上、右上、左下三个区域
        return search(matrix, target, top, left, midRow - 1, right) ||
               search(matrix, target, midRow, left, bottom, midCol - 1);
    } else {
        // 搜索右下、左下、右上三个区域
        return search(matrix, target, midRow + 1, left, bottom, right) ||
               search(matrix, target, top, midCol + 1, midRow, right);
    }
}
```

**时间复杂度**：O(n^1.58) - 比O(m+n)慢
**不推荐**：代码复杂，性能不佳
