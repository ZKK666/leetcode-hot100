# 48. 旋转图像【中等】

## 题目描述

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

---

## 输入输出示例

### 示例 1
```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

### 示例 2
```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

![示例2](https://assets.leetcode.com/uploads/2020/08/28/mat2.jpg)

### 提示
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 解题思路（面试推荐 - 最优解）

### 方法：先转置，再反转每一行

**核心思想：**
- 顺时针旋转90度 = 转置 + 反转每一行
- 转置：`matrix[i][j]` 与 `matrix[j][i]` 交换
- 反转：每一行逆序

**数学原理：**
```
原矩阵:
[a, b, c]
[d, e, f]
[g, h, i]

转置后（沿主对角线翻转）:
[a, d, g]
[b, e, h]
[c, f, i]

反转每一行:
[g, d, a]
[h, e, b]
[i, f, c]

这就是顺时针旋转90度的结果！
```

**验证：**
```
位置 (0,2) 的元素 c
转置后在 (2,0)
反转后在 (2,2) ✓

位置 (i,j) 的元素
旋转90度后应在 (j, n-1-i)

转置: (i,j) → (j,i)
反转: (j,i) → (j, n-1-i) ✓
```

**时间复杂度：** O(n²) - 遍历所有元素
**空间复杂度：** O(1) - 原地操作

## 代码实现（TypeScript）

```typescript
/**
 Do not return anything, modify matrix in-place instead.
 */
function rotate(matrix: number[][]): void {
    const n = matrix.length;

    // 第一步：转置矩阵（沿主对角线翻转）
    // 只需遍历上三角（不包括对角线）
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            // 交换 matrix[i][j] 和 matrix[j][i]
            [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
        }
    }

    // 第二步：反转每一行
    for (let i = 0; i < n; i++) {
        // 双指针反转第i行
        let left = 0;
        let right = n - 1;
        while (left < right) {
            [matrix[i][left], matrix[i][right]] = [matrix[i][right], matrix[i][left]];
            left++;
            right--;
        }
    }
}
```

## 代码原理详解

### 核心逻辑

1. **转置矩阵**：
   - 遍历上三角区域（j > i）
   - 交换 `matrix[i][j]` 和 `matrix[j][i]`
   - 主对角线元素不需要交换

2. **反转每一行**：
   - 对每一行使用双指针
   - 交换 `matrix[i][left]` 和 `matrix[i][right]`

3. **为什么j从i+1开始？**
   - 避免重复交换
   - 主对角线元素与自己交换无意义
   - 只处理上三角即可

### 设计思路

- **分解问题**：将旋转分解为两个简单操作
- **原地操作**：两步都是原地进行
- **数学变换**：利用矩阵变换的性质

## 常见问题

**Q1: 为什么是先转置再反转，而不是先反转再转置？**
A:
- 先转置再反转 = 顺时针90度
- 先反转再转置 = 逆时针90度

**Q2: 能否直接一次遍历完成？**
A: 可以，但需要四元素循环交换，代码更复杂：
```typescript
function rotate(matrix: number[][]): void {
    const n = matrix.length;
    for (let i = 0; i < n / 2; i++) {
        for (let j = i; j < n - 1 - i; j++) {
            const temp = matrix[i][j];
            matrix[i][j] = matrix[n-1-j][i];
            matrix[n-1-j][i] = matrix[n-1-i][n-1-j];
            matrix[n-1-i][n-1-j] = matrix[j][n-1-i];
            matrix[j][n-1-i] = temp;
        }
    }
}
```

**Q3: 如何逆时针旋转90度？**
A: 先反转每一行，再转置：
```typescript
function rotateCounterClockwise(matrix: number[][]): void {
    const n = matrix.length;

    // 先反转每一行
    for (let i = 0; i < n; i++) {
        matrix[i].reverse();
    }

    // 再转置
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
        }
    }
}
```

**Q4: 如何旋转180度？**
A: 两次旋转90度，或直接上下翻转+左右翻转：
```typescript
// 方法1: 两次90度
rotate(matrix);
rotate(matrix);

// 方法2: 上下翻转+左右翻转
matrix.reverse();
for (let i = 0; i < n; i++) {
    matrix[i].reverse();
}
```

## 位置变换公式

### 顺时针90度

```
(i, j) → (j, n-1-i)

验证:
(0,0) → (0,2)  左上 → 右上 ✓
(0,2) → (2,2)  右上 → 右下 ✓
(2,2) → (2,0)  右下 → 左下 ✓
(2,0) → (0,0)  左下 → 左上 ✓
```

### 其他旋转

```
逆时针90度: (i, j) → (n-1-j, i)
旋转180度:  (i, j) → (n-1-i, n-1-j)
旋转270度:  (i, j) → (j, n-1-i) 再做两次
```
