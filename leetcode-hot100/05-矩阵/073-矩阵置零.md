# 73. 矩阵置零【中等】

## 题目描述

给定一个 `m x n` 的矩阵，如果一个元素为 **0**，则将其所在行和列的所有元素都设为 **0**。请使用 **原地** 算法。

---

## 输入输出示例

### 示例 1
```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

![示例1](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

### 示例 2
```
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

![示例2](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

### 提示
- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

**进阶：**
- 一个直观的解决方案是使用 O(mn) 的额外空间，但这并不是一个好的解决方案。
- 一个简单的改进方案是使用 O(m + n) 的额外空间，但这仍然不是最好的解决方案。
- 你能想出一个仅使用常数空间的解决方案吗？

---

## 解题思路（面试推荐 - 最优解）

### 方法：使用第一行和第一列作为标记

**核心思想：**
- 用矩阵的第一行和第一列来记录哪些行和列需要置零
- 需要额外两个变量记录第一行和第一列本身是否需要置零
- 分三步进行：
  1. 检查第一行和第一列是否有0，记录结果
  2. 遍历其余元素，如果是0，标记对应的第一行和第一列
  3. 根据标记，置零相应的行和列，最后处理第一行和第一列

**为什么这样做？**
```
不能直接置零，因为会影响后续判断

例如：
[1, 0, 1]
[1, 1, 1]

如果直接把第一列置零：
[0, 0, 1]
[0, 1, 1]

那么第二行会误认为需要置零（看到第一列是0）
```

**时间复杂度：** O(m × n) - 遍历所有元素
**空间复杂度：** O(1) - 只使用两个变量

## 代码实现（TypeScript）

```typescript
/**
 Do not return anything, modify matrix in-place instead.
 */
function setZeroes(matrix: number[][]): void {
    const m = matrix.length;
    const n = matrix[0].length;

    // 标记第一行和第一列本身是否需要置零
    let firstRowHasZero = false;
    let firstColHasZero = false;

    // 第一步：检查第一行是否有0
    for (let j = 0; j < n; j++) {
        if (matrix[0][j] === 0) {
            firstRowHasZero = true;
            break;
        }
    }

    // 检查第一列是否有0
    for (let i = 0; i < m; i++) {
        if (matrix[i][0] === 0) {
            firstColHasZero = true;
            break;
        }
    }

    // 第二步：遍历其余元素，用第一行和第一列做标记
    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {
            if (matrix[i][j] === 0) {
                // 标记该行和该列需要置零
                matrix[i][0] = 0;  // 在第一列标记行
                matrix[0][j] = 0;  // 在第一行标记列
            }
        }
    }

    // 第三步：根据标记置零（不包括第一行和第一列）
    for (let i = 1; i < m; i++) {
        for (let j = 1; j < n; j++) {
            if (matrix[i][0] === 0 || matrix[0][j] === 0) {
                matrix[i][j] = 0;
            }
        }
    }

    // 第四步：处理第一行
    if (firstRowHasZero) {
        for (let j = 0; j < n; j++) {
            matrix[0][j] = 0;
        }
    }

    // 处理第一列
    if (firstColHasZero) {
        for (let i = 0; i < m; i++) {
            matrix[i][0] = 0;
        }
    }
}
```

---

## 代码原理详解

### 核心逻辑

1. **标记变量**：
   - `firstRowHasZero`：第一行是否需要置零
   - `firstColHasZero`：第一列是否需要置零

2. **标记位置**：
   - `matrix[i][0]`：标记第 i 行是否需要置零
   - `matrix[0][j]`：标记第 j 列是否需要置零

3. **处理顺序**：
   - 先处理第一行和第一列的标记
   - 再处理其余元素的标记
   - 根据标记置零
   - 最后处理第一行和第一列本身

4. **为什么要分开处理第一行和第一列？**
   - 因为它们既是数据，又是标记
   - 必须先记录它们自己的状态，再用它们标记其他元素

### 设计思路

- **空间复用**：利用矩阵本身存储标记信息
- **分步处理**：避免标记和数据混淆
- **常数空间**：只用两个额外变量

## 运行示例

### 示例 1：`matrix = [[1,1,1],[1,0,1],[1,1,1]]`

**执行过程：**

```
原始矩阵:
[1, 1, 1]
[1, 0, 1]
[1, 1, 1]

第一步：检查第一行和第一列
  第一行: [1,1,1] → 无0 → firstRowHasZero = false
  第一列: [1,1,1] → 无0 → firstColHasZero = false

第二步：遍历其余元素(i,j从1开始)
  i=1, j=1: matrix[1][1]=0
    标记: matrix[1][0]=0, matrix[0][1]=0

矩阵状态(标记后):
[1, 0, 1]   ← 第0列被标记
[0, 0, 1]   ← 第0行被标记
[1, 1, 1]

第三步：根据标记置零(i,j从1开始)
  i=1, j=1: matrix[1][0]=0 或 matrix[0][1]=0? 是 → matrix[1][1]=0
  i=1, j=2: matrix[1][0]=0 或 matrix[0][2]=0? 是 → matrix[1][2]=0
  i=2, j=1: matrix[2][0]=0 或 matrix[0][1]=0? 是 → matrix[2][1]=0
  i=2, j=2: matrix[2][0]=0 或 matrix[0][2]=0? 否 → 不变

矩阵状态:
[1, 0, 1]
[0, 0, 0]
[1, 0, 1]

第四步：处理第一行和第一列
  firstRowHasZero = false → 第一行不变
  firstColHasZero = false → 第一列不变

最终结果:
[1, 0, 1]
[0, 0, 0]
[1, 0, 1] ✓
```

  [0, 0, 0, 0]
  [0, 4, 5, 0]

## 常见问题

**Q1: 为什么要先检查第一行和第一列？**
A: 因为我们要用第一行和第一列作为标记，必须先保存它们自己的状态，否则会被覆盖。

**Q2: 为什么从 i=1, j=1 开始遍历？**
A: 因为第一行和第一列用来做标记，我们需要先处理其他元素，再根据标记更新矩阵。

**Q3: 能否只用一个变量？**
A: 不能。需要分别记录第一行和第一列的状态。

**Q4: 如果允许 O(m+n) 空间，有更简单的方法吗？**
A: 有，用两个数组分别记录哪些行和列需要置零：
```typescript
function setZeroes(matrix: number[][]): void {
    const m = matrix.length;
    const n = matrix[0].length;
    const rows = new Array(m).fill(false);
    const cols = new Array(n).fill(false);

    // 标记
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (matrix[i][j] === 0) {
                rows[i] = true;
                cols[j] = true;
            }
        }
    }

    // 置零
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (rows[i] || cols[j]) {
                matrix[i][j] = 0;
            }
        }
    }
}
```
