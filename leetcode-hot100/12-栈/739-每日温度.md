# 739. 每日温度【中等】

## 题目描述

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

---

## 输入输出示例

### 示例 1
```
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,2,4,2,1,1,0,0]

解释:
- 第0天：73°，第1天74°更高 → 等待1天
- 第1天：74°，第2天75°更高 → 等待2天
- 第2天：75°，第6天76°更高 → 等待4天
- 第3天：71°，第5天72°更高 → 等待2天
- 第4天：69°，第5天72°更高 → 等待1天
- 第5天：72°，第6天76°更高 → 等待1天
- 第6天：76°，后面没有更高温度 → 0
- 第7天：73°，后面没有更高温度 → 0
```

### 示例 2
```
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

### 示例 3
```
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

### 提示
- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
找"下一个更大元素"的位置

对于每个元素：
找到它右边第一个比它大的元素

这是典型的单调栈问题
```

**暴力解法的问题：**
```
对每个元素：
遍历后面所有元素找更大的
时间：O(n^2)

例如：[73,74,75,71,69,72,76,73]
对于73：遍历[74,75,71,...]找到74
对于74：遍历[75,71,69,...]找到75
...

大量重复计算
```

**单调栈优化：**
```
关键观察：
如果 a < b，且 a 在 b 左边
那么对于 b 右边的所有元素，a 永远不可能是"答案"

例如：[73, 74, ...]
- 对于后面的元素，如果它 > 74，那么它也 > 73
- 73 可以被"淘汰"了

维护一个递减栈：
- 栈中存储待匹配的元素（从栈底到栈顶递减）
- 遇到更大元素时，栈中小于它的都找到了答案
```

---

### 方法：单调递减栈（推荐）

**核心思想：**
- 维护一个单调递减栈（存储下标）
- 遇到更高温度时，弹出栈中所有小于它的元素
- 这些被弹出的元素找到了它们的答案

**算法流程：**

1. **初始化：**
   - 结果数组 result，全为0
   - 栈 stack（存储下标）

2. **遍历温度数组：**
   - 当前温度 > 栈顶温度：
     - 栈顶找到了答案
     - 计算距离：当前下标 - 栈顶下标
     - 弹出栈顶，继续比较
   - 当前下标入栈

3. **返回 result**

**为什么是单调递减栈？**
```
栈中保持从栈底到栈顶递减：
- 确保每个元素都在等待更大的元素
- 一旦遇到更大的，立即找到答案

例如：[73, 74, 75, 71]
栈的变化：
[73] → [74]（73找到答案，出栈）
      → [75]（74找到答案，出栈）
      → [75, 71]（71入栈，等待）

栈顶元素 = 最近的、还没找到答案的元素
```

**时间复杂度：** O(n) - 每个元素最多入栈和出栈各一次
**空间复杂度：** O(n) - 栈的空间

---

### 方法二：倒序遍历 + 栈

**核心思想：**
- 从右向左遍历
- 栈中维护"可能成为答案"的元素

**优点：**
- 思路不同，但本质相同

**缺点：**
- 不如正序遍历直观

## 代码实现（TypeScript）

### 方法一：单调递减栈（推荐）

```typescript
function dailyTemperatures(temperatures: number[]): number[] {
    const n = temperatures.length;
    const result: number[] = Array(n).fill(0);
    const stack: number[] = [];  // 存储下标

    for (let i = 0; i < n; i++) {
        // 当前温度 > 栈顶温度：栈顶找到答案
        while (stack.length > 0 && temperatures[i] > temperatures[stack[stack.length - 1]]) {
            const prevIndex = stack.pop()!;
            result[prevIndex] = i - prevIndex;  // 计算等待天数
        }

        // 当前下标入栈
        stack.push(i);
    }

    // 栈中剩余的元素都是没有答案的（已经是0）
    return result;
}
```

---

### 方法二：倒序遍历

```typescript
function dailyTemperatures(temperatures: number[]): number[] {
    const n = temperatures.length;
    const result: number[] = Array(n).fill(0);
    const stack: number[] = [];  // 存储下标

    // 从右向左遍历
    for (let i = n - 1; i >= 0; i--) {
        // 弹出所有 <= 当前温度的元素
        while (stack.length > 0 && temperatures[i] >= temperatures[stack[stack.length - 1]]) {
            stack.pop();
        }

        // 栈不为空，栈顶就是答案
        if (stack.length > 0) {
            result[i] = stack[stack.length - 1] - i;
        }

        // 当前下标入栈
        stack.push(i);
    }

    return result;
}
```

### 方法三：暴力解法（不推荐）

```typescript
function dailyTemperatures(temperatures: number[]): number[] {
    const n = temperatures.length;
    const result: number[] = Array(n).fill(0);

    for (let i = 0; i < n; i++) {
        // 对每个元素，遍历后面的所有元素
        for (let j = i + 1; j < n; j++) {
            if (temperatures[j] > temperatures[i]) {
                result[i] = j - i;
                break;
            }
        }
    }

    return result;
}

// 时间复杂度：O(n^2)
// 会超时
```

## 代码原理详解

### 单调栈方法

**1. 栈的含义：**
```typescript
stack: number[] = [i1, i2, i3, ...]

含义：
- 存储下标
- 从栈底到栈顶，温度递减
- 这些元素都还没找到"下一个更高温度"

例如：temperatures = [73, 72, 71, ...]
stack = [0, 1, 2]
表示：73°, 72°, 71° 都在等待更高温度
```

**2. 遇到更高温度：**
```typescript
while (stack.length > 0 && temperatures[i] > temperatures[stack[stack.length - 1]]) {
    const prevIndex = stack.pop()!;
    result[prevIndex] = i - prevIndex;
}

当前温度更高：
- 栈中所有小于它的元素都找到答案了
- 弹出并计算距离

例如：
stack = [0, 1, 2]（73°, 72°, 71°）
当前：i=3，76°
- 76° > 71°：71°找到答案，距离=3-2=1
- 76° > 72°：72°找到答案，距离=3-1=2
- 76° > 73°：73°找到答案，距离=3-0=3
```

**3. 当前下标入栈：**
```typescript
stack.push(i);

当前元素也在等待更高温度
加入栈中
```

## 常见问题

**Q1: 为什么是单调递减栈？**
A: 保证栈中元素有意义：
```
单调递减：
- 栈中元素都在等待更大值
- 一旦遇到更大值，立即处理

如果不单调：
- 栈中可能有 [小, 大, 小]
- 中间的"大"永远不会是答案（被"小"挡住了）
- 浪费空间

例如：[73, 75, 71, ...]
如果75在栈中：
- 对于后面的元素，如果它 > 75，那么它也 > 73
- 73 不需要等了（被75"遮挡"）
```

**Q2: 为什么要存下标而不是温度？**
A: 需要计算距离：
```
result[prevIndex] = i - prevIndex

需要知道两个位置的下标
只存温度无法计算距离
```

**Q3: 栈中剩余的元素怎么办？**
A: 它们没有答案：
```
遍历结束后，栈中剩余的元素：
- 右边没有更高温度
- result 已初始化为0
- 不需要额外处理
```

**Q4: 为什么每个元素只入栈一次？**
A: 单调性保证：
```
入栈后：
- 要么被后面更大的元素弹出（找到答案）
- 要么一直留在栈中（没有答案）

不会再次入栈
因此时间复杂度O(n)
```

**Q5: 倒序遍历和正序遍历的区别？**
A:
```
正序（推荐）：
- 遇到更大元素时，处理之前的元素
- 更直观

倒序：
- 维护"可能成为答案"的元素集合
- 查找答案时更快（栈顶）

本质相同，正序更易理解
```

## 复杂度分析

**时间复杂度：** O(n)
- 遍历一次：O(n)
- 每个元素最多入栈一次、出栈一次
- 总操作次数：2n
- O(2n) = O(n)

**空间复杂度：** O(n)
- 栈的空间
- 最坏情况：递减序列，所有元素都在栈中
- O(n)

## 单调栈的应用场景

**适用问题：**
1. 下一个更大/更小元素
2. 最近的更大/更小元素
3. 区间内的最大/最小值

**单调栈模板：**
```typescript
// 找"下一个更大元素"
function nextGreaterElement(nums: number[]): number[] {
    const n = nums.length;
    const result: number[] = Array(n).fill(-1);
    const stack: number[] = [];

    for (let i = 0; i < n; i++) {
        while (stack.length > 0 && nums[i] > nums[stack[stack.length - 1]]) {
            const prevIndex = stack.pop()!;
            result[prevIndex] = nums[i];
        }
        stack.push(i);
    }

    return result;
}
```

## 总结

**关键点：**
1. 单调递减栈维护待匹配元素
2. 遇到更大元素时弹出栈中所有小于它的
3. 栈中存储下标（计算距离）
4. 每个元素最多入栈、出栈各一次

**单调栈模板（每日温度）：**
```typescript
const stack: number[] = [];  // 存储下标
const result: number[] = Array(n).fill(0);

for (let i = 0; i < n; i++) {

    while (stack.length > 0 && arr[i] > arr[stack[stack.length - 1]]) {
```

**易错点：**

- while 条件写成 if（只弹出一个）
- 忘记处理栈中剩余元素（其实已经是0）
- 递增和递减栈搞混
- 边界条件：单个元素、全相同

**记忆技巧：**
- 单调栈 = 维护有序 + 快速匹配
- 递减栈 = 找更大（栈底到栈顶递减，等待更大）
- 递增栈 = 找更小（栈底到栈顶递增，等待更小）
- while 循环 = 弹出所有满足条件的（不只是一个）
