# 84. 柱状图中最大的矩形【困难】

## 题目描述

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 `1`。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

---

## 输入输出示例

### 示例 1

![示例1](https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg)

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

### 示例 2

```
输入：heights = [2,4]
输出：4
```

### 提示
- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
对于每个柱子 i：
找到以它为高度的最大矩形

矩形面积 = 高度 × 宽度

高度：heights[i]
宽度：向左右扩展，直到遇到更矮的柱子

关键：
如何快速找到左右边界？
```

**暴力解法的问题：**
```
对每个柱子 i：
- 向左找到第一个 < heights[i] 的位置
- 向右找到第一个 < heights[i] 的位置
- 计算面积

时间：O(n^2)
会超时
```

**单调栈优化：**
```
关键观察：
"找左/右第一个更小的元素"
= 单调栈的典型应用

维护单调递增栈：
- 栈中元素从栈底到栈顶递增
- 遇到更小元素时，栈中大于它的都找到了右边界

对于每个柱子：
- 左边界：栈中前一个元素
- 右边界：当前遍历到的元素
```

---

### 方法一：单调递增栈（推荐）

**核心思想：**
- 维护单调递增栈（存储下标）
- 遇到更矮柱子时，计算之前柱子能形成的最大矩形

**算法流程：**

1. **添加哨兵：**
   - 在heights首尾各加一个0
   - 确保所有柱子都能出栈

2. **遍历柱子：**
   - 当前高度 < 栈顶高度：
     - 栈顶柱子找到了右边界
     - 计算以栈顶为高度的矩形面积
     - 左边界 = 栈中前一个元素
     - 右边界 = 当前位置
   - 当前下标入栈

3. **返回最大面积**

**为什么是单调递增栈？**
```
栈中保持从栈底到栈顶递增：
- 每个柱子都在等待右边更矮的柱子
- 一旦遇到更矮的，就可以计算面积了

例如：[2, 1, 5, 6, 2, 3]
栈的变化：
[2] → [1]（2出栈，计算面积）
    → [1, 5]
    → [1, 5, 6]
    → [1, 2]（5和6出栈，计算面积）
    → [1, 2, 3]
```

**时间复杂度：** O(n) - 每个元素最多入栈和出栈各一次
**空间复杂度：** O(n) - 栈的空间

---

### 方法二：分治法

**核心思想：**
- 找到最矮的柱子
- 最大矩形要么包含它，要么在左右两侧
- 递归求解

**缺点：**
- 最坏情况O(n^2)
- 实现复杂

## 代码实现（TypeScript）

### 方法一：单调递增栈（推荐）

```typescript
function largestRectangleArea(heights: number[]): number {
    // 添加哨兵：首尾各加0
    // 确保所有柱子都能出栈
    const newHeights = [0, ...heights, 0];
    const n = newHeights.length;

    const stack: number[] = [];  // 存储下标
    let maxArea = 0;

    for (let i = 0; i < n; i++) {
        // 当前高度 < 栈顶高度：计算面积
        while (stack.length > 0 && newHeights[i] < newHeights[stack[stack.length - 1]]) {
            const heightIndex = stack.pop()!;
            const height = newHeights[heightIndex];

            // 宽度计算：
            // 左边界：栈中前一个元素的位置
            // 右边界：当前位置
            const width = i - stack[stack.length - 1] - 1;

            const area = height * width;
            maxArea = Math.max(maxArea, area);
        }

        // 当前下标入栈
        stack.push(i);
    }

    return maxArea;
}
```

### 方法一优化：不添加哨兵

```typescript
function largestRectangleArea(heights: number[]): number {
    const n = heights.length;
    const stack: number[] = [];
    let maxArea = 0;

    for (let i = 0; i < n; i++) {
        while (stack.length > 0 && heights[i] < heights[stack[stack.length - 1]]) {
            const heightIndex = stack.pop()!;
            const height = heights[heightIndex];

            // 宽度计算
            const leftBound = stack.length === 0 ? -1 : stack[stack.length - 1];
            const width = i - leftBound - 1;

            maxArea = Math.max(maxArea, height * width);
        }

        stack.push(i);
    }

    // 处理栈中剩余元素
    while (stack.length > 0) {
        const heightIndex = stack.pop()!;
        const height = heights[heightIndex];
        const leftBound = stack.length === 0 ? -1 : stack[stack.length - 1];
        const width = n - leftBound - 1;

        maxArea = Math.max(maxArea, height * width);
    }

    return maxArea;
}
```

### 方法二：预处理左右边界

```typescript
function largestRectangleArea(heights: number[]): number {
    const n = heights.length;

    // 预处理每个柱子的左右边界
    const leftBound: number[] = Array(n);   // 左边第一个 < heights[i] 的位置
    const rightBound: number[] = Array(n);  // 右边第一个 < heights[i] 的位置

    // 计算左边界
    const stack1: number[] = [];
    for (let i = 0; i < n; i++) {
        while (stack1.length > 0 && heights[i] <= heights[stack1[stack1.length - 1]]) {
            stack1.pop();
        }
        leftBound[i] = stack1.length === 0 ? -1 : stack1[stack1.length - 1];
        stack1.push(i);
    }

    // 计算右边界
    const stack2: number[] = [];
    for (let i = n - 1; i >= 0; i--) {
        while (stack2.length > 0 && heights[i] <= heights[stack2[stack2.length - 1]]) {
            stack2.pop();
        }
        rightBound[i] = stack2.length === 0 ? n : stack2[stack2.length - 1];
        stack2.push(i);
    }

    // 计算最大面积
    let maxArea = 0;
    for (let i = 0; i < n; i++) {
        const width = rightBound[i] - leftBound[i] - 1;
        const area = heights[i] * width;
        maxArea = Math.max(maxArea, area);
    }

    return maxArea;
}
```

## 代码原理详解

### 单调栈方法

**1. 为什么添加哨兵？**
```typescript
const newHeights = [0, ...heights, 0];

首部加0：
- 确保第一个柱子也有左边界
- 简化边界处理

尾部加0：
- 确保所有柱子都能出栈
- 不需要单独处理剩余元素

例如：[2, 1, 5, 6, 2, 3]
变为：[0, 2, 1, 5, 6, 2, 3, 0]
      ↑                     ↑
    左哨兵               右哨兵
```

**2. 宽度计算：**
```typescript
const width = i - stack[stack.length - 1] - 1;

解释：
- i：当前位置（右边界）
- stack[stack.length - 1]：栈顶（左边界）
- 宽度：右边界 - 左边界 - 1

为什么-1？
因为左右边界都是"第一个更小的"，不包含在矩形内

例如：
heights = [0, 2, 1, 5, 6, 2, 3, 0]
           ↑     ↑     ↑
          left  高度  right

计算高度5的矩形：
- 左边界：1（高度2的位置）
- 右边界：5（高度2的位置）
- 高度位置：3
- 宽度：5 - 1 - 1 = 3
- 实际包含：[1, 5, 6]，宽度确实是3 ✓
```

**3. 出栈时机：**
```typescript
while (newHeights[i] < newHeights[stack[stack.length - 1]]) {
    // 栈顶找到了右边界
}

当前高度更矮：
- 栈中所有高于它的柱子都找到右边界了
- 弹出并计算面积
```

## 常见问题

**Q1: 为什么是单调递增栈？**
A: 找"下一个更小元素"：
```
单调递增栈：
- 栈中元素从栈底到栈顶递增
- 每个柱子等待右边更矮的柱子
- 一旦遇到更矮的，就找到了右边界

对比每日温度（单调递减栈）：
- 找"下一个更大元素"
- 栈中元素递减

本题：
- 找"下一个更小元素"
- 栈中元素递增
```

**Q2: 为什么宽度是 i - stack[top] - 1？**
A: 左右边界都是"更小的"：
```
示意图：
left  height  right
 ↓      ↓      ↓
[1, 2, 5, 6, 2, 3]

计算高度6的矩形：
- left = 5的位置（第一个 < 6）
- right = 2的位置（第一个 < 6）
- 矩形只包含6本身

宽度 = right - left - 1
     = 不包含left和right之间的柱子数量

如果是"不小于"，公式会不同
```

**Q3: 不加哨兵可以吗？**
A: 可以但需要额外处理：
```
不加哨兵：
1. 遍历结束后，栈中可能还有元素
2. 需要单独弹出并计算
3. 边界条件复杂

加哨兵：
- 尾部0确保所有元素都出栈
- 首部0简化左边界计算
- 代码更简洁
```

**Q4: 能否用DP？**
A: 不适用：
```
DP需要最优子结构：
问题：以i结尾的最大矩形
难点：子问题之间没有明显依赖关系

本题更适合：
- 单调栈：O(n)
- 分治：O(nlogn)平均，O(n^2)最坏
```

**Q5: 如何理解"以某个柱子为高度"？**
A: 矩形高度的约束：
```
矩形高度 = min(heights[left...right])

如果固定高度 = heights[i]：
- 矩形只能包含 >= heights[i] 的柱子
- 向左右扩展，直到遇到 < heights[i]

这样保证：
矩形内所有柱子都 >= heights[i]
因此矩形高度可以是heights[i]
```

## 复杂度分析

**时间复杂度：** O(n)
- 遍历一次：O(n)
- 每个元素最多入栈、出栈各一次
- 总操作：2n
- O(n)

**空间复杂度：** O(n)
- 栈的空间
- 最坏情况：递增序列，所有元素都在栈中

## 总结

**关键点：**
1. 单调递增栈找"下一个更小元素"
2. 以每个柱子为高度，计算最大矩形
3. 添加哨兵简化边界处理
4. 宽度 = 右边界 - 左边界 - 1

**单调栈模板（柱状图）：**
```typescript
const newHeights = [0, ...heights, 0];
const stack: number[] = [];
let maxArea = 0;

for (let i = 0; i < newHeights.length; i++) {
    while (stack.length > 0 && newHeights[i] < newHeights[stack[stack.length - 1]]) {
        const h = stack.pop()!;
        const height = newHeights[h];
        const width = i - stack[stack.length - 1] - 1;
        maxArea = Math.max(maxArea, height * width);
    }
    stack.push(i);
}

return maxArea;
```

- 递增栈找更小（栈递增，等待更小）
- 递减栈找更大（栈递减，等待更大）
- 哨兵确保完整处理
- 宽度 = 两个边界之间（不含边界）
