# 394. 字符串解码【中等】

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

---

## 输入输出示例

### 示例 1
```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

### 示例 2
```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

### 示例 3
```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

### 示例 4
```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

### 提示
- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个**有效**的输入
- `s` 中所有整数的取值范围为 `[1, 300]`

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
嵌套结构：3[a2[c]]
- 内层：2[c] = cc
- 外层：3[acc] = accaccacc

类似：括号匹配问题
- 遇到 [ ：进入新的层级
- 遇到 ] ：完成当前层级，返回上一层

关键：
需要记录每一层的：
1. 重复次数（数字）
2. 已构建的字符串
```

**为什么用栈？**
```
栈的特点：
- 后进先出（LIFO）
- 完美匹配嵌套结构

处理流程：
遇到 [ → 保存当前状态，入栈
遇到 ] → 出栈，恢复上一层状态，拼接结果
```

---

### 方法一：双栈（推荐）

**核心思想：**
- 使用两个栈：
  - numStack：存储重复次数
  - strStack：存储当前字符串

**算法流程：**

1. **初始化：**
   - 当前数字 num = 0
   - 当前字符串 str = ""

2. **遍历字符串：**
   - **数字**：累积到 num（处理多位数）
   - **字母**：添加到 str
   - **'['**：
     - 将 num 入 numStack
     - 将 str 入 strStack
     - 重置 num = 0, str = ""
   - **']'**：
     - 弹出 lastNum 和 lastStr
     - str = lastStr + str.repeat(lastNum)

3. **返回 str**

**为什么需要两个栈？**
```
每一层需要记录两个信息：
1. 重复次数 k
2. 外层已构建的字符串

例如：3[a2[c]]
- 遇到第一个 [：numStack=[3], strStack=[""]
- 遇到第二个 [：numStack=[3,2], strStack=["","a"]
- 遇到第二个 ]：弹出 2 和 "a"，str = "a" + "c"*2 = "acc"
- 遇到第一个 ]：弹出 3 和 ""，str = "" + "acc"*3 = "accaccacc"
```

**时间复杂度：** O(n) - n是解码后字符串的长度
**空间复杂度：** O(n) - 栈的空间

---

### 方法二：单栈（字符栈）

**核心思想：**
- 用一个栈存储所有字符
- 遇到 ] 时回退处理

**缺点：**
- 需要从栈中提取数字和字符串
- 代码复杂度高

**时间复杂度：** O(n)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：双栈（推荐）

```typescript
function decodeString(s: string): string {
    const numStack: number[] = [];      // 存储重复次数
    const strStack: string[] = [];      // 存储外层字符串

    let num = 0;                         // 当前数字
    let str = "";                        // 当前字符串

    for (const char of s) {
        if (char >= '0' && char <= '9') {
            // 数字：累积（处理多位数）
            num = num * 10 + Number(char);

        } else if (char === '[') {
            // 左括号：保存当前状态，进入新层级
            numStack.push(num);
            strStack.push(str);

            // 重置当前状态
            num = 0;
            str = "";

        } else if (char === ']') {
            // 右括号：完成当前层级
            const repeatTimes = numStack.pop()!;
            const lastStr = strStack.pop()!;

            // 当前字符串重复 repeatTimes 次，拼接到上一层
            str = lastStr + str.repeat(repeatTimes);

        } else {
            // 字母：添加到当前字符串
            str += char;
        }
    }

    return str;
}
```

### 方法二：单栈

```typescript
function decodeString(s: string): string {
    const stack: string[] = [];

    for (const char of s) {
        if (char !== ']') {
            // 非右括号：全部入栈
            stack.push(char);
        } else {
            // 遇到右括号：开始解码

            // 1. 提取字符串
            let str = "";
            while (stack.length > 0 && stack[stack.length - 1] !== '[') {
                str = stack.pop()! + str;
            }

            // 2. 弹出 '['
            stack.pop();

            // 3. 提取数字
            let num = "";
            while (stack.length > 0 && stack[stack.length - 1] >= '0' && stack[stack.length - 1] <= '9') {
                num = stack.pop()! + num;
            }

            // 4. 重复字符串并入栈
            const repeatTimes = Number(num);
            const repeated = str.repeat(repeatTimes);

            // 将结果逐字符入栈（或作为整体入栈）
            stack.push(repeated);
        }
    }

    return stack.join('');
}
```

## 代码原理详解

### 双栈方法

**1. 数字累积（处理多位数）：**
```typescript
num = num * 10 + Number(char);

例如：12[a]
char = '1': num = 0*10 + 1 = 1
char = '2': num = 1*10 + 2 = 12
char = '[': 将12入栈
```

**2. 左括号处理：**
```typescript
numStack.push(num);
strStack.push(str);
num = 0;
str = "";

保存外层状态：
- 外层的重复次数
- 外层已构建的字符串

重置当前状态：
- 准备处理内层
```

**3. 右括号处理：**
```typescript
const repeatTimes = numStack.pop()!;
const lastStr = strStack.pop()!;
str = lastStr + str.repeat(repeatTimes);

恢复外层状态：
- 获取重复次数
- 获取外层字符串

拼接结果：
- 内层字符串重复 k 次
- 拼接到外层字符串后面
```

## 运行示例

### 示例 1：`s = "3[a]2[bc]"`

**执行过程：**

```
初始：numStack=[], strStack=[], num=0, str=""

char='3'：数字
  num = 0*10 + 3 = 3
  状态：num=3, str=""

char='['：左括号
  numStack.push(3) → numStack=[3]
  strStack.push("") → strStack=[""]
  重置：num=0, str=""

char='a'：字母
  str = "" + "a" = "a"
  状态：num=0, str="a"

char=']'：右括号
  repeatTimes = numStack.pop() = 3
  lastStr = strStack.pop() = ""
  str = "" + "a".repeat(3) = "aaa"
  状态：numStack=[], strStack=[], num=0, str="aaa"

char='2'：数字
  num = 0*10 + 2 = 2
  状态：num=2, str="aaa"

char='['：左括号
  numStack.push(2) → numStack=[2]
  strStack.push("aaa") → strStack=["aaa"]
  重置：num=0, str=""

char='b'：字母
  str = "" + "b" = "b"

char='c'：字母
  str = "b" + "c" = "bc"
  状态：num=0, str="bc"

char=']'：右括号
  repeatTimes = numStack.pop() = 2
  lastStr = strStack.pop() = "aaa"
  str = "aaa" + "bc".repeat(2) = "aaa" + "bcbc" = "aaabcbc"

返回："aaabcbc" ✓
```

### 示例 2：`s = "3[a2[c]]"`（嵌套）

**执行过程：**

```
初始：numStack=[], strStack=[], num=0, str=""

char='3'：数字
  num = 3

char='['：左括号
  numStack = [3]
  strStack = [""]
  num = 0, str = ""

char='a'：字母
  str = "a"

char='2'：数字
  num = 2

char='['：左括号（嵌套！）
  numStack = [3, 2]
  strStack = ["", "a"]
  num = 0, str = ""

char='c'：字母
  str = "c"

char=']'：右括号（内层）
  repeatTimes = 2
  lastStr = "a"
  str = "a" + "c".repeat(2) = "a" + "cc" = "acc"
  状态：numStack=[3], strStack=[""], str="acc"

char=']'：右括号（外层）
  repeatTimes = 3
  lastStr = ""
  str = "" + "acc".repeat(3) = "accaccacc"

返回："accaccacc" ✓
```

### 示例 3：`s = "2[abc]3[cd]ef"`

**执行过程：**

```
初始状态：num=0, str=""

处理 "2[abc]"：
  '2' → num=2
  '[' → numStack=[2], strStack=[""]
  'a','b','c' → str="abc"
  ']' → str="" + "abc"*2 = "abcabc"

处理 "3[cd]"：
  '3' → num=3
  '[' → numStack=[3], strStack=["abcabc"]
  'c','d' → str="cd"
  ']' → str="abcabc" + "cd"*3 = "abcabccdcdcd"

处理 "ef"：
  'e','f' → str="abcabccdcdcdef"

返回："abcabccdcdcdef" ✓
```

## 常见问题

**Q1: 为什么需要两个栈？**
A: 每层需要保存两个信息：
```
栈1（numStack）：重复次数
栈2（strStack）：外层已构建的字符串

例如 3[a2[c]]：
- 外层：重复3次，外层字符串=""
- 内层：重复2次，外层字符串="a"

如果只用一个栈，无法同时保存这两个信息
```

**Q2: 如何处理多位数？**
A: 累积计算：
```typescript
num = num * 10 + Number(char);

例如：123[a]
'1' → num = 0*10 + 1 = 1
'2' → num = 1*10 + 2 = 12
'3' → num = 12*10 + 3 = 123
```

**Q3: 遇到 [ 后为什么要重置 num 和 str？**
A: 进入新层级：
```
遇到 [ 表示：
- 当前层级的信息已保存到栈中
- 开始处理内层

重置：
- num = 0：准备读取内层的数字
- str = ""：准备构建内层的字符串
```

**Q4: 能否用递归？**
A: 可以但不推荐：
```typescript
function decodeString(s: string): string {
    let i = 0;

    function decode(): string {
        let result = "";
        let num = 0;

        while (i < s.length) {
            const char = s[i];

            if (char >= '0' && char <= '9') {
                num = num * 10 + Number(char);
                i++;
            } else if (char === '[') {
                i++;  // 跳过 [
                const str = decode();  // 递归处理内层
                result += str.repeat(num);
                num = 0;
            } else if (char === ']') {
                i++;  // 跳过 ]
                return result;
            } else {
                result += char;
                i++;
            }
        }

        return result;
    }

    return decode();
}

缺点：
- 需要外部变量 i 记录位置
- 代码复杂度高
- 不够直观
```

**Q5: 为什么外层字符串要入栈？**
A: 保存上下文：
```
例如：2[abc]3[cd]ef

处理第一个括号：
- 解码后 str = "abcabc"
- 这个结果要保留，作为后续的基础

处理第二个括号：
- 需要将 "cd"*3 拼接到 "abcabc" 后面

如果不保存外层字符串：
无法在内层解码完成后正确拼接
```

## 复杂度分析

**时间复杂度：** O(n)
- n 是解码后字符串的长度
- 每个字符最多入栈和出栈各一次
- repeat 操作：O(k)，k是重复次数
- 总时间：O(n)，n是最终结果长度

**空间复杂度：** O(n)
- 栈的空间：最多嵌套层数 × 每层字符串长度
- 最坏情况：嵌套层数与字符串长度成正比
- O(n)

```
输入: s = "2[2[y]p]"
输出: "yypyyp"

外层：2[yyp] = "yypyyp"

```

```

```
输入: s = "abc3[cd]xyz"
输出: "abccdcdcdxyz"

处理：
- "abc" → str="abc"
- 3[cd] → str="abc"+"cdcdcd"="abccdcdcd"
- "xyz" → str="abccdcdcdxyz"
```

### 情况6：连续括号

```
输入: s = "2[a]3[b]"
输出: "aabbb"

## 总结

**关键点：**
1. 使用双栈分别存储重复次数和外层字符串
2. 遇到 [ 保存状态并重置
3. 遇到 ] 恢复状态并拼接结果
4. 处理多位数需要累积计算

**栈模板（字符串解码）：**
```typescript
const numStack: number[] = [];
const strStack: string[] = [];
let num = 0, str = "";

for (const char of s) {
    if (isDigit(char)) {
        num = num * 10 + Number(char);
    } else if (char === '[') {
        numStack.push(num);
        strStack.push(str);
        num = 0;
        str = "";
    } else if (char === ']') {
        const k = numStack.pop()!;
        const lastStr = strStack.pop()!;
        str = lastStr + str.repeat(k);
    } else {
        str += char;
    }
}

return str;
```

- 先说明用双栈（清晰直观）
- 解释为什么需要两个栈（保存两个信息）
- 演示嵌套情况的处理
- 提及多位数的处理
- 可以画图演示栈的变化

**易错点：**
- 忘记处理多位数（num累积）
- 遇到 [ 后忘记重置 num 和 str
- repeat 的位置错误
- 拼接顺序错误（lastStr + repeated）
- 栈空时没有检查

**记忆技巧：**
- [ = 保存并重置（进入新层）
- ] = 恢复并拼接（返回上层）
- 外层字符串 + 内层字符串 × 重复次数
- 双栈同进同出（状态对应）
