# 155. 最小栈【中等】

## 题目描述

设计一个支持 `push`，`pop`，`top` 操作，并能在 **常数时间** 内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

---

## 输入输出示例

### 示例
```
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   // 返回 -3
minStack.pop();
minStack.top();      // 返回 0
minStack.getMin();   // 返回 -2
```

### 提示
- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
- `push`, `pop`, `top`, and `getMin` 最多被调用 `3 * 10^4` 次

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题挑战：**
```
普通栈：push, pop, top都是O(1)
本题额外要求：getMin()也要O(1)

如果每次getMin()都遍历栈：O(n)
不满足要求

必须：
在O(1)时间内知道当前最小值
```

**关键观察：**
```
栈的特点：
只能访问栈顶元素

当前最小值的变化：
- push新元素：最小值可能变化
- pop元素：如果pop的是最小值，需要知道"次小值"

需要：
随时知道"当前栈中的最小值"
```

---

### 方法一：辅助栈（推荐）

**核心思想：**
- 使用两个栈：
  - stack：存储所有元素
  - minStack：存储每个状态的最小值

**同步规则：**
```
push(x)：
- stack.push(x)
- minStack.push(min(x, 当前最小值))

pop()：
- stack.pop()
- minStack.pop()

getMin()：
- return minStack.top()
```

**例子：**
```
操作序列：push(-2), push(0), push(-3)

stack:    [-2]  [-2,0]  [-2,0,-3]
minStack: [-2]  [-2,-2] [-2,-2,-3]
           ↑     ↑        ↑
         最小值  最小值   最小值

pop后：
stack:    [-2,0]
minStack: [-2,-2]
           ↑
         最小值
```

**时间复杂度：** 所有操作O(1)
**空间复杂度：** O(n) - 额外的minStack

---

### 方法二：单栈存差值

**核心思想：**
- 只用一个栈
- 栈中存储：当前值与当前最小值的差值
- 用变量min记录当前最小值

**优点：**
- 空间可能更小（某些情况）

**缺点：**
- 代码复杂
- 可能溢出

**时间复杂度：** O(1)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：辅助栈（推荐）

```typescript
class MinStack {
    private stack: number[];      // 数据栈
    private minStack: number[];   // 最小值栈

    constructor() {
        this.stack = [];
        this.minStack = [];
    }

    /**
     * 入栈
     */
    push(val: number): void {
        this.stack.push(val);

        // 更新最小值栈
        if (this.minStack.length === 0) {
            this.minStack.push(val);
        } else {
            // 存储当前最小值
            this.minStack.push(Math.min(val, this.minStack[this.minStack.length - 1]));
        }
    }

    /**
     * 出栈
     */
    pop(): void {
        this.stack.pop();
        this.minStack.pop();
    }

    /**
     * 获取栈顶元素
     */
    top(): number {
        return this.stack[this.stack.length - 1];
    }

    /**
     * 获取最小元素
     */
    getMin(): number {
        return this.minStack[this.minStack.length - 1];
    }
}
```

### 方法一优化：只在必要时push到minStack

```typescript
class MinStack {
    private stack: number[];
    private minStack: number[];

    constructor() {
        this.stack = [];
        this.minStack = [];
    }

    push(val: number): void {
        this.stack.push(val);

        // 只有当val <= 当前最小值时，才push到minStack
        if (this.minStack.length === 0 || val <= this.minStack[this.minStack.length - 1]) {
            this.minStack.push(val);
        }
    }

    pop(): void {
        const val = this.stack.pop()!;

        // 如果pop的是最小值，minStack也要pop
        if (val === this.minStack[this.minStack.length - 1]) {
            this.minStack.pop();
        }
    }

    top(): number {
        return this.stack[this.stack.length - 1];
    }

    getMin(): number {
        return this.minStack[this.minStack.length - 1];
    }
}
```

### 方法二：单栈存差值

```typescript
class MinStack {
    private stack: number[];
    private min: number;  // 当前最小值

    constructor() {
        this.stack = [];
        this.min = 0;
    }

    push(val: number): void {
        if (this.stack.length === 0) {
            this.stack.push(0);
            this.min = val;
        } else {
            // 存储差值
            this.stack.push(val - this.min);

            // 更新最小值
            if (val < this.min) {
                this.min = val;
            }
        }
    }

    pop(): void {
        const diff = this.stack.pop()!;

        // 如果差值<0，说明pop的是最小值
        if (diff < 0) {
            // 恢复之前的最小值
            this.min = this.min - diff;
        }
    }

    top(): number {
        const diff = this.stack[this.stack.length - 1];

        if (diff < 0) {
            // 栈顶是最小值
            return this.min;
        } else {
            return this.min + diff;
        }
    }

    getMin(): number {
        return this.min;
    }
}
```

## 代码原理详解

### 辅助栈方法

**同步机制：**
```typescript
push(val)：
  stack.push(val)
  minStack.push(min(val, currentMin))

stack和minStack始终同步：
- 长度相同
- minStack[i] = stack[0...i]的最小值

例如：
push(-2): stack=[-2],   minStack=[-2]
push(0):  stack=[-2,0], minStack=[-2,-2]
push(-3): stack=[-2,0,-3], minStack=[-2,-2,-3]

minStack栈顶 = 当前最小值
```

**为什么pop时两个栈都要pop？**
```
保持同步：
stack和minStack长度必须一致

如果只pop stack：
minStack会多余，导致getMin()错误

例如：
pop前：stack=[-2,0], minStack=[-2,-2]
pop后：stack=[-2], minStack=[-2,-2]✗
getMin()返回-2✗（错误，应该是-2✓）

正确：
pop后：stack=[-2], minStack=[-2]✓
```

### 优化版本

**减少minStack的空间：**
```typescript
push(val)：
  if (val <= currentMin) {
    minStack.push(val);  // 只push更小的值
  }

pop()：
  if (popVal == minStack.top()) {
    minStack.pop();  // 只有pop最小值时才pop
  }

优点：
minStack通常更小

例如：
push(5): stack=[5], minStack=[5]
push(3): stack=[5,3], minStack=[5,3]
push(4): stack=[5,3,4], minStack=[5,3]（不push）
push(1): stack=[5,3,4,1], minStack=[5,3,1]

minStack只存递减序列
```

## 常见问题

**Q1: 为什么不每次getMin()时遍历栈？**
A: 不满足O(1)要求：
```
遍历方法：
每次getMin()遍历整个栈
时间：O(n)

题目要求：
所有操作都是O(1)
必须用额外空间换时间
```

**Q2: 能否只用一个变量记录最小值？**
A: 不够：
```
只有一个min变量：
push时可以更新
但pop时无法恢复之前的最小值

例如：
push(-2): min = -2
push(0): min = -2
push(-3): min = -3
pop(): min = ？（无法知道是-2）

需要栈记录历史最小值
```

**Q3: 辅助栈的空间能优化多少？**
A: 取决于数据：
```
最坏情况：
递减序列 [5,4,3,2,1]
minStack = [5,4,3,2,1]
无法优化

最好情况：
递增序列 [1,2,3,4,5]
minStack = [1]（优化版）
空间大幅减少

一般情况：
介于两者之间
```

**Q4: 差值法的缺点？**
A:
```
1. 代码复杂，难理解
2. 可能溢出：
   val - min可能超过int范围
3. 需要特殊处理负差值

面试不推荐（除非面试官要求优化空间）
```

**Q5: 如果要求getMax()呢？**
A: 类似实现：
```typescript
class MinMaxStack {
    private stack: number[];
    private minStack: number[];
    private maxStack: number[];  // 额外的最大值栈

    push(val: number): void {
        this.stack.push(val);
        this.minStack.push(Math.min(val, this.getMin() || val));
        this.maxStack.push(Math.max(val, this.getMax() || val));
    }

    // ...
}
```

## 复杂度分析

### 辅助栈方法

**时间复杂度：** O(1)
- push: O(1)
- pop: O(1)
- top: O(1)
- getMin: O(1)

- 额外的minStack
- 最坏情况：与stack相同大小

## 边界情况

### 情况1：单个元素

```
push(1)
getMin() → 1
```

### 情况2：递减序列

```
push(3), push(2), push(1)
getMin() → 1
pop()
getMin() → 2
pop()
getMin() → 3
```

### 情况3：递增序列

```
push(1), push(2), push(3)
getMin() → 始终是1
```

### 情况4：pop最小值

```
push(1), push(2)
getMin() → 1
pop()  // pop 2
getMin() → 1（最小值没变）
pop()  // pop 1
stack空
```

## 总结

**关键点：**
1. 用辅助栈记录每个状态的最小值
2. 两个栈同步操作
3. getMin()直接返回minStack栈顶
4. 所有操作O(1)

**设计模板（辅助栈）：**
```typescript
class MinStack {
    stack: number[];
    minStack: number[];

    push(val: number): void {
        this.stack.push(val);
        this.minStack.push(
            this.minStack.length === 0
                ? val
                : Math.min(val, this.minStack[this.minStack.length - 1])
        );
    }

    pop(): void {
        this.stack.pop();
        this.minStack.pop();
    }

    top(): number {
        return this.stack[this.stack.length - 1];
    }

    getMin(): number {
        return this.minStack[this.minStack.length - 1];
    }
}
```

**面试建议：**
- 先说明用辅助栈（最清晰）
- 解释同步机制
- 画图演示两个栈的变化
- 可以提及优化版本（按需push）
- 分析空间复杂度

**易错点：**
- pop时忘记minStack也要pop
- minStack初始化错误
- 边界情况（空栈）处理
- 优化版本中判断条件错误

**记忆技巧：**
- 两个栈同进同出
- minStack存的是"历史最小值"
- 栈顶 = 当前最小值
