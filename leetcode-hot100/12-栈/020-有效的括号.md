# 20. 有效的括号【简单】

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

---

## 输入输出示例

### 示例 1
```
输入：s = "()"
输出：true
```

### 示例 2
```
输入：s = "()[]{}"
输出：true
```

### 示例 3
```
输入：s = "(]"
输出：false
```

### 提示
- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**有效括号的特点：**
```
1. 配对：每个左括号有对应的右括号
2. 顺序：最近的左括号先配对（后进先出）
3. 完全：所有括号都配对完成

例如：
"()" ✓
"([{}])" ✓ - 最内层先配对
"([)]" ✗ - 交叉配对，无效
```

**为什么用栈？**
```
栈的LIFO特性（后进先出）
完美匹配括号的配对规则

遇到左括号：入栈
遇到右括号：
  - 栈顶是对应的左括号 → 配对成功，出栈
  - 否则 → 配对失败

最后栈为空 → 所有括号配对完成
```

---

### 方法：栈

**算法流程：**
1. 创建空栈
2. 遍历字符串：
   - 遇到左括号('(', '[', '{')：入栈
   - 遇到右括号(')', ']', '}')：
     - 栈空：无法配对，返回false
     - 栈顶不匹配：返回false
     - 栈顶匹配：出栈，继续
3. 遍历结束后，栈为空返回true，否则false

**时间复杂度：** O(n)
**空间复杂度：** O(n)

## 代码实现（TypeScript）

### 方法一：栈 + Map（推荐）

```typescript
function isValid(s: string): boolean {
    // 奇数长度必然无效
    if (s.length % 2 === 1) {
        return false;
    }

    // 括号配对映射
    const pairs = new Map([
        [')', '('],
        [']', '['],
        ['}', '{']
    ]);

    const stack: string[] = [];

    for (const char of s) {
        if (pairs.has(char)) {
            // 右括号
            if (stack.length === 0 || stack[stack.length - 1] !== pairs.get(char)) {
                return false;
            }
            stack.pop();
        } else {
            // 左括号
            stack.push(char);
        }
    }

    // 栈为空表示所有括号都配对
    return stack.length === 0;
}
```

---

### 方法二：栈 + 字符比较

```typescript
function isValid(s: string): boolean {
    if (s.length % 2 === 1) {
        return false;
    }

    const stack: string[] = [];

    for (const char of s) {
        if (char === '(' || char === '[' || char === '{') {
            // 左括号入栈
            stack.push(char);
        } else {
            // 右括号
            if (stack.length === 0) {
                return false;
            }

            const top = stack.pop()!;

            // 检查是否匹配
            if (char === ')' && top !== '(') return false;
            if (char === ']' && top !== '[') return false;
            if (char === '}' && top !== '{') return false;
        }
    }

    return stack.length === 0;
}
```

---

### 方法三：替换法（不推荐）

```typescript
function isValid(s: string): boolean {
    // 不断删除成对的括号
    while (s.includes('()') || s.includes('[]') || s.includes('{}')) {
        s = s.replace('()', '').replace('[]', '').replace('{}', '');
    }

    return s.length === 0;
}

// 时间复杂度：O(n^2) - 不满足最优
```

## 代码原理详解

### 栈的使用

**入栈时机：**
```typescript
if (char === '(' || char === '[' || char === '{') {
    stack.push(char);
}

左括号：等待配对
入栈保存，等右括号来配对
```

**出栈时机：**
```typescript
if (char === ')' || char === ']' || char === '}') {
    if (stack.length === 0 || !match(stack.pop(), char)) {
        return false;
    }
}

右括号：尝试配对
检查栈顶是否是对应的左括号
```

### Map的优势

```typescript
const pairs = new Map([
    [')', '('],
    [']', '['],
    ['}', '{']
]);

优点：
1. O(1)查询
2. 代码简洁
3. 易于扩展（添加新括号类型）

使用：
if (pairs.has(char)) {
    // 是右括号
    const expected = pairs.get(char);
    if (stack.pop() !== expected) {
        return false;
    }
}
```

## 常见问题

**Q1: 为什么奇数长度一定无效？**
A: 括号成对出现：
```
每个左括号对应一个右括号
总数必然是偶数

奇数长度：
必有括号无法配对
提前返回false，优化性能
```

**Q2: 能否不用栈？**
A: 可以但不推荐：
```
替换法：
不断删除成对括号
时间：O(n^2)

计数法：
只对单一类型有效
多种括号混合时失效

栈是最优解：O(n)
```

**Q3: 空字符串是有效的吗？**
A: 题目约束`1 <= s.length`，不会有空字符串：
```
如果允许空字符串：
应该返回true
（没有括号，自然有效）
```

**Q4: 如何扩展到更多括号类型？**
A: 修改Map即可：
```typescript
const pairs = new Map([
    [')', '('],
    [']', '['],
    ['}', '{'],
    ['>', '<'],  // 添加新类型
    // ...
]);

其他代码不需要改动
```

**Q5: 能否用递归？**
A: 可以但不直观：
```typescript
function isValid(s: string): boolean {
    if (s.length === 0) return true;
    if (s.length % 2 === 1) return false;

    // 找最内层的配对括号
    for (let i = 0; i < s.length - 1; i++) {
        if ((s[i] === '(' && s[i+1] === ')') ||
            (s[i] === '[' && s[i+1] === ']') ||
            (s[i] === '{' && s[i+1] === '}')) {
            // 删除这对括号，递归
            return isValid(s.slice(0, i) + s.slice(i + 2));
        }
    }

    return false;
}

问题：效率低，O(n^2)
```

## 复杂度分析

**时间复杂度：** O(n)
- 遍历字符串一次
- 每个字符O(1)操作

**空间复杂度：** O(n)
- 栈最多存储n/2个左括号
- O(n/2) = O(n)

## 总结

**关键点：**
1. 栈的后进先出特性匹配括号配对规则
2. 左括号入栈，右括号配对出栈
3. 最后栈必须为空
4. 奇数长度提前剪枝

**栈模板（括号匹配）：**
```typescript
const stack: string[] = [];

for (const char of s) {
    if (isLeftBracket(char)) {
        stack.push(char);
    } else {
        if (stack.length === 0 || !match(stack.pop(), char)) {
            return false;
        }
    }
}

return stack.length === 0;
```

**面试建议：**
- 先说明栈的LIFO特性
- 解释左括号入栈、右括号配对
- 强调最后栈必须为空
- 可以画图演示栈的变化
- 提及奇数长度优化

**易错点：**
- 忘记检查栈是否为空
- 最后没有检查栈长度
- 括号类型判断错误
- 配对逻辑写反

**记忆技巧：**
- 左进右出（左括号入栈，右括号出栈）
- 栈空两种情况：配对完成 or 提前遇到右括号
- LIFO = Last In First Out = 最近的先配对
