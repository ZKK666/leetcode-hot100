# 136. 只出现一次的数字【简单】

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

---

## 输入输出示例

### 示例 1
```
输入：nums = [2,2,1]
输出：1
```

### 示例 2
```
输入：nums = [4,1,2,1,2]
输出：4
```

### 示例 3
```
输入：nums = [1]
输出：1
```

### 提示
- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
其他元素都出现2次
只有1个元素出现1次

要求：
- 时间复杂度：O(n)
- 空间复杂度：O(1)
```

**巧妙解法：位运算（异或）**
```
异或运算（XOR）的性质：
1. a ^ a = 0
2. a ^ 0 = a
3. 异或满足交换律和结合律

利用性质：
所有数字异或
出现2次的数字会相互抵消（a ^ a = 0）
最后剩下只出现1次的数字
```

---

### 方法：异或运算

**核心思想：**
- 将所有数字进行异或运算
- 出现两次的数字会抵消
- 最后剩下的就是只出现一次的数字

**算法流程：**

1. **初始化：**
   - result = 0

2. **遍历数组：**
   - 对每个数字进行异或：result ^= nums[i]

3. **返回 result**

**数学原理：**
```
假设数组：[a, b, a, c, b]
只有c出现1次

异或过程：
result = 0 ^ a ^ b ^ a ^ c ^ b
       = (a ^ a) ^ (b ^ b) ^ c  （交换律和结合律）
       = 0 ^ 0 ^ c
       = c
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

## 代码实现（TypeScript）

### 方法一：异或运算（推荐，最优解）

```typescript
function singleNumber(nums: number[]): number {
    let result = 0;

    for (const num of nums) {
        result ^= num;
    }

    return result;
}
```

**一行写法：**
```typescript
function singleNumber(nums: number[]): number {
    return nums.reduce((acc, num) => acc ^ num, 0);
}
```

---

### 方法二：哈希表（不满足空间要求）

```typescript
function singleNumber(nums: number[]): number {
    const count = new Map<number, number>();

    // 统计每个数字出现的次数
    for (const num of nums) {
        count.set(num, (count.get(num) || 0) + 1);
    }

    // 找到出现1次的数字
    for (const [num, cnt] of count) {
        if (cnt === 1) {
            return num;
        }
    }

    return -1; // 不会到达
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n) - 不满足题目要求

### 方法三：数学方法（不实用）

```typescript
function singleNumber(nums: number[]): number {
    const uniqueSum = new Set(nums).reduce((a, b) => a + b, 0);
    const totalSum = nums.reduce((a, b) => a + b, 0);
```

**时间复杂度：** O(n)

## 代码原理详解

### 异或运算详解

**1. 异或的性质：**
```
a ^ a = 0
- 相同数字异或为0
- 例如：5 ^ 5 = 0

a ^ 0 = a
- 任何数字与0异或等于自身
- 例如：5 ^ 0 = 5

交换律：a ^ b = b ^ a
结合律：(a ^ b) ^ c = a ^ (b ^ c)
```

**2. 位运算原理：**
```
异或（XOR）：相同为0，不同为1

5 ^ 5 的二进制过程：
  101  (5)
^ 101  (5)
------
  000  (0)

5 ^ 3 的二进制过程：
  101  (5)
^ 011  (3)
------
  110  (6)
```

**3. 为什么能找到单独的数字？**
```
数组：[4, 1, 2, 1, 2]

异或过程：
0 ^ 4 = 4
4 ^ 1 = 5
5 ^ 2 = 7
7 ^ 1 = 6  （1抵消了之前的1）
6 ^ 2 = 4  （2抵消了之前的2）

最终结果：4 ✓

原理：
所有出现2次的数字会两两抵消
只剩下出现1次的数字
```

**4. 顺序无关性：**
```
[1, 2, 1, 2, 4]
[4, 1, 1, 2, 2]
[1, 1, 2, 2, 4]

无论顺序如何，结果都是4
因为异或满足交换律和结合律
```

---

### 哈希表方法

**统计思路：**
```
遍历数组，统计每个数字出现次数
找到出现次数为1的数字

简单直观，但空间复杂度O(n)
不满足题目要求
```

---

### 数学方法

**公式推导：**
```
假设数组：[a, a, b, b, c]

uniqueSum = a + b + c
totalSum = a + a + b + b + c

2 * uniqueSum - totalSum
= 2(a + b + c) - (2a + 2b + c)
= 2a + 2b + 2c - 2a - 2b - c
= c

原理：
每个出现2次的数字在2*uniqueSum中多算了1次
totalSum中出现2次
相减后抵消
```

## 运行示例

### 示例 1：`nums = [2,2,1]`

**异或过程：**

```
初始：result = 0

i=0, nums[0]=2：
  result = 0 ^ 2 = 2
  二进制：000 ^ 010 = 010

i=1, nums[1]=2：
  result = 2 ^ 2 = 0
  二进制：010 ^ 010 = 000

i=2, nums[2]=1：
  result = 0 ^ 1 = 1
  二进制：000 ^ 001 = 001

返回：1 ✓
```

---

### 示例 2：`nums = [4,1,2,1,2]`

**异或过程：**

```
result = 0
result = 0 ^ 4 = 4   (二进制：0000 ^ 0100 = 0100)
result = 4 ^ 1 = 5   (二进制：0100 ^ 0001 = 0101)
result = 5 ^ 2 = 7   (二进制：0101 ^ 0010 = 0111)
result = 7 ^ 1 = 6   (二进制：0111 ^ 0001 = 0110)
result = 6 ^ 2 = 4   (二进制：0110 ^ 0010 = 0100)

返回：4 ✓

解释：
1出现2次：第2次和第4次抵消
2出现2次：第3次和第5次抵消
4出现1次：保留
```

---

### 示例 3：`nums = [1]`

```
result = 0 ^ 1 = 1

只有1个元素，直接返回
```

## 常见问题

**Q1: 为什么异或可以解决这个问题？**
A: 异或的性质：
```
1. a ^ a = 0（相同数字抵消）
2. a ^ 0 = a（与0异或保持不变）
3. 满足交换律和结合律（顺序无关）

出现2次的数字会两两抵消
最后剩下只出现1次的数字
```

**Q2: 如果有3个重复呢？**
A: 需要改用其他方法：
```
题目延伸：137. 只出现一次的数字 II
其他元素出现3次，1个元素出现1次

需要用位运算的其他技巧：
统计每一位上1的个数
对3取模
```

**Q3: 负数可以异或吗？**
A: 可以：
```
负数在计算机中用补码表示
异或运算对补码同样适用

例如：-5 ^ -5 = 0
```

**Q4: 为什么初始值是0？**
A: 因为 a ^ 0 = a：
```
任何数与0异或等于自身
从0开始不影响结果

如果从1开始：
result = 1 ^ nums[0] ^ nums[1] ^ ...
最后会多一个1，结果错误
```

**Q5: 可以用减法吗？**
A: 理论上可以，但有局限：
```
数学方法：2 * uniqueSum - totalSum

问题：
1. 需要Set去重，空间O(n)
2. 可能溢出（对于很大的数字）

异或方法更优雅
```

## 总结

**关键点：**
1. 异或运算的三大性质：
   - a ^ a = 0
   - a ^ 0 = a
   - 满足交换律和结合律
2. 出现2次的数字会相互抵消

**异或模板：**
```typescript
function singleNumber(nums: number[]): number {
    let result = 0;

}
```
