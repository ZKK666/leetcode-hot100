# 75. 颜色分类【中等】

## 题目描述

给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums`，**原地**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、`1` 和 `2` 分别表示红色、白色和蓝色。

必须在不使用库函数的情况下解决这个问题。

---

## 输入输出示例

### 示例 1
```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

### 示例 2
```
输入：nums = [2,0,1]
输出：[0,1,2]
```

### 提示
- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` 为 `0`、`1` 或 `2`

**进阶：**
- 你可以不使用库的 sort 函数来解决这个问题吗？
- 你能想出一个仅使用常数空间的一趟扫描算法吗？

---

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
只有3种元素：0, 1, 2
需要原地排序
要求一趟扫描

本质上是三路快排的应用
```

**多种解法：**
```
1. 计数排序：两趟扫描，O(n) 时间，O(1) 空间
2. 双指针（荷兰国旗）：一趟扫描，O(n) 时间，O(1) 空间 ⭐
3. 库函数排序：O(nlogn) 时间
```

---

### 方法一：双指针（荷兰国旗问题）

**核心思想：**
- 维护三个区间：
  - [0, left)：全是0
  - [left, i)：全是1
  - [right, n-1]：全是2
  - [i, right)：待处理

**指针含义：**
```
left：下一个0应该放的位置
right：下一个2应该放的位置
i：当前遍历位置

区间划分：
[0 0 0 | 1 1 1 | ? ? ? | 2 2 2]
       ↑       ↑       ↑
      left     i      right
```

**算法流程：**

1. **初始化：**
   - left = 0（0区域的右边界）
   - right = n - 1（2区域的左边界）
   - i = 0（当前遍历位置）

2. **遍历数组（i <= right）：**
   - **nums[i] == 0：**
     - 交换 nums[i] 和 nums[left]
     - left++, i++

   - **nums[i] == 1：**
     - i++（已经在正确位置）

   - **nums[i] == 2：**
     - 交换 nums[i] 和 nums[right]
     - right--
     - **注意：i不变**（因为交换来的元素还未处理）

3. **结束条件：** i > right

**为什么i遇到2不自增？**
```
交换来的nums[right]可能是0或1
需要重新判断

遇到0或1时，交换来的一定已经处理过
（来自[left, i)区域，全是1）
所以可以i++
```

**时间复杂度：** O(n) - 一趟扫描
**空间复杂度：** O(1) - 原地排序

---

### 方法二：计数排序

**核心思想：**
- 第一趟：统计0、1、2的个数
- 第二趟：按顺序填充数组

**算法流程：**

1. **统计个数：**
   - count[0] = 0的个数
   - count[1] = 1的个数
   - count[2] = 2的个数

2. **重新填充：**
   - 填充count[0]个0
   - 填充count[1]个1
   - 填充count[2]个2

**时间复杂度：** O(n) - 两趟扫描
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：双指针（荷兰国旗，推荐）

```typescript
function sortColors(nums: number[]): void {
    let left = 0;   // 下一个0的位置
    let right = nums.length - 1;  // 下一个2的位置
    let i = 0;      // 当前遍历位置

    while (i <= right) {
        if (nums[i] === 0) {
            // 交换到左边
            [nums[i], nums[left]] = [nums[left], nums[i]];
            left++;
            i++;
        } else if (nums[i] === 2) {
            // 交换到右边
            [nums[i], nums[right]] = [nums[right], nums[i]];
            right--;
            // i不变，因为交换来的元素还未处理
        } else {
            // nums[i] === 1，已经在正确位置
            i++;
        }
    }
}
```

**详细注释版本：**

```typescript
function sortColors(nums: number[]): void {
    const n = nums.length;
    let left = 0;   // [0, left) 全是0
    let right = n - 1;  // (right, n-1] 全是2
    let i = 0;      // [left, i) 全是1, [i, right] 待处理

    while (i <= right) {
        if (nums[i] === 0) {
            // 将0交换到左边
            // 交换后nums[i]是1（来自[left, i)区域）
            // 可以安全地i++
            [nums[i], nums[left]] = [nums[left], nums[i]];
            left++;
            i++;
        } else if (nums[i] === 2) {
            // 将2交换到右边
            // 交换后nums[i]可能是0、1、2
            // 需要重新判断，所以i不变
            [nums[i], nums[right]] = [nums[right], nums[i]];
            right--;
        } else {
            // nums[i] === 1
            // 已经在正确区域，直接跳过
            i++;
        }
    }
}
```

### 方法二：计数排序

```typescript
function sortColors(nums: number[]): void {
    const count = [0, 0, 0];

    // 第一趟：统计个数
    for (const num of nums) {
        count[num]++;
    }

    // 第二趟：重新填充
    let index = 0;

    for (let color = 0; color <= 2; color++) {
        for (let i = 0; i < count[color]; i++) {
            nums[index++] = color;
        }
    }
}
```

**简化版本：**

```typescript
function sortColors(nums: number[]): void {
    const count = [0, 0, 0];

    // 统计
    for (const num of nums) {
        count[num]++;
    }

    // 填充
    let i = 0;
    while (count[0]-- > 0) nums[i++] = 0;
    while (count[1]-- > 0) nums[i++] = 1;
    while (count[2]-- > 0) nums[i++] = 2;
}
```

## 代码原理详解

### 双指针详解

**1. 区间不变式：**

```
遍历过程中始终保持：
[0, left)：全是0
[left, i)：全是1
[i, right]：待处理
(right, n-1]：全是2

初始状态：
left=0, i=0, right=n-1
[待处理区域占满整个数组]

结束状态：
i > right
[0 0 0 | 1 1 1 | 2 2 2]
```

**2. 为什么遇到0时i++，遇到2时i不变？**

```
遇到0：
交换 nums[i] 和 nums[left]

交换前：
[0...0 | 1...1 | i=0 ? | 2...2]
       left    i

交换后：
[0...0 0 | 1...1 ? | 2...2]
         left  i

交换来的?：
- 来自[left, i)区域
- 这个区域全是1
- 所以?一定是1
- 可以安全地i++

遇到2：
交换 nums[i] 和 nums[right]

交换前：
[0...0 | 1...1 i=2 | ? 2...2]
                    right

交换后：
[0...0 | 1...1 ? | 2 2...2]
                i   right

交换来的?：
- 来自待处理区域
- 可能是0、1、2
- 需要重新判断
- 所以i不变
```

**3. 循环不变式证明：**

```
初始化：
left=0, i=0, right=n-1
[0, 0): 空，满足"全是0"
[0, 0): 空，满足"全是1"
(n-1, n-1]: 空，满足"全是2"
✓

保持：
每次操作后，区间性质仍然满足
✓

终止：
i > right
整个数组被划分为三个区域
✓
```

---

### 计数排序详解

**原理：**

```
只有3种元素：0, 1, 2
不需要比较排序

统计每种元素的个数
按顺序填充即可

例如：[2, 0, 2, 1, 1, 0]
count = [2, 2, 2]

填充：
0 0 1 1 2 2
```

**为什么两趟扫描？**

```
第一趟：读取原数组，统计个数
第二趟：写入原数组，按顺序填充

不能一趟完成：
需要先知道所有元素的分布
才能确定每种颜色的起始位置
```

## 运行示例

### 示例 1：`nums = [2,0,2,1,1,0]`

**双指针过程：**

```
初始：left=0, i=0, right=5
数组：[2, 0, 2, 1, 1, 0]

i=0, nums[0]=2：
  交换 nums[0] 和 nums[5]
  数组：[0, 0, 2, 1, 1, 2]
  right=4, i=0

i=0, nums[0]=0：
  交换 nums[0] 和 nums[0]（自己）
  left=1, i=1

i=1, nums[1]=0：
  交换 nums[1] 和 nums[1]（自己）
  left=2, i=2

i=2, nums[2]=2：
  交换 nums[2] 和 nums[4]
  数组：[0, 0, 1, 1, 2, 2]
  right=3, i=2

i=2, nums[2]=1：
  i=3

i=3, nums[3]=1：
  i=4

i=4, i > right，结束

结果：[0, 0, 1, 1, 2, 2] ✓
```

**区间变化：**

```
[2, 0, 2, 1, 1, 0]
 ↑             ↑
left=0         right=5

[0, 0, 2, 1, 1, 2]
 ↑         ↑
left=0     right=4

[0, 0, 2, 1, 1, 2]
    ↑     ↑
   left=1 right=4

[0, 0, 2, 1, 1, 2]
       ↑  ↑
      left=2, i=2, right=4

[0, 0, 1, 1, 2, 2]
       ↑ ↑
      left=2, i=2, right=3

最终：
[0, 0 | 1, 1 | 2, 2]
```

## 常见问题

**Q1: 为什么叫荷兰国旗问题？**
A: 历史由来：
```
荷兰国旗：
红 | 白 | 蓝
（三种颜色）

Dijkstra提出的算法问题：
如何高效地将三种颜色排序

算法思想：
三路快排的简化版
```

**Q2: 为什么遇到2时i不自增？**
A: 交换来的元素未知：
```
遇到0：
交换来的一定是1（来自已处理区域）
可以i++

遇到2：
交换来的可能是0、1、2（来自未处理区域）
需要重新判断，i不变

这是算法的关键点！
```

**Q3: 可以用快速排序吗？**
A: 可以，但不是最优：
```
快速排序：O(nlogn)
双指针：O(n)

本题只有3种元素
不需要完整的快速排序
```

**Q4: 如果有4种颜色怎么办？**
A: 需要修改算法：
```
4种颜色：计数排序更简单

n种颜色（n较小）：
计数排序 O(n)

n种颜色（n很大）：
快速排序 O(nlogn)
```

**Q5: 一定要用3个指针吗？**
A: 可以用2个指针，但需要两趟：
```
第一趟：将0移到左边（双指针）
第二趟：将2移到右边（双指针）

一趟扫描：需要3个指针（left, i, right）
```

## 复杂度分析

### 双指针方法
**时间复杂度：** O(n)
- 一趟扫描
- 每个元素最多被访问一次

**空间复杂度：** O(1)
- 原地排序
- 只用常数个变量

### 计数排序
**时间复杂度：** O(n)
- 两趟扫描

**空间复杂度：** O(1)
- 固定大小的count数组

## 总结

**关键点：**
1. 荷兰国旗问题（三路快排简化版）
2. 维护三个区间：
   - [0, left)：全是0
   - [left, i)：全是1
   - (right, n-1]：全是2
3. 遇到0：交换并i++
4. 遇到1：直接i++
5. 遇到2：交换但i不变（关键！）

**双指针模板（荷兰国旗）：**
```typescript
function sortColors(nums: number[]): void {
    let left = 0;
    let right = nums.length - 1;
    let i = 0;

    while (i <= right) {
        if (nums[i] === 0) {
            [nums[i], nums[left]] = [nums[left], nums[i]];
            left++;
            i++;
        } else if (nums[i] === 2) {
            [nums[i], nums[right]] = [nums[right], nums[i]];
            right--;
            // i不变！
        } else {
            i++;
        }
    }
}
```

- 交换后忘记更新指针

**记忆技巧：**
- 荷兰国旗 = 三种颜色 = 三个区间
- 遇到0/1向右走，遇到2停下来
- i <= right（=号很重要）
- 时间O(n)，空间O(1)，一趟扫描
- 三路快排的应用
