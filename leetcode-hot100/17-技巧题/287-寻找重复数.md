# 287. 寻找重复数【中等】

## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有**一个重复的整数**，返回**这个重复的数**。

你设计的解决方案必须**不修改**数组 `nums` 且只用常量级 `O(1)` 的额外空间。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,3,4,2,2]
输出：2
```

### 示例 2
```
输入：nums = [3,1,3,4,2]
输出：3
```

### 示例 3
```
输入：nums = [3,3,3,3,3]
输出：3
```

### 提示
- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个整数出现两次或多次，其余整数均只出现一次

**进阶：**
- 如何证明 `nums` 中至少存在一个重复的数字？
- 你可以设计一个线性级时间复杂度 `O(n)` 的解决方案吗？

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题特点：**
```
n+1 个数字，范围 [1, n]
鸽笼原理：至少有一个重复

限制条件：
1. 不能修改数组
2. 空间复杂度 O(1)
3. 时间复杂度最好 O(n)

这些限制排除了：
- 排序（修改数组）
- 哈希表（空间O(n)）
- 标记法（修改数组）
```

**巧妙解法：**
```
将数组看作链表：
nums[i] 的值作为下一个节点的索引

例如：[1, 3, 4, 2, 2]
索引： 0  1  2  3  4
值：   1  3  4  2  2

链表：0 → 1 → 3 → 2 → 4 → 2（环）
                  ↑_______↓

有重复数字 = 链表有环
找重复数 = 找环的入口
```

---

### 方法一：快慢指针（Floyd判圈算法）

**核心思想：**
- 快慢指针找环
- 类似 142. 环形链表 II

**算法流程：**

1. **第一阶段：快慢指针找相遇点**
   - slow 每次走1步
   - fast 每次走2步
   - 在环内相遇

2. **第二阶段：找环的入口**
   - slow 回到起点
   - fast 留在相遇点
   - 两者同时每次走1步
   - 再次相遇的点就是环的入口（重复数字）

**数学原理：**
```
设：
a = 起点到环入口的距离
b = 环入口到相遇点的距离
c = 相遇点到环入口的距离（环的其余部分）
环长 = b + c

第一次相遇：
slow走的距离：a + b
fast走的距离：a + b + n(b + c)（n为fast在环中多走的圈数）

fast走的距离是slow的2倍：
2(a + b) = a + b + n(b + c)
a + b = n(b + c)
a = n(b + c) - b
a = (n-1)(b + c) + c

意义：
从起点走a步 = 从相遇点走c + (n-1)圈
都会到达环入口
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

---

### 方法二：二分查找

**核心思想：**
- 二分答案
- 统计小于等于 mid 的数字个数

**算法流程：**

1. **二分范围 [1, n]**

2. **对于每个 mid：**
   - 统计 nums 中 <= mid 的数字个数 count
   - 如果 count > mid：重复数字在 [1, mid]
   - 如果 count <= mid：重复数字在 [mid+1, n]

3. **返回最终的 left**

**原理：**
```
如果没有重复：
<= mid 的数字个数 = mid

如果有重复：
重复数字在 [1, mid] → count > mid
重复数字在 [mid+1, n] → count <= mid
```

**时间复杂度：** O(nlogn)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 方法一：快慢指针（推荐，O(n)）

```typescript
function findDuplicate(nums: number[]): number {
    // 第一阶段：快慢指针找相遇点
    let slow = nums[0];
    let fast = nums[0];

    do {
        slow = nums[slow];       // 走1步
        fast = nums[nums[fast]]; // 走2步
    } while (slow !== fast);

    // 第二阶段：找环的入口
    slow = nums[0];

    while (slow !== fast) {
        slow = nums[slow];
        fast = nums[fast];
    }

    return slow;
}
```

**详细注释版本：**

```typescript
function findDuplicate(nums: number[]): number {
    // 将数组看作链表：nums[i] 指向 nums[nums[i]]
    // 有重复数字 → 链表有环
    // 找重复数字 → 找环的入口

    // 第一阶段：快慢指针找相遇点
    let slow = nums[0];
    let fast = nums[0];

    // 先走一步，然后判断（do-while）
    do {
        slow = nums[slow];       // slow 走1步
        fast = nums[nums[fast]]; // fast 走2步
    } while (slow !== fast);

    // 此时 slow 和 fast 在环内相遇

    // 第二阶段：找环的入口
    // slow 回到起点，fast 留在相遇点
    slow = nums[0];

    // 两者同时每次走1步
    while (slow !== fast) {
        slow = nums[slow];
        fast = nums[fast]; // 注意：这里fast也是走1步
    }

    // 再次相遇的点就是环的入口（重复数字）
    return slow;
}
```

### 方法二：二分查找

```typescript
function findDuplicate(nums: number[]): number {
    let left = 1;
    let right = nums.length - 1;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);

        // 统计 <= mid 的数字个数
        let count = 0;
        for (const num of nums) {
            if (num <= mid) {
                count++;
            }
        }

        // 根据鸽笼原理
        if (count > mid) {
            // 重复数字在 [1, mid]
            right = mid;
        } else {
            // 重复数字在 [mid+1, n]
            left = mid + 1;
        }
    }

    return left;
}
```

### 方法三：位运算（不推荐，复杂）

```typescript
function findDuplicate(nums: number[]): number {
    const n = nums.length - 1;
    let result = 0;

    // 对每一位进行统计
    for (let bit = 0; bit < 32; bit++) {
        let countNums = 0;
        let countRange = 0;

        for (let i = 0; i < nums.length; i++) {
            // 统计 nums 中第 bit 位为1的个数
            if ((nums[i] & (1 << bit)) !== 0) {
                countNums++;
            }

            // 统计 [1, n] 中第 bit 位为1的个数
            if (i >= 1 && (i & (1 << bit)) !== 0) {
                countRange++;
            }
        }

        // 如果 nums 中的1更多，说明重复数字的这一位是1
        if (countNums > countRange) {
            result |= (1 << bit);
        }
    }

    return result;
}
```

## 代码原理详解

### 快慢指针详解

**1. 为什么可以看作链表？**

```
数组：[1, 3, 4, 2, 2]
索引：  0  1  2  3  4

链表视角：
0 → nums[0]=1 → nums[1]=3 → nums[3]=2 → nums[2]=4 → nums[4]=2
                                ↑                        ↓
                                └────────────────────────┘

有环！环的入口是索引2，值是2
```

**2. 为什么有重复就有环？**

```
n+1 个数字，范围 [1, n]
鸽笼原理：至少有一个数字出现2次

假设数字k出现2次：
nums[i] = k
nums[j] = k （i ≠ j）

链表中：
两个不同的节点都指向索引k
→ 形成环
→ 环的入口是k
```

**3. Floyd判圈算法原理：**

```
第一阶段：找相遇点
slow 走1步，fast 走2步
在环内某处相遇

第二阶段：找环入口
slow 回到起点
两者都走1步
再次相遇点 = 环入口

数学证明：
设起点到环入口距离为a
环入口到相遇点距离为b
相遇点到环入口距离为c

相遇时：
slow: a + b
fast: a + b + n(b + c)

2(a + b) = a + b + n(b + c)
a = (n-1)(b + c) + c

从起点走a步 = 从相遇点走c步（+ n-1圈）
都到达环入口
```

---

### 二分查找详解

**1. 为什么可以二分？**

```
数字范围：[1, n]
数组长度：n+1

鸽笼原理：
如果没有重复，<= mid 的数字最多有 mid 个

如果有重复：
重复数字 <= mid → count > mid
重复数字 > mid → count <= mid

满足二分的单调性
```

**2. 执行示例：**

```
nums = [1, 3, 4, 2, 2]
n = 4

left=1, right=4, mid=2
count(<= 2) = 3（1, 2, 2）
3 > 2 → right=2

left=1, right=2, mid=1
count(<= 1) = 1（1）
1 <= 1 → left=2

left=2, right=2
返回 2 ✓
```

## 运行示例

### 示例 1：`nums = [1,3,4,2,2]`

**快慢指针：**

```
链表：0 → 1 → 3 → 2 → 4 → 2（环）
                  ↑_______↓

第一阶段：找相遇点
slow=0, fast=0
do {
  slow=nums[0]=1, fast=nums[nums[0]]=nums[1]=3
  slow=nums[1]=3, fast=nums[nums[3]]=nums[2]=4

slow=0, fast=4

```

```
left=1, right=4

```

## 常见问题

**Q1: 为什么fast初始也是nums[0]？**
A: 统一起点：
```
如果fast从nums[nums[0]]开始：
需要特殊处理空链表

从nums[0]开始：
使用do-while，先走再判断
代码更简洁
```

**Q2: 第二阶段为什么fast也走1步？**
A: 数学推导的结果：
```
从起点走a步 = 从相遇点走c步
都是每次1步

如果fast还是走2步，无法保证相遇
```

**Q3: 二分查找的边界条件？**
A: 左闭右开：
```
left = 1（最小值）
right = n（最大值）

循环：left < right
更新：right = mid 或 left = mid + 1

返回：left
```

**Q4: 能用异或吗？**
A: 不能：
```
异或只能找出现1次的数字
本题其他数字也可能出现1次

例如：[1, 3, 4, 2, 2]
异或结果不是2
```

**Q5: 如果有多个重复数字呢？**
A: 快慢指针失效：
```
可能有多个环
Floyd算法找到一个环入口
不一定是题目要求的

本题保证只有一个数字重复
```

## 总结

**关键点：**
1. 将数组看作链表：nums[i] 指向 nums[nums[i]]
2. 有重复 = 有环，找重复 = 找环入口
3. Floyd判圈算法：
   - 第一阶段：快慢指针找相遇点
   - 第二阶段：同时走1步找环入口
4. 二分查找：统计 <= mid 的个数
5. 满足所有限制：O(n) 时间，O(1) 空间，不修改数组

**快慢指针模板：**
```typescript
function findDuplicate(nums: number[]): number {
    // 第一阶段：找相遇点
    let slow = nums[0];
    let fast = nums[0];

    do {
        slow = nums[slow];
        fast = nums[nums[fast]];
    } while (slow !== fast);

    // 第二阶段：找环入口
    slow = nums[0];

    while (slow !== fast) {
        slow = nums[slow];
        fast = nums[fast];
    }

    return slow;
}
```
