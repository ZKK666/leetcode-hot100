# 25. K 个一组翻转链表【困难】

## 题目描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

## 解题思路（面试推荐 - 最优解）

### 方法：分组反转

**核心思想：**
1. 检查剩余节点是否足够k个
2. 如果足够，反转这k个节点
3. 连接反转后的链表段
4. 重复直到节点不足k个

**关键步骤：**
```
原链表：1 → 2 → 3 → 4 → 5, k=2

分组：
  [1,2] → [3,4] → [5]

反转每组（5不足k个，保持原样）：
  [2,1] → [4,3] → [5]

连接：
  2 → 1 → 4 → 3 → 5
```

**为什么需要记录多个指针？**
```
反转一组需要记录：
- prev: 前一组的尾部（用于连接）
- start: 当前组的第一个节点（反转后成为尾部）
- end: 当前组的最后一个节点（反转后成为头部）
- next: 下一组的第一个节点（保存引用）

连接关系：
  prev → end(反转后的头) → ... → start(反转后的尾) → next
```

**算法流程：**
1. 创建哑节点
2. 循环处理每一组：
   - 检查是否还有k个节点
   - 反转这k个节点
   - 连接前后
   - 移动到下一组
3. 返回dummy.next

**时间复杂度：** O(n) - 每个节点访问2次（检查+反转）
**空间复杂度：** O(1) - 只用几个指针

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function reverseKGroup(head: ListNode | null, k: number): ListNode | null {
    // 哑节点，简化边界处理
    const dummy = new ListNode(0);
    dummy.next = head;

    // prev指向当前要反转的组的前一个节点
    let prev = dummy;

    while (true) {
        // 检查剩余节点是否足够k个
        // 同时找到当前组的最后一个节点（第k个）
        let end = prev;
        for (let i = 0; i < k; i++) {
            end = end.next;
            if (end === null) {
                // 不足k个，直接返回
                return dummy.next;
            }
        }

        // 记录当前组的第一个节点和下一组的第一个节点
        const start = prev.next;       // 当前组的第一个（反转后成为尾）
        const next = end.next;         // 下一组的第一个

        // 反转当前组的k个节点
        // 返回反转后的新头（原来的end）
        const newStart = reverseList(start, end);

        // 连接前一组和反转后的当前组
        prev.next = newStart;          // prev指向反转后的头

        // 连接当前组和下一组
        start.next = next;             // start现在是尾，连接到next

        // 移动prev到当前组的尾部（即start），准备处理下一组
        prev = start;
    }
}

/**
 * 反转从start到end的链表（包含start和end）
 * 返回反转后的新头节点
 */
function reverseList(start: ListNode | null, end: ListNode | null): ListNode | null {
    let prev: ListNode | null = null;
    let curr: ListNode | null = start;

    // 反转到end为止（包含end）
    while (prev !== end) {
        const next = curr!.next;
        curr!.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;  // 返回新的头节点（原来的end）
}
```

## 代码原理详解

### 核心逻辑

1. **检查是否有k个节点**：
   ```typescript
   let end = prev;
   for (let i = 0; i < k; i++) {
       end = end.next;
       if (end === null) {
           return dummy.next;  // 不足k个，结束
       }
   }
   // end现在指向第k个节点
   ```

2. **记录关键节点**：
   ```typescript
   const start = prev.next;   // 第1个（反转后成为尾）
   const next = end.next;     // 第k+1个（下一组的头）
   ```

3. **反转k个节点**：
   ```typescript
   const newStart = reverseList(start, end);
   // newStart是反转后的头（原来的end）
   ```

4. **连接三部分**：
   ```typescript
   prev.next = newStart;      // 前一组 → 当前组头
   start.next = next;         // 当前组尾 → 下一组
   prev = start;              // 移动prev到当前组尾
   ```

### 反转函数详解

```typescript
function reverseList(start, end) {
    let prev = null;
    let curr = start;

    // 循环条件：prev !== end
    // 当prev == end时，说明end已经反转完成
    while (prev !== end) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;  // prev就是原来的end
}
```

**为什么条件是 `prev !== end`？**
- 当prev == end时，end已经被反转
- 此时curr指向下一组的第一个节点（或null）
- 返回prev（即end）作为反转后的头

### 设计思路

- **分组处理**：每k个一组
- **原地反转**：复用链表节点
- **记录关键点**：prev、start、end、next
- **连接管理**：维护前后组的连接

## 常见问题

**Q1: 为什么反转函数的条件是 `while (prev !== end)` 而不是 `while (curr !== null)`？**
A: 因为我们只需要反转从start到end的节点，不能反转end之后的节点。
```typescript
// 如果用 while (curr !== null)：
// 会反转整个链表，而不是只反转k个

// 用 while (prev !== end)：
// 当prev == end时，end已被反转，停止
```

**Q2: 如果k等于1怎么办？**
A: 每组只有1个节点，不需要反转，直接返回原链表。算法仍然正确，但效率较低。

**Q3: 能否用递归实现？**
A: 可以，但递归深度是n/k，可能栈溢出。迭代更稳定。

```typescript
function reverseKGroup(head: ListNode | null, k: number): ListNode | null {
    // 检查是否有k个节点
    let curr = head;
    for (let i = 0; i < k; i++) {
        if (curr === null) return head;
        curr = curr.next;
    }

    // 反转前k个节点
    let prev: ListNode | null = null;
    curr = head;
    for (let i = 0; i < k; i++) {
        const next = curr!.next;
        curr!.next = prev;
        prev = curr;
        curr = next;
    }

    // 递归处理剩余部分
    head!.next = reverseKGroup(curr, k);

    return prev;
}
```

**Q4: 为什么要保存next？**
A: 因为反转后，start.next会变，需要提前保存下一组的头节点。

## 边界情况

### 情况1：k = 1

```
输入: head = [1,2,3,4,5], k = 1
输出: [1,2,3,4,5]
说明：每组1个，不需要反转
```

### 情况2：k = n（链表长度）

```
输入: head = [1,2,3,4,5], k = 5
输出: [5,4,3,2,1]
说明：整个链表反转
```

### 情况3：只有一组

```
输入: head = [1,2], k = 2
输出: [2,1]
```

### 情况4：最后一组不足k个

```
输入: head = [1,2,3,4,5], k = 3
输出: [3,2,1,4,5]
说明：最后2个节点保持原样
```

## 复杂度分析

### 时间复杂度：O(n)
- n是链表长度
- 检查每个节点：O(n)
- 反转每个节点：O(n)
- 总共：O(2n) = O(n)

### 空间复杂度：O(1)
- 只用了几个指针变量
- 没有使用额外的数据结构

## 总结

**关键点：**
1. 分组处理：每k个一组
2. 检查剩余：不足k个保持原样
3. 记录四个关键指针：prev、start、end、next
4. 反转范围：从start到end（包含）
5. 连接管理：前组→当前组→后组

**面试建议：**
- 先讲清楚整体思路（分组+反转+连接）
- 画图演示指针移动过程
- 强调边界情况（不足k个）
- 说明反转函数的终止条件
- 可以先实现k=2，再推广到任意k

**易错点：**
- 反转范围不对（反转了太多或太少）
- 连接顺序错误（丢失节点引用）
- 忘记移动prev
- 最后一组处理不当
