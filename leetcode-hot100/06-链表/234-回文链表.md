# 234. 回文链表【简单】

## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

---

## 输入输出示例

### 示例 1
```
输入：head = [1,2,2,1]
输出：true
```

![示例1](https://assets.leetcode.com/uploads/2021/03/03/pal1linked-list.jpg)

### 示例 2
```
输入：head = [1,2]
输出：false
```

![示例2](https://assets.leetcode.com/uploads/2021/03/03/pal2linked-list.jpg)

### 提示
- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶**：你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

---

## 解题思路（面试推荐 - 最优解）

### 方法：快慢指针 + 反转后半部分

**核心思想：**
1. 使用快慢指针找到链表中点
2. 反转后半部分链表
3. 比较前半部分和反转后的后半部分
4. （可选）恢复链表

**为什么这样做？**
```
回文链表的特点：前半部分和后半部分对称

例如：1 → 2 → 3 → 2 → 1
前半：1 → 2 → 3
后半：2 → 1

反转后半：1 → 2
比较：1→2→3 和 1→2，前两个节点相同 ✓
```

**算法流程：**
1. 快慢指针找中点：快指针走2步，慢指针走1步
2. 反转后半部分链表
3. 双指针从头和中点同时遍历比较
4. 如果所有值相等，是回文

**时间复杂度：** O(n) - 遍历链表常数次
**空间复杂度：** O(1) - 只用几个指针

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function isPalindrome(head: ListNode | null): boolean {
    if (head === null || head.next === null) {
        return true;
    }

    // 步骤1：使用快慢指针找到链表中点
    let slow: ListNode | null = head;
    let fast: ListNode | null = head;

    while (fast !== null && fast.next !== null) {
        slow = slow!.next;
        fast = fast.next.next;
    }

    // slow 现在指向中点（奇数长度）或后半部分第一个节点（偶数长度）

    // 步骤2：反转后半部分链表
    let secondHalf = reverseList(slow);

    // 步骤3：比较前半部分和反转后的后半部分
    let firstHalf: ListNode | null = head;
    let secondHalfCopy = secondHalf; // 保存用于恢复

    let result = true;
    while (result && secondHalf !== null) {
        if (firstHalf!.val !== secondHalf.val) {
            result = false;
        }
        firstHalf = firstHalf!.next;
        secondHalf = secondHalf.next;
    }

    // 步骤4：（可选）恢复链表
    // reverseList(secondHalfCopy);

    return result;
}

/**
 * 反转链表的辅助函数
 */
function reverseList(head: ListNode | null): ListNode | null {
    let prev: ListNode | null = null;
    let curr: ListNode | null = head;

    while (curr !== null) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
}
```

## 代码原理详解

### 核心逻辑

1. **找中点（快慢指针）**：
   ```
   奇数长度：1 → 2 → 3 → 2 → 1
            slow最终指向3（中点）

   偶数长度：1 → 2 → 2 → 1
            slow最终指向后半部分的第一个2

   规则：fast走2步，slow走1步
        当fast到达末尾，slow到达中点
   ```

2. **反转后半部分**：
   ```
   原链表：1 → 2 → 3 → 2 → 1
            ↑       ↑
          head    slow

   反转后：1 → 2 → 3 ← 2 ← 1
                       ↑
                  secondHalf
   ```

3. **双指针比较**：
   ```
   firstHalf从头开始：1 → 2 → 3
   secondHalf从中点开始：1 → 2（反转后）

   逐个比较值是否相等
   ```

4. **为什么不需要比较所有节点？**
   - 奇数长度：中间节点不需要比较（自己和自己对称）
   - 偶数长度：后半部分比完就够了

### 设计思路

- **找中点**：快慢指针技巧
- **反转**：利用链表反转
- **比较**：双指针同时遍历
- **空间优化**：原地操作，不使用额外空间

## 运行示例

### 示例 1：`head = [1,2,2,1]`

**执行过程：**

```
初始链表: 1 → 2 → 2 → 1

步骤1：找中点
  slow = 1, fast = 1

  迭代1:
    slow = 2 (head.next)
    fast = 2 (head.next.next)

  迭代2:
    slow = 2（第二个2）
    fast = null (第二个2.next.next)

  循环结束，slow指向第二个2

步骤2：反转后半部分（从第二个2开始）
  原链表：1 → 2 → 2 → 1
  反转：2 → 1 变成 1 → 2

  secondHalf指向反转后的链表：1 → 2

步骤3：比较
  firstHalf: 1 → 2 → 2 → 1
  secondHalf: 1 → 2

  比较1：
    firstHalf.val = 1, secondHalf.val = 1 ✓
    移动指针

  比较2：
    firstHalf.val = 2, secondHalf.val = 2 ✓
    移动指针

  secondHalf = null，比较结束

结果: true（所有值都相等）
```

**图示：**
```
原链表：
1 → 2 → 2 → 1
↑       ↑
头     中点

反转后半部分：
前半：1 → 2 →
后半：      ← 2 ← 1
            ↑
        secondHalf

比较：
1 == 1 ✓
2 == 2 ✓
```

### 示例 3：`head = [1,2,3,2,1]`（奇数长度）

```
初始链表: 1 → 2 → 3 → 2 → 1

步骤1：找中点
  最终 slow 指向 3（中间节点）

步骤2：反转后半部分（从3开始）
  3 → 2 → 1 反转为 1 → 2 → 3

步骤3：比较
  firstHalf: 1 → 2 → 3
  secondHalf: 1 → 2 → 3

  比较1: 1 == 1 ✓
  比较2: 2 == 2 ✓
  比较3: 3 == 3 ✓

结果: true
```

**关键观察**：奇数长度时，中间节点在两边都被比较了，但不影响结果。

## 常见问题

**Q1: 为什么快指针走2步，慢指针走1步能找到中点？**
A: 当快指针到达末尾时，慢指针恰好走了一半的距离。
```
长度为n的链表：
- 快指针走了n步（每次2步，走n/2次）
- 慢指针走了n/2步（每次1步，走n/2次）
- 慢指针正好在中点
```

**Q2: 奇数和偶数长度有什么区别？**
A:
- **奇数长度**：slow指向正中间节点（如5个节点的第3个）
- **偶数长度**：slow指向后半部分第一个节点（如4个节点的第3个）

两种情况下算法都正确工作。

**Q3: 需要恢复链表吗？**
A: 看题目要求。如果要求不修改原链表，需要在返回前再次反转后半部分恢复。但通常不要求。

**Q4: 如果允许使用额外空间，有更简单的方法吗？**
A: 有，可以用数组或栈：
```typescript
function isPalindrome(head: ListNode | null): boolean {
    const values: number[] = [];
    let curr = head;

    // 存储所有值
    while (curr !== null) {
        values.push(curr.val);
        curr = curr.next;
    }

    // 双指针比较
    let left = 0, right = values.length - 1;
    while (left < right) {
        if (values[left] !== values[right]) {
            return false;
        }
        left++;
        right--;
    }

    return true;
}
```
但这需要 O(n) 空间，不如 O(1) 优。

## 其他解法（了解）

### 方法二：递归（空间 O(n)）

```typescript
function isPalindrome(head: ListNode | null): boolean {
    let frontPointer: ListNode | null = head;

    function recursiveCheck(currentNode: ListNode | null): boolean {
        if (currentNode !== null) {
            // 递归到最后
            if (!recursiveCheck(currentNode.next)) {
                return false;
            }
            // 回溯时比较
            if (currentNode.val !== frontPointer!.val) {
                return false;
            }
            frontPointer = frontPointer!.next;
        }
        return true;
    }

    return recursiveCheck(head);
}
```

**优点**：代码优雅
**缺点**：递归栈空间 O(n)

## 边界情况

### 情况1：空链表或单节点

```
输入: null 或 [1]
输出: true（空和单节点都是回文）
```

### 情况2：两节点

```
输入: [1,1]
输出: true

输入: [1,2]
输出: false
```

### 情况3：所有节点值相同

```
输入: [1,1,1,1,1]
输出: true（所有值相同，一定是回文）
```
