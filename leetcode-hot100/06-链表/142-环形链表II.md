# 142. 环形链表 II【中等】

## 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**不允许修改**链表。

## 解题思路（面试推荐 - 最优解）

### 方法：快慢指针 + 数学推导

**核心思想：**
1. 先用快慢指针判断是否有环（同141题）
2. 如果有环，找到相遇点后，利用数学关系找到环的入口

**数学推导：**
```
设：
- 链表头到环入口的距离为 a
- 环入口到相遇点的距离为 b
- 相遇点到环入口的距离为 c
- 环的长度为 b + c

链表结构：
head → ... → 环入口 → ... → 相遇点 → ... → 环入口
     (a步)         (b步)         (c步)

快慢指针相遇时：
- 慢指针走了：a + b
- 快指针走了：a + b + n(b + c)  [n为快指针在环内多转的圈数]

由于快指针速度是慢指针的2倍：
  2(a + b) = a + b + n(b + c)
  2a + 2b = a + b + n(b + c)
  a + b = n(b + c)
  a = n(b + c) - b
  a = (n-1)(b + c) + c

关键结论：
  a = c + (n-1) × 环长

当 n=1 时（快指针只多转了1圈）：
  a = c

这意味着：
- 从head到环入口的距离 = 从相遇点到环入口的距离
```

**算法流程：**
1. 快慢指针找相遇点
2. 一个指针从head出发，一个从相遇点出发，每次都走1步
3. 两个指针相遇的地方就是环的入口

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function detectCycle(head: ListNode | null): ListNode | null {
    // 步骤1：判断是否有环，找到相遇点
    let slow: ListNode | null = head;
    let fast: ListNode | null = head;

    // 快慢指针找相遇点
    while (fast !== null && fast.next !== null) {
        slow = slow!.next;          // 慢指针走1步
        fast = fast.next.next;      // 快指针走2步

        // 相遇，说明有环
        if (slow === fast) {
            // 步骤2：找环的入口
            // 一个指针从head开始，一个从相遇点开始
            let ptr1: ListNode | null = head;
            let ptr2: ListNode | null = slow;

            // 两个指针同时走，相遇点就是环入口
            while (ptr1 !== ptr2) {
                ptr1 = ptr1!.next;
                ptr2 = ptr2!.next;
            }

            // 返回环的入口节点
            return ptr1;
        }
    }

    // 快指针到达末尾，无环
    return null;
}
```

## 代码原理详解

### 核心逻辑

1. **阶段一：检测环并找相遇点**
   ```typescript
   while (fast !== null && fast.next !== null) {
       slow = slow.next;
       fast = fast.next.next;
       if (slow === fast) {
           // 找到相遇点，进入阶段二
       }
   }
   ```

2. **阶段二：找环的入口**
   ```typescript
   let ptr1 = head;           // 从头开始
   let ptr2 = slow;           // 从相遇点开始

   while (ptr1 !== ptr2) {
       ptr1 = ptr1.next;      // 都走1步
       ptr2 = ptr2.next;
   }

   return ptr1;               // 相遇点就是环入口
   ```

3. **为什么这样可以找到环入口？**
   - 根据数学推导：a = c（当n=1时）
   - head到环入口的距离 = 相遇点到环入口的距离
   - 所以两个指针同速度走，必在环入口相遇

### 设计思路

- **两阶段算法**：先检测环，再找入口
- **数学关系**：利用距离关系巧妙找到入口
- **空间最优**：只用几个指针，O(1)空间

## 运行示例

### 示例 1：`head = [3,2,0,-4], pos = 1`

**链表结构：**
```
3 → 2 → 0 → -4
    ↑        ↓
    ←←←←←←←←

a = 1 (3到2的距离)
b = 2 (2到-4的距离，经过0)
c = 1 (-4到2的距离)
环长 = b + c = 3
```

**执行过程：**

```
阶段1：快慢指针找相遇点

初始: slow=3, fast=3

迭代1:
  slow = 2 (走1步)
  fast = 0 (走2步: 3→2→0)
  不相等，继续

迭代2:
  slow = 0 (走1步)
  fast = 2 (走2步: 0→-4→2)
  不相等，继续

迭代3:
  slow = -4 (走1步)
  fast = -4 (走2步: 2→0→-4)
  相等！相遇点是 -4

阶段2：找环入口

  ptr1 = head (节点3)
  ptr2 = slow (节点-4)

  迭代1:
    ptr1 = 2 (走1步)
    ptr2 = 2 (走1步: -4→2)
    相等！环入口是 节点2

返回: 节点2（索引1）
```

**图示：**
```

3 → 2 → 0 → -4
    ↑       ↓
    ←←←←←←←

slow路径: 3 → 2 → 0 → -4 (3步后相遇)
fast路径: 3 → 0 → 2 → -4 (3次迭代，走6步)

阶段2寻找入口：
ptr1从3出发，走1步到2
ptr2从-4出发，走1步到2
在2相遇！
```

**验证数学关系：**
```
a = 1 (head到环入口)
c = 1 (相遇点到环入口)
```

## 数学证明详解

**完整推导：**

```
设链表结构：
  head → [非环部分，长度a] → 环入口 → [环部分]

环的长度为L

快慢指针相遇时：
  设慢指针在环内走了k步（从环入口算起）

  慢指针总路程：a + k
  快指针总路程：a + k + nL  (n为快指针比慢指针多转的整圈数)

  由于快指针速度是慢指针2倍：
    2(a + k) = a + k + nL
    a + k = nL
    a = nL - k
    a = (n-1)L + (L - k)

  记 c = L - k（从相遇点到环入口的距离）
  则 a = (n-1)L + c

  这意味着：
    从head到环入口的距离 = 从相遇点到环入口的距离 + 若干整圈

  因此，从head和相遇点同时出发，每次走1步：
    - ptr1走a步到环入口
    - ptr2走a步 = c + (n-1)L步 = 也到环入口（因为走了c到入口，然后绕了n-1圈，还在入口）

  所以它们会在环入口相遇！
```

## 常见问题

**Q1: 为什么第二阶段两个指针都走1步？**
A: 因为数学关系保证了head到环入口的距离 等于 相遇点到环入口的距离（模环长）。同速走保证在环入口相遇。

**Q2: 如果不用数学推导，有其他方法吗？**
A: 可以用HashSet记录访问过的节点，第一个重复访问的就是环入口。但需要O(n)空间。

```typescript
function detectCycle(head: ListNode | null): ListNode | null {
    const visited = new Set<ListNode>();
    let curr = head;

    while (curr !== null) {
        if (visited.has(curr)) {
            return curr;  // 第一个重复的就是环入口
        }
        visited.add(curr);
        curr = curr.next;
    }

    return null;
}
```

**Q3: 为什么说快指针可能多转n圈？**
A: 因为在相遇前，快指针在环内转圈，慢指针刚进入环。快指针转的圈数取决于链表结构。

**Q4: 这个算法有什么局限性吗？**
A: 没有。这是检测环和找环入口的最优算法，时间O(n)，空间O(1)。
