# 160. 相交链表【简单】

## 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

题目数据 **保证** 整个链式结构中不存在环。

**注意**，函数返回结果后，链表必须 **保持其原始结构**。

---

## 输入输出示例

### 示例 1
```
输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：Intersected at '8'
```

```
输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1

```

### 示例 3
```
输入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
输出：null
```

### 提示
- `listA` 中节点数目为 `m`
- `listB` 中节点数目为 `n`
- `1 <= m, n <= 3 * 10^4`
- `1 <= Node.val <= 10^5`
- `0 <= skipA < m`
- `0 <= skipB < n`

**进阶**：你能否设计一个时间复杂度 `O(m + n)`、仅用 `O(1)` 内存的解决方案？

## 解题思路（面试推荐 - 最优解）

### 方法：双指针（消除长度差）

**核心思想：**
- 两个指针分别从headA和headB开始遍历
- 当指针到达末尾时，重定向到另一个链表的头部
- 两个指针会在相交点相遇，或同时到达null

**为什么这样做？**
```
链表A: a1 → a2 → c1 → c2 → c3
链表B: b1 → b2 → b3 → c1 → c2 → c3

指针pA: a1 → a2 → c1 → c2 → c3 → null → b1 → b2 → b3 → c1
指针pB: b1 → b2 → b3 → c1 → c2 → c3 → null → a1 → a2 → c1

pA走的距离: (a的独立部分) + (公共部分) + (b的独立部分)
pB走的距离: (b的独立部分) + (公共部分) + (a的独立部分)

两者距离相等，所以会在公共部分的起点相遇！
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function getIntersectionNode(headA: ListNode | null, headB: ListNode | null): ListNode | null {
    // 边界情况：任一链表为空
    if (!headA || !headB) return null;

    // 两个指针分别从两个链表头部开始
    let pA: ListNode | null = headA;
    let pB: ListNode | null = headB;

    // 当两个指针相遇时停止
    while (pA !== pB) {
        // pA到达末尾后，重定向到headB；否则继续前进
        pA = pA === null ? headB : pA.next;

        // pB到达末尾后，重定向到headA；否则继续前进
        pB = pB === null ? headA : pB.next;
    }

    // pA和pB相遇的节点就是相交节点（可能是null）
    return pA;
}
```

## 代码原理详解

### 核心逻辑

1. **双指针遍历**：
   - pA从headA开始，pB从headB开始
   - 同时向后移动

2. **重定向机制**：
   - pA到达null后，跳到headB
   - pB到达null后，跳到headA

3. **相遇条件**：
   - 如果有相交：在相交节点相遇
   - 如果无相交：都会到达null，pA === pB === null

4. **数学证明**：
   ```
   设A的独立长度为a，B的独立长度为b，公共长度为c

   pA路径: a + c + b
   pB路径: b + c + a

   长度相等，所以同时到达相交点
   ```

### 设计思路

- **消除长度差**：通过切换链表，使两指针走相同距离
- **优雅简洁**：代码只有几行，逻辑清晰
- **无需额外空间**：只用两个指针

## 运行示例

### 示例 1：有相交

```
链表A: 4 → 1 → 8 → 4 → 5
链表B: 5 → 6 → 1 → 8 → 4 → 5
相交点: 8

执行过程:
  步骤  pA指向  pB指向
  0     4       5
  1     1       6
  2     8       1
  3     4       8     ← pB到达相交点
  4     5       4
  5     null    5
  6     5(B头)  null
  7     6       4(A头)
  8     1       1
  9     8       8     ← 相遇！

返回: 节点8
```

### 示例 2：无相交

```
链表A: 2 → 6 → 4
链表B: 1 → 5

执行过程:
  步骤  pA      pB
  0     2       1
  1     6       5
  2     4       null
  3     null    1(A头)
  4     1(B头)  2
  5     5       6
  6     null    4
  7     null    null  ← 同时为null，相遇！

返回: null
```

## 常见问题

**Q1: 为什么要重定向到另一个链表？**
A: 为了消除两链表的长度差。走完自己的链表后，走对方的链表，最终走过的总长度相等。

**Q2: 如果两链表长度相同，还需要重定向吗？**
A: 算法仍然有效。如果长度相同且有相交，第一次遍历就会相遇；如果无相交，同时到达null。

**Q3: 能否用HashSet？**
A: 可以，但需要O(m)或O(n)空间。双指针更优。

**Q4: 如果链表有环怎么办？**
A: 题目保证无环。如果有环，此算法会陷入死循环。

## 其他解法（了解）

### 方法二：HashSet

```typescript
function getIntersectionNode(headA: ListNode | null, headB: ListNode | null): ListNode | null {
    const set = new Set<ListNode>();

    // 遍历链表A，存入set
    let curr = headA;
    while (curr) {
        set.add(curr);
        curr = curr.next;
    }

    // 遍历链表B，查找第一个在set中的节点
    curr = headB;
    while (curr) {
        if (set.has(curr)) {
            return curr;
        }
        curr = curr.next;
    }

    return null;
}
```

**时间复杂度**：O(m + n)
**空间复杂度**：O(m)

### 方法三：计算长度差

```typescript
function getIntersectionNode(headA: ListNode | null, headB: ListNode | null): ListNode | null {
    // 计算两链表长度
    const lenA = getLength(headA);
    const lenB = getLength(headB);

    // 让长的链表先走差值步
    let pA = headA;
    let pB = headB;

    if (lenA > lenB) {
        for (let i = 0; i < lenA - lenB; i++) {
            pA = pA!.next;
        }
    } else {
        for (let i = 0; i < lenB - lenA; i++) {
            pB = pB!.next;
        }
    }

    // 同时前进，找相交点
    while (pA !== pB) {
        pA = pA!.next;
        pB = pB!.next;
    }

    return pA;
}

function getLength(head: ListNode | null): number {
    let len = 0;
    while (head) {
        len++;
        head = head.next;
    }
    return len;
}
```

**时间复杂度**：O(m + n)
**空间复杂度**：O(1)
**缺点**：代码更长，需要额外函数
