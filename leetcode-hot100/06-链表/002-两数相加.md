# 2. 两数相加【中等】

## 题目描述

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

---

## 输入输出示例

### 示例 1
```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807
```

![示例1](https://assets.leetcode.com/uploads/2020/10/02/addtwonumber1.jpg)

### 示例 2
```
输入：l1 = [0], l2 = [0]
输出：[0]
```

### 示例 3
```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
解释：9999999 + 9999 = 10009998
```

### 提示
- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 解题思路（面试推荐 - 最优解）

### 方法：模拟加法过程

**核心思想：**
- 模拟小学加法：从个位开始逐位相加
- 处理进位：当两位数字相加 >= 10 时，进位到下一位
- 链表已经是逆序存储，正好符合从低位到高位相加的顺序

**为什么逆序存储更方便？**
```
正常表示：342 + 465 = 807
需要从右往左加，不方便

逆序链表：2→4→3 + 5→6→4 = 7→0→8
从左往右加，符合遍历顺序！
```

**算法流程：**
1. 创建哑节点作为结果链表的头部
2. 初始化进位carry = 0
3. 同时遍历两个链表：
   - 计算当前位的和 = val1 + val2 + carry
   - 当前位的值 = sum % 10
   - 进位 = sum / 10
4. 处理最后的进位
5. 返回结果链表

**时间复杂度：** O(max(m, n)) - m和n是两个链表的长度
**空间复杂度：** O(max(m, n)) - 结果链表的长度

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
    // 哑节点，简化边界处理
    const dummy = new ListNode(0);
    let current = dummy;

    // 进位，初始为0
    let carry = 0;

    // 遍历两个链表，直到都为null且没有进位
    while (l1 !== null || l2 !== null || carry !== 0) {
        // 获取当前位的值（如果链表已结束，值为0）
        const val1 = l1 !== null ? l1.val : 0;
        const val2 = l2 !== null ? l2.val : 0;

        // 计算当前位的和
        const sum = val1 + val2 + carry;

        // 计算当前位的值和新的进位
        const digit = sum % 10;      // 当前位的值
        carry = Math.floor(sum / 10); // 进位

        // 创建新节点存储当前位的值
        current.next = new ListNode(digit);
        current = current.next;

        // 移动到下一位
        if (l1 !== null) l1 = l1.next;
        if (l2 !== null) l2 = l2.next;
    }

    // 返回结果链表（跳过哑节点）
    return dummy.next;
}
```

## 代码原理详解

### 核心逻辑

1. **哑节点技巧**：
   ```typescript
   const dummy = new ListNode(0);
   let current = dummy;
   // 简化了头节点的处理
   ```

2. **循环条件**：
   ```typescript
   while (l1 !== null || l2 !== null || carry !== 0)
   // 三个条件：
   // - l1还有节点
   // - l2还有节点
   // - 还有进位需要处理
   ```

3. **处理不同长度**：
   ```typescript
   const val1 = l1 !== null ? l1.val : 0;
   const val2 = l2 !== null ? l2.val : 0;
   // 如果某个链表已经结束，当作0处理
   ```

4. **计算和与进位**：
   ```typescript
   const sum = val1 + val2 + carry;
   const digit = sum % 10;           // 当前位：取个位
   carry = Math.floor(sum / 10);     // 进位：取十位

   例如：
   sum = 17
   digit = 7 (17 % 10)
   carry = 1 (17 / 10的整数部分)
   ```

### 设计思路

- **模拟加法**：完全模拟手工加法过程
- **逐位处理**：从低位到高位依次计算
- **进位传递**：每一位的进位影响下一位
- **统一处理**：用0填充较短的链表

## 运行示例

### 示例 1：`l1 = [2,4,3], l2 = [5,6,4]`

**含义：** 342 + 465 = 807

**执行过程：**

```
初始状态：
  l1: 2 → 4 → 3
  l2: 5 → 6 → 4
  carry = 0
  dummy: 0
  current: dummy

步骤1：处理第一位（个位）
  val1 = 2, val2 = 5
  sum = 2 + 5 + 0 = 7
  digit = 7 % 10 = 7
  carry = 7 / 10 = 0

  创建节点：7
  dummy: 0 → 7
  l1 = l1.next (指向4)
  l2 = l2.next (指向6)
  current = current.next (指向7)

步骤2：处理第二位（十位）
  val1 = 4, val2 = 6
  sum = 4 + 6 + 0 = 10
  digit = 10 % 10 = 0
  carry = 10 / 10 = 1

  创建节点：0
  dummy: 0 → 7 → 0
  l1 = l1.next (指向3)
  l2 = l2.next (指向4)
  current = current.next (指向0)

步骤3：处理第三位（百位）
  val1 = 3, val2 = 4
  sum = 3 + 4 + 1 = 8
  digit = 8 % 10 = 8
  carry = 8 / 10 = 0

  创建节点：8
  dummy: 0 → 7 → 0 → 8
  l1 = l1.next (null)
  l2 = l2.next (null)
  current = current.next (指向8)

步骤4：检查循环条件
  l1 = null, l2 = null, carry = 0
  循环结束

返回：dummy.next = 7 → 0 → 8 ✓
```

```
  ↑   ↑   ↑
  个  十  百

```

## 常见问题

**Q1: 为什么要用 `carry !== 0` 作为循环条件之一？**
A: 防止最后一位相加产生进位但链表都已遍历完的情况。
```
例如：[9,9] + [1] = [0,0,1]
最后 9+0+1=10，需要创建新节点存储进位1
```

**Q2: 如果链表是正序存储（高位在前）怎么办？**
A: 那是445题"两数相加II"，有几种方法：
- 先反转链表，计算后再反转回来
- 使用栈先进后出的特性
- 递归处理

**Q3: 如果数字很大超过了整数范围怎么办？**
A: 本题的解法已经是按位处理，不会有整数溢出问题。我们没有把整个数转成整数，而是逐位相加。

**Q4: 能否不创建新链表，复用l1或l2？**
A: 可以，但不推荐：
```typescript
function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
    const dummy = new ListNode(0);
    dummy.next = l1; // 复用l1
    let current = dummy;
    let carry = 0;

    while (l1 !== null || l2 !== null || carry !== 0) {
        const val1 = l1 !== null ? l1.val : 0;
        const val2 = l2 !== null ? l2.val : 0;
        const sum = val1 + val2 + carry;

        if (current.next === null) {
            current.next = new ListNode(sum % 10);
        } else {
            current.next.val = sum % 10;
        }

        carry = Math.floor(sum / 10);
        current = current.next;

        if (l1) l1 = l1.next;
        if (l2) l2 = l2.next;
    }

    return dummy.next;
}
```
但这样代码更复杂，不如创建新链表清晰。

## 复杂度分析

### 时间复杂度：O(max(m, n))
- m是l1的长度，n是l2的长度
- 需要遍历较长链表的所有节点
- 每个节点处理时间O(1)

### 空间复杂度：O(max(m, n))
- 结果链表的长度最多为max(m,n) + 1
- 不计入结果链表的话，额外空间O(1)

## 总结

**关键点：**
1. 逆序存储正好方便从低位到高位相加
2. 哑节点简化头节点处理
3. carry变量处理进位
4. 注意最后的进位需要单独处理
5. 用0填充较短的链表
