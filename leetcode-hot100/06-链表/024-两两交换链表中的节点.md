# 24. 两两交换链表中的节点【中等】

## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

---

## 输入输出示例

### 示例 1
```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

![示例1](https://assets.leetcode.com/uploads/2020/10/03/swap_ex1.jpg)

### 示例 2
```
输入：head = []
输出：[]
```

### 示例 3
```
输入：head = [1]
输出：[1]
```

### 提示
- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`

## 解题思路（面试推荐 - 最优解）

### 方法一：迭代（推荐）

**核心思想：**
- 使用哑节点简化边界处理
- 每次处理两个节点，交换它们的位置
- 使用三个指针：prev（前驱）、first（第一个节点）、second（第二个节点）

**交换过程：**
```
交换前：
prev → first → second → next
  0  →   1   →   2    →  3

交换后：
prev → second → first → next
  0  →   2    →   1   →  3

操作步骤：
1. prev.next = second
2. first.next = second.next
3. second.next = first
```

**为什么需要prev指针？**
```
没有prev：无法修改指向first的指针
有prev：prev.next可以指向新的头（second）

例如：交换1和2
需要0.next指向2，而不是1
```

**算法流程：**
1. 创建哑节点
2. 当前有至少两个节点时：
   - 记录first和second
   - 交换它们（修改3个指针）
   - 移动prev到下一对的前驱
3. 返回dummy.next

**时间复杂度：** O(n) - 遍历链表一次
**空间复杂度：** O(1) - 只用几个指针

## 代码实现（TypeScript）

### 迭代法（推荐）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function swapPairs(head: ListNode | null): ListNode | null {
    // 创建哑节点，简化边界处理
    const dummy = new ListNode(0);
    dummy.next = head;

    // prev指向当前要交换的两个节点的前驱
    let prev = dummy;

    // 当至少还有两个节点可以交换时
    while (prev.next !== null && prev.next.next !== null) {
        // 记录要交换的两个节点
        const first = prev.next;
        const second = prev.next.next;

        // 交换节点（关键步骤）
        // 步骤1: prev指向second（跳过first）
        prev.next = second;

        // 步骤2: first指向second的下一个节点
        first.next = second.next;

        // 步骤3: second指向first（完成交换）
        second.next = first;

        // 移动prev到下一对节点的前驱（即当前的first）
        prev = first;
    }

    return dummy.next;
}
```

### 递归法

```typescript
function swapPairs(head: ListNode | null): ListNode | null {
    // 递归终止条件：没有节点或只有一个节点
    if (head === null || head.next === null) {
        return head;
    }

    // 记录第二个节点（交换后的新头）
    const newHead = head.next;

    // 递归交换后续节点，并连接到当前的第一个节点
    head.next = swapPairs(newHead.next);

    // 第二个节点指向第一个节点
    newHead.next = head;

    // 返回新的头节点
    return newHead;
}
```

## 代码原理详解

### 迭代法原理

1. **指针关系**：
   ```
   prev → first → second → next

   需要修改的指针：
   - prev.next: first → second
   - first.next: second.next → next
   - second.next: null → first
   ```

2. **交换步骤（关键）**：
   ```typescript
   // 顺序很重要！
   prev.next = second;      // ①
   first.next = second.next; // ②
   second.next = first;      // ③

   如果顺序错误，会丢失节点引用！
   ```

3. **移动到下一对**：
   ```typescript
   prev = first;
   // first在交换后变成了下一对的前驱
   ```

### 递归法原理

1. **递归定义**：
   ```
   swapPairs(head) =
     - 如果head为空或只有一个节点，返回head
     - 否则：
       * 交换head和head.next
       * head.next = swapPairs(head.next.next)
       * 返回新头（原来的head.next）
   ```

2. **递归过程**：
   ```
   swapPairs([1,2,3,4])
   └─ 交换1和2
      └─ 1.next = swapPairs([3,4])
         └─ 交换3和4
            └─ 3.next = swapPairs([])
               └─ 返回null
            └─ 返回4→3→null
      └─ 返回2→1→4→3→null
   ```

### 设计思路

- **迭代法**：直观，空间O(1)，推荐
- **递归法**：代码简洁，但递归栈O(n)
- **三指针**：prev、first、second协同工作

## 常见问题

**Q1: 交换步骤的顺序能改变吗？**
A: 不能随意改变，否则会丢失节点引用。

```typescript
// 错误顺序1：
second.next = first;       // ① 先这样
first.next = second.next;  // ② 此时second.next已经是first，这行会让first指向自己！

// 错误顺序2：
first.next = second.next;  // ① 先这样
prev.next = second;        // ② 可以
second.next = first;       // ③ 可以
// 这个顺序是对的

// 推荐顺序（最安全）：
prev.next = second;        // ① 建立prev到second的连接
first.next = second.next;  // ② 保存后续节点
second.next = first;       // ③ 完成交换
```

**Q2: 为什么循环条件是 `prev.next !== null && prev.next.next !== null`？**
A: 确保至少有两个节点可以交换：
- `prev.next !== null`：至少有一个节点
- `prev.next.next !== null`：至少有两个节点

**Q3: 迭代和递归哪个更好？**
A:
- **迭代**：空间O(1)，性能更好，推荐面试使用
- **递归**：代码简洁，但递归栈O(n)，可能栈溢出

**Q4: 能否直接交换节点的值？**
A: 题目明确要求"不修改节点内部的值"，必须交换节点本身。

## 指针操作详解

### 交换的详细步骤

```
交换前：
prev → 1 → 2 → 3
       ↑   ↑   ↑
     first second next

步骤1: prev.next = second
prev → 2 → 3
       ↑   ↑
     second next
(first=1暂时悬空)

步骤2: first.next = second.next (即next)
1 → 3
    ↑
   next

步骤3: second.next = first
2 → 1 → 3
    ↑   ↑
  second first

最终连接：
prev → 2 → 1 → 3
       ↑   ↑   ↑
     second first next
```

## 复杂度分析

### 时间复杂度：O(n)
- n是链表长度
- 每个节点访问一次
- 每对节点交换时间O(1)

### 空间复杂度：
- **迭代法**：O(1) - 只用几个指针
- **递归法**：O(n) - 递归栈深度n/2

## 总结

**关键点：**
1. 哑节点简化边界处理
2. 三指针协同：prev、first、second
3. 交换步骤顺序很重要
4. 循环条件：至少有两个节点
5. 交换后移动prev到下一对的前驱
