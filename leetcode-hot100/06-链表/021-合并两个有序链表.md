# 21. 合并两个有序链表【简单】

## 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

---

## 输入输出示例

### 示例 1
```
输入：list1 = [1,2,4], list2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

![示例1](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

### 示例 2
```
输入：list1 = [], list2 = []
输出：[]
```

### 示例 3
```
输入：list1 = [], list2 = [0]
输出：[0]
```

### 提示
- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `list1` 和 `list2` 均按 **非递减顺序** 排列

---

## 解题思路（面试推荐 - 最优解）

### 方法一：迭代（推荐）

**核心思想：**
- 创建一个哑节点（dummy node）作为合并链表的头部
- 使用指针遍历两个链表，每次选择较小的节点连接到结果链表
- 处理剩余节点

**为什么需要哑节点？**
```
哑节点（dummy）的作用：
- 简化边界处理（不需要特殊处理第一个节点）
- 提供一个固定的起点
- 最后返回 dummy.next 即为真正的头节点

例如：
  dummy → 1 → 1 → 2 → 3 → 4 → 4
  ↑
返回 dummy.next
```

**算法流程：**
1. 创建哑节点和当前指针
2. 比较两个链表的当前节点，连接较小的
3. 移动相应的链表指针和当前指针
4. 连接剩余的节点
5. 返回 dummy.next

**时间复杂度：** O(m + n) - m和n是两个链表的长度
**空间复杂度：** O(1) - 只用几个指针

## 代码实现（TypeScript）

### 迭代法（推荐）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null {
    // 创建哑节点，简化边界处理
    const dummy = new ListNode(-1);
    // 当前指针，用于构建新链表
    let current = dummy;

    // 同时遍历两个链表
    while (list1 !== null && list2 !== null) {
        if (list1.val <= list2.val) {
            // list1的值更小，连接list1
            current.next = list1;
            list1 = list1.next;
        } else {
            // list2的值更小，连接list2
            current.next = list2;
            list2 = list2.next;
        }
        // 移动当前指针
        current = current.next;
    }

    // 连接剩余的节点
    // 至少有一个链表已经遍历完，直接连接另一个链表的剩余部分
    if (list1 !== null) {
        current.next = list1;
    } else {
        current.next = list2;
    }

    // 返回真正的头节点（跳过哑节点）
    return dummy.next;
}
```

### 递归法

```typescript
function mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null {
    // 递归终止条件
    if (list1 === null) {
        return list2;
    }
    if (list2 === null) {
        return list1;
    }

    // 递归合并
    if (list1.val <= list2.val) {
        // list1.val更小，list1.next指向剩余部分的合并结果
        list1.next = mergeTwoLists(list1.next, list2);
        return list1;
    } else {
        // list2.val更小，list2.next指向剩余部分的合并结果
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}
```

## 代码原理详解

### 迭代法原理

1. **哑节点技巧**：
   ```
   dummy = new ListNode(-1)

   作用：
   - 避免处理头节点的特殊情况
   - 提供统一的插入逻辑
   - 最后返回 dummy.next
   ```

2. **比较与连接**：
   ```
   while (list1 !== null && list2 !== null) {
       // 选择较小的节点
       if (list1.val <= list2.val) {
           current.next = list1;
           list1 = list1.next;
       } else {
           current.next = list2;
           list2 = list2.next;
       }
       current = current.next;
   }
   ```

3. **处理剩余节点**：
   ```
   // 最多只有一个链表有剩余
   current.next = list1 !== null ? list1 : list2;
   ```

### 递归法原理

1. **递归定义**：
   ```
   mergeTwoLists(l1, l2) =
     - 如果l1为空，返回l2
     - 如果l2为空，返回l1
     - 否则，选择较小的作为头，递归合并剩余部分
   ```

2. **递归树**：
   ```
   mergeTwoLists([1,2,4], [1,3,4])
   └─ 1 (list1[0] <= list2[0])
      └─ mergeTwoLists([2,4], [1,3,4])
         └─ 1 (list2[0] < list1[0])
            └─ mergeTwoLists([2,4], [3,4])
               └─ 2 (list1[0] < list2[0])
                  └─ mergeTwoLists([4], [3,4])
                     └─ 3 (list2[0] < list1[0])
                        └─ mergeTwoLists([4], [4])
                           └─ 4 (list1[0] <= list2[0])
                              └─ mergeTwoLists([], [4])
                                 └─ [4] (list1为空)
   ```

### 设计思路

- **迭代法**：逐步构建，空间O(1)，推荐
- **递归法**：代码优雅，但递归栈O(n)
- **双指针**：同时遍历两个链表

### 示例 1：`list1 = [1,2,4], list2 = [1,3,4]`

**迭代法执行过程：**

```

  list1: 1 → 2 → 4
  list2: 1 → 3 → 4
  dummy: -1
  current: dummy

  1 <= 1，选择list1
  current.next = list1节点(1)
  list1 = list1.next (现在指向2)
  current = current.next (现在指向1)

  dummy: -1 → 1
                ↑
             current

步骤2：比较 list1.val(2) 和 list2.val(1)
  2 > 1，选择list2
  current.next = list2节点(1)
  list2 = list2.next (现在指向3)
  current = current.next

  dummy: -1 → 1 → 1
                    ↑
                 current

步骤3：比较 list1.val(2) 和 list2.val(3)
  2 <= 3，选择list1
  current.next = list1节点(2)
  list1 = list1.next (现在指向4)
  current = current.next

  dummy: -1 → 1 → 1 → 2
                        ↑
                     current

步骤4：比较 list1.val(4) 和 list2.val(3)
  4 > 3，选择list2
  current.next = list2节点(3)
  list2 = list2.next (现在指向4)
  current = current.next

  dummy: -1 → 1 → 1 → 2 → 3
                            ↑
                         current

步骤5：比较 list1.val(4) 和 list2.val(4)
  4 <= 4，选择list1
  current.next = list1节点(4)
  list1 = list1.next (现在为null)
  current = current.next

  dummy: -1 → 1 → 1 → 2 → 3 → 4
                                ↑
                             current

步骤6：list1为null，退出循环
  连接剩余部分：current.next = list2 (指向节点4)

  dummy: -1 → 1 → 1 → 2 → 3 → 4 → 4

返回：dummy.next = 1 → 1 → 2 → 3 → 4 → 4 ✓
```

## 常见问题

**Q1: 为什么要用哑节点？**
A: 哑节点（dummy node）简化了边界处理：
```typescript
// 不用哑节点（复杂）
let head = null;
let current = null;

if (list1.val <= list2.val) {
    head = list1;  // 特殊处理第一个节点
    current = head;
    list1 = list1.next;
} else {
    head = list2;
    current = head;
    list2 = list2.next;
}

// 用哑节点（简洁）
const dummy = new ListNode(-1);
let current = dummy;
// 统一的插入逻辑，不需要特殊处理
```

**Q2: 迭代和递归哪个更好？**
A:
- **迭代**：空间O(1)，性能更好，推荐面试使用
- **递归**：代码简洁，但递归栈空间O(n)，可能栈溢出

**Q3: 如果要合并k个有序链表呢？**
A: 那是LeetCode 23题，可以用分治法或最小堆。

**Q4: 能否原地合并不创建新节点？**
A: 这个算法本身就是原地合并，只是重新连接现有节点，没有创建新的数据节点（只创建了一个哑节点）。

## 复杂度分析

### 时间复杂度：O(m + n)
- m是list1的长度，n是list2的长度
- 每个节点最多访问一次
- 总共访问m+n个节点

### 空间复杂度：
- **迭代法**：O(1) - 只用几个指针
- **递归法**：O(m + n) - 递归栈深度最多m+n
