# 141. 环形链表【简单】

## 题目描述

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**。仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 `true`。否则，返回 `false`。

## 解题思路（面试推荐 - 最优解）

### 方法：快慢指针（Floyd判圈算法）

**核心思想：**
- 使用两个指针：慢指针每次走1步，快指针每次走2步
- 如果链表有环，快指针最终会追上慢指针
- 如果链表无环，快指针会先到达末尾（null）

**为什么快指针一定能追上慢指针？**
```
假设链表有环：

慢指针进入环后，快指针也在环内
每次迭代，快指针相对慢指针前进1步
环的长度有限，快指针一定会追上慢指针

类比：操场跑道上，快的人一定能追上慢的人
```

**直觉理解：**
```
无环链表：
1 → 2 → 3 → 4 → null
快指针会先到达null，返回false

有环链表：
1 → 2 → 3 → 4
    ↑       ↓
    6 ← 5 ←

快慢指针都会在环内无限循环
快指针会追上慢指针，返回true
```

**时间复杂度：** O(n) - 最多遍历链表一遍多一点
**空间复杂度：** O(1) - 只用两个指针

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function hasCycle(head: ListNode | null): boolean {
    // 边界情况：空链表或只有一个节点
    if (head === null || head.next === null) {
        return false;
    }

    // 初始化快慢指针
    let slow: ListNode | null = head;
    let fast: ListNode | null = head.next;

    // 快慢指针追逐
    while (slow !== fast) {
        // 快指针到达末尾，说明无环
        if (fast === null || fast.next === null) {
            return false;
        }

        // 慢指针走1步，快指针走2步
        slow = slow!.next;
        fast = fast.next.next;
    }

    // 快慢指针相遇，说明有环
    return true;
}
```

**另一种写法（更简洁）：**

```typescript
function hasCycle(head: ListNode | null): boolean {
    let slow = head;
    let fast = head;

    while (fast !== null && fast.next !== null) {
        slow = slow!.next;          // 慢指针走1步
        fast = fast.next.next;      // 快指针走2步

        if (slow === fast) {
            return true;  // 相遇，有环
        }
    }

    return false;  // 快指针到达末尾，无环
}
```

## 代码原理详解

### 核心逻辑

1. **初始化**：
   ```
   slow = head        // 慢指针从头开始
   fast = head.next   // 快指针从第二个节点开始
   // 或者都从head开始也可以
   ```

2. **移动规则**：
   ```
   每次迭代：
   - slow 移动1步：slow = slow.next
   - fast 移动2步：fast = fast.next.next
   ```

3. **终止条件**：
   ```
   无环：fast 或 fast.next 为 null
   有环：slow === fast（相遇）
   ```

4. **为什么是 O(n) 时间？**
   ```
   无环情况：
   - 快指针最多走 n 步到达末尾
   - 时间 O(n)

   有环情况：
   - 进入环前：最多 n 步
   - 环内追逐：快指针每次缩短1步距离，环长最多 n
   - 总时间 O(n)
   ```

### 设计思路

- **Floyd判圈算法**：经典的检测环算法
- **相对速度**：快指针相对慢指针速度是1步/次
- **必然相遇**：如果有环，相对移动必然相遇
- **空间最优**：只用两个指针，O(1) 空间

## 常见问题

**Q1: 为什么快指针走2步，慢指针走1步？**
A: 这是最优选择：
- 如果快指针走3步或更多，可能会"跳过"慢指针，错过相遇
- 走2步保证每次相对距离缩短1，必然相遇
- 2步是最简单且高效的选择

**Q2: 快慢指针会不会"错过"相遇？**
A: 不会。在环内，快指针每次相对慢指针前进1步，距离从 d 减少到 d-1，最终一定会到0（相遇）。

**Q3: 为什么不用 HashSet 记录访问过的节点？**
A: 可以用，但需要 O(n) 空间。快慢指针只需 O(1) 空间，更优。

```typescript
// HashSet 方法（空间 O(n)）
function hasCycle(head: ListNode | null): boolean {
    const visited = new Set<ListNode>();
    let curr = head;

    while (curr !== null) {
        if (visited.has(curr)) {
            return true;  // 访问过，有环
        }
        visited.add(curr);
        curr = curr.next;
    }

    return false;  // 遍历完，无环
}
```

**Q4: 如果题目要求找到环的入口节点怎么办？**
A: 那是142题（环形链表 II）。可以使用快慢指针找到相遇点后，再推导出环的入口。

function hasCycle(head: ListNode | null): boolean {

## 数学证明

**定理：** 如果链表有环，快慢指针一定会相遇。

**证明：**
```
设链表有环，慢指针进入环后：

记慢指针位置为 s，快指针位置为 f
环的长度为 c

每次迭代：
- 慢指针前进1步
- 快指针前进2步
- 快指针相对慢指针前进1步

初始时，快慢指针距离为 d (0 < d < c)

第1次迭代后，距离变为 (d-1) % c
第2次迭代后，距离变为 (d-2) % c
...
第d次迭代后，距离变为 0

即：最多 d < c 次迭代后，快慢指针相遇

由于 c ≤ n（环长不超过链表长度）
所以时间复杂度 O(n)

证毕。
```
