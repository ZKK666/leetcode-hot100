# 138. 随机链表的复制【中等】

## 题目描述

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 **深拷贝**。深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点**。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y`。那么在复制链表中对应的两个节点 `x` 和 `y`，同样有 `x.random --> y`。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：

- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null`。

你的代码 **只** 接受原链表的头节点 `head` 作为传入参数。

## 解题思路（面试推荐 - 最优解）

### 方法一：哈希表（最直观）

**核心思想：**
- 第一遍遍历：创建所有新节点，建立原节点到新节点的映射
- 第二遍遍历：根据映射设置新节点的next和random指针

**为什么需要两遍遍历？**
```
问题：random可能指向后面的节点
如果一遍遍历：后面的节点还没创建，无法设置random

解决：先创建所有节点，再设置指针
```

**算法流程：**
1. 第一遍：创建所有新节点，存入HashMap
2. 第二遍：设置所有新节点的next和random

**时间复杂度：** O(n) - 遍历两次
**空间复杂度：** O(n) - HashMap存储n个节点映射

---

### 方法二：原地复制（O(1)空间，推荐）

**核心思想：**
- 在原链表的每个节点后面插入对应的新节点
- 利用这种结构设置random指针
- 拆分成两个独立的链表

**为什么这样做？**
```
原链表：A → B → C

插入新节点后：
A → A' → B → B' → C → C'

此时：A'.random = A.random.next
因为A.random指向原节点，而原节点.next就是对应的新节点！

最后拆分成：
原链表：A → B → C
新链表：A' → B' → C'
```

**算法流程：**
1. 第一遍：在每个节点后插入克隆节点
2. 第二遍：设置克隆节点的random指针
3. 第三遍：拆分两个链表

**时间复杂度：** O(n) - 遍历三次
**空间复杂度：** O(1) - 不算返回值，只用几个指针

## 代码实现（TypeScript）

### 方法一：哈希表

```typescript
/**
 * Definition for Node.
 * class Node {
 *     val: number
 *     next: Node | null
 *     random: Node | null
 *     constructor(val?: number, next?: Node, random?: Node) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *         this.random = (random===undefined ? null : random)
 *     }
 * }
 */

function copyRandomList(head: Node | null): Node | null {
    if (head === null) {
        return null;
    }

    // 第一遍：创建所有新节点，建立映射
    const map = new Map<Node, Node>();
    let curr = head;

    while (curr !== null) {
        // 创建新节点（暂时不设置next和random）
        map.set(curr, new Node(curr.val));
        curr = curr.next;
    }

    // 第二遍：设置新节点的next和random指针
    curr = head;
    while (curr !== null) {
        const newNode = map.get(curr)!;

        // 设置next（如果curr.next存在，通过map找到对应的新节点）
        newNode.next = curr.next !== null ? map.get(curr.next)! : null;

        // 设置random（如果curr.random存在，通过map找到对应的新节点）
        newNode.random = curr.random !== null ? map.get(curr.random)! : null;

        curr = curr.next;
    }

    // 返回新链表的头节点
    return map.get(head)!;
}
```

### 方法二：原地复制（O(1)空间）

```typescript
function copyRandomList(head: Node | null): Node | null {
    if (head === null) {
        return null;
    }

    // 第一步：在每个原节点后面插入克隆节点
    // A → B → C 变成 A → A' → B → B' → C → C'
    let curr: Node | null = head;
    while (curr !== null) {
        const clone = new Node(curr.val);
        clone.next = curr.next;
        curr.next = clone;
        curr = clone.next;
    }

    // 第二步：设置克隆节点的random指针
    // 利用：A'.random = A.random.next
    curr = head;
    while (curr !== null) {
        if (curr.random !== null) {
            // curr.next是克隆节点
            // curr.random.next是curr.random的克隆节点
            curr.next!.random = curr.random.next;
        }
        curr = curr.next!.next;  // 跳过克隆节点，到下一个原节点
    }

    // 第三步：拆分成两个链表
    curr = head;
    const newHead = head.next;  // 新链表的头
    let newCurr: Node | null = newHead;

    while (curr !== null) {
        // 恢复原链表
        curr.next = curr.next!.next;

        // 构建新链表
        if (newCurr!.next !== null) {
            newCurr!.next = newCurr!.next.next;
        }

        curr = curr.next;
        newCurr = newCurr!.next;
    }

    return newHead;
}
```

## 代码原理详解

### 哈希表方法

1. **第一遍：建立映射**
   ```typescript
   map: 原节点 → 新节点
   map.set(A, A')
   map.set(B, B')
   map.set(C, C')
   ```

2. **第二遍：设置指针**
   ```typescript
   对于原节点curr：
     newNode = map.get(curr)
     newNode.next = map.get(curr.next)
     newNode.random = map.get(curr.random)
   ```

### 原地复制方法

1. **插入克隆节点**：
   ```
   原链表：A → B → C

   插入后：
   A → A' → B → B' → C → C'
   ↑   ↑
   原  克隆
   ```

2. **设置random**：
   ```
   如果 A.random = C
   那么 A'.random = C' = C.next

   因为C后面就是C'！
   ```

3. **拆分链表**：
   ```
   A → A' → B → B' → C → C'

   拆分成：
   A → B → C         (原链表)
   A' → B' → C'      (新链表)
   ```

## 运行示例

### 示例：`head = [[7,null],[13,0],[11,4],[10,2],[1,0]]`

**链表结构：**
```
节点:   7  →  13  →  11  →  10  →  1
random: ×     7      1      11     7

（索引0是7，索引1是13，以此类推）
```

**哈希表方法执行过程：**

```
第一遍：创建新节点
  原节点7 → 新节点7'
  原节点13 → 新节点13'
  原节点11 → 新节点11'
  原节点10 → 新节点10'
  原节点1 → 新节点1'

  map = {
    7: 7',
    13: 13',
    11: 11',
    10: 10',
    1: 1'
  }

第二遍：设置指针
  处理7：
    7'.next = map.get(13) = 13' ✓
    7'.random = null ✓

  处理13：
    13'.next = map.get(11) = 11' ✓
    13'.random = map.get(7) = 7' ✓

  处理11：
    11'.next = map.get(10) = 10' ✓
    11'.random = map.get(1) = 1' ✓

  处理10：
    10'.next = map.get(1) = 1' ✓
    10'.random = map.get(11) = 11' ✓

  处理1：
    1'.next = null ✓
    1'.random = map.get(7) = 7' ✓

返回：map.get(head) = 7'
```

---

**原地复制方法执行过程：**

```
原链表：
  7 → 13 → 11 → 10 → 1

第一步：插入克隆节点
  7 → 7' → 13 → 13' → 11 → 11' → 10 → 10' → 1 → 1'

第二步：设置random
  原节点13.random = 7
  → 13'.random = 7.next = 7' ✓

  原节点11.random = 1
  → 11'.random = 1.next = 1' ✓

  原节点10.random = 11
  → 10'.random = 11.next = 11' ✓

  原节点1.random = 7
  → 1'.random = 7.next = 7' ✓

第三步：拆分链表
  原链表：7 → 13 → 11 → 10 → 1
  新链表：7' → 13' → 11' → 10' → 1'

返回：7'
```

## 常见问题

**Q1: 为什么哈希表方法需要两遍遍历？**
A: 因为random可能指向后面还没创建的节点。
```
例如：第一个节点的random指向最后一个节点
如果一遍遍历：处理第一个节点时，最后一个新节点还不存在
```

**Q2: 原地复制方法如何保证random指针正确？**
A: 关键在于插入位置：
```
原节点A.random = 原节点C
克隆节点A' = A.next
克隆节点C' = C.next

所以：A'.random = A.random.next = C.next = C' ✓
```

**Q3: 哪个方法更好？**
A:
- **哈希表**：代码简单，易理解，但需要O(n)空间
- **原地复制**：O(1)空间，但代码复杂，需要恢复原链表

面试时可以先说哈希表方法，然后提O(1)空间的优化。

**Q4: 为什么拆分时要恢复原链表？**
A: 题目要求不能修改原链表结构，所以需要恢复。

## 总结

**关键点：**
1. 深拷贝：创建全新节点，不能共享
2. 两次遍历：先创建节点，再设置指针
3. 哈希映射：原节点 → 新节点
4. 原地优化：插入-设置-拆分三步走

**面试建议：**
- 先说哈希表方法（更直观）
- 画图演示映射关系
- 强调深拷贝的含义

- 注意random可能为null的情况
