# 19. 删除链表的倒数第 N 个结点【中等】

## 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

---

## 输入输出示例

### 示例 1
```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

### 示例 2

输入：head = [1], n = 1
输出：[]
```

```

- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## 解题思路（面试推荐 - 最优解）

### 方法：双指针（快慢指针）

**核心思想：**
- 使用两个指针，快指针先走n步
- 然后快慢指针一起走，当快指针到达末尾时，慢指针指向倒数第n+1个节点
- 删除慢指针的下一个节点

**为什么快指针先走n步？**
```
假设链表长度为L，要删除倒数第n个节点：

倒数第n个 = 正数第(L-n+1)个

快指针先走n步后，快慢指针间距为n
当快指针到达末尾（第L个节点），慢指针在第(L-n)个节点
慢指针.next 就是要删除的节点（第L-n+1个）

例如：[1,2,3,4,5], n=2
L=5, 要删除第4个节点

fast先走2步到3
slow在1

一起走到：
fast在5（末尾）
slow在3（第L-n=3个节点）
slow.next是4，删除它
```

**为什么需要哑节点？**
```
如果要删除的是头节点（倒数第L个，即正数第1个）：
- 没有哑节点：需要特殊处理
- 有哑节点：统一处理

例如：[1], n=1
slow会指向dummy，slow.next=head，删除head即可
```

**算法流程：**
1. 创建哑节点指向head
2. 初始化快慢指针都指向dummy
3. 快指针先走n步
4. 快慢指针一起走，直到快指针到达末尾
5. 删除慢指针的下一个节点
6. 返回dummy.next

**时间复杂度：** O(L) - L是链表长度，只遍历一次
**空间复杂度：** O(1) - 只用两个指针

## 代码实现（TypeScript）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    // 创建哑节点，简化边界处理（特别是删除头节点的情况）
    const dummy = new ListNode(0);
    dummy.next = head;

    // 初始化快慢指针，都指向dummy
    let fast: ListNode | null = dummy;
    let slow: ListNode | null = dummy;

    // 步骤1：快指针先走n步
    for (let i = 0; i < n; i++) {
        fast = fast!.next;
    }

    // 步骤2：快慢指针一起走，直到快指针到达最后一个节点
    // 注意：是fast.next !== null，不是fast !== null
    // 因为我们要slow停在待删除节点的前一个节点
    while (fast!.next !== null) {
        fast = fast!.next;
        slow = slow!.next;
    }

    // 步骤3：删除slow的下一个节点（倒数第n个节点）
    slow!.next = slow!.next!.next;

    // 返回新的头节点
    return dummy.next;
}
```

**另一种写法（快指针多走一步）：**

```typescript
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    const dummy = new ListNode(0);
    dummy.next = head;

    let fast: ListNode | null = dummy;
    let slow: ListNode | null = dummy;

    // 快指针先走n+1步
    for (let i = 0; i <= n; i++) {
        fast = fast!.next;
    }

    // 快慢指针一起走，直到快指针为null
    while (fast !== null) {
        fast = fast.next;
        slow = slow!.next;
    }

    // 删除slow的下一个节点
    slow!.next = slow!.next!.next;

    return dummy.next;
}
```

两种写法的区别：
- 第一种：快指针走n步，循环条件是fast.next !== null
- 第二种：快指针走n+1步，循环条件是fast !== null

效果相同，推荐第一种（更直观）。

## 代码原理详解

### 核心逻辑

1. **哑节点**：
   ```typescript
   const dummy = new ListNode(0);
   dummy.next = head;

   作用：
   - 处理删除头节点的情况
   - 提供统一的删除逻辑
   ```

2. **快指针先走n步**：
   ```typescript
   for (let i = 0; i < n; i++) {
       fast = fast.next;
   }

   此时快慢指针间距为n
   ```

3. **一起移动到合适位置**：
   ```typescript
   while (fast.next !== null) {
       fast = fast.next;
       slow = slow.next;
   }

   结束时：
   - fast指向最后一个节点
   - slow指向倒数第n+1个节点
   - slow.next就是要删除的节点
   ```

4. **删除节点**：
   ```typescript
   slow.next = slow.next.next;

   跳过倒数第n个节点
   ```

### 设计思路

- **双指针**：维护固定间距n
- **一次遍历**：不需要先计算长度
- **哑节点**：统一处理边界
- **间距技巧**：利用距离关系定位

          ↑       ↑
         slow   fast

  fast.next = 4，不为null，继续

  移动2次：

  dummy → 1 → 2 → 3 → 4 → 5
                  ↑       ↑
                slow    fast

                      ↑       ↑
                    slow    fast

  即 3.next = 5

## 常见问题

**Q1: 为什么循环条件是 `fast.next !== null` 而不是 `fast !== null`？**
A: 因为我们需要slow停在**待删除节点的前一个节点**。
```
如果用 fast !== null：
  slow会停在待删除节点本身，无法删除
  （因为单链表无法访问前一个节点）

用 fast.next !== null：
  slow停在待删除节点的前一个节点
  可以通过 slow.next = slow.next.next 删除
```

**Q2: 如果n超出链表长度怎么办？**
A: 题目保证 `1 <= n <= sz`，所以不会出现这种情况。如果没有保证，需要增加边界检查。

**Q3: 能否不用哑节点？**
A: 可以，但需要特殊处理删除头节点的情况：
```typescript
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    let fast = head;
    let slow = head;

    // 快指针先走n步
    for (let i = 0; i < n; i++) {
        fast = fast!.next;
    }

    // 特殊情况：删除头节点
    if (fast === null) {
        return head!.next;
    }

    // 快慢指针一起走
    while (fast.next !== null) {
        fast = fast.next;
        slow = slow!.next;
    }

    // 删除节点
    slow!.next = slow!.next!.next;

    return head;
}
```
用哑节点更简洁。

**Q4: 这个方法为什么只需要一趟扫描？**
A: 因为双指针技巧：
- 不需要先计算链表长度（避免了第一趟扫描）
- 快指针先走n步，维护间距，一次遍历完成定位

## 其他解法（了解）

### 方法二：两趟扫描

```typescript
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    // 第一趟：计算链表长度
    let length = 0;
    let curr = head;
    while (curr !== null) {
        length++;
        curr = curr.next;
    }

    // 计算要删除的是正数第几个
    const target = length - n;

    // 第二趟：找到目标节点的前一个节点
    const dummy = new ListNode(0);
    dummy.next = head;
    curr = dummy;

    for (let i = 0; i < target; i++) {
        curr = curr!.next;
    }

    // 删除节点
    curr!.next = curr!.next!.next;

    return dummy.next;
}
```

**优点**：逻辑清晰
**缺点**：需要两趟扫描，不如双指针优

## 复杂度分析

### 时间复杂度：O(L)
- L是链表长度
- 快指针走n步：O(n)
- 快慢指针一起走：O(L-n)
- 总共：O(n + L - n) = O(L)

### 空间复杂度：O(1)
- 只用了几个指针变量
- 没有使用额外的数据结构
