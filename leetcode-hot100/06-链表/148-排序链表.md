# 148. 排序链表【中等】

## 题目描述

给你链表的头结点 `head`，请将其按 **升序** 排列并返回 **排序后的链表**。

- `-10^5 <= Node.val <= 10^5`

## 解题思路（面试推荐 - 最优解）

### 方法：归并排序（自顶向下）

**核心思想：**
- 使用归并排序，时间复杂度O(n log n)
- 利用快慢指针找中点，分割链表
- 递归排序左右两部分
- 合并两个有序链表

**为什么选择归并排序？**
```
常见排序算法对比：

快速排序：
- 平均O(n log n)，最坏O(n²)
- 需要随机访问（链表不适合）

归并排序：
- 稳定O(n log n)
- 只需要顺序访问（链表适合！）
- 自然适合链表结构

堆排序：
- O(n log n)
- 需要随机访问（链表不适合）
```

**算法流程：**
1. 使用快慢指针找到链表中点
2. 将链表分成两半
3. 递归排序左右两半
4. 合并两个有序链表

**时间复杂度：** O(n log n)
- 递归深度log n
- 每层合并需要O(n)

**空间复杂度：** O(log n)
- 递归调用栈的深度

## 代码实现（TypeScript）

### 方法一：自顶向下归并排序（递归）

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function sortList(head: ListNode | null): ListNode | null {
    // 递归终止条件：空链表或只有一个节点
    if (head === null || head.next === null) {
        return head;
    }

    // 步骤1：使用快慢指针找到中点
    const mid = getMid(head);
    const rightHead = mid.next;  // 右半部分的头
    mid.next = null;             // 断开左右两部分

    // 步骤2：递归排序左右两部分
    const left = sortList(head);
    const right = sortList(rightHead);

    // 步骤3：合并两个有序链表
    return merge(left, right);
}

/**
 * 使用快慢指针找到链表的中点（左中点）
 * 例如：1→2→3→4→5 返回3
 *      1→2→3→4 返回2
 */
function getMid(head: ListNode | null): ListNode {
    let slow: ListNode | null = head;
    let fast: ListNode | null = head.next;  // fast从第二个节点开始

    // 当fast能走两步时继续
    while (fast !== null && fast.next !== null) {
        slow = slow!.next;
        fast = fast.next.next;
    }

    return slow!;  // slow指向中点
}

/**
 * 合并两个有序链表（同第21题）
 */
function merge(l1: ListNode | null, l2: ListNode | null): ListNode | null {
    const dummy = new ListNode(0);
    let curr = dummy;

    while (l1 !== null && l2 !== null) {
        if (l1.val <= l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }

    // 连接剩余部分
    curr.next = l1 !== null ? l1 : l2;

    return dummy.next;
}
```

### 方法二：自底向上归并排序（迭代，O(1)空间）

```typescript
function sortList(head: ListNode | null): ListNode | null {
    if (head === null || head.next === null) {
        return head;
    }

    // 计算链表长度
    let length = 0;
    let curr = head;
    while (curr !== null) {
        length++;
        curr = curr.next;
    }

    const dummy = new ListNode(0);
    dummy.next = head;

    // 从长度1开始，每次翻倍
    for (let size = 1; size < length; size *= 2) {
        let prev = dummy;
        curr = dummy.next;

        // 每次处理两个长度为size的子链表
        while (curr !== null) {
            // 第一个子链表
            const left = curr;
            const right = split(left, size);  // 分割出长度为size的链表
            curr = split(right, size);        // 分割出第二个长度为size的链表

            // 合并并连接
            prev.next = merge(left, right);

            // 移动prev到合并后的末尾
            while (prev.next !== null) {
                prev = prev.next;
            }
        }
    }

    return dummy.next;
}

/**
 * 将链表的前n个节点分割出来
 * 返回第n+1个节点（下一段的开始）
 */
function split(head: ListNode | null, n: number): ListNode | null {
    while (head !== null && n > 1) {
        head = head.next;
        n--;
    }

    if (head === null) return null;

    const next = head.next;
    head.next = null;  // 断开
    return next;
}
```

## 代码原理详解

### 自顶向下（递归）原理

1. **分割**：
   ```
   原链表：4 → 2 → 1 → 3

   找中点：2
   分割成：
     左：4 → 2
     右：1 → 3
   ```

2. **递归排序**：
   ```
   sortList([4,2])
   ├─ 分割：[4] 和 [2]
   ├─ 递归：[4]已排序，[2]已排序
   └─ 合并：[2,4]

   sortList([1,3])
   ├─ 分割：[1] 和 [3]
   ├─ 递归：[1]已排序，[3]已排序
   └─ 合并：[1,3]
   ```

3. **合并**：
   ```
   merge([2,4], [1,3])
   = [1,2,3,4]
   ```

### 自底向上（迭代）原理

1. **size=1时**：
   ```
   原链表：4 → 2 → 1 → 3

   合并相邻的长度1的子链表：
   [4] 和 [2] → [2,4]
   [1] 和 [3] → [1,3]

   结果：2 → 4 → 1 → 3
   ```

2. **size=2时**：
   ```
   合并相邻的长度2的子链表：
   [2,4] 和 [1,3] → [1,2,3,4]

   结果：1 → 2 → 3 → 4
   ```

### 设计思路

- **分治法**：将大问题分解成小问题
- **快慢指针**：找链表中点
- **归并**：合并两个有序链表
- **迭代优化**：自底向上减少递归空间

### 合并过程详解：`merge([2,4], [1,3])`

```

  3 < 4，选3

  结果：1 → 2 → 3 → 4 ✓
```

## 常见问题

**Q1: 为什么快指针从head.next开始？**
A: 为了找到左中点：
```
[1,2,3,4]
如果fast从head开始：slow停在3（右中点）
如果fast从head.next开始：slow停在2（左中点）

左中点更适合分割：
  左：[1,2]
  右：[3,4]
  长度相近，更平衡
```

**Q2: 为什么不用快速排序？**
A: 快速排序需要随机访问：
```
快排的partition操作需要：
- 选择pivot
- 将所有元素与pivot比较
- 小的放左边，大的放右边

链表不支持随机访问，效率低
```

**Q3: 自顶向下和自底向上哪个更好？**
A:
- **自顶向下（递归）**：
  - 代码简洁，易理解
  - 空间O(log n)（递归栈）

- **自底向上（迭代）**：
  - 空间O(1)
  - 代码复杂，不够直观

面试推荐自顶向下（除非特别要求O(1)空间）。

**Q4: 能否用其他排序算法？**
A: 可以，但不如归并排序：
- 插入排序：O(n²)，太慢
- 堆排序：需要随机访问，不适合链表
- 计数排序：需要知道值的范围，且空间大

## 复杂度分析

### 自顶向下归并排序

**时间复杂度：** O(n log n)
- 递归深度：log n（每次分成两半）
- 每层合并：O(n)（遍历所有节点）
- 总共：O(n log n)

**空间复杂度：** O(log n)
- 递归调用栈的深度

### 自底向上归并排序

**时间复杂度：** O(n log n)
- 外层循环：log n次（size从1到n）
- 每次循环：O(n)（合并所有节点）

**空间复杂度：** O(1)
- 只用几个指针，没有递归

## 边界情况

### 情况1：空链表

```
输入: head = []
输出: []
```

### 情况2：单节点

```
输入: head = [1]
输出: [1]
```

### 情况3：已排序

```
输入: head = [1,2,3,4,5]
输出: [1,2,3,4,5]
说明：归并排序仍然O(n log n)，不能提前终止
```

### 情况4：逆序

```
输入: head = [5,4,3,2,1]
输出: [1,2,3,4,5]
```

### 情况5：有重复元素

```
输入: head = [3,1,2,3,1]
输出: [1,1,2,3,3]
说明：归并排序是稳定排序，相同元素顺序不变
```

## 总结

**关键点：**
1. 归并排序最适合链表
2. 快慢指针找中点（左中点）
3. 递归分割和合并
4. 合并两个有序链表是关键
5. 迭代版本可以达到O(1)空间

**面试建议：**
- 优先讲自顶向下（递归版本）
- 画递归树演示分治过程
- 强调时间复杂度O(n log n)
- 说明为什么选归并排序而不是快排
- 可以提到自底向上的O(1)空间优化

**易错点：**
- 忘记断开左右两部分（mid.next = null）
- 快慢指针的初始位置（fast从head.next开始）
- 合并函数的边界处理
