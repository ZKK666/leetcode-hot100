# 206. 反转链表【简单】

## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

---

## 输入输出示例

### 示例 1
```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

![示例1](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

### 示例 2
```
输入：head = [1,2]
输出：[2,1]
```

### 示例 3
```
输入：head = []
输出：[]
```

### 提示
- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶**：链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

---

## 解题思路（面试推荐 - 最优解）

### 方法一：迭代（双指针）

**核心思想：**
- 使用两个指针prev和curr
- 遍历链表，逐个反转节点的next指针
- prev记录前一个节点，curr记录当前节点

**反转过程：**
```
原链表: 1 → 2 → 3 → 4 → 5 → null

步骤1: null ← 1   2 → 3 → 4 → 5 → null
步骤2: null ← 1 ← 2   3 → 4 → 5 → null
步骤3: null ← 1 ← 2 ← 3   4 → 5 → null
步骤4: null ← 1 ← 2 ← 3 ← 4   5 → null
步骤5: null ← 1 ← 2 ← 3 ← 4 ← 5

返回节点5
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 代码实现（TypeScript）

### 迭代法

```typescript
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 *     constructor(val?: number, next?: ListNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.next = (next===undefined ? null : next)
 *     }
 * }
 */

function reverseList(head: ListNode | null): ListNode | null {
    // prev指向前一个节点，初始为null
    let prev: ListNode | null = null;
    // curr指向当前节点
    let curr: ListNode | null = head;

    while (curr !== null) {
        // 保存下一个节点（因为要修改curr.next）
        const next: ListNode | null = curr.next;

        // 反转当前节点的指针
        curr.next = prev;

        // 移动prev和curr指针
        prev = curr;
        curr = next;
    }

    // 循环结束时，prev指向原链表的最后一个节点（新的头节点）
    return prev;
}
```

### 递归法

```typescript
function reverseList(head: ListNode | null): ListNode | null {
    // 递归终止条件：空链表或只有一个节点
    if (head === null || head.next === null) {
        return head;
    }

    // 递归反转后续部分
    // newHead是反转后的新头节点（原链表的最后一个节点）
    const newHead = reverseList(head.next);

    // 反转当前节点和下一个节点的指向
    // head.next 是当前节点的下一个节点
    // 让它指向当前节点，实现反转
    head.next.next = head;

    // 当前节点变成末尾，next指向null
    head.next = null;

    // 返回新的头节点
    return newHead;
}
```

## 代码原理详解

### 迭代法原理

1. **三个指针**：
   - `prev`：前一个节点
   - `curr`：当前节点
   - `next`：下一个节点（临时保存）

2. **核心步骤**：
   ```
   next = curr.next;  // 保存下一个
   curr.next = prev;  // 反转指针
   prev = curr;       // prev前进
   curr = next;       // curr前进
   ```

3. **返回值**：
   - 循环结束时，curr为null
   - prev指向原链表最后一个节点（新头节点）

### 递归法原理

1. **递归定义**：
   - `reverseList(head)` 返回反转head开头链表后的新头节点

2. **递归过程**：
   ```
   原链表: 1 → 2 → 3 → 4 → 5

   reverseList(1):
     递归: reverseList(2) 返回 5
     操作: 2.next = 1, 1.next = null
     返回: 5

   reverseList(2):
     递归: reverseList(3) 返回 5
     操作: 3.next = 2, 2.next = null
     返回: 5

   ...以此类推
   ```

3. **关键操作**：
   - `head.next.next = head`：让下一个节点指向当前节点
   - `head.next = null`：断开当前节点的原指向

### 设计思路

- **迭代**：逐个处理，空间O(1)
- **递归**：栈空间O(n)，但代码优雅

## 运行示例

### 迭代法：`head = [1,2,3,4,5]`

```
初始: prev=null, curr=1

步骤1: curr=1
  next = 2
  1.next = null
  prev = 1, curr = 2
  状态: null ← 1   2 → 3 → 4 → 5

步骤2: curr=2
  next = 3
  2.next = 1
  prev = 2, curr = 3
  状态: null ← 1 ← 2   3 → 4 → 5

步骤3: curr=3
  next = 4
  3.next = 2
  prev = 3, curr = 4
  状态: null ← 1 ← 2 ← 3   4 → 5

步骤4: curr=4
  next = 5
  4.next = 3
  prev = 4, curr = 5
  状态: null ← 1 ← 2 ← 3 ← 4   5

步骤5: curr=5
  next = null
  5.next = 4
  prev = 5, curr = null
  状态: null ← 1 ← 2 ← 3 ← 4 ← 5

curr=null，循环结束
返回: prev = 5
```

### 递归法：`head = [1,2,3]`

```
调用栈:

reverseList(1):
  head=1, head.next=2
  调用 reverseList(2)

    reverseList(2):
      head=2, head.next=3
      调用 reverseList(3)

        reverseList(3):
          head=3, head.next=null
          返回 3

      head=2
      2.next.next = 2  即 3.next = 2
      2.next = null
      返回 3

  head=1
  1.next.next = 1  即 2.next = 1
  1.next = null
  返回 3

最终: 3 → 2 → 1 → null
```

## 常见问题

**Q1: 为什么需要临时变量next？**
A: 因为修改`curr.next`后，会丢失对下一个节点的引用，所以必须先保存。

**Q2: 递归法的空间复杂度是多少？**
A: O(n)，因为递归调用栈的深度是n。

**Q3: 两种方法哪个更好？**
A:
- 迭代法：空间O(1)，性能更好，推荐
- 递归法：代码优雅，但有栈溢出风险

**Q4: 能否原地反转不改变节点？**
A: 不能。必须改变next指针才能反转链表。
