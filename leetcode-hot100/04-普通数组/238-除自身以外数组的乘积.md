# 238. 除自身以外数组的乘积【中等】

## 题目描述

给你一个整数数组 `nums`，返回 数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据 保证 数组 `nums` 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位 整数范围内。

请 **不要使用除法**，且在 `O(n)` 时间复杂度内完成此题。

---

## 输入输出示例

### 示例 1
```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
解释:
answer[0] = 2*3*4 = 24
answer[1] = 1*3*4 = 12
answer[2] = 1*2*4 = 8
answer[3] = 1*2*3 = 6
```

### 示例 2
```
输入: nums = [-1,1,0,-3,3]
输出: [0,0,9,0,0]
```

### 提示
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- 保证 数组 `nums` 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位 整数范围内

**进阶**：你可以在 `O(1)` 的额外空间复杂度内完成这个题目吗？（输出数组不被视为额外空间）

---

## 解题思路（面试推荐 - 最优解）

### 方法：左右乘积列表

**核心思想：**
- 对于索引 i，`answer[i] = 左侧所有元素的乘积 × 右侧所有元素的乘积`
- 使用两次遍历：
  1. 从左到右：计算每个位置左侧的乘积
  2. 从右到左：计算每个位置右侧的乘积，并与左侧乘积相乘

**举例说明：**
```
nums = [1, 2, 3, 4]

左侧乘积:
  i=0: 1 (左侧没有元素，默认为1)
  i=1: 1 (nums[0] = 1)
  i=2: 1*2 = 2
  i=3: 1*2*3 = 6
left = [1, 1, 2, 6]

右侧乘积:
  i=3: 1 (右侧没有元素，默认为1)
  i=2: 4
  i=1: 3*4 = 12
  i=0: 2*3*4 = 24
right = [24, 12, 4, 1]

结果:
  answer[i] = left[i] * right[i]
  answer = [1*24, 1*12, 2*4, 6*1]
        = [24, 12, 8, 6] ✓
```

**空间优化：**
- 不使用 left 和 right 数组
- 直接用 answer 数组存储左侧乘积
- 用一个变量存储右侧乘积

**时间复杂度：** O(n) - 遍历两次数组
**空间复杂度：** O(1) - 不计输出数组

## 代码实现（TypeScript）

```typescript
function productExceptSelf(nums: number[]): number[] {
    const n = nums.length;
    const answer = new Array(n);

    // 第一步：计算每个位置左侧所有元素的乘积
    // answer[i] 存储 nums[0] * nums[1] * ... * nums[i-1]
    answer[0] = 1; // 左侧没有元素，乘积为1
    for (let i = 1; i < n; i++) {
        // 当前位置的左侧乘积 = 前一个位置的左侧乘积 × nums[i-1]
        answer[i] = answer[i - 1] * nums[i - 1];
    }

    // 第二步：计算每个位置右侧所有元素的乘积，并与左侧乘积相乘
    // 使用一个变量 right 记录右侧乘积
    let right = 1; // 右侧没有元素，初始为1

    // 从右向左遍历
    for (let i = n - 1; i >= 0; i--) {
        // answer[i] 目前存储的是左侧乘积
        // 乘以右侧乘积，得到最终结果
        answer[i] = answer[i] * right;

        // 更新right：加入当前元素
        right = right * nums[i];
    }

    return answer;
}
```

## 代码原理详解

### 核心逻辑

1. **左侧乘积计算**：
   ```
   answer[0] = 1                    // 左侧无元素
   answer[1] = nums[0]              // 左侧1个元素
   answer[2] = nums[0] * nums[1]    // 左侧2个元素
   answer[3] = nums[0] * nums[1] * nums[2]

   递推公式: answer[i] = answer[i-1] * nums[i-1]
   ```

2. **右侧乘积计算**：
   ```
   从右向左遍历，用变量 right 记录右侧累积乘积
   i=3: right = 1                   (右侧无元素)
   i=2: right = nums[3]             (右侧1个元素)
   i=1: right = nums[2] * nums[3]   (右侧2个元素)
   i=0: right = nums[1] * nums[2] * nums[3]
   ```

3. **最终结果**：
   ```
   answer[i] = (左侧乘积) * (右侧乘积)
   ```

### 设计思路

- **分解问题**：除自身以外 = 左侧 × 右侧
- **空间优化**：复用输出数组存储中间结果
- **单向累积**：避免重复计算

## 常见问题

**Q1: 为什么不能用除法？**
A:
1. 题目明确要求不使用除法
2. 如果数组中有0，除法会出现除以0的错误
3. 除法可能导致精度问题

**Q2: 如果可以用除法，怎么做？**
A:
```typescript
function productExceptSelf(nums: number[]): number[] {
    // 计算所有元素的乘积
    let totalProduct = 1;
    let zeroCount = 0;

    for (const num of nums) {
        if (num === 0) {
            zeroCount++;
        } else {
            totalProduct *= num;
        }
    }

    const answer = new Array(nums.length);

    for (let i = 0; i < nums.length; i++) {
        if (zeroCount > 1) {
            answer[i] = 0; // 多个0，所有结果都是0
        } else if (zeroCount === 1) {
            answer[i] = nums[i] === 0 ? totalProduct : 0;
        } else {
            answer[i] = totalProduct / nums[i];
        }
    }

    return answer;
}
```

但这种方法不推荐，因为：
- 违反题目要求
- 需要处理0的特殊情况
- 可能有精度问题

**Q3: 空间复杂度真的是 O(1) 吗？**
A: 是的。虽然使用了 answer 数组，但题目明确说明"输出数组不被视为额外空间"。除此之外只用了常数个变量。

**Q4: 能否只遍历一次数组？**
A: 不能。至少需要两次遍历：一次计算左侧乘积，一次计算右侧乘积。

## 算法演进

### 方法一：暴力法（不推荐）

```typescript
function productExceptSelf(nums: number[]): number[] {
    const n = nums.length;
    const answer = new Array(n);

    for (let i = 0; i < n; i++) {
        let product = 1;
        for (let j = 0; j < n; j++) {
            if (i !== j) {
                product *= nums[j];
            }
        }
        answer[i] = product;
    }

    return answer;
}
```

**时间复杂度**：O(n²) - 双层循环
**空间复杂度**：O(1)

### 方法二：左右数组（未优化）

```typescript
function productExceptSelf(nums: number[]): number[] {
    const n = nums.length;
    const left = new Array(n);
    const right = new Array(n);
    const answer = new Array(n);

    // 计算左侧乘积
    left[0] = 1;
    for (let i = 1; i < n; i++) {
        left[i] = left[i - 1] * nums[i - 1];
    }

    // 计算右侧乘积
    right[n - 1] = 1;
    for (let i = n - 2; i >= 0; i--) {
        right[i] = right[i + 1] * nums[i + 1];
    }

    // 计算结果
    for (let i = 0; i < n; i++) {
        answer[i] = left[i] * right[i];
    }

    return answer;
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(n) - 使用了 left 和 right 数组

### 方法三：空间优化（推荐）

就是上面的最优解，空间复杂度优化到 O(1)。
