# 56. 合并区间【中等】

## 题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

---

## 输入输出示例

### 示例 1
```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

### 示例 2
```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

### 提示
- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 方法：排序 + 一次遍历

**核心思想：**
- 先按区间的起始位置排序
- 遍历排序后的区间，判断当前区间是否与结果中的最后一个区间重叠
- 如果重叠，合并区间（更新结束位置为两者的最大值）
- 如果不重叠，直接将当前区间加入结果

**判断重叠的条件：**
```
当前区间 [start, end]
最后一个结果区间 [lastStart, lastEnd]

重叠条件：start <= lastEnd
合并方式：lastEnd = max(lastEnd, end)
```

**为什么要排序？**
- 排序后，只需要比较相邻区间，不需要两两比较
- 时间复杂度从 O(n²) 优化到 O(n log n)

**时间复杂度：** O(n log n) - 排序
**空间复杂度：** O(log n) - 排序的栈空间（不计结果数组）

## 代码实现（TypeScript）

```typescript
function merge(intervals: number[][]): number[][] {
    // 边界情况：只有一个区间，直接返回
    if (intervals.length <= 1) return intervals;

    // 第一步：按区间起始位置排序
    intervals.sort((a, b) => a[0] - b[0]);

    // 结果数组
    const result: number[][] = [];

    // 将第一个区间加入结果
    result.push(intervals[0]);

    // 遍历剩余区间
    for (let i = 1; i < intervals.length; i++) {
        // 当前区间
        const current = intervals[i];
        // 结果中的最后一个区间
        const last = result[result.length - 1];

        // 判断是否重叠
        if (current[0] <= last[1]) {
            // 重叠：合并区间，更新结束位置
            last[1] = Math.max(last[1], current[1]);
        } else {
            // 不重叠：直接加入结果
            result.push(current);
        }
    }

    return result;
}
```

---

## 代码原理详解

### 核心逻辑

1. **排序**：
   - 按区间起始位置从小到大排序
   - `intervals.sort((a, b) => a[0] - b[0])`
   - 排序后相邻区间才可能重叠

2. **初始化**：
   - 将第一个区间加入结果
   - 作为初始的"待合并区间"

3. **遍历合并**：
   - 对于每个区间，与结果中的最后一个区间比较
   - 判断是否重叠：`current[0] <= last[1]`

4. **合并策略**：
   - 重叠：更新 `last[1] = max(last[1], current[1])`
   - 不重叠：`result.push(current)`

### 设计思路

- **贪心思想**：排序后局部最优即全局最优
- **原地修改**：直接修改结果数组的最后一个区间，不需要额外空间
- **一次遍历**：排序后只需遍历一次

### 示例 1：`intervals = [[1,3],[2,6],[8,10],[15,18]]`

**执行过程：**

```

  result = [[1,3]]

第三步：遍历合并

i = 1, current = [2,6]:
  last = [1,3]
  判断: 2 <= 3 ? 是，重叠 ✓
  合并: last[1] = max(3, 6) = 6
  result = [[1,6]]

i = 2, current = [8,10]:
  last = [1,6]
  判断: 8 <= 6 ? 否，不重叠
  添加: result.push([8,10])
  result = [[1,6], [8,10]]

i = 3, current = [15,18]:
  last = [8,10]
  判断: 15 <= 10 ? 否，不重叠
  添加: result.push([15,18])

```

## 重叠判断详解

### 区间关系分类

```
1. 不重叠（左）:
   [--A--]
            [--B--]
   条件: A.end < B.start

2. 边界相接:
   [--A--]
         [--B--]
   条件: A.end == B.start
   算作重叠（题目要求）

3. 部分重叠:
   [--A--]
      [--B--]
   条件: A.start < B.start <= A.end < B.end

4. 完全包含:
   [---A---]
     [--B--]
   条件: A.start <= B.start && B.end <= A.end

5. 不重叠（右）:
            [--A--]
   [--B--]
   条件: B.end < A.start（排序后不会出现）
```

**统一判断：**
```
排序后，只需判断 B.start <= A.end 即可
涵盖了情况 2、3、4
```

## 常见问题

**Q1: 为什么边界相接也算重叠？**
A: 题目示例2明确了 `[1,4]` 和 `[4,5]` 合并为 `[1,5]`，说明边界相接算重叠。

**Q2: 如果不排序能做吗？**
A: 不能。不排序需要两两比较所有区间，时间复杂度 O(n²)，且实现复杂。

**Q3: 能否在原数组上修改，不用额外空间？**
A: 可以，但需要额外的索引记录，代码会更复杂。通常不推荐。

**Q4: 如果区间很多，如何优化？**
A: 对于静态区间，排序+遍历已是最优。对于动态添加区间，可以用平衡树（如红黑树）维护。

## 边界情况处理

### 情况1：所有区间都重叠

```
输入: [[1,4], [2,5], [3,6]]
排序: [[1,4], [2,5], [3,6]]

过程:
  result = [[1,4]]
  合并[2,5]: [1,5]
  合并[3,6]: [1,6]

输出: [[1,6]]
```

### 情况2：所有区间都不重叠

```
输入: [[1,2], [3,4], [5,6]]
排序: [[1,2], [3,4], [5,6]]

过程:
  result = [[1,2]]
  添加[3,4]: [[1,2], [3,4]]
  添加[5,6]: [[1,2], [3,4], [5,6]]

输出: [[1,2], [3,4], [5,6]]
```

### 情况3：只有一个区间

```
输入: [[1,5]]
输出: [[1,5]]（直接返回）
```

## 时间复杂度分析

**排序：** O(n log n)
- 使用快速排序或归并排序

**遍历：** O(n)
- 每个区间最多访问一次

**总计：** O(n log n)

**空间复杂度：**
- 排序：O(log n)（递归栈）
- 结果数组：O(n)（最坏情况，所有区间都不重叠）
- 总计：O(n)
