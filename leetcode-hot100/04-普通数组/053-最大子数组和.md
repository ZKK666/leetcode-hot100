# 53. 最大子数组和【中等】

## 题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组** 是数组中的一个连续部分。

---

## 输入输出示例

### 示例 1
```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

### 示例 2
```
输入：nums = [1]
输出：1
```

### 示例 3
```
输入：nums = [5,4,-1,7,8]
输出：23
```

### 提示
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

---

## 解题思路（面试推荐 - 最优解）

### 方法：动态规划（Kadane算法）

**核心思想：**
- 定义 `dp[i]`：以 `nums[i]` 结尾的最大子数组和
- 状态转移方程：
  - `dp[i] = max(nums[i], dp[i-1] + nums[i])`
  - 要么自己单独成为一个子数组，要么加入前面的子数组
- 最终答案：`max(dp[0], dp[1], ..., dp[n-1])`

**为什么这样做是对的？**
```
对于位置 i，有两种选择：
1. 从当前位置重新开始：子数组 = [nums[i]]
2. 继续前面的子数组：子数组 = [..., nums[i]]

如果 dp[i-1] < 0，加上它只会让和变小，不如重新开始
如果 dp[i-1] > 0，加上它可以让和变大，应该继续
```

**空间优化：**
- 不需要完整的 dp 数组，只需要一个变量记录前一个状态
- 空间复杂度从 O(n) 优化到 O(1)

**时间复杂度：** O(n) - 只遍历一次数组
**空间复杂度：** O(1) - 只使用常数个变量

## 代码实现（TypeScript）

```typescript
function maxSubArray(nums: number[]): number {
    // maxSum 记录全局最大子数组和
    let maxSum = nums[0];

    // currentSum 记录以当前位置结尾的最大子数组和（相当于 dp[i]）
    let currentSum = nums[0];

    // 从第二个元素开始遍历
    for (let i = 1; i < nums.length; i++) {
        // 状态转移：要么重新开始，要么继续前面的子数组
        // currentSum = max(nums[i], currentSum + nums[i])
        currentSum = Math.max(nums[i], currentSum + nums[i]);

        // 更新全局最大值
        maxSum = Math.max(maxSum, currentSum);
    }

    return maxSum;
}
```

**代码简化版本：**

```typescript
function maxSubArray(nums: number[]): number {
    let maxSum = nums[0];
    let currentSum = nums[0];

    for (let i = 1; i < nums.length; i++) {
        // 如果前面的和是负数，丢弃它，重新开始
        currentSum = currentSum > 0 ? currentSum + nums[i] : nums[i];
        maxSum = Math.max(maxSum, currentSum);
    }

    return maxSum;
}
```

## 代码原理详解

### 核心逻辑

1. **状态定义**：
   - `currentSum`：以当前元素结尾的最大子数组和
   - `maxSum`：全局最大子数组和

2. **状态转移**：
   ```
   currentSum = max(nums[i], currentSum + nums[i])

   等价于：
   if (currentSum > 0) {
       currentSum += nums[i];  // 继续累加
   } else {
       currentSum = nums[i];   // 重新开始
   }
   ```

3. **更新答案**：
   - 每次计算完 currentSum 后，更新 maxSum

### 设计思路

- **贪心思想**：负数前缀会拖累后面的和，直接丢弃
- **动态规划**：记录局部最优解，推导全局最优解
- **空间优化**：滚动变量代替 dp 数组

## 运行示例

### 示例 1：`nums = [-2,1,-3,4,-1,2,1,-5,4]`

**完整执行过程：**

```
初始状态:
  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
  索引    0   1   2  3   4  5  6   7  8
  maxSum = -2, currentSum = -2

i = 1, nums[1] = 1:
  currentSum = max(1, -2 + 1) = max(1, -1) = 1
  重新开始，子数组 = [1]
  maxSum = max(-2, 1) = 1

i = 2, nums[2] = -3:
  currentSum = max(-3, 1 + (-3)) = max(-3, -2) = -2
  继续，子数组 = [1, -3]
  maxSum = max(1, -2) = 1

i = 3, nums[3] = 4:
  currentSum = max(4, -2 + 4) = max(4, 2) = 4
  重新开始，子数组 = [4]
  maxSum = max(1, 4) = 4

i = 4, nums[4] = -1:
  currentSum = max(-1, 4 + (-1)) = max(-1, 3) = 3
  继续，子数组 = [4, -1]
  maxSum = max(4, 3) = 4

i = 5, nums[5] = 2:
  currentSum = max(2, 3 + 2) = max(2, 5) = 5
  继续，子数组 = [4, -1, 2]
  maxSum = max(4, 5) = 5

i = 6, nums[6] = 1:
  currentSum = max(1, 5 + 1) = max(1, 6) = 6
  继续，子数组 = [4, -1, 2, 1]
  maxSum = max(5, 6) = 6 ✓

i = 7, nums[7] = -5:
  currentSum = max(-5, 6 + (-5)) = max(-5, 1) = 1
  继续，子数组 = [4, -1, 2, 1, -5]
  maxSum = max(6, 1) = 6

i = 8, nums[8] = 4:
  currentSum = max(4, 1 + 4) = max(4, 5) = 5
  继续，子数组 = [4, -1, 2, 1, -5, 4]
  maxSum = max(6, 5) = 6

最终结果: maxSum = 6
最大子数组: [4, -1, 2, 1]
```

## Kadane算法详解

这个算法由Jay Kadane于1984年提出，是最大子数组和问题的经典解法。

**算法精髓：**
```
如果前面的累积和是负数，丢弃它，从当前位置重新开始。
因为负数只会拖累后面的和。
```

**为什么是O(n)？**
- 只遍历一次数组
- 每个元素只被访问一次
- 每次操作都是O(1)

**为什么是最优的？**
- 任何解法都至少要看一遍所有元素（需要O(n)）
- Kadane算法恰好O(n)，无法再优化

## 常见问题

**Q1: 如果要返回最大子数组的起始和结束索引怎么办？**
A: 需要额外记录起始位置：
```typescript
function maxSubArray(nums: number[]): [number, number, number] {
    let maxSum = nums[0];
    let currentSum = nums[0];
    let start = 0, end = 0;
    let tempStart = 0;

    for (let i = 1; i < nums.length; i++) {
        if (currentSum < 0) {
            currentSum = nums[i];
            tempStart = i;  // 重新开始，更新临时起点
        } else {
            currentSum += nums[i];
        }

        if (currentSum > maxSum) {
            maxSum = currentSum;
            start = tempStart;
            end = i;
        }
    }

    return [start, end, maxSum];
}
```

**Q2: 如果允许删除一个元素，最大子数组和是多少？**
A: 这是一道更难的题（LeetCode 1186），需要维护两个状态。

**Q3: 如果数组是环形的呢？**
A: 需要考虑两种情况：最大子数组不跨越边界 / 跨越边界（LeetCode 918）。

**Q4: 能否用分治法？**
A: 可以，时间复杂度仍是O(n log n)，但代码更复杂，不如Kadane算法。

## 其他解法（了解）

### 方法二：分治法

```typescript
function maxSubArray(nums: number[]): number {
    const helper = (left: number, right: number): number => {
        if (left === right) return nums[left];

        const mid = Math.floor((left + right) / 2);

        // 左半部分最大和
        const leftMax = helper(left, mid);
        // 右半部分最大和
        const rightMax = helper(mid + 1, right);

        // 跨越中点的最大和
        let leftSum = nums[mid], rightSum = nums[mid + 1];
        let tempSum = 0;
        for (let i = mid; i >= left; i--) {
            tempSum += nums[i];
            leftSum = Math.max(leftSum, tempSum);
        }
        tempSum = 0;
        for (let i = mid + 1; i <= right; i++) {
            tempSum += nums[i];
            rightSum = Math.max(rightSum, tempSum);
        }

        const crossMax = leftSum + rightSum;

        return Math.max(leftMax, rightMax, crossMax);
    };

    return helper(0, nums.length - 1);
}
```

**时间复杂度**：O(n log n)
**空间复杂度**：O(log n) - 递归栈
