# 189. 轮转数组【中等】

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

---

## 输入输出示例

### 示例 1
```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

### 示例 2
```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

### 提示
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`
- 尝试使用时间复杂度为 O(n) 的原地算法

---

## 解题思路（面试推荐 - 最优解）

### 方法：三次反转

**核心思想：**
- 观察规律：向右轮转 k 个位置 = 将后 k 个元素移到前面
- 使用三次反转实现：
  1. 反转整个数组
  2. 反转前 k 个元素
  3. 反转后 n-k 个元素

**举例说明：**
```
原数组: [1, 2, 3, 4, 5, 6, 7], k = 3

步骤1: 反转整个数组
[7, 6, 5, 4, 3, 2, 1]

步骤2: 反转前 k=3 个元素
[5, 6, 7, 4, 3, 2, 1]

步骤3: 反转后 n-k=4 个元素
[5, 6, 7, 1, 2, 3, 4] ✓
```

**为什么这样做是对的？**
```
原数组可分为两部分：[A, B]
A = [1,2,3,4]（前 n-k 个）
B = [5,6,7]（后 k 个）

目标：[B, A] = [5,6,7,1,2,3,4]

步骤1: reverse([A, B]) = [B', A']
步骤2: reverse(B') = [B, A']
步骤3: reverse(A') = [B, A] ✓
```

**时间复杂度：** O(n) - 遍历3次数组
**空间复杂度：** O(1) - 原地操作

## 代码实现（TypeScript）

```typescript
/**
 Do not return anything, modify nums in-place instead.
 */
function rotate(nums: number[], k: number): void {
    const n = nums.length;

    // 优化：k可能大于n，取模避免多余的旋转
    k = k % n;

    // 如果k为0，无需旋转
    if (k === 0) return;

    // 辅助函数：反转数组的[start, end]区间
    const reverse = (start: number, end: number): void => {
        while (start < end) {
            // 交换start和end位置的元素
            [nums[start], nums[end]] = [nums[end], nums[start]];
            start++;
            end--;
        }
    };

    // 步骤1: 反转整个数组
    reverse(0, n - 1);

    // 步骤2: 反转前k个元素
    reverse(0, k - 1);

    // 步骤3: 反转后n-k个元素
    reverse(k, n - 1);
}
```

---

## 代码原理详解

### 核心逻辑

1. **取模优化**：
   - `k % n`：如果 k >= n，轮转 n 次相当于没轮转
   - 例如：n=7, k=10，等价于 k=3

2. **反转函数**：
   - 双指针从两端向中间移动
   - 交换对应位置的元素
   - 时间 O(end - start)，空间 O(1)

3. **三次反转**：
   - 每次反转都是原地操作
   - 总时间 O(n)，空间 O(1)

### 设计思路

- **数学变换**：利用反转的性质巧妙实现轮转
- **原地操作**：不使用额外数组，满足题目要求
- **优雅简洁**：代码量少，逻辑清晰

## 常见问题

**Q1: 为什么要对 k 取模？**
A: 因为轮转 n 次等于没轮转，k=10 和 k=10%7=3 的效果相同。取模可以减少不必要的操作。

**Q2: 能否用额外数组？**
A: 可以，但空间复杂度 O(n)，不如三次反转的 O(1)。
```typescript
function rotate(nums: number[], k: number): void {
    const n = nums.length;
    k = k % n;
    const result = [...nums.slice(n - k), ...nums.slice(0, n - k)];
    for (let i = 0; i < n; i++) {
        nums[i] = result[i];
    }
}
```

**Q3: 能否一个一个轮转 k 次？**
A: 可以，但时间复杂度 O(n * k)，k 很大时会超时。

**Q4: 反转的边界为什么是 `k-1` 和 `k`？**
A:
- 前 k 个元素的索引是 [0, k-1]
- 后 n-k 个元素的索引是 [k, n-1]

## 其他解法（了解）

### 方法二：环状替换

```typescript
function rotate(nums: number[], k: number): void {
    const n = nums.length;
    k = k % n;

    let count = 0; // 已移动的元素数量

    for (let start = 0; count < n; start++) {
        let current = start;
        let prev = nums[start];

        do {
            const next = (current + k) % n;
            [nums[next], prev] = [prev, nums[next]];
            current = next;
            count++;
        } while (start !== current);
    }
}
```

**优点**：理论上只遍历一次
**缺点**：代码复杂，不如三次反转直观

## 数学证明

**定理：** 三次反转等价于轮转

**证明：**
```
设数组 A = [a₁, a₂, ..., aₙ₋ₖ, aₙ₋ₖ₊₁, ..., aₙ]
记 L = [a₁, ..., aₙ₋ₖ]（左部分）
记 R = [aₙ₋ₖ₊₁, ..., aₙ]（右部分）

目标：得到 [R, L]

步骤1: reverse(A) = reverse([L, R])
     = [reverse(R), reverse(L)]
     = [R', L']

步骤2: reverse(R') = R

步骤3: reverse(L') = L

结果: [R, L] ✓

证毕。
```

## 边界情况

### 情况1：k = 0

```
输入: [1,2,3], k = 0
输出: [1,2,3]（无需操作）
```

### 情况2：k = n

```
输入: [1,2,3], k = 3
优化: k = 3 % 3 = 0
输出: [1,2,3]（相当于没轮转）
```

### 情况3：k > n

```
输入: [1,2,3], k = 10
优化: k = 10 % 3 = 1
输出: [3,1,2]
```

### 情况4：只有一个元素

```
输入: [1], k = 任意值
输出: [1]（无需操作）
```
