# 41. 缺失的第一个正数【困难】

## 题目描述

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,2,0]
输出：3
```

### 示例 2
```
输入：nums = [3,4,-1,1]
输出：2
```

### 示例 3
```
输入：nums = [7,8,9,11,12]
输出：1
```

### 提示
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

---

## 解题思路（面试推荐 - 最优解）

### 方法：原地哈希

**核心思想：**
- 对于长度为 n 的数组，缺失的第一个正数一定在 [1, n+1] 范围内
- 把数组本身当作哈希表：将值 i 放到索引 i-1 的位置
- 遍历调整后的数组，第一个不满足 `nums[i] == i+1` 的位置 i，答案就是 i+1

**为什么答案在 [1, n+1]？**
```
最好情况：数组是 [1, 2, 3, ..., n]
         答案是 n+1

最坏情况：数组缺少某个 1~n 之间的正数
         答案在 [1, n] 之间

所以答案一定在 [1, n+1] 范围内
```

**算法流程：**
1. 遍历数组，将值 i 放到索引 i-1 的位置（通过交换）
2. 再次遍历数组，找到第一个 `nums[i] != i+1` 的位置
3. 返回 i+1

**时间复杂度：** O(n) - 每个元素最多被交换一次
**空间复杂度：** O(1) - 原地操作

---

## 代码实现（TypeScript）

```typescript
function firstMissingPositive(nums: number[]): number {
    const n = nums.length;

    // 第一步：将每个正数放到它应该在的位置
    // 目标：nums[i] = i + 1（值为 i+1 的元素放在索引 i）
    for (let i = 0; i < n; i++) {
        // 持续交换，直到当前位置的元素无法再交换
        while (
            nums[i] > 0 &&           // 是正数
            nums[i] <= n &&          // 在范围内
            nums[nums[i] - 1] !== nums[i]  // 目标位置的值不等于当前值（避免死循环）
        ) {
            // 将 nums[i] 交换到索引 nums[i]-1 的位置
            const targetIndex = nums[i] - 1;
            [nums[i], nums[targetIndex]] = [nums[targetIndex], nums[i]];
        }
    }

    // 第二步：找到第一个不满足 nums[i] = i+1 的位置
    for (let i = 0; i < n; i++) {
        if (nums[i] !== i + 1) {
            return i + 1;
        }
    }

    // 如果所有位置都满足，说明数组是 [1,2,3,...,n]，答案是 n+1
    return n + 1;
}
```

## 代码原理详解

### 核心逻辑

1. **原地哈希思想**：
   - 将数组视为哈希表
   - 索引 i 存储值 i+1
   - 例如：索引0存1，索引1存2，索引2存3...

2. **交换条件**：
   ```
   nums[i] > 0              // 只处理正数
   nums[i] <= n             // 超出范围的数无用（答案最多是n+1）
   nums[nums[i]-1] != nums[i]  // 避免重复交换（如两个1）
   ```

3. **为什么用 while 不用 if？**
   - 交换后，新的 nums[i] 可能还需要交换
   - 例如：[3,4,-1,1]，i=0时，先交换3到索引2，然后处理交换来的-1

4. **查找答案**：
   - 第一个不满足 `nums[i] == i+1` 的位置，答案就是 i+1

### 设计思路

- **巧妙利用数组本身**：不使用额外空间
- **范围限定**：只关心 [1, n] 的数字
- **原地标记**：通过位置关系标记存在性

## 为什么时间复杂度是 O(n)？

虽然有嵌套循环，但：

```
每个元素最多被交换到正确位置一次

例如：值为3的元素
- 第一次遇到：交换到索引2
- 第二次遇到（在索引2）：已经在正确位置，不交换

所以总交换次数 <= n
总时间复杂度 = O(n)
```

**反例**：如果没有 `nums[nums[i]-1] !== nums[i]` 这个条件

```
nums = [1, 1]
i=0: 交换 nums[0] 和 nums[0] → 死循环！
```

这个条件避免了重复元素的死循环。

## 常见问题

**Q1: 为什么不用 HashSet？**
A: HashSet 需要 O(n) 额外空间，不满足 O(1) 空间要求。原地哈希利用数组本身，不需要额外空间。

**Q2: 如果数组中有重复元素怎么办？**
A: 条件 `nums[nums[i]-1] !== nums[i]` 处理了这种情况。如果目标位置已经是相同的值，不交换。

**Q3: 负数和大于 n 的数如何处理？**
A: 它们对答案没有贡献，在第一步就被过滤（不满足交换条件）。

**Q4: 能否用排序？**
A: 排序后可以解决，但排序需要 O(n log n) 时间，不满足 O(n) 要求。

## 其他解法（了解）

### 方法二：HashSet（空间 O(n)）

```typescript
function firstMissingPositive(nums: number[]): number {
    const set = new Set(nums);
    const n = nums.length;

    for (let i = 1; i <= n; i++) {
        if (!set.has(i)) {
            return i;
        }
    }

    return n + 1;
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(n) - 不满足题目要求

### 方法三：标记法（负数标记）

```typescript
function firstMissingPositive(nums: number[]): number {
    const n = nums.length;

    // 将所有非正数改为 n+1
    for (let i = 0; i < n; i++) {
        if (nums[i] <= 0) {
            nums[i] = n + 1;
        }
    }

    // 使用索引标记：将值 i 对应的索引 i-1 的元素改为负数
    for (let i = 0; i < n; i++) {
        const val = Math.abs(nums[i]);
        if (val <= n) {
            nums[val - 1] = -Math.abs(nums[val - 1]);
        }
    }

    // 找到第一个正数的索引
    for (let i = 0; i < n; i++) {
        if (nums[i] > 0) {
            return i + 1;
        }
    }

    return n + 1;
}
```

**优点**：也是 O(n) 时间 O(1) 空间
**缺点**：代码稍复杂，需要处理负数

## 边界情况

### 情况1：数组是连续正整数

```
输入: [1, 2, 3, 4, 5]
调整: [1, 2, 3, 4, 5]（已经在正确位置）
查找: 所有位置都满足
输出: 6
```

### 情况2：数组全是负数或0

```
输入: [-1, -2, 0]
调整: [-1, -2, 0]（无正数，不交换）
查找: nums[0]=-1 != 1
输出: 1
```

### 情况3：数组只有一个元素

```
输入: [1]
输出: 2

输入: [2]
调整: [2]（2超出范围[1,1]，不交换）
查找: nums[0]=2 != 1
输出: 1
```
