# 560. 和为 K 的子数组【中等】

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回 该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,1,1], k = 2
输出：2
```

### 示例 2
```
输入：nums = [1,2,3], k = 3
输出：2
```

### 提示
- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

---

## 解题思路（面试推荐 - 最优解）

### 方法：前缀和 + 哈希表

**核心思想：**
- 使用前缀和 `preSum[i]` 表示 `nums[0...i]` 的和
- 如果 `preSum[j] - preSum[i] = k`，则 `nums[i+1...j]` 的和为 `k`
- 转化为：寻找满足 `preSum[i] = preSum[j] - k` 的 `i`
- 使用哈希表记录每个前缀和出现的次数
- 遍历数组时，查找 `preSum - k` 是否存在于哈希表中

**为什么不能用滑动窗口？**
- 数组中有负数，窗口扩大不一定和增大，窗口缩小不一定和减小
- 滑动窗口适用于单调性问题（如全是正数）
- 本题需要用前缀和+哈希表

**算法流程：**
```
1. 初始化：preSum = 0, count = 0, map = {0: 1}
   （map[0] = 1 表示前缀和为0出现过1次，对应空数组）
2. 遍历数组：
   - 更新前缀和：preSum += nums[i]
   - 查找：if (preSum - k) in map，count += map[preSum - k]
   - 记录：map[preSum]++
3. 返回 count
```

**时间复杂度：** O(n) - 只遍历一次数组
**空间复杂度：** O(n) - 哈希表最多存储 n 个前缀和

## 代码实现（TypeScript）

```typescript
function subarraySum(nums: number[], k: number): number {
    // 记录和为k的子数组个数
    let count = 0;

    // 当前的前缀和
    let preSum = 0;

    // 哈希表：key是前缀和，value是该前缀和出现的次数
    const preSumMap = new Map<number, number>();

    // 初始化：前缀和为0出现过1次（对应空数组）
    // 这是为了处理"从数组开头到当前位置的和恰好为k"的情况
    preSumMap.set(0, 1);

    // 遍历数组
    for (let i = 0; i < nums.length; i++) {
        // 更新前缀和
        preSum += nums[i];

        // 查找是否存在前缀和 = preSum - k
        // 如果存在，说明存在子数组的和为k
        // preSum[j] - preSum[i] = k  =>  preSum[i] = preSum[j] - k
        const target = preSum - k;
        if (preSumMap.has(target)) {
            // 累加符合条件的子数组个数
            count += preSumMap.get(target)!;
        }

        // 将当前前缀和加入哈希表
        preSumMap.set(preSum, (preSumMap.get(preSum) || 0) + 1);
    }

    return count;
}
```

## 代码原理详解

### 核心逻辑

1. **前缀和定义**：
   - `preSum[i]` = `nums[0] + nums[1] + ... + nums[i]`
   - 子数组 `nums[i+1...j]` 的和 = `preSum[j] - preSum[i]`

2. **转化问题**：
   - 找满足 `preSum[j] - preSum[i] = k` 的 (i, j) 对
   - 等价于：对于每个 j，找有多少个 i 满足 `preSum[i] = preSum[j] - k`

3. **哈希表作用**：
   - 记录每个前缀和出现的次数
   - O(1) 时间查找 `preSum - k` 是否存在

4. **为什么初始化 `map.set(0, 1)`？**：
   - 表示"前缀和为0出现过1次"
   - 对应空数组（没有元素）
   - 处理"从数组开头到当前位置的和恰好为k"的情况

### 设计思路

- **状态压缩**：不需要存储完整的前缀和数组，只需维护当前前缀和
- **哈希优化**：用哈希表记录历史信息，实现 O(1) 查找
- **一次遍历**：边计算前缀和，边查找，边记录

## 运行示例

### 示例 1：`nums = [1, 1, 1], k = 2`

**完整执行过程：**

```
初始状态:
  preSum = 0
  count = 0
  preSumMap = {0: 1}

迭代1: i = 0, nums[0] = 1
  - preSum = 0 + 1 = 1
  - target = preSum - k = 1 - 2 = -1
  - preSumMap 中没有 -1
  - count = 0
  - preSumMap.set(1, 1) → preSumMap = {0: 1, 1: 1}

迭代2: i = 1, nums[1] = 1
  - preSum = 1 + 1 = 2
  - target = preSum - k = 2 - 2 = 0
  - preSumMap 中有 0，出现次数为 1
  - count = 0 + 1 = 1 ✓ (对应子数组 [1,1])
  - preSumMap.set(2, 1) → preSumMap = {0: 1, 1: 1, 2: 1}

迭代3: i = 2, nums[2] = 1
  - preSum = 2 + 1 = 3
  - target = preSum - k = 3 - 2 = 1
  - preSumMap 中有 1，出现次数为 1
  - count = 1 + 1 = 2 ✓ (对应子数组 [1,1])
  - preSumMap.set(3, 1) → preSumMap = {0: 1, 1: 1, 2: 1, 3: 1}

最终结果: count = 2
```

**找到的两个子数组：**
1. `nums[0...1] = [1, 1]`，和为 2
2. `nums[1...2] = [1, 1]`，和为 2

**执行表格：**

| i | nums[i] | preSum | target (preSum-k) | map中有target? | count | preSumMap |
|---|---------|--------|-------------------|----------------|-------|-----------|
| 初始 | - | 0 | - | - | 0 | {0:1} |
| 0 | 1 | 1 | -1 | 否 | 0 | {0:1, 1:1} |
| 1 | 1 | 2 | 0 | 是(1次) | **1** | {0:1, 1:1, 2:1} |
| 2 | 1 | 3 | 1 | 是(1次) | **2** | {0:1, 1:1, 2:1, 3:1} |

## 常见问题

**Q1: 为什么要初始化 `preSumMap.set(0, 1)`？**
A: 这表示"前缀和为0出现过1次"，对应空数组。例如 `nums = [1, 2]`，`k = 3`，当 `preSum = 3` 时，需要查找 `target = 0`，如果没有初始化，就找不到子数组 `[1, 2]`。

**Q2: 为什么不能用滑动窗口？**
A: 数组中有负数，窗口大小变化与和的变化没有单调性关系。滑动窗口只适用于单调问题。

**Q3: 能否用前缀和数组？**
A: 可以，但需要两层循环枚举所有子数组，时间复杂度 O(n²)。哈希表优化到 O(n)。

**Q4: 如果题目要求返回子数组的索引呢？**
A: 需要在哈希表中存储索引列表，而不仅仅是计数。

## 算法正确性证明

**定理：** 前缀和差值等于子数组和

**证明：**
```
设 preSum[i] = nums[0] + nums[1] + ... + nums[i]

子数组 nums[i+1...j] 的和:
  = nums[i+1] + nums[i+2] + ... + nums[j]
  = (nums[0] + ... + nums[j]) - (nums[0] + ... + nums[i])
  = preSum[j] - preSum[i]

如果 preSum[j] - preSum[i] = k
则 preSum[i] = preSum[j] - k

所以只需统计满足 preSum[i] = preSum[j] - k 的 i 的个数
```
