# 76. 最小覆盖子串【困难】

## 题目描述

给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。

**注意：**
- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

---

## 输入输出示例

### 示例 1
```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

### 示例 2
```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

### 示例 3
```
输入：s = "a", t = "aa"
输出：""
解释：t 中两个字符 'a' 均应包含在 s 的子串中，因此没有符合条件的子字符串，返回空字符串。
```

### 提示
- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由英文字母组成

---

## 解题思路（面试推荐 - 最优解）

### 方法：滑动窗口 + 哈希表

**核心思想：**
- 使用滑动窗口 `[left, right]` 在 s 中寻找包含 t 所有字符的子串
- 用两个哈希表：
  - `need`：记录 t 中每个字符需要的数量
  - `window`：记录当前窗口中每个字符的数量
- 用 `valid` 记录窗口中满足 need 条件的字符种类数
- 算法流程：
  1. **扩大窗口**：right 右移，将字符加入窗口
  2. **判断是否覆盖**：当 `valid == need.size` 时，窗口覆盖了 t
  3. **缩小窗口**：left 右移，尝试找到最小窗口
  4. **更新结果**：每次找到覆盖时，更新最小子串

**时间复杂度：** O(m + n) - m 是 s 的长度，n 是 t 的长度
**空间复杂度：** O(k) - k 是字符集大小

## 代码实现（TypeScript）

```typescript
function minWindow(s: string, t: string): string {
    // need记录t中每个字符需要的数量
    const need = new Map<string, number>();
    // window记录当前窗口中每个字符的数量
    const window = new Map<string, number>();

    // 统计t中每个字符的频率
    for (const char of t) {
        need.set(char, (need.get(char) || 0) + 1);
    }

    // 左右指针
    let left = 0, right = 0;
    // valid表示窗口中满足need条件的字符种类数
    let valid = 0;

    // 记录最小覆盖子串的起始位置和长度
    let start = 0, minLen = Infinity;

    while (right < s.length) {
        // 即将移入窗口的字符
        const charIn = s[right];
        // 扩大窗口
        right++;

        // 如果charIn在need中，更新窗口数据
        if (need.has(charIn)) {
            window.set(charIn, (window.get(charIn) || 0) + 1);
            // 如果当前字符的数量满足need，valid++
            if (window.get(charIn) === need.get(charIn)) {
                valid++;
            }
        }

        // 判断左侧窗口是否要收缩
        // 当窗口覆盖了t的所有字符时，尝试缩小窗口
        while (valid === need.size) {
            // 更新最小覆盖子串
            if (right - left < minLen) {
                start = left;
                minLen = right - left;
            }

            // 即将移出窗口的字符
            const charOut = s[left];
            // 缩小窗口
            left++;

            // 如果charOut在need中，更新窗口数据
            if (need.has(charOut)) {
                // 如果当前字符的数量刚好满足need，移除后会不满足
                if (window.get(charOut) === need.get(charOut)) {
                    valid--;
                }
                window.set(charOut, window.get(charOut)! - 1);
            }
        }
    }

    // 返回最小覆盖子串
    return minLen === Infinity ? "" : s.substring(start, start + minLen);
}
```

## 代码原理详解

### 核心逻辑

1. **两个哈希表**：
   - `need`：目标字符及其数量（t 的字符频率）
   - `window`：当前窗口的字符及其数量

2. **valid 计数器**：
   - 记录窗口中有多少字符种类的数量满足 need
   - 当 `valid === need.size` 时，窗口覆盖了 t

3. **窗口扩大**（right++）：
   - 将 s[right] 加入窗口
   - 更新 window 和 valid

4. **窗口缩小**（left++）：
   - 当窗口覆盖 t 时，尝试缩小窗口找最小子串
   - 将 s[left] 移出窗口
   - 更新 window 和 valid

5. **结果更新**：
   - 每次窗口覆盖 t 时，检查是否是更小的子串
   - 记录起始位置和长度

### 设计思路

- **双指针滑动窗口**：动态调整窗口大小
- **哈希表快速查询**：O(1) 时间判断字符是否在 t 中
- **valid 优化**：避免每次都遍历哈希表比较

## 常见问题

**Q1: valid 的作用是什么？**
A: valid 记录窗口中满足 need 条件的字符种类数。当 `valid === need.size` 时，说明所有字符都满足数量要求，窗口覆盖了 t。

**Q2: 为什么要用 `window.get(charIn) === need.get(charIn)` 而不是 `>=`？**
A: 因为我们只在数量刚好相等时 valid++。如果窗口中某字符数量超过 need，valid 不变（已经满足了）。

**Q3: 能否不用 valid，每次都遍历比较 window 和 need？**
A: 可以，但时间复杂度会增加到 O(n * k)，k 是字符种类数。valid 优化到 O(n)。

**Q4: 为什么窗口缩小时要用 while 而不是 if？**
A: 因为可能需要连续移除多个字符才能找到最小窗口。
