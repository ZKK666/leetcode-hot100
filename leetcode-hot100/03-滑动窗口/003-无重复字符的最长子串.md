# 3. 无重复字符的最长子串【中等】

## 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。

---

## 输入输出示例

### 示例 1
```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

### 示例 2
```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

### 示例 3
```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。
```

### 提示
- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

---

## 解题思路（面试推荐 - 最优解）

### 方法：滑动窗口 + 哈希集合

**核心思想：**
- 使用滑动窗口 `[left, right]` 维护一个无重复字符的子串
- 使用 `Set` 记录窗口内的字符
- `right` 指针不断右移扩大窗口
- 当遇到重复字符时，`left` 指针右移缩小窗口，直到没有重复
- 每次更新最大长度

**为什么使用滑动窗口？**
- 暴力法需要枚举所有子串，时间复杂度 O(n³) 或 O(n²)
- 滑动窗口利用了"无重复子串"的性质：
  - 如果 `[left, right]` 没有重复，那么 `[left, right+1]` 最多只有一个重复
  - 不需要重新检查整个窗口

**算法流程：**
```
1. right 向右扩展，将 s[right] 加入窗口
2. 如果 s[right] 已经在窗口中：
   - left 不断右移，移除 s[left]，直到 s[right] 不重复
3. 更新最大长度 = max(maxLen, right - left + 1)
4. 重复步骤 1-3，直到 right 到达字符串末尾
```

**时间复杂度：** O(n) - 每个字符最多被访问两次（一次被 right 加入，一次被 left 移除）
**空间复杂度：** O(min(n, m)) - m 是字符集大小（英文字母+数字+符号，最多128个字符）

## 代码实现（TypeScript）

```typescript
function lengthOfLongestSubstring(s: string): number {
    // 使用Set存储当前窗口内的字符
    const charSet = new Set<string>();

    // 左指针，表示窗口的左边界
    let left = 0;

    // 记录最长无重复子串的长度
    let maxLength = 0;

    // 右指针遍历整个字符串
    for (let right = 0; right < s.length; right++) {
        // 当前要加入窗口的字符
        const currentChar = s[right];

        // 如果当前字符已经在窗口中，说明有重复
        // 需要移动left指针，直到窗口中不包含currentChar
        while (charSet.has(currentChar)) {
            // 移除窗口左边界的字符
            charSet.delete(s[left]);
            // 左指针右移
            left++;
        }

        // 将当前字符加入窗口
        charSet.add(currentChar);

        // 更新最大长度
        // 当前窗口的长度 = right - left + 1
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}
```

## 代码原理详解

### 核心逻辑

1. **滑动窗口维护**：
   - `[left, right]` 表示当前的无重复子串
   - `charSet` 存储窗口内的所有字符
   - 窗口始终保持无重复字符的性质

2. **窗口扩展**：
   - `right` 指针每次向右移动一位
   - 尝试将 `s[right]` 加入窗口

3. **窗口收缩**：
   - 当 `s[right]` 已在窗口中时，触发收缩
   - 不断移除 `s[left]` 并 `left++`，直到 `s[right]` 不重复

4. **长度更新**：
   - 每次加入新字符后，更新最大长度
   - `right - left + 1` 就是当前窗口的大小

### 设计思路

- **动态维护**：窗口随着遍历动态调整大小
- **单调性**：right 只增不减，left 只增不减
- **快速查找**：Set 提供 O(1) 的查找、插入、删除操作

### 示例 1：`s = "abcabcbb"`

**完整执行过程：**

```
初始状态:
  s = "abcabcbb"
  索引 0 1 2 3 4 5 6 7
  left = 0, maxLength = 0, charSet = {}

迭代1: right = 0, s[0] = 'a'
  - charSet 中没有 'a'
  - charSet.add('a') → charSet = {'a'}
  - 窗口: "a"
  - maxLength = max(0, 0-0+1) = 1
  - 状态: left=0, charSet={'a'}, maxLen=1

迭代2: right = 1, s[1] = 'b'
  - charSet 中没有 'b'
  - charSet.add('b') → charSet = {'a', 'b'}
```

## 常见问题

**Q1: 为什么时间复杂度是 O(n) 而不是 O(n²)？**
A: 虽然有嵌套循环，但每个字符最多被访问两次：
- 一次被 `right` 加入窗口
- 一次被 `left` 移除窗口
- 总访问次数 ≤ 2n，所以是 O(n)

**Q2: 能否用数组代替 Set？**
A: 可以。如果字符集已知（如只有小写字母），可以用数组记录字符最后出现的位置，优化空间。

**Q3: 为什么用 while 而不是 if？**
A: 因为可能需要连续删除多个字符。例如 "abba"，当 right 指向第二个 'a' 时，需要删除前面的 'a' 和 'b'。

**Q4: 能否用双指针但不用 Set？**
A: 可以，但需要额外逻辑判断重复。Set 使代码更简洁。

## 优化方法（可选）

### 方法二：优化的滑动窗口（使用 Map）

```typescript
function lengthOfLongestSubstring(s: string): number {
    // Map 存储字符最后出现的索引
    const charIndexMap = new Map<string, number>();
    let left = 0;
    let maxLength = 0;

    for (let right = 0; right < s.length; right++) {
        const char = s[right];

        // 如果字符在窗口内出现过，直接跳到重复位置的下一个
        if (charIndexMap.has(char) && charIndexMap.get(char)! >= left) {
            left = charIndexMap.get(char)! + 1;
        }

        // 更新字符的最新位置
        charIndexMap.set(char, right);

        // 更新最大长度
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}
```

**优点**：
- 避免了 while 循环，更直接
- 直接跳到重复字符的下一个位置

**时间复杂度**：O(n)
**空间复杂度**：O(min(n, m))
