# 239. 滑动窗口最大值【困难】

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

---

## 输入输出示例

### 示例 1
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

### 示例 2
```
输入：nums = [1], k = 1
输出：[1]
```

### 提示
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

---

## 解题思路（面试推荐 - 最优解）

### 方法：单调双端队列

**核心思想：**
- 使用双端队列（deque）维护窗口内可能成为最大值的元素的**索引**
- 队列保持**单调递减**性质：队首元素最大，队尾元素最小
- 窗口滑动时：
  - 移除队首过期的元素（索引 < i - k + 1）
  - 移除队尾比当前元素小的元素（它们永远不可能是最大值）
  - 将当前元素索引加入队尾
  - 队首元素就是当前窗口的最大值

**为什么使用单调队列？**
- 暴力法：每次窗口移动都遍历k个元素找最大值，时间复杂度 O(n * k)
- 单调队列：维护一个有序结构，每个元素最多进队出队各一次，时间复杂度 O(n)

**单调队列的性质：**
```
队列中存储索引，从队首到队尾，索引对应的值递减

例如：nums = [3, 1, 5, 2], 队列可能是 [2] (只存5的索引)
- 3入队: [0]
- 1入队: [0, 1] (3 > 1, 保持递减)
- 5入队: 移除0,1 → [2] (5最大，前面的都没用了)
- 2入队: [2, 3] (5 > 2, 保持递减)
```

**时间复杂度：** O(n) - 每个元素最多入队出队各一次
**空间复杂度：** O(k) - 队列最多存储k个元素

## 代码实现（TypeScript）

```typescript
function maxSlidingWindow(nums: number[], k: number): number[] {
    const result: number[] = [];
    // 双端队列，存储数组索引
    // 队列保持单调递减：队首索引对应的值最大
    const deque: number[] = [];

    for (let i = 0; i < nums.length; i++) {
        // 1. 移除队首过期的元素
        // 如果队首元素的索引已经不在当前窗口内，移除它
        // 窗口范围: [i - k + 1, i]
        while (deque.length > 0 && deque[0] < i - k + 1) {
            deque.shift();  // 移除队首
        }

        // 2. 维护单调递减性质
        // 移除队尾所有小于当前元素的索引
        // 因为当前元素更大且更新，旧的小元素不可能成为最大值
        while (deque.length > 0 && nums[deque[deque.length - 1]] < nums[i]) {
            deque.pop();  // 移除队尾
        }

        // 3. 将当前索引加入队尾
        deque.push(i);

        // 4. 当窗口形成后（i >= k-1），记录当前窗口最大值
        // 队首元素就是当前窗口的最大值
        if (i >= k - 1) {
            result.push(nums[deque[0]]);
        }
    }

    return result;
}
```

## 代码原理详解

### 核心逻辑

1. **队列存储索引**：
   - 不存储值，存储索引
   - 方便判断元素是否过期

2. **单调递减维护**：
   - 队首到队尾，索引对应的值递减
   - `nums[deque[0]] >= nums[deque[1]] >= ... >= nums[deque[n]]`

3. **三步操作**：
   - **移除过期**：队首索引 < i - k + 1 时移除
   - **维护单调**：队尾值 < nums[i] 时移除
   - **加入新元素**：将 i 加入队尾

4. **获取最大值**：
   - 队首元素 `deque[0]` 对应的值就是最大值
   - `nums[deque[0]]` 就是当前窗口的最大值

### 设计思路

- **单调性优化**：只保留可能成为最大值的元素
- **双端队列**：需要队首队尾都能删除元素
- **索引而非值**：便于判断是否过期

## 单调队列图示

### 为什么移除队尾小元素？

```
假设队列: [索引i, 索引j], 其中 i < j, nums[i] <= nums[j]

当窗口向右滑动：
- 索引i会比索引j先过期
- nums[i] <= nums[j]，索引j的值更大
- 索引i永远不可能成为最大值（被j压制）

结论：可以安全移除索引i
```

**示例：**
```
nums = [3, 1, 5], 窗口大小 = 2

当 i=2 时：
  - deque = [0, 1] (值为 [3, 1])
  - 要加入 5（索引2）
  - nums[1]=1 < 5，移除索引1
  - nums[0]=3 < 5，移除索引0
  - deque = [2] (值为 [5])

这样做的好处：5比前面所有元素都大，前面的元素不可能再成为最大值
```

## 常见问题

**Q1: 为什么要存储索引而不是值？**
A: 因为需要判断元素是否过期（是否还在窗口内）。只有索引才能判断位置关系。

**Q2: 时间复杂度真的是 O(n) 吗？**
A: 是的。虽然有 while 循环，但每个元素最多入队一次、出队一次，总操作次数 ≤ 2n，所以是 O(n)。

**Q3: 能否用优先队列（堆）？**
A: 可以，但堆无法高效删除中间元素，需要标记删除，实现更复杂。单调队列是最优解。

**Q4: 为什么用 shift() 而不是更高效的数据结构？**
A: 在 TypeScript/JavaScript 中，数组的 shift() 是 O(n)，理论上应该用真正的双端队列。但题目数据规模下，shift() 的常数因子很小，实际表现可接受。要优化可以用循环数组或双向链表。

## 优化（可选）

### 使用循环数组模拟双端队列

```typescript
function maxSlidingWindow(nums: number[], k: number): number[] {
    const result: number[] = [];
    const deque = new Array(nums.length);
    let head = 0, tail = 0;

    for (let i = 0; i < nums.length; i++) {
        // 移除过期元素
        while (head < tail && deque[head] < i - k + 1) {
            head++;
        }

        // 维护单调递减
        while (head < tail && nums[deque[tail - 1]] < nums[i]) {
            tail--;
        }

        // 加入当前索引
        deque[tail++] = i;

        // 记录最大值
        if (i >= k - 1) {
            result.push(nums[deque[head]]);
        }
    }

    return result;
}
```

**优点**：避免了 shift() 的 O(n) 操作，所有操作都是 O(1)
