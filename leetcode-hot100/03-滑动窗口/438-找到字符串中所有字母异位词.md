# 438. 找到字符串中所有字母异位词【中等】

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**异位词** 指由相同字母重排列形成的字符串（包括相同的字符串）。

---

## 输入输出示例

### 示例 1
```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

### 示例 2
```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

### 提示
- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

---

## 解题思路（面试推荐 - 最优解）

### 方法：固定大小滑动窗口 + 字符频率数组

**核心思想：**
- 使用固定大小的滑动窗口，窗口大小 = `p.length`
- 用数组记录字符频率（因为只有小写字母，用长度26的数组）
- 窗口每次滑动一位：移除左边字符，加入右边字符
- 当窗口内字符频率与 `p` 的字符频率完全相同时，找到一个异位词

**为什么使用滑动窗口？**
- 暴力法需要枚举所有长度为 `p.length` 的子串，每个子串需要 O(m) 时间判断是否为异位词，总时间 O(n * m)
- 滑动窗口每次只更新一个字符的频率，时间 O(1)
- 总时间复杂度优化到 O(n)

**算法流程：**
```
1. 统计 p 的字符频率
2. 初始化窗口：统计 s 前 p.length 个字符的频率
3. 比较频率数组，相同则记录起始索引
4. 窗口向右滑动：
   - 移除 s[left] 的频率
   - 加入 s[right] 的频率
   - 比较频率数组
5. 重复步骤 4 直到遍历完整个 s
```

**时间复杂度：** O(n + m) ≈ O(n)
- n 是 s 的长度，m 是 p 的长度
- 统计频率：O(m)
- 滑动窗口：O(n)，每次比较26个字符频率 O(26) = O(1)

**空间复杂度：** O(1) - 只用两个长度26的数组

## 代码实现（TypeScript）

```typescript
function findAnagrams(s: string, p: string): number[] {
    const result: number[] = [];
    const sLen = s.length;
    const pLen = p.length;

    // 边界情况：s 比 p 短，不可能有异位词
    if (sLen < pLen) return result;

    // 字符频率数组（小写字母 a-z）
    const pCount = new Array(26).fill(0);
    const sCount = new Array(26).fill(0);

    // 统计 p 的字符频率
    for (let i = 0; i < pLen; i++) {
        pCount[p.charCodeAt(i) - 'a'.charCodeAt(0)]++;
    }

    // 初始化窗口：统计 s 前 pLen 个字符的频率
    for (let i = 0; i < pLen; i++) {
        sCount[s.charCodeAt(i) - 'a'.charCodeAt(0)]++;
    }

    // 辅助函数：比较两个频率数组是否相等
    const isEqual = (): boolean => {
        for (let i = 0; i < 26; i++) {
            if (pCount[i] !== sCount[i]) return false;
        }
        return true;
    };

    // 检查第一个窗口
    if (isEqual()) {
        result.push(0);
    }

    // 滑动窗口：从索引 pLen 开始
    for (let right = pLen; right < sLen; right++) {
        // 计算左边界索引
        const left = right - pLen;

        // 移除窗口最左边的字符
        sCount[s.charCodeAt(left) - 'a'.charCodeAt(0)]--;

        // 加入窗口最右边的新字符
        sCount[s.charCodeAt(right) - 'a'.charCodeAt(0)]++;

        // 检查当前窗口是否为异位词
        if (isEqual()) {
            result.push(left + 1);  // left + 1 是新窗口的起始索引
        }
    }

    return result;
}
```

## 代码原理详解

### 核心逻辑

1. **频率统计**：
   - 用长度26的数组表示26个小写字母的频率
   - `charCodeAt(i) - 'a'.charCodeAt(0)` 将字符映射到 0-25 的索引

2. **固定窗口**：
   - 窗口大小固定为 `p.length`
   - 窗口 `[left, right]`，其中 `right - left + 1 = pLen`

3. **窗口滑动**：
   - 每次移动：移除 `s[left]`，加入 `s[right]`
   - 更新频率数组：O(1) 时间

4. **频率比较**：
   - 比较两个频率数组是否完全相等
   - 26次比较，O(1) 时间

### 设计思路

- **空间优化**：使用数组代替 Map（小写字母固定26个）
- **时间优化**：滑动窗口避免重复计算
- **简洁实现**：isEqual 函数提高代码可读性

## 常见问题

**Q1: 为什么用数组而不是 Map？**
A: 因为只有小写字母（26个），数组访问更快，空间固定。如果字符集很大或未知，用 Map 更合适。

**Q2: 能否优化 isEqual 函数？**
A: 可以。维护一个计数器记录"匹配的字符种类数"，当计数器等于26时表示完全匹配。这样每次滑动只需 O(1) 时间。

**Q3: 如果 s 或 p 为空怎么办？**
A: 题目保证长度 >= 1，但可以在开头加边界检查：`if (!s || !p || s.length < p.length) return []`。

**Q4: 为什么 `left = right - pLen` 而不是 `left++`？**
A: 这样计算更清晰。当 `right = pLen` 时，`left = 0`；当 `right = pLen+1` 时，`left = 1`，符合窗口大小固定的逻辑。

## 优化方法（可选）

### 方法二：优化的滑动窗口（计数器优化）

```typescript
function findAnagrams(s: string, p: string): number[] {
    const result: number[] = [];
    const sLen = s.length;
    const pLen = p.length;

    if (sLen < pLen) return result;

    const count = new Array(26).fill(0);

    // 统计 p 的字符频率（正数）和 s 前 pLen 个字符的频率（负数）
    for (let i = 0; i < pLen; i++) {
        count[p.charCodeAt(i) - 'a'.charCodeAt(0)]++;
        count[s.charCodeAt(i) - 'a'.charCodeAt(0)]--;
    }

    // diff 记录不匹配的字符种类数
    let diff = 0;
    for (let i = 0; i < 26; i++) {
        if (count[i] !== 0) diff++;
    }

    if (diff === 0) result.push(0);

    // 滑动窗口
    for (let right = pLen; right < sLen; right++) {
        const left = right - pLen;

        // 加入 s[right]
        const rightIdx = s.charCodeAt(right) - 'a'.charCodeAt(0);
        if (count[rightIdx] === 0) diff++;
        count[rightIdx]--;
        if (count[rightIdx] === 0) diff--;

        // 移除 s[left]
        const leftIdx = s.charCodeAt(left) - 'a'.charCodeAt(0);
        if (count[leftIdx] === 0) diff++;
        count[leftIdx]++;
        if (count[leftIdx] === 0) diff--;

        if (diff === 0) result.push(left + 1);
    }

    return result;
}
```

**优点**：每次比较只需 O(1) 时间，而不是 O(26)
**总时间复杂度**：O(n)，常数因子更小
