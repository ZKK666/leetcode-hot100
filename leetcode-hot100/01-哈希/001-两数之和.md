# 001. 两数之和【简单】

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

---

## 输入输出示例

### 示例 1
```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

### 示例 2
```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

### 示例 3
```
输入：nums = [3,3], target = 6
输出：[0,1]
```

### 提示
- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- **只会存在一个有效答案**

---

## 解题思路（面试推荐）

### 方法：哈希表（一遍哈希）

**核心思想：**
- 使用哈希表（Map）存储已经遍历过的元素值和对应的索引
- 对于当前元素 `nums[i]`，计算 `complement = target - nums[i]`
- 在哈希表中查找是否存在 `complement`
- 如果存在，直接返回两个索引；否则将当前元素存入哈希表

**为什么使用哈希表？**
- 暴力解法需要双层循环，时间复杂度 O(n²)
- 哈希表可以在 O(1) 时间内查找元素是否存在
- 一次遍历即可完成，时间复杂度降低到 O(n)

**时间复杂度：** O(n) - 只需遍历一次数组
**空间复杂度：** O(n) - 哈希表最多存储 n 个元素

---

## 代码实现（TypeScript）

```typescript
function twoSum(nums: number[], target: number): number[] {
    // 创建哈希表，key存储数组元素值，value存储对应的索引
    const map = new Map<number, number>();

    // 遍历数组
    for (let i = 0; i < nums.length; i++) {
        // 计算当前元素需要配对的数字（目标值 - 当前值）
        const complement = target - nums[i];

        // 在哈希表中查找complement是否存在
        if (map.has(complement)) {
            // 如果存在，说明找到了两个数，返回它们的索引
            // map.get(complement)! 返回complement的索引
            // i 是当前元素的索引
            return [map.get(complement)!, i];
        }

        // 如果不存在，将当前元素及其索引存入哈希表
        // 为后续的元素提供查找依据
        map.set(nums[i], i);
    }

    // 根据题目约束，一定存在答案，这里只是为了满足TypeScript的返回类型
    return [];
}
```

## 代码原理详解

### 核心逻辑

1. **初始化哈希表**：使用 `Map<number, number>` 数据结构，键是数组元素值，值是该元素的索引。

2. **单次遍历**：只需要遍历一次数组，对于每个元素：
   - 先计算它需要配对的数字（`complement = target - nums[i]`）
   - 在已遍历的元素中查找这个配对数字
   - 如果找到，立即返回结果
   - 如果没找到，把当前元素存入哈希表

3. **为什么是一遍哈希？**
   - 我们不需要提前把所有元素都存入哈希表
   - 边遍历边查找，边存储
   - 当找到配对元素时，它的索引一定比当前索引小（因为已经被存入哈希表）

### 设计思路

- **空间换时间**：使用额外的哈希表空间，将查找时间从 O(n) 降低到 O(1)
- **提前返回**：一旦找到答案立即返回，不需要继续遍历
- **避免重复使用同一元素**：因为我们先查找再存储，所以不会将当前元素与自己配对

## 运行示例

### 示例 1：`nums = [2,7,11,15], target = 9`

| 步骤 | i | nums[i] | complement | map 状态 | 查找结果 | 操作 |
|------|---|---------|------------|----------|----------|------|
| 初始 | - | - | - | {} | - | 创建空Map |
| 1 | 0 | 2 | 7 | {} | 不存在 | map.set(2, 0) |
| 2 | 1 | 7 | 2 | {2→0} | **存在！** | 返回 [0, 1] |

**详细过程：**

```
初始状态：map = {}

第1步 (i=0, nums[0]=2):
  - complement = 9 - 2 = 7
  - map中查找7：不存在
  - 将(2, 0)存入map
  - map = {2 → 0}

第2步 (i=1, nums[1]=7):
  - complement = 9 - 7 = 2
  - map中查找2：存在！索引为0
  - 返回 [0, 1]
```

## 常见问题

**Q1: 为什么不会重复使用同一个元素？**
A: 因为我们先查找 `map.has(complement)`，再执行 `map.set(nums[i], i)`。当前元素还没有被存入哈希表，所以不会与自己匹配。

**Q2: 如果数组中有重复元素怎么办？**
A: 哈希表的键会被覆盖，但这不影响结果。因为我们只需要找到任意一对和为 target 的索引即可。

**Q3: 时间复杂度真的是 O(n) 吗？Map 的操作不需要时间吗？**
A: Map 的 `has()` 和 `set()` 操作在平均情况下都是 O(1)，所以总体时间复杂度是 O(n)。
