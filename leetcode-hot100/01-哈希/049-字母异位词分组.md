# 049. 字母异位词分组【中等】

## 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

---

## 输入输出示例

### 示例 1
```
输入: strs = ["eat","tea","tan","ate","nat","bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

### 示例 2
```
输入: strs = [""]
输出: [[""]]
```

### 示例 3
```
输入: strs = ["a"]
输出: [["a"]]
```

### 提示
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

---

## 解题思路（面试推荐）

### 方法：哈希表 + 排序

**核心思想：**
- 字母异位词的特点是：字符相同，但顺序不同
- 将每个字符串按字母排序后，异位词会得到相同的结果
- 使用排序后的字符串作为哈希表的 key，原字符串作为 value
- 最后将哈希表中的所有 value 数组收集起来

**举例说明：**
```
"eat" -> 排序后 -> "aet"
"tea" -> 排序后 -> "aet"
"ate" -> 排序后 -> "aet"

这三个单词排序后相同，说明它们是字母异位词
```

**为什么使用哈希表 + 排序？**
- 排序可以将字母异位词统一成相同的形式（作为唯一标识）
- 哈希表可以快速分组，相同 key 的字符串归为一组
- 时间复杂度相对较优，实现简单清晰

**时间复杂度：** O(n * k * log k)
- n 是字符串数组的长度
- k 是字符串的最大长度
- 每个字符串需要 O(k * log k) 时间排序

**空间复杂度：** O(n * k) - 哈希表存储所有字符串

## 代码实现（TypeScript）

```typescript
function groupAnagrams(strs: string[]): string[][] {
    // 创建哈希表，key是排序后的字符串，value是原始字符串数组
    const map = new Map<string, string[]>();

    // 遍历每个字符串
    for (const str of strs) {
        // 将字符串转为字符数组，排序后再拼接回字符串
        // 这个排序后的字符串作为该组字母异位词的唯一标识（key）
        const sortedStr = str.split('').sort().join('');

        // 如果map中还没有这个key，创建一个空数组
        if (!map.has(sortedStr)) {
            map.set(sortedStr, []);
        }

        // 将当前字符串添加到对应的分组中
        map.get(sortedStr)!.push(str);
    }

    // 将哈希表中的所有value（字符串数组）收集到结果数组中
    // Array.from(map.values()) 将Map的values迭代器转换为数组
    return Array.from(map.values());
}
```

---

## 代码原理详解

### 核心逻辑

1. **字符串排序作为key**：
   - `str.split('')`：将字符串拆分成字符数组，如 "eat" → ['e', 'a', 't']
   - `.sort()`：对字符数组排序，如 ['e', 'a', 't'] → ['a', 'e', 't']
   - `.join('')`：将字符数组拼接回字符串，如 ['a', 'e', 't'] → "aet"
   - 所有字母异位词排序后都会得到相同的字符串

2. **哈希表分组**：
   - Map 的 key 是排序后的字符串（异位词的标识）
   - Map 的 value 是字符串数组（该标识对应的所有异位词）
   - 使用 `map.has()` 检查 key 是否存在
   - 使用 `map.get()` 获取对应的数组并添加新元素

3. **结果收集**：
   - `map.values()` 返回一个迭代器，包含所有的字符串数组
   - `Array.from()` 将迭代器转换为真正的数组

### 设计思路

- **统一标识**：通过排序将不同顺序的字母统一成相同的形式
- **分组聚合**：利用哈希表的特性，自动将相同 key 的元素聚合在一起
- **一次遍历**：只需遍历一次字符串数组，效率高

## 运行示例

### 示例 1：`strs = ["eat","tea","tan","ate","nat","bat"]`

**完整执行过程：**

```

  - sortedStr = "eat".split('').sort().join('') = "aet"

  - sortedStr = "tea".split('').sort().join('') = "aet"

  - 添加"tan"：map.get("ant").push("tan")
  - map = {"aet" → ["eat", "tea"], "ant" → ["tan"]}

第4步：处理 "ate"

  - map中查找"aet"：存在

第5步：处理 "nat"
  - sortedStr = "nat".split('').sort().join('') = "ant"
  - map中查找"ant"：存在

第6步：处理 "bat"
```

## 优化方法（可选）

### 方法二：字符计数法

如果不想使用排序，可以用字符计数来生成 key：

```typescript
function groupAnagrams(strs: string[]): string[][] {
    const map = new Map<string, string[]>();

    for (const str of strs) {
        // 统计每个字符的出现次数
        const count = new Array(26).fill(0);
        for (const char of str) {
            count[char.charCodeAt(0) - 'a'.charCodeAt(0)]++;
        }

        // 将计数数组转换为字符串作为key
        const key = count.join('#');

        if (!map.has(key)) {
            map.set(key, []);
        }
        map.get(key)!.push(str);
    }

    return Array.from(map.values());
}
```

**优点：** 时间复杂度优化为 O(n * k)，不需要排序
**缺点：** 代码稍复杂，但对于长字符串性能更好

## 常见问题

**Q1: 为什么要用 `split('').sort().join('')` 这种写法？**
A: 因为 JavaScript/TypeScript 中字符串是不可变的，不能直接排序。需要先转为数组，排序后再转回字符串。

**Q2: `map.get(sortedStr)!` 中的 `!` 是什么意思？**
A: 这是 TypeScript 的非空断言操作符，告诉编译器这个值一定不是 undefined。因为我们在 push 之前已经用 `if (!map.has())` 确保了 key 存在。

**Q3: 如果字符串包含大写字母或特殊字符怎么办？**
A: 根据题目提示，字符串只包含小写字母。如果包含其他字符，排序法依然适用，字符计数法需要调整计数数组的大小。

**Q4: 返回结果的顺序有要求吗？**
A: 题目说明可以按任意顺序返回，所以不需要对结果进行额外排序。
