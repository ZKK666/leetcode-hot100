# 283. 移动零【简单】

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**注意**：必须在原数组上操作，不能拷贝额外的数组。尽量减少操作次数。

---

## 输入输出示例

### 示例 1
```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

### 示例 2
```
输入: nums = [0]
输出: [0]
```

### 提示
- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

---

## 解题思路（面试推荐 - 最优解）

### 方法：双指针（快慢指针）

**核心思想：**
- 使用两个指针：`slow`（慢指针）和 `fast`（快指针）
- `slow` 指向下一个非零元素应该放置的位置
- `fast` 遍历整个数组
- 当 `fast` 遇到非零元素时，将其与 `slow` 位置的元素交换，然后 `slow++`
- 遍历结束后，所有非零元素都在前面，零都在后面

**为什么使用双指针？**
- 原地操作，空间复杂度 O(1)
- 一次遍历，时间复杂度 O(n)
- 通过交换保持了非零元素的相对顺序
- 代码简洁，易于理解

**工作原理：**
```
数组: [0, 1, 0, 3, 12]
      ↑
      slow, fast

规则：
- slow指向第一个0的位置（或下一个非零元素要放的位置）
- fast向前扫描，找到非零元素就与slow交换
```

**时间复杂度：** O(n) - 只遍历一次数组
**空间复杂度：** O(1) - 只使用常数个额外变量

---

## 代码实现（TypeScript）

```typescript
/**
 Do not return anything, modify nums in-place instead.
 */
function moveZeroes(nums: number[]): void {
    // slow指针：指向下一个非零元素应该存放的位置
    // 初始为0，表示从数组开头开始放置非零元素
    let slow = 0;

    // fast指针：遍历整个数组
    for (let fast = 0; fast < nums.length; fast++) {
        // 当fast指向的元素不为0时
        if (nums[fast] !== 0) {
            // 将fast位置的非零元素与slow位置的元素交换
            // 如果slow和fast相同，交换自己没有意义，但不影响正确性
            [nums[slow], nums[fast]] = [nums[fast], nums[slow]];

            // slow指针向后移动一位，指向下一个非零元素的存放位置
            slow++;
        }
        // 如果nums[fast]为0，fast继续前进，slow不动
        // 这样slow就会一直指向第一个0的位置
    }
}
```

## 代码原理详解

### 核心逻辑

1. **双指针设计**：
   - `slow`：慢指针，维护一个不变式——`[0, slow)` 区间内都是非零元素
   - `fast`：快指针，负责扫描整个数组

2. **交换策略**：
   - 当 `nums[fast] !== 0` 时，说明找到了一个非零元素
   - 将其交换到 `slow` 位置，确保非零元素都在前面
   - 交换后 `slow++`，为下一个非零元素腾出位置

3. **为什么能保持相对顺序？**
   - 因为我们是按顺序扫描的，先遇到的非零元素先放到前面
   - slow 指针单调递增，不会破坏已经放置好的元素顺序

4. **为什么零会自动移到后面？**
   - 所有非零元素都被交换到前面后
   - 原来非零元素的位置自然被交换成了零
   - 不需要额外操作

### 设计思路

- **区间不变式**：维护 `[0, slow)` 区间内都是非零元素
- **一次遍历**：fast 指针从头到尾扫描一次
- **原地交换**：不使用额外空间
- **优雅简洁**：逻辑清晰，代码量少

## 运行示例

### 示例 1：`nums = [0, 1, 0, 3, 12]`

**完整执行过程：**

```
初始状态: nums = [0, 1, 0, 3, 12]
          slow = 0

迭代1: fast = 0
  - nums[0] = 0 (是0)
  - 不进行交换，slow保持为0
  - nums = [0, 1, 0, 3, 12]
           ↑
           slow=0, fast=0

迭代2: fast = 1
  - nums[1] = 1 (非0) ✓
  - 交换 nums[slow] 和 nums[fast]
  - 交换 nums[0] 和 nums[1]: [0,1] → [1,0]
  - slow++，slow变为1
  - nums = [1, 0, 0, 3, 12]
              ↑
              slow=1, fast=1

迭代3: fast = 2
  - nums[2] = 0 (是0)
  - 不进行交换，slow保持为1
  - nums = [1, 0, 0, 3, 12]
              ↑
              slow=1, fast=2

迭代4: fast = 3
  - nums[3] = 3 (非0) ✓
  - 交换 nums[slow] 和 nums[fast]
  - 交换 nums[1] 和 nums[3]: [0,3] → [3,0]
  - slow++，slow变为2
  - nums = [1, 3, 0, 0, 12]
                 ↑
                 slow=2, fast=3

迭代5: fast = 4
  - nums[4] = 12 (非0) ✓
  - 交换 nums[slow] 和 nums[fast]
  - 交换 nums[2] 和 nums[4]: [0,12] → [12,0]
  - slow++，slow变为3
  - nums = [1, 3, 12, 0, 0]
                    ↑
                    slow=3, fast=4

遍历结束
最终结果: [1, 3, 12, 0, 0]
```

**执行表格：**

| 迭代 | fast | nums[fast] | slow | 操作 | 数组状态 |
|-----|------|-----------|------|------|---------|
| 初始 | - | - | 0 | - | [0,1,0,3,12] |
| 1 | 0 | 0 | 0 | 不交换 | [0,1,0,3,12] |
| 2 | 1 | 1 | 0 | 交换[0,1]，slow++ | [1,0,0,3,12] |
| 3 | 2 | 0 | 1 | 不交换 | [1,0,0,3,12] |
| 4 | 3 | 3 | 1 | 交换[1,3]，slow++ | [1,3,0,0,12] |
| 5 | 4 | 12 | 2 | 交换[2,4]，slow++ | [1,3,12,0,0] |

```
初始状态: nums = [0, 0, 1]
          slow = 0

迭代1: fast = 0
  - nums[0] = 0 → 不交换
  - nums = [0, 0, 1], slow = 0

  - nums[1] = 0 → 不交换
  - nums = [0, 0, 1], slow = 0

迭代3: fast = 2
```

**关键观察**：即使有连续的零，slow 会一直停在第一个零的位置，直到遇到非零元素。

## 常见问题

**Q1: 为什么当 slow == fast 时交换自己不会出错？**
A: 交换自己虽然没有实际意义，但不影响正确性。也可以加一个判断 `if (slow !== fast)` 来优化，但通常为了代码简洁不加。

**Q2: 能否先统计零的个数，然后覆盖？**
A: 可以，但需要两次遍历：第一次统计并移动非零元素，第二次填充零。双指针法只需一次遍历。

**Q3: 这个算法是稳定的吗？**
A: 是的。非零元素的相对顺序保持不变，因为我们是按照原数组顺序依次将非零元素移到前面。

**Q4: 能否从后往前遍历？**
A: 理论上可以，但会更复杂。从前往后遍历更符合直觉，代码更简洁。

## 其他解法（了解）

### 方法二：两次遍历法

```typescript
function moveZeroes(nums: number[]): void {
    let slow = 0;

    // 第一次遍历：将所有非零元素移到前面
    for (let fast = 0; fast < nums.length; fast++) {
        if (nums[fast] !== 0) {
            nums[slow] = nums[fast];
            slow++;
        }
    }

    // 第二次遍历：将剩余位置填充为0
    for (let i = slow; i < nums.length; i++) {
        nums[i] = 0;
    }
}
```

**优点**：逻辑更清晰，不涉及交换
**缺点**：需要两次遍历，常数因子更大
