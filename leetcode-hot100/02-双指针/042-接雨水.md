# 42. 接雨水【困难】

## 题目描述

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

---

### 示例 1
```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，
在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

## 解题思路（面试推荐 - 最优解）

### 方法：双指针

**核心思想：**
- 对于位置 `i`，能接的雨水量 = `min(左边最高, 右边最高) - height[i]`
- 使用两个指针 `left` 和 `right` 从两端向中间移动
- 维护 `leftMax` 和 `rightMax`，分别表示左边和右边遇到的最大高度
- **关键策略**：每次移动较矮的那一边
  - 如果 `height[left] < height[right]`，移动 `left`
  - 此时 `left` 位置能接的水由 `leftMax` 决定（因为 `rightMax >= height[right] > height[left]`）
  - 反之亦然

**为什么可以这样做？**

```
假设 height[left] < height[right]

对于 left 位置：
  - 左边最高 = leftMax（已知）
  - 右边最高 >= height[right]（未知，但一定 >= height[right]）
  - 因为 height[right] > height[left]
  - 所以 min(leftMax, 右边最高) = leftMax
  - 即：left 位置的雨水量只取决于 leftMax

结论：可以立即计算 left 位置的雨水量，无需等待右边的信息
```

**时间复杂度：** O(n) - 只遍历一次数组
**空间复杂度：** O(1) - 只使用常数个变量

## 代码实现（TypeScript）

```typescript
function trap(height: number[]): number {
    // 边界情况：数组为空或只有一个元素
    if (height.length === 0) return 0;

    // 左右指针
    let left = 0;
    let right = height.length - 1;

    // 左边和右边遇到的最大高度
    let leftMax = 0;
    let rightMax = 0;

    // 总雨水量
    let water = 0;

    // 当左右指针没有相遇时
    while (left < right) {
        // 更新左边的最大高度
        leftMax = Math.max(leftMax, height[left]);
        // 更新右边的最大高度
        rightMax = Math.max(rightMax, height[right]);

        // 移动较矮的那一边
        if (height[left] < height[right]) {
            // 左边较矮，计算left位置能接的水
            // 能接的水 = 左边最大高度 - 当前高度
            // 如果leftMax <= height[left]，差值为0或负数，但实际不会接水
            water += leftMax - height[left];
            left++;
        } else {
            // 右边较矮或相等，计算right位置能接的水
            // 能接的水 = 右边最大高度 - 当前高度
            water += rightMax - height[right];
            right--;
        }
    }

    return water;
}
```

## 代码原理详解

### 核心逻辑

1. **双指针 + 两个最大值**：
   - `left, right`：扫描指针
   - `leftMax, rightMax`：左右两侧的最大高度

2. **移动策略**：
   - 总是移动 `height[left]` 和 `height[right]` 中较小的那个
   - 移动前，先计算该位置能接的雨水
   - 移动后，更新对应的 `Max` 值

3. **雨水计算**：
   - 对于 `left` 位置：`water += leftMax - height[left]`
   - 对于 `right` 位置：`water += rightMax - height[right]`
   - 如果 `height[i] >= Max`，则 `Max - height[i] = 0`，不接水

4. **为什么不会出错？**：
   - 当我们决定计算 `left` 位置的雨水时
   - 我们知道 `height[right] > height[left]`
   - 所以右边一定存在一个不低于 `height[right]` 的柱子
   - 因此 `min(leftMax, 右边最高) = leftMax`

### 设计思路

- **贪心思想**：每次处理确定能计算的位置
- **双指针收缩**：从两端向中间移动
- **动态维护**：动态更新左右最大值

## 常见问题

**Q1: 为什么双指针法是最优的？**
A: 时间 O(n)，空间 O(1)，只遍历一次，不需要额外数组。

**Q2: 能否用动态规划？**
A: 可以，但需要 O(n) 的额外空间存储左右最大值数组。双指针法优化了空间。

**Q3: 为什么 `leftMax - height[left]` 不会是负数？**
A: 因为 `leftMax = Math.max(leftMax, height[left])`，所以 `leftMax >= height[left]`，差值 >= 0。

**Q4: 这个方法和"盛最多水的容器"有什么区别？**
A:
- 盛水容器：选两条线，计算矩形面积
- 接雨水：所有位置累加，计算不规则容器的水量

## 其他解法（了解）

### 方法二：动态规划

```typescript
function trap(height: number[]): number {
    if (height.length === 0) return 0;

    const n = height.length;
    const leftMax = new Array(n);
    const rightMax = new Array(n);

    // 计算每个位置左边的最大值
    leftMax[0] = height[0];
    for (let i = 1; i < n; i++) {
        leftMax[i] = Math.max(leftMax[i - 1], height[i]);
    }

    // 计算每个位置右边的最大值
    rightMax[n - 1] = height[n - 1];
    for (let i = n - 2; i >= 0; i--) {
        rightMax[i] = Math.max(rightMax[i + 1], height[i]);
    }

    // 计算每个位置的雨水
    let water = 0;
    for (let i = 0; i < n; i++) {
        water += Math.min(leftMax[i], rightMax[i]) - height[i];
    }

    return water;
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(n) - 需要两个辅助数组
