# 15. 三数之和【中等】

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且不重复的三元组。

**注意**：答案中不可以包含重复的三元组。

---

## 输入输出示例

### 示例 1
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
```

### 示例 2
```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。
```

### 示例 3
```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。
```

### 提示
- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

---

## 解题思路（面试推荐 - 最优解）

### 方法：排序 + 双指针

**核心思想：**
1. **先排序**：将数组从小到大排序，便于去重和使用双指针
2. **固定一个数**：遍历数组，固定第一个数 `nums[i]`
3. **双指针查找**：在 `i` 后面的区间用双指针找两个数，使三数之和为 0
   - `left = i + 1`（左指针）
   - `right = nums.length - 1`（右指针）
   - 如果 `nums[i] + nums[left] + nums[right] == 0`，找到一组解
   - 如果和 < 0，说明太小，`left++`
   - 如果和 > 0，说明太大，`right--`
4. **去重处理**：
   - 跳过相同的 `nums[i]`
   - 跳过相同的 `nums[left]` 和 `nums[right]`

**为什么要排序？**
- 排序后可以使用双指针
- 便于跳过重复元素
- 可以提前终止（如果 `nums[i] > 0`，后面都是正数，不可能和为 0）

**时间复杂度：** O(n²)
- 排序：O(n log n)
- 外层循环：O(n)
- 内层双指针：O(n)
- 总计：O(n log n + n²) = O(n²)

**空间复杂度：** O(log n) - 排序的栈空间（不计结果数组）

## 代码实现（TypeScript）

```typescript
function threeSum(nums: number[]): number[][] {
    const result: number[][] = [];
    const n = nums.length;

    // 如果数组长度小于3，无法组成三元组
    if (n < 3) return result;

    // 第一步：排序数组
    nums.sort((a, b) => a - b);

    // 第二步：遍历数组，固定第一个数
    for (let i = 0; i < n - 2; i++) {
        // 优化1：如果当前数字大于0，后面都是正数，不可能和为0
        if (nums[i] > 0) break;

        // 去重：跳过相同的nums[i]，避免重复的三元组
        // 注意：i > 0 而不是 i > 1，因为第一个元素不需要去重
        if (i > 0 && nums[i] === nums[i - 1]) {
            continue;
        }

        // 第三步：使用双指针在 [i+1, n-1] 区间查找两个数
        let left = i + 1;
        let right = n - 1;

        while (left < right) {
            const sum = nums[i] + nums[left] + nums[right];

            if (sum === 0) {
                // 找到一组解，添加到结果中
                result.push([nums[i], nums[left], nums[right]]);

                // 去重：跳过所有重复的left
                while (left < right && nums[left] === nums[left + 1]) {
                    left++;
                }
                // 去重：跳过所有重复的right
                while (left < right && nums[right] === nums[right - 1]) {
                    right--;
                }

                // 移动双指针，继续查找下一组解
                left++;
                right--;
            } else if (sum < 0) {
                // 和太小，左指针右移，增大和
                left++;
            } else {
                // 和太大，右指针左移，减小和
                right--;
            }
        }
    }

    return result;
}
```

## 代码原理详解

### 核心逻辑

1. **排序的作用**：
   - 使数组有序，可以使用双指针
   - 相同的元素会相邻，便于去重
   - 可以进行剪枝优化

2. **三层逻辑**：
   - 外层循环：固定第一个数 `nums[i]`
   - 双指针：在剩余区间查找另外两个数
   - 去重：在三个层面都需要去重

3. **去重策略**：
   - **第一个数去重**：`if (i > 0 && nums[i] === nums[i-1]) continue`
   - **第二个数去重**：找到解后，跳过所有相同的 `nums[left]`
   - **第三个数去重**：找到解后，跳过所有相同的 `nums[right]`

4. **双指针移动规则**：
   - `sum == 0`：找到解，记录后继续查找
   - `sum < 0`：和太小，需要更大的数，`left++`
   - `sum > 0`：和太大，需要更小的数，`right--`

### 设计思路

- **降维思想**：将三数之和转化为「固定一个数 + 两数之和」
- **排序优化**：排序后可以使用双指针，避免哈希表的空间开销
- **去重技巧**：通过跳过相同元素避免重复解

## 运行示例

### 示例 1：`nums = [-1, 0, 1, 2, -1, -4]`

**完整执行过程：**

```
第一步：排序
  原数组: [-1, 0, 1, 2, -1, -4]
  排序后: [-4, -1, -1, 0, 1, 2]
  索引:     0   1   2  3  4  5

第二步：遍历数组

----- i = 0, nums[0] = -4 -----
  left = 1, right = 5

  迭代1: sum = -4 + (-1) + 2 = -3 < 0 → left++ → left=2
  迭代2: sum = -4 + (-1) + 2 = -3 < 0 → left++ → left=3
  迭代3: sum = -4 + 0 + 2 = -2 < 0 → left++ → left=4
  迭代4: sum = -4 + 1 + 2 = -1 < 0 → left++ → left=5
  left == right，内循环结束

----- i = 1, nums[1] = -1 -----
  left = 2, right = 5

  迭代1: sum = -1 + (-1) + 2 = 0 ✓
    - 找到解: [-1, -1, 2]
    - 去重left: nums[2]=-1, nums[3]=0, 不重复，left=3
    - 去重right: nums[5]=2, nums[4]=1, 不重复，right=4
    - left++, right-- → left=3, right=4

  迭代2: sum = -1 + 0 + 1 = 0 ✓
    - 找到解: [-1, 0, 1]
    - 去重left: nums[3]=0, nums[4]=1, 不重复，left=4
    - 去重right: nums[4]=1, nums[3]=0, 不重复，right=3
    - left++, right-- → left=4, right=3

  left > right，内循环结束

----- i = 2, nums[2] = -1 -----
  发现 nums[2] == nums[1]，跳过（去重）

----- i = 3, nums[3] = 0 -----
  left = 4, right = 5

  迭代1: sum = 0 + 1 + 2 = 3 > 0 → right-- → right=4
  left == right，内循环结束

----- i = 4 -----
  i = n - 2 = 4，循环结束

最终结果: [[-1, -1, 2], [-1, 0, 1]]
```

**执行表格（关键步骤）：**

| i | nums[i] | left | right | nums[left] | nums[right] | sum | 操作 | 结果 |
|---|---------|------|-------|------------|-------------|-----|------|------|
| 0 | -4 | 1-5 | - | - | - | - | 无解 | - |
| 1 | -1 | 2 | 5 | -1 | 2 | 0 | 找到解 | [-1,-1,2] |
| 1 | -1 | 3 | 4 | 0 | 1 | 0 | 找到解 | [-1,0,1] |
| 2 | -1 | - | - | - | - | - | 跳过(重复) | - |
| 3 | 0 | 4-5 | - | - | - | >0 | 无解 | - |

## 去重详解

### 为什么需要去重？

```
例如 nums = [-1, -1, 2]
如果不去重：
  - i=0: 找到 [-1, -1, 2]
  - i=1: 又找到 [-1, -1, 2] (重复!)
```

### 三个层面的去重

1. **第一个数去重（外层循环）**：
```typescript
if (i > 0 && nums[i] === nums[i - 1]) {
    continue;  // 跳过相同的第一个数
}
```

2. **第二个数去重（找到解后）**：
```typescript
while (left < right && nums[left] === nums[left + 1]) {
    left++;  // 跳过所有相同的left
}
```

3. **第三个数去重（找到解后）**：
```typescript
while (left < right && nums[right] === nums[right - 1]) {
    right--;  // 跳过所有相同的right
}
```

### 为什么是 `i > 0` 而不是 `i > 1`？

```
因为第一个元素(i=0)不需要与前面的元素比较
从第二个元素(i=1)开始，才需要判断是否与前一个相同
```

## 常见问题

**Q1: 为什么要先排序？不排序能做吗？**
A: 不排序很难做。排序的好处：① 可以使用双指针 ② 便于去重 ③ 可以剪枝优化。

**Q2: 能否用哈希表做？**
A: 可以，但去重很麻烦，需要用 Set 来存储结果，性能不如排序+双指针。

**Q3: 为什么找到解后要同时移动 left 和 right？**
A: 因为数组已排序，如果只移动一个指针，和一定会变大或变小，不可能再等于 0。

**Q4: 时间复杂度真的是 O(n²) 吗？**
A: 是的。外层循环 O(n)，内层双指针 O(n)，总计 O(n²)。排序 O(n log n) 在 O(n²) 面前可以忽略。
