# 207. 课程表【中等】

## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi`。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0`，你需要先完成课程 `1`。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

---

## 输入输出示例

### 示例 1
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0。这是可能的。
```

### 示例 2
```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，需要先完成课程 0；
     并且学习课程 0 之前，还应先完成课程 1。这是不可能的。
```

### 提示
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有课程对 **互不相同**

## 解题思路（面试推荐 - 最优解）

### 核心思想

**问题本质：**
```
拓扑排序 / 有向图环检测

关键理解：
- 课程 = 图的节点
- 先修关系 = 有向边
- [a, b] 表示：b → a（先学b，再学a）

能否完成所有课程 ⟺ 图中是否有环

有环：无法完成（循环依赖）
无环：可以完成（存在拓扑排序）
```

**什么是拓扑排序？**
```
拓扑排序：
- 有向无环图(DAG)的线性排序
- 每条边 u→v，u在v前面

例如：
课程关系：1→0, 2→0, 2→1
拓扑排序：[2, 1, 0] 或 [2, 0, 1]（可能有多个）

有环：
课程关系：0→1, 1→0
无法排序（循环依赖）
```

---

### 方法一：BFS + 入度（推荐）

**核心思想：**
- 每次选择入度为0的课程（没有前置要求）
- 学完后，将依赖它的课程入度-1
- 如果能学完所有课程，说明无环

**算法流程：**

1. **构建图和入度数组：**
   - graph[i]：学完课程i后可以学的课程
   - inDegree[i]：课程i的前置课程数量

2. **将所有入度为0的课程加入队列**

3. **BFS处理：**
   - 取出课程，学习数量+1
   - 将后续课程的入度-1
   - 如果入度变为0，加入队列

4. **判断：学习数量 == 总课程数？**

**为什么用入度？**
```
入度 = 前置课程数量

入度为0 = 没有前置要求 = 可以直接学

学完课程后：
- 后续课程的前置要求减少
- 入度-1
```

**时间复杂度：** O(V+E) - V是课程数，E是依赖关系数
**空间复杂度：** O(V+E) - 图的存储

---

### 方法二：DFS + 三色标记

**核心思想：**
- 使用DFS遍历图
- 三种状态标记节点
- 检测是否有环

**三色标记：**
```
0（白色）：未访问
1（灰色）：正在访问（在当前DFS路径中）
2（黑色）：已访问完成

检测环：
如果遇到灰色节点 → 有环
```

**算法流程：**
1. 构建邻接表
2. 对每个未访问节点进行DFS
3. DFS中：
   - 标记为灰色
   - 递归访问邻居
   - 如果遇到灰色节点，有环
   - 标记为黑色

**时间复杂度：** O(V+E)
**空间复杂度：** O(V+E)

## 代码实现（TypeScript）

### 方法一：BFS + 入度（推荐）

```typescript
function canFinish(numCourses: number, prerequisites: number[][]): boolean {
    // 构建图和入度数组
    const graph: number[][] = Array(numCourses).fill(0).map(() => []);
    const inDegree: number[] = Array(numCourses).fill(0);

    // 构建图：[a,b] 表示 b→a（先学b再学a）
    for (const [course, prereq] of prerequisites) {
        graph[prereq].push(course);  // prereq → course
        inDegree[course]++;          // course的入度+1
    }

    // 将所有入度为0的课程加入队列
    const queue: number[] = [];
    for (let i = 0; i < numCourses; i++) {
        if (inDegree[i] === 0) {
            queue.push(i);
        }
    }

    // BFS处理
    let learned = 0;  // 已学习的课程数

    while (queue.length > 0) {
        const course = queue.shift()!;
        learned++;  // 学习这门课程

        // 将后续课程的入度-1
        for (const nextCourse of graph[course]) {
            inDegree[nextCourse]--;

            // 如果入度变为0，可以学习了
            if (inDegree[nextCourse] === 0) {
                queue.push(nextCourse);
            }
        }
    }

    // 如果学习了所有课程，说明无环
    return learned === numCourses;
}
```

### 方法二：DFS + 三色标记

```typescript
function canFinish(numCourses: number, prerequisites: number[][]): boolean {
    // 构建邻接表
    const graph: number[][] = Array(numCourses).fill(0).map(() => []);

    for (const [course, prereq] of prerequisites) {
        graph[prereq].push(course);
    }

    // 三色标记：0-未访问，1-正在访问，2-已完成
    const visited: number[] = Array(numCourses).fill(0);

    /**
     * DFS检测环
     * @returns true表示有环，false表示无环
     */
    function hasCycle(course: number): boolean {
        if (visited[course] === 1) {
            // 正在访问中，说明有环
            return true;
        }

        if (visited[course] === 2) {
            // 已访问完成，无需再访问
            return false;
        }

        // 标记为正在访问
        visited[course] = 1;

        // 递归访问所有后续课程
        for (const nextCourse of graph[course]) {
            if (hasCycle(nextCourse)) {
                return true;
            }
        }

        // 标记为已完成
        visited[course] = 2;
        return false;
    }

    // 对每个课程进行DFS检测
    for (let i = 0; i < numCourses; i++) {
        if (visited[i] === 0) {
            if (hasCycle(i)) {
                return false;  // 发现环
            }
        }
    }

    return true;  // 无环
}
```

## 代码原理详解

### BFS方法

**1. 构建图：**
```typescript
// [a, b] 表示 b→a
graph[prereq].push(course);  // prereq学完后可以学course
inDegree[course]++;          // course需要的前置课程+1
```

**2. 初始化队列：**
```typescript
// 入度为0 = 没有前置课程 = 可以直接学
if (inDegree[i] === 0) {
    queue.push(i);
}
```

**3. BFS拓扑排序：**
```typescript
while (queue.length > 0) {
    const course = queue.shift()!;
    learned++;  // 学习这门课

    // 更新后续课程的入度
    for (const next of graph[course]) {
        inDegree[next]--;
        if (inDegree[next] === 0) {
            queue.push(next);  // 可以学习了
        }
    }
}
```

### DFS方法

**三色含义：**
```
白色(0)：未访问
灰色(1)：正在DFS路径中
黑色(2)：DFS完成

检测环：
如果遇到灰色节点 → 回到了DFS路径中的节点 → 有环
```

## 运行示例

### 示例 1：`numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]`

**图结构：**
```
0 → 1 → 3
↓       ↑
2 ------┘

拓扑排序：0 → 1 → 2 → 3 或 0 → 2 → 1 → 3
```

**BFS执行过程：**

```
初始化：
graph = {
    0: [1, 2],
    1: [3],
    2: [3],
    3: []
}
inDegree = [0, 1, 1, 2]

初始队列：[0]（入度为0）

轮1：
  取出0，learned = 1
  更新：inDegree[1] = 0, inDegree[2] = 0
  队列：[1, 2]

轮2：
  取出1，learned = 2
  更新：inDegree[3] = 1
  队列：[2]

轮3：
  取出2，learned = 3
  更新：inDegree[3] = 0
  队列：[3]

轮4：
  取出3，learned = 4
  队列：[]

learned = 4 = numCourses → true ✓
```

### 示例 2：有环

**输入：**
```
numCourses = 2
prerequisites = [[1,0],[0,1]]
```

**图结构：**
```
0 ⇄ 1（有环）
```

**BFS执行过程：**

```
初始化：
graph = {
    0: [1],
    1: [0]
}
inDegree = [1, 1]

初始队列：[]（没有入度为0的课程！）

learned = 0 ≠ numCourses → false ✗
```

**DFS执行过程：**

```
从课程0开始DFS：
visited[0] = 1（灰色）

访问后续课程1：
  visited[1] = 1（灰色）

  访问后续课程0：
    visited[0] = 1（灰色）
    发现灰色节点 → 有环！

返回 false ✗
```

## 常见问题

**Q1: 为什么[a,b]表示b→a？**
A: 题目定义：
```
[a, b] = 学习课程a需要先学b
即：b是a的前置课程
方向：b → a
```

**Q2: BFS和DFS哪个更好？**
A:
- **BFS（拓扑排序）**：更直观，易理解，推荐面试使用
- **DFS（环检测）**：代码更简洁，但三色标记不够直观

**Q3: 如何输出拓扑排序结果？**
A: BFS方法天然输出拓扑排序：
```typescript
const result: number[] = [];

while (queue.length > 0) {
    const course = queue.shift()!;
    result.push(course);  // 记录学习顺序
    // ...
}

return result;  // 拓扑排序结果
```

**Q4: 为什么DFS要三色标记？**
A: 区分不同状态：
```
只用visited（已访问/未访问）：
- 无法区分当前DFS路径中的节点
- 无法检测环

三色标记：
- 白色：未访问
- 灰色：当前DFS路径中（关键！）
- 黑色：已完成（不在当前路径）
```

**Q5: 有多个拓扑排序吗？**
A: 可能有多个：
```
例如：
0 → 1
0 → 2

两种拓扑排序：
[0, 1, 2] 或 [0, 2, 1]
```

## 复杂度分析

### 两种方法

**时间复杂度：** O(V+E)
- V = numCourses（节点数）
- E = prerequisites.length（边数）
- BFS：每个节点和边访问一次
- DFS：每个节点和边访问一次

**空间复杂度：** O(V+E)
- 邻接表：O(E)
- 入度数组/访问数组：O(V)
- 队列/递归栈：O(V)

## 总结

**关键点：**
1. 课程表问题 = 有向图环检测 = 拓扑排序
2. BFS：入度为0的节点先处理
3. DFS：三色标记检测环
4. 能学完所有课程 ⟺ 图无环

**面试建议：**
- 优先使用BFS+入度（最清晰）
- 解释拓扑排序的概念
- 画图演示有环和无环的情况
- 说明入度的含义
- 可以补充DFS方法

**易错点：**
- [a,b]的方向理解错误（b→a不是a→b）
- 忘记检查learned是否等于numCourses
- DFS忘记恢复visited（三色标记不需要恢复）
- 队列初始化：只加入入度为0的课程
- 自环的处理
